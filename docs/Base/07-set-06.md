# 集合与运算符

## 1. 介绍

### 1.1 什么是集合运算符

集合运算符是 Python 提供的一组特殊符号，用于在两个集合之间执行数学集合运算——交集、并集、差集、对称差集，以及子集、超集等关系判断。你可以把它理解为数学课上"集合论"那些符号（∩、∪、− 等）在 Python 中的直接对应。

与调用方法（如 `set.intersection()`）相比，运算符写法更简洁、更直观。例如 `A & B` 就是 `A.intersection(B)` 的运算符写法，两者功能等价，但 `A & B` 更接近数学表达习惯。

集合运算符的核心特点：

- **返回新集合**：二元运算符（`&`、`|`、`-`、`^`）不会修改原集合，而是返回一个新的集合对象
- **自动去重**：所有集合运算的结果天然不含重复元素
- **操作数必须是集合**：运算符的两侧都必须是 `set`（或 `frozenset`），不接受列表、元组等其他可迭代对象
- **支持链式运算**：`A & B & C` 可以连续运算，从左到右依次执行

### 1.2 最简示例

```python
# 两个集合
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# 交集：两个集合都有的元素
print(a & b)  # 输出：{3, 4}

# 并集：两个集合所有的元素（去重）
print(a | b)  # 输出：{1, 2, 3, 4, 5, 6}

# 差集：在 a 中但不在 b 中的元素
print(a - b)  # 输出：{1, 2}

# 对称差集：只在一个集合中出现的元素
print(a ^ b)  # 输出：{1, 2, 5, 6}
```

四个运算符的直观含义可以用下图表示：

```text
        集合 A              集合 B
      ┌─────────┐      ┌─────────┐
      │ 1  2    │      │    5  6 │
      │    ┌────┼──────┼────┐    │
      │    │ 3  │  4   │    │    │
      │    └────┼──────┼────┘    │
      └─────────┘      └─────────┘

  & 交集：{3, 4}          ← 重叠部分
  | 并集：{1,2,3,4,5,6}   ← 全部
  - 差集：{1, 2}          ← A 独有
  ^ 对称差集：{1,2,5,6}   ← 非重叠部分
```

## 2. 核心内容

### 2.1 交集运算符 &

`&` 运算符返回两个集合的交集——即同时存在于两个集合中的元素。结果是一个新的集合，包含且仅包含两个集合共有的元素。

**运算逻辑**：遍历两个集合的元素，只保留两边都有的那些。如果两个集合没有共同元素，结果就是空集 `set()`。

**基本用法**：

```python
# 场景：找出两个班级都选了的学生
class_a = {"张三", "李四", "王五", "赵六"}
class_b = {"李四", "赵六", "孙八", "周九"}

both = class_a & class_b
print(both)  # 输出：{'李四', '赵六'}
```

**运行结果**：

```text
{'李四', '赵六'}
```

`&` 运算符不会修改原集合，它产生一个全新的集合：

```python
print(class_a)  # 原集合不变：{'张三', '李四', '王五', '赵六'}
print(class_b)  # 原集合不变：{'李四', '赵六', '孙八', '周九'}
```

**链式交集**：`&` 支持连续运算，从左到右逐步缩小结果范围：

```python
class_c = {"李四", "周九", "吴十"}

# 三个集合依次取交集
result = class_a & class_b & class_c
print(result)  # 输出：{'李四'}
```

**运行结果**：

```text
{'李四'}
```

**交集为空的情况**：

```python
set_x = {1, 2, 3}
set_y = {4, 5, 6}

result = set_x & set_y
print(result)          # 输出：set()
print(len(result) == 0)  # 输出：True
```

**关键点**：

- `&` 是二元运算符，两侧必须都是集合（`set` 或 `frozenset`），传列表会报 `TypeError`
- 结果集合的元素顺序不保证与输入一致——集合本身是无序的
- 多个集合连续 `&` 运算时，等价于从左到右依次取交集

### 2.2 并集运算符 |

`|` 运算符返回两个集合的并集——即两个集合中所有元素的汇总，重复元素自动去重。结果是一个新的集合。

**运算逻辑**：将两个集合的元素合并到一起，由于集合的互异性，共有的元素只保留一份。

**基本用法**：

```python
# 场景：合并两个来源的用户标签
tags_app = {"vip", "active", "mobile_user", "new_user"}
tags_web = {"vip", "active", "web_user", "returning_user"}

all_tags = tags_app | tags_web
print(all_tags)
```

**运行结果**：

```text
{'vip', 'active', 'mobile_user', 'new_user', 'web_user', 'returning_user'}
```

注意 `"vip"` 和 `"active"` 在两个集合中都出现了，但并集结果中只保留一份——这就是集合的自动去重特性。

**链式并集**：

```python
tags_mini = {"vip", "mini_user", "trial_user"}

# 三个来源的标签全部合并
all_sources = tags_app | tags_web | tags_mini
print(all_sources)
```

**运行结果**：

```text
{'vip', 'active', 'mobile_user', 'new_user', 'web_user', 'returning_user', 'mini_user', 'trial_user'}
```

**并集的数学关系**：

并集的元素数量等于两个集合元素数量之和减去交集的元素数量：

```text
|A | B| = |A| + |B| - |A & B|
```

用代码验证：

```python
print(len(tags_app))                    # 输出：4
print(len(tags_web))                    # 输出：4
print(len(tags_app & tags_web))         # 输出：2
print(len(tags_app | tags_web))         # 输出：6
# 验证：4 + 4 - 2 = 6 ✓
```

**关键点**：

- `|` 不是位运算符在集合上下文中的含义——Python 根据操作数类型自动选择对应的行为。当操作数是集合时，`|` 就是并集运算
- 结果是一个新集合，原集合不受影响
- 链式 `|` 运算时，结果集合逐渐增大

### 2.3 差集运算符 -

`-` 运算符返回差集——即只在左侧集合中出现、不在右侧集合中出现的元素。结果是一个新的集合。

**运算逻辑**：从左侧集合中剔除所有也存在于右侧集合的元素，保留左侧独有的部分。

**基本用法**：

```python
# 场景：购物车中尚未下单的商品
cart = {"鼠标", "键盘", "显示器", "耳机", "摄像头"}
ordered = {"键盘", "显示器"}

not_ordered = cart - ordered
print(not_ordered)
```

**运行结果**：

```text
{'鼠标', '耳机', '摄像头'}
```

**差集不具有交换性**：`A - B` 和 `B - A` 的结果通常不同：

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a - b)  # 输出：{1, 2}    ← a 独有的元素
print(b - a)  # 输出：{5, 6}    ← b 独有的元素
```

**运行结果**：

```text
{1, 2}
{5, 6}
```

**连续差集运算**：可以从一个集合中依次剔除多个集合的元素：

```python
full_menu = {"红烧肉", "糖醋排骨", "宫保鸡丁", "麻婆豆腐", "鱼香肉丝", "回锅肉"}
sold_out = {"糖醋排骨", "宫保鸡丁"}
allergic = {"麻婆豆腐"}

# 先去掉已售罄的，再去掉过敏的
available = full_menu - sold_out - allergic
print(available)
```

**运行结果**：

```text
{'红烧肉', '鱼香肉丝', '回锅肉'}
```

**差集为空的情况**：当左侧集合是右侧集合的子集时，差集为空：

```python
subset = {1, 2}
superset = {1, 2, 3, 4, 5}

result = subset - superset
print(result)  # 输出：set()
```

**关键点**：

- `-` 运算符有方向性，`A - B` 和 `B - A` 通常不一样
- 连续 `A - B - C` 等价于 `(A - B) - C`，即从 A 中先剔除 B 的元素，再从剩余中剔除 C 的元素
- 如果左侧集合完全包含在右侧集合中，差集为空集

### 2.4 对称差集运算符 ^

`^` 运算符返回对称差集——即只在一个集合中出现的元素，不包含两个集合共有的元素。换句话说，对称差集就是"非重叠部分"。

**运算逻辑**：`(A | B) - (A & B)` ——先取并集，再剔除交集部分。等价于"两个集合的并集减去两个集合的交集"。

**基本用法**：

```python
# 场景：两个团队各自的技能栈，找出只在一个团队中拥有的独占技能
team_backend = {"Python", "Docker", "PostgreSQL", "Redis", "Linux"}
team_frontend = {"JavaScript", "Docker", "React", "Vue", "Linux"}

unique_skills = team_backend ^ team_frontend
print(unique_skills)
```

**运行结果**：

```text
{'Python', 'PostgreSQL', 'Redis', 'JavaScript', 'React', 'Vue'}
```

注意 `Docker` 和 `Linux` 不在结果中——因为两个团队都有这两个技能。

**用公式验证对称差集的定义**：

```python
union_set = team_backend | team_frontend
intersect_set = team_backend & team_frontend
formula_result = union_set - intersect_set

print(formula_result == unique_skills)  # 输出：True
```

**对称差集具有交换性**：`A ^ B` 和 `B ^ A` 的结果相同：

```python
print(team_backend ^ team_frontend == team_frontend ^ team_backend)  # 输出：True
```

**用图解理解对称差集**：

```text
           集合 A                    集合 B
      ┌──────────────┐         ┌──────────────┐
      │   Python     │         │  JavaScript  │
      │  PostgreSQL  │         │     React    │
      │    Redis     │         │     Vue      │
      │    Docker  ──┼─────────┼── Docker     │  ← 重叠部分被排除
      │    Linux   ──┼─────────┼── Linux      │  ← 重叠部分被排除
      └──────────────┘         └──────────────┘

  ^ 对称差集 = {Python, PostgreSQL, Redis, JavaScript, React, Vue}
               ← 只在一边出现的元素，共有的 Docker 和 Linux 被排除
```

**关键点**：

- `^` 与 `&` 是互补的：`&` 取共有部分，`^` 取非共有部分
- 对称差集满足交换律：`A ^ B == B ^ A`
- 对称差集不满足结合律的直觉：`A ^ B ^ C` 的结果是"出现奇数次的元素"，在实际使用中需要注意

### 2.5 子集与超集运算符

Python 为集合的包含关系判断提供了四个运算符：`<=`、`<`、`>=`、`>`。它们返回布尔值，不产生新集合。

#### 2.5.1 子集运算符 <=（包含或等于）

`<=` 判断左侧集合是否是右侧集合的子集——即左侧的每一个元素都在右侧集合中。如果两个集合相等，`<=` 也返回 `True`。

```python
all_permissions = {"read", "write", "delete", "create", "admin"}
user_permissions = {"read", "write"}

print(user_permissions <= all_permissions)  # 输出：True
```

#### 2.5.2 真子集运算符 <（严格包含）

`<` 判断左侧集合是否是右侧集合的**真子集**——左侧的每个元素都在右侧中，且两个集合不相等。

```python
print(user_permissions < all_permissions)  # 输出：True（user 是 all 的真子集）

# 当两个集合相等时：< 返回 False
admin_permissions = {"read", "write", "delete", "create", "admin"}
print(admin_permissions < all_permissions)  # 输出：False（两者相等，不是真子集）
print(admin_permissions <= all_permissions)  # 输出：True（相等也算子集）
```

#### 2.5.3 超集运算符 >=（包含或等于）

`>=` 判断左侧集合是否是右侧集合的超集——即右侧的每个元素都在左侧集合中。这是 `<=` 的反向判断。

```python
print(all_permissions >= user_permissions)  # 输出：True（all 包含 user 的所有权限）
```

#### 2.5.4 真超集运算符 >（严格包含）

`>` 判断左侧集合是否是右侧集合的**真超集**——右侧的每个元素都在左侧中，且两个集合不相等。

```python
print(all_permissions > user_permissions)      # 输出：True
print(all_permissions > admin_permissions)      # 输出：False（两者相等）
```

**`<=` 与 `<`、`>=` 与 `>` 的区别一览**：

```text
  集合 A = {1, 2}          集合 B = {1, 2, 3}
  ┌─────────┐              ┌───────────────┐
  │  1   2  │     ⊆        │  1   2   3    │
  └─────────┘              └───────────────┘

  A <= B → True     （A 是 B 的子集）
  A <  B → True     （A 是 B 的真子集，A ≠ B）
  B >= A → True     （B 是 A 的超集）
  B >  A → True     （B 是 A 的真超集，B ≠ A）

  当 A == B 时：
  A <= B → True     （相等也算子集）
  A <  B → False    （相等不是真子集）
```

**链式比较**：`<=` 和 `<` 支持链式写法，一次判断多个集合之间的层层包含关系：

```python
group_a = {1, 2}
group_b = {1, 2, 3}
group_c = {1, 2, 3, 4}

print(group_a <= group_b <= group_c)  # 输出：True
print(group_a < group_b < group_c)    # 输出：True
```

**关键点**：

- `<=` 等价于 `set.issubset()` 方法，`>=` 等价于 `set.issuperset()` 方法
- `<=` 包含"相等"的情况，`<` 不包含——这是两者唯一的区别
- 链式比较 `A <= B <= C` 从左到右依次判断，等价于 `A <= B and B <= C`

### 2.6 集合相等比较运算符 == 和 !=

`==` 判断两个集合包含的元素是否完全相同，`!=` 判断两个集合的元素是否不完全相同。由于集合是无序的，比较时只看元素内容，不看排列顺序。

**基本用法**：

```python
config_v1 = {"host", "port", "debug", "timeout"}
config_v2 = {"host", "port", "debug", "timeout"}
config_v3 = {"host", "port", "debug", "log"}

print(config_v1 == config_v2)  # 输出：True（元素完全相同）
print(config_v1 == config_v3)  # 输出：False（config_v3 没有 timeout，多了 log）
print(config_v1 != config_v3)  # 输出：True
```

**顺序不影响比较结果**：

```python
set_a = {1, 2, 3}
set_b = {3, 2, 1}
set_c = {2, 1, 3}

print(set_a == set_b)  # 输出：True
print(set_a == set_c)  # 输出：True
```

**比较运算符与子集运算符的关系**：

```python
small = {1, 2}
large = {1, 2, 3, 4}

print(small == large)  # 输出：False
print(small < large)   # 输出：True
print(small <= large)  # 输出：True
```

如果 `A == B` 为 `True`，那么 `A <= B` 和 `B <= A` 也都为 `True`。反过来，如果 `A <= B` 和 `B <= A` 同时为 `True`，则 `A == B` 为 `True`。这说明"集合相等"和"互为子集"是等价的。

**in 运算符**：虽然不是集合间的运算符，但 `in` 和 `not in` 在集合操作中非常常用——判断元素是否属于某个集合：

```python
fruits = {"apple", "banana", "cherry"}

print("apple" in fruits)         # 输出：True
print("grape" in fruits)         # 输出：False
print("grape" not in fruits)     # 输出：True
```

### 2.7 复合赋值运算符

Python 为集合的二元运算符提供了对应的复合赋值形式：`&=`、`|=`、`-=`、`^=`。它们将运算结果赋值回左侧变量，**会修改原集合**（in-place 修改）。

**与普通运算符的核心区别**：

| 运算符 | 语法 | 是否修改原集合 | 返回值 |
|--------|------|--------------|--------|
| `&` | `A = A & B` | 否（产生新集合） | 新集合 |
| `&=` | `A &= B` | 是（原地修改） | None |
| `|` | `A = A | B` | 否（产生新集合） | 新集合 |
| `|=` | `A |= B` | 是（原地修改） | None |
| `-` | `A = A - B` | 否（产生新集合） | 新集合 |
| `-=` | `A -= B` | 是（原地修改） | None |
| `^` | `A = A ^ B` | 否（产生新集合） | 新集合 |
| `^=` | `A ^= B` | 是（原地修改） | None |

**&= 交集赋值**：

```python
# 场景：筛选出同时在线且活跃的用户
online_users = {"张三", "李四", "王五"}
active_users = {"李四", "王五", "赵六"}

online_users &= active_users
print(online_users)  # 输出：{'李四', '王五'}
```

**|= 并集赋值**：

```python
# 场景：新用户上线，加入在线列表
online_users = {"李四", "王五"}
online_users |= {"张三", "钱七"}
print(online_users)  # 输出：{'李四', '王五', '张三', '钱七'}
```

**-= 差集赋值**：

```python
# 场景：用户下线，从在线列表中移除
online_users -= {"李四"}
print(online_users)  # 输出：{'王五', '张三', '钱七'}
```

**^= 对称差集赋值**：

```python
# 场景：切换一组用户的状态
online_users ^= {"王五", "孙八"}
print(online_users)  # 王五从在线变离线，孙八从离线变在线
```

**普通运算符 vs 复合赋值运算符的行为差异**：

```python
# 普通运算符：产生新集合，原集合不变
set_a = {1, 2, 3, 4, 5}
new_set = set_a & {3, 4, 5, 6}
print(set_a)     # 输出：{1, 2, 3, 4, 5}  ← 原集合不变
print(new_set)   # 输出：{3, 4, 5}

# 复合赋值运算符：直接修改原集合
set_b = {1, 2, 3, 4, 5}
set_b &= {3, 4, 5, 6}
print(set_b)     # 输出：{3, 4, 5}  ← 原集合被修改
```

**frozenset 不支持复合赋值运算符**：因为 `frozenset` 是不可变集合，任何修改操作都会报错：

```python
fs = frozenset({1, 2, 3})
# fs &= {2, 3}  # 报错：AttributeError
```

**关键点**：

- 复合赋值运算符修改的是左侧变量绑定的集合对象本身，而不是创建新集合
- 这在需要频繁更新同一个集合的场景中更高效——避免了反复创建新对象的内存开销
- 如果你不希望原集合被修改，请使用普通运算符（`&`、`|`、`-`、`^`）

### 2.8 集合运算符速查表

| 运算符 | 名称 | 语法 | 等价方法 | 返回值 | 修改原集合 |
|--------|------|------|---------|--------|-----------|
| `&` | 交集 | `A & B` | `A.intersection(B)` | 新集合 | 否 |
| `|` | 并集 | `A | B` | `A.union(B)` | 新集合 | 否 |
| `-` | 差集 | `A - B` | `A.difference(B)` | 新集合 | 否 |
| `^` | 对称差集 | `A ^ B` | `A.symmetric_difference(B)` | 新集合 | 否 |
| `<=` | 子集判断 | `A <= B` | `A.issubset(B)` | `bool` | 否 |
| `<` | 真子集判断 | `A < B` | 无直接等价方法 | `bool` | 否 |
| `>=` | 超集判断 | `A >= B` | `A.issuperset(B)` | `bool` | 否 |
| `>` | 真超集判断 | `A > B` | 无直接等价方法 | `bool` | 否 |
| `==` | 相等判断 | `A == B` | 无 | `bool` | 否 |
| `!=` | 不等判断 | `A != B` | 无 | `bool` | 否 |
| `&=` | 交集赋值 | `A &= B` | `A.intersection_update(B)` | None | 是 |
| `|=` | 并集赋值 | `A |= B` | `A.update(B)` | None | 是 |
| `-=` | 差集赋值 | `A -= B` | `A.difference_update(B)` | None | 是 |
| `^=` | 对称差集赋值 | `A ^= B` | `A.symmetric_difference_update(B)` | None | 是 |

## 3. 最佳实践

### 3.1 运算符 vs 方法：选哪个

集合运算符和对应的方法在功能上等价，但在实际使用中有几个关键差异，需要根据场景选择。

**差异一：操作数类型要求**

运算符只接受集合类型（`set`、`frozenset`），传入列表、元组等可迭代对象会报 `TypeError`。方法则接受任意可迭代对象。

```python
a = {1, 2, 3, 4, 5}
b_list = [4, 5, 6, 7, 8]

# 方法可以接受列表
print(a.intersection(b_list))  # 输出：{4, 5}

# 运算符不接受列表
# print(a & b_list)  # 报错：TypeError: unsupported operand type(s) for &: 'set' and 'list'
```

**差异二：多参数支持**

方法可以一次接受多个参数，运算符需要链式调用。

```python
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}
c = {5, 6, 9, 10}

# 方法：一次传多个参数
result_method = a.intersection(b, c)

# 运算符：链式调用
result_operator = a & b & c

print(result_method == result_operator)  # 输出：True
```

**差异三：可读性**

运算符写法更简洁、更接近数学表达，适合两个集合之间的简单运算。方法写法语义更明确，适合复杂的多参数场景或需要接受非集合类型的场景。

**推荐选择**：

| 场景 | 推荐 | 原因 |
|------|------|------|
| 两个集合的简单运算 | 运算符 | 写法简洁，接近数学表达 |
| 需要与非集合可迭代对象运算 | 方法 | 运算符不支持非集合类型 |
| 一次与多个可迭代对象运算 | 方法 | 方法支持多参数，不用链式 |
| 代码需要面向非技术读者 | 方法 | 方法名语义更直白 |

### 3.2 推荐 vs 不推荐写法对比

**推荐：用 `&` 取交集而不是用循环过滤**

```python
# 推荐：直接用运算符
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}
result = a & b  # 简洁、高效

# 不推荐：用循环手动过滤
result = set()
for item in a:
    if item in b:
        result.add(item)
```

运算符写法不仅更简洁，底层还经过 C 语言优化，性能远超手动循环。

**推荐：注意差集的方向性**

```python
# 推荐：明确注释差集方向
cart = {"鼠标", "键盘", "显示器", "耳机"}
ordered = {"键盘", "显示器"}
not_ordered = cart - ordered  # 购物车中尚未下单的商品

# 不推荐：方向搞反，语义错误
wrong = ordered - cart  # 这是"已下单但不在购物车中的"——语义完全不同
```

**推荐：需要保留原集合时用普通运算符**

```python
# 推荐：需要保留原集合时用普通运算符
original = {1, 2, 3, 4, 5}
filtered = original & {3, 4, 5, 6}
# original 仍然是 {1, 2, 3, 4, 5}

# 不推荐：不小心用了复合赋值，原集合被修改
original = {1, 2, 3, 4, 5}
original &= {3, 4, 5, 6}
# original 变成了 {3, 4, 5}——如果后续还需要原数据就出问题了
```

**推荐：用 `<=` 做子集判断而不是手动遍历**

```python
# 推荐：用运算符
required = {"read", "write"}
user_perms = {"read", "write", "delete"}
has_required = required <= user_perms  # True

# 不推荐：手动遍历
has_required = all(perm in user_perms for perm in required)
```

### 3.3 常见错误模式

**错误一：对非集合类型使用运算符**

```python
a = {1, 2, 3}
b = [3, 4, 5]

# TypeError: unsupported operand type(s) for &: 'set' and 'list'
# result = a & b

# 修正：先将列表转为集合，或使用方法
result = a & set(b)           # 转换后用运算符
result = a.intersection(b)    # 直接用方法
```

**错误二：混淆 `<` 和 `<=`**

```python
a = {1, 2, 3}
b = {1, 2, 3}

print(a <= b)  # True（相等也算子集）
print(a < b)   # False（相等不是真子集）

# 如果你想判断"a 是否被 b 包含（包括相等的情况）"，用 <=
# 如果你只想判断"a 是否是 b 的真子集（严格小于）"，用 <
```

**错误三：以为 `^` 运算符是乘方**

```python
a = {1, 2, 3}
b = {3, 4, 5}

# 在集合上下文中，^ 是对称差集，不是乘方
print(a ^ b)  # 输出：{1, 2, 4, 5}（对称差集）

# 乘方是 **，与集合无关
# a ** b 会报错
```

**错误四：在循环中频繁用普通运算符产生大量临时集合**

```python
# 不推荐：每次循环都创建新集合
result = set()
for item in data:
    result = result | {item}  # 每次都创建新集合

# 推荐：用 |= 复合赋值，原地修改
result = set()
for item in data:
    result |= {item}  # 原地添加，更高效

# 更推荐：直接用 update 或 add
result = set()
for item in data:
    result.add(item)
```

## 4. 原理：运算符的底层机制

### 4.1 运算符重载与特殊方法

Python 的集合运算符背后是通过**运算符重载**（operator overloading）实现的。每个运算符对应一个 Python 内部的特殊方法（也叫魔术方法或 dunder 方法），当你写 `A & B` 时，Python 实际上调用的是 `A.__and__(B)`。

| 运算符 | 特殊方法 | 对应的集合方法 |
|--------|---------|--------------|
| `A & B` | `A.__and__(B)` | `A.intersection(B)` |
| `A | B` | `A.__or__(B)` | `A.union(B)` |
| `A - B` | `A.__sub__(B)` | `A.difference(B)` |
| `A ^ B` | `A.__xor__(B)` | `A.symmetric_difference(B)` |
| `A &= B` | `A.__iand__(B)` | `A.intersection_update(B)` |
| `A |= B` | `A.__ior__(B)` | `A.update(B)` |
| `A -= B` | `A.__isub__(B)` | `A.difference_update(B)` |
| `A ^= B` | `A.__ixor__(B)` | `A.symmetric_difference_update(B)` |
| `A <= B` | `A.__le__(B)` | `A.issubset(B)` |
| `A < B` | `A.__lt__(B)` | 无直接等价方法 |
| `A >= B` | `A.__ge__(B)` | `A.issuperset(B)` |
| `A > B` | `A.__gt__(B)` | 无直接等价方法 |
| `A == B` | `A.__eq__(B)` | 无 |

你可以用代码验证这一点：

```python
a = {1, 2, 3}
b = {3, 4, 5}

# 运算符和特殊方法是等价的
print(a & b)              # 输出：{3}
print(a.__and__(b))       # 输出：{3}

print(a | b)              # 输出：{1, 2, 3, 4, 5}
print(a.__or__(b))        # 输出：{1, 2, 3, 4, 5}

print(a <= b)             # 输出：False
print(a.__le__(b))        # 输出：False
```

### 4.2 为什么运算符只接受集合而方法接受任意可迭代对象

这是集合运算符和方法之间最重要的设计差异。理解原因需要看 Python 的设计决策。

**运算符的设计哲学**：运算符的两侧操作数应该是对称的——`A & B` 中的 A 和 B 应该是相同类型。如果允许 `A & [1, 2, 3]`，就破坏了对称性：左侧是集合，右侧是列表，类型不一致容易引发歧义。因此 Python 规定运算符两侧必须都是集合类型。

**方法的设计哲学**：方法名（如 `intersection`）已经明确表达了"我在做集合运算"的意图，所以参数可以是任意可迭代对象——Python 会自动将可迭代对象中的元素提取出来进行运算。这让方法更灵活：

```python
a = {1, 2, 3, 4, 5}

# 方法接受列表——自动提取元素
print(a.intersection([4, 5, 6, 7, 8]))  # 输出：{4, 5}

# 方法接受元组
print(a.intersection((4, 5, 6)))        # 输出：{4, 5}

# 方法接受生成器
print(a.intersection(x for x in range(4, 10)))  # 输出：{4, 5}

# 方法接受字符串（字符串也是可迭代对象，每个字符是一个元素）
print(a.intersection("45678"))          # 输出：set()（因为 a 中没有字符元素）
```

### 4.3 复合赋值运算符的原地修改机制

普通运算符和复合赋值运算符在底层调用的特殊方法不同。普通运算符调用 `__and__` 等方法返回新集合，复合赋值运算符调用 `__iand__` 等方法原地修改集合。

```text
  普通运算符 A & B               复合赋值 A &= B
  ┌──────────────────┐          ┌──────────────────┐
  │ A.__and__(B)     │          │ A.__iand__(B)    │
  │                  │          │                  │
  │ 1. 创建新集合     │          │ 1. 直接在 A 上修改│
  │ 2. 填入交集元素   │          │ 2. 删除不在 B 中的│
  │ 3. 返回新集合     │          │    元素           │
  │ 4. A 不变        │          │ 3. 返回 None     │
  │                  │          │ 4. A 被修改      │
  └──────────────────┘          └──────────────────┘
```

用 `id()` 函数可以验证这个差异：

```python
a = {1, 2, 3, 4, 5}
original_id = id(a)

# 普通运算符：产生新对象，a 的 id 不变
a = a & {3, 4, 5, 6}
print(id(a) == original_id)  # 输出：False（a 指向了新对象）

a = {1, 2, 3, 4, 5}
original_id = id(a)

# 复合赋值运算符：原地修改，a 的 id 不变
a &= {3, 4, 5, 6}
print(id(a) == original_id)  # 输出：True（a 仍然是同一个对象，只是内容变了）
```

**为什么这很重要**：如果你有多个变量引用同一个集合对象，复合赋值运算符会影响到所有引用，而普通运算符不会：

```python
shared = {1, 2, 3, 4, 5}
ref = shared  # ref 和 shared 指向同一个集合

# 复合赋值：ref 也会被影响
shared &= {3, 4, 5}
print(ref)   # 输出：{3, 4, 5}  ← ref 看到了变化

shared = {1, 2, 3, 4, 5}
ref = shared

# 普通运算符：ref 不受影响
shared = shared & {3, 4, 5}
print(ref)   # 输出：{1, 2, 3, 4, 5}  ← ref 不变
```

## 5. 总结

本文围绕集合运算符展开，主要介绍了以下内容：

- 集合运算符是 Python 对数学集合运算的直接支持，包括 `&`（交集）、`|`（并集）、`-`（差集）、`^`（对称差集）四种二元运算符
- `<=`、`<`、`>=`、`>` 用于判断集合间的包含关系（子集、真子集、超集、真超集），`==`、`!=` 用于判断集合是否相等
- 复合赋值运算符 `&=`、`|=`、`-=`、`^=` 会原地修改集合，与普通运算符"产生新集合"的行为有本质区别
- `&` 满足交换律（`A & B == B & A`），`-` 不满足交换律（`A - B ≠ B - A`），`^` 满足交换律
- 运算符只接受集合类型作为操作数，而等价的方法（如 `intersection()`）接受任意可迭代对象——这是运算符和方法最重要的使用差异
- 每个运算符背后对应一个特殊方法（如 `&` 对应 `__and__`），复合赋值运算符对应原地修改的特殊方法（如 `&=` 对应 `__iand__`）
- 在两个集合间的简单运算中推荐用运算符（写法简洁），在需要与非集合类型运算或多参数场景中推荐用方法（更灵活）
