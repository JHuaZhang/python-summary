# 列表拷贝深浅剖析

## 1. 介绍

在 Python 中，"拷贝一个列表"不是一个简单的操作——赋值不是拷贝，浅拷贝只复制外层，深拷贝才复制所有层级。理解深浅拷贝的区别，是避免"修改了副本却意外改了原列表"这类 bug 的关键。

Python 中有三种"复制"列表的方式：**赋值**（创建引用，不是拷贝）、**浅拷贝**（复制外层，内层元素共享引用）、**深拷贝**（递归复制所有层级，完全独立）。浅拷贝有四种写法——切片 `[:]`、`list()` 函数、`list.copy()` 方法、`copy.copy()` 函数——效果完全相同。深拷贝只有一种方式——`copy.deepcopy()` 函数。

**最简示例**

赋值、浅拷贝、深拷贝的区别在一维列表中看不出来，但在嵌套列表中一目了然：

```python
import copy

original = [[1, 2], [3, 4]]

# 赋值：不拷贝，只是别名
alias = original

# 浅拷贝：复制外层，内层共享
shallow = original.copy()

# 深拷贝：复制所有层级，完全独立
deep = copy.deepcopy(original)

# 修改内层元素
shallow[0].append(99)
deep[0].append(88)

print(f"original[0]: {original[0]}")   # [1, 2, 99]  ← 浅拷贝的内层修改波及原列表
print(f"shallow[0]:  {shallow[0]}")    # [1, 2, 99]
print(f"deep[0]:     {deep[0]}")       # [1, 2, 88]  ← 深拷贝不影响原列表
```

运行结果：

```text
original[0]: [1, 2, 99]
shallow[0]:  [1, 2, 99]
deep[0]:     [1, 2, 88]
```

## 2. 核心内容

三种复制方式的对比如下：

| 方式 | 是否创建新对象 | 内层是否共享 | 适用场景 |
|------|-------------|------------|---------|
| 赋值 `a = b` | 否（同一对象） | 是（完全共享） | 需要别名 |
| 浅拷贝 `b = a.copy()` | 是（外层新对象） | 是（内层共享） | 一维列表拷贝 |
| 深拷贝 `b = deepcopy(a)` | 是（所有层级新对象） | 否（完全独立） | 嵌套列表拷贝 |

下面逐一详细讲解。

### 2.1 赋值与引用

在 Python 中，`a = b` 不是拷贝——它让 `a` 和 `b` 指向**同一个列表对象**。修改其中一个，另一个也会变化。

**赋值创建引用**

```python
original = [1, 2, 3, 4, 5]
alias = original  # 赋值：创建引用，不创建新列表
print(f"original: {original}")
print(f"alias:    {alias}")
print(f"original is alias: {original is alias}")
print(f"id(original) = {id(original)}")
print(f"id(alias)     = {id(alias)}")
```

运行结果：

```text
original: [1, 2, 3, 4, 5]
alias:    [1, 2, 3, 4, 5]
original is alias: True
id(original) = 4300245312
id(alias)     = 4300245312
```

`original is alias` 为 `True`，`id` 也相同——`original` 和 `alias` 是同一个列表对象的两个名字。

**修改 alias 后 original 也变了**

```python
alias.append(6)
print(f"alias.append(6) 后:")
print(f"  original: {original}")
print(f"  alias:    {alias}")
```

运行结果：

```text
alias.append(6) 后:
  original: [1, 2, 3, 4, 5, 6]
  alias:    [1, 2, 3, 4, 5, 6]
```

因为 `alias` 和 `original` 是同一个列表，给 `alias` 追加元素等于给 `original` 追加元素。

**函数传参也是传引用**

```python
def add_item(seq, item):
    seq.append(item)
    print(f"  函数内 seq: {seq}")

my_list = [1, 2, 3]
add_item(my_list, 4)
print(f"函数外 my_list: {my_list}")
```

运行结果：

```text
  函数内 seq: [1, 2, 3, 4]
函数外 my_list: [1, 2, 3, 4]
函数修改了传入的列表!
```

函数参数传递的是引用——函数内部的 `seq` 和外部的 `my_list` 指向同一个列表。函数内 `append` 会修改调用者的列表。如果不想让函数修改原列表，需要在调用前拷贝：

```python
add_item(my_list.copy(), 5)  # 传入副本，原列表不受影响
```

**多重赋值也是同一引用**

```python
a = b = c = [10, 20, 30]
print(f"a is b: {a is b}")
print(f"b is c: {b is c}")
a.append(40)
print(f"a.append(40) 后:")
print(f"  a: {a}")
print(f"  b: {b}")
print(f"  c: {c}")
```

运行结果：

```text
a is b: True
b is c: True
a.append(40) 后:
  a: [10, 20, 30, 40]
  b: [10, 20, 30, 40]
  c: [10, 20, 30, 40]
```

`a = b = c = [10, 20, 30]` 只创建了一个列表对象，`a`、`b`、`c` 都指向它。修改任何一个，其他全部同步变化。

### 2.2 浅拷贝的四种方式

浅拷贝创建一个新列表，把原列表的元素逐个复制到新列表中。但如果元素本身是可变对象（如子列表），新列表中的元素仍然指向原列表中相同的子列表对象——**外层独立，内层共享**。

Python 提供了四种浅拷贝方式，效果完全相同：

**方式1：切片拷贝 `[:]`**

```python
lst1 = [1, 2, 3, 4, 5]
copy1 = lst1[:]
print(f"copy1 is lst1: {copy1 is lst1}")
copy1.append(6)
print(f"copy1.append(6) 后:")
print(f"  lst1:  {lst1}")
print(f"  copy1: {copy1}")
```

运行结果：

```text
copy1 is lst1: False
copy1.append(6) 后:
  lst1:  [1, 2, 3, 4, 5]
  copy1: [1, 2, 3, 4, 5, 6]
```

`lst1[:]` 创建了一个新列表，`copy1` 和 `lst1` 是不同的对象。修改 `copy1` 不影响 `lst1`。

**方式2：`list()` 函数**

```python
lst2 = [10, 20, 30]
copy2 = list(lst2)
print(f"copy2 is lst2: {copy2 is lst2}")
```

运行结果：

```text
copy2 is lst2: False
```

`list(lst2)` 以 `lst2` 为可迭代对象，创建一个新列表，效果等同于浅拷贝。

**方式3：`list.copy()` 方法**

```python
lst3 = [100, 200, 300]
copy3 = lst3.copy()
print(f"copy3 is lst3: {copy3 is lst3}")
```

运行结果：

```text
copy3 is lst3: False
```

`lst3.copy()` 是 Python 3.3+ 新增的列表方法，语义最直观——"复制这个列表"。

**方式4：`copy.copy()` 函数**

```python
import copy

lst4 = [1, 2, 3]
copy4 = copy.copy(lst4)
print(f"copy4 is lst4: {copy4 is lst4}")
```

运行结果：

```text
copy4 is lst4: False
```

`copy.copy()` 是 `copy` 模块提供的通用浅拷贝函数，适用于所有支持 `__copy__` 方法的对象。

**四种方式效果相同**

```python
import copy

original = [1, 2, 3]
c1 = original[:]
c2 = list(original)
c3 = original.copy()
c4 = copy.copy(original)
print(f"c1 == c2 == c3 == c4: {c1 == c2 == c3 == c4}")
print(f"c1 is original: {c1 is original}")
print(f"c2 is original: {c2 is original}")
print(f"c3 is original: {c3 is original}")
print(f"c4 is original: {c4 is original}")
```

运行结果：

```text
c1 == c2 == c3 == c4: True
c1 is original: False
c2 is original: False
c3 is original: False
c4 is original: False
```

四种方式创建的拷贝值相同但都是新对象（`is` 为 `False`）。选择哪种取决于个人偏好——`lst.copy()` 语义最直观，`lst[:]` 最简洁，`copy.copy()` 最通用。

### 2.3 浅拷贝的内存模型

浅拷贝的核心特征是"外层独立，内层共享"。用嵌套列表可以清楚看到这一点：

**浅拷贝只复制外层**

```python
nested = [[1, 2], [3, 4], [5, 6]]
shallow = nested[:]
print(f"nested:  {nested}")
print(f"shallow: {shallow}")
print(f"shallow is nested: {shallow is nested}")
print(f"shallow[0] is nested[0]: {shallow[0] is nested[0]}")
```

运行结果：

```text
nested:  [[1, 2], [3, 4], [5, 6]]
shallow: [[1, 2], [3, 4], [5, 6]]
print(f"shallow is nested: False
print(f"shallow[0] is nested[0]: True
```

`shallow is nested` 为 `False`——外层列表是不同的对象。但 `shallow[0] is nested[0]` 为 `True`——内层子列表是同一个对象。

**内存模型图**

```text
浅拷贝的内存结构：

  nested ──→ [ ptr_0,  ptr_1,  ptr_2 ]    (外层列表 A)
                │        │        │
                ↓        ↓        ↓
              [1, 2]  [3, 4]  [5, 6]      (内层子列表)

  shallow ──→ [ ptr_0,  ptr_1,  ptr_2 ]    (外层列表 B，新建)
                │        │        │
                └────────┴────────┘
                    │
                    ↓
              共享同一组内层子列表!
```

浅拷贝新建了外层列表 B，但 B 中的指针和 A 中的指针指向相同的内层子列表。修改外层（如 `append`、`del`）只影响自己，修改内层（如 `shallow[0].append()`）则两个列表都受影响。

**修改外层元素不影响原列表**

```python
shallow.append([7, 8])
print(f"shallow.append([7,8]) 后:")
print(f"  nested:  {nested}")
print(f"  shallow: {shallow}")
```

运行结果：

```text
shallow.append([7,8]) 后:
  nested:  [[1, 2], [3, 4], [5, 6]]
  shallow: [[1, 2], [3, 4], [5, 6], [7, 8]]
```

`append` 修改的是外层列表——在 `shallow` 末尾加了一个新元素，`nested` 不受影响。

**修改内层元素会影响原列表**

```python
shallow[0].append(99)
print(f"shallow[0].append(99) 后:")
print(f"  nested[0]:  {nested[0]}")
print(f"  shallow[0]: {shallow[0]}")
print(f"  内层共享! nested[0] is shallow[0]: {nested[0] is shallow[0]}")
```

运行结果：

```text
shallow[0].append(99) 后:
  nested[0]:  [1, 2, 99]
  shallow[0]: [1, 2, 99]
  内层共享! nested[0] is shallow[0]: True
```

`shallow[0]` 和 `nested[0]` 是同一个子列表对象——给 `shallow[0]` 追加元素等于给 `nested[0]` 追加元素。这就是浅拷贝的陷阱。

**替换外层索引不影响原列表**

```python
nested2 = [[1, 2], [3, 4]]
shallow2 = nested2.copy()
shallow2[0] = [10, 20]  # 替换索引0的元素
print(f"shallow2[0] = [10, 20] 后:")
print(f"  nested2:  {nested2}")
print(f"  shallow2: {shallow2}")
```

运行结果：

```text
shallow2[0] = [10, 20] 后:
  nested2:  [[1, 2], [3, 4]]
  shallow2: [[10, 20], [3, 4]]
```

`shallow2[0] = [10, 20]` 是替换操作——把 `shallow2` 的索引 0 指向了一个全新的列表 `[10, 20]`，原列表 `nested2` 的索引 0 仍指向原来的 `[1, 2]`。这和 `shallow2[0].append()` 不同——后者是修改内层对象（共享），前者是替换外层指针（独立）。

### 2.4 深拷贝

深拷贝递归复制所有层级的对象——不仅外层是新的，内层也是新的，两个列表在所有层级上完全独立。

**deepcopy 基本用法**

```python
import copy

original = [1, 2, 3, 4, 5]
deep = copy.deepcopy(original)
print(f"deep is original: {deep is original}")
deep.append(6)
print(f"deep.append(6) 后:")
print(f"  original: {original}")
print(f"  deep:     {deep}")
```

运行结果：

```text
deep is original: False
deep.append(6) 后:
  original: [1, 2, 3, 4, 5]
  deep:     [1, 2, 3, 4, 5, 6]
```

对于一维列表，深拷贝和浅拷贝效果相同——因为元素是不可变对象（整数），不存在内层共享的问题。

**deepcopy 嵌套列表（彻底独立）**

```python
nested = [[1, 2], [3, 4], [5, 6]]
deep_nested = copy.deepcopy(nested)
print(f"deep_nested is nested: {deep_nested is nested}")
print(f"deep_nested[0] is nested[0]: {deep_nested[0] is nested[0]}")
```

运行结果：

```text
deep_nested is nested: False
deep_nested[0] is nested[0]: False
```

深拷贝不仅外层是新的，内层子列表也是新的——`deep_nested[0] is nested[0]` 为 `False`。

**deepcopy 修改内层不影响原列表**

```python
deep_nested[0].append(99)
print(f"deep_nested[0].append(99) 后:")
print(f"  nested[0]:       {nested[0]}")
print(f"  deep_nested[0]:  {deep_nested[0]}")
```

运行结果：

```text
deep_nested[0].append(99) 后:
  nested[0]:       [1, 2]
  deep_nested[0]:  [1, 2, 99]
```

因为内层子列表也是独立的，修改 `deep_nested[0]` 不影响 `nested[0]`——这是深拷贝与浅拷贝的根本区别。

**deepcopy 三层嵌套**

```python
cubic = [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]
deep_cubic = copy.deepcopy(cubic)
print(f"cubic[0][0] is deep_cubic[0][0]: {cubic[0][0] is deep_cubic[0][0]}")
deep_cubic[0][0].append(99)
print(f"deep_cubic[0][0].append(99) 后:")
print(f"  cubic[0][0]:      {cubic[0][0]}")
print(f"  deep_cubic[0][0]: {deep_cubic[0][0]}")
```

运行结果：

```text
cubic[0][0] is deep_cubic[0][0]: False
deep_cubic[0][0].append(99) 后:
  cubic[0][0]:      [1, 2]
  deep_cubic[0][0]: [1, 2, 99]
```

三层嵌套也完全独立——深拷贝递归到所有层级。

**deepcopy 处理循环引用**

```python
cyclic = [1, 2, 3]
cyclic.append(cyclic)  # 列表包含自己！
print(f"cyclic[3] is cyclic: {cyclic[3] is cyclic}")
deep_cyclic = copy.deepcopy(cyclic)
print(f"deep_cyclic[3] is deep_cyclic: {deep_cyclic[3] is deep_cyclic}")
print(f"deep_cyclic[3] is cyclic: {deep_cyclic[3] is cyclic}")
```

运行结果：

```text
cyclic[3] is cyclic: True
deep_cyclic[3] is deep_cyclic: True
deep_cyclic[3] is cyclic: False
```

`deepcopy` 能正确处理循环引用——它维护一个 `memo` 字典记录已拷贝的对象，遇到已拷贝过的对象时直接返回引用，不会无限递归。

**deepcopy 处理字典中的列表**

```python
data = {"names": ["Alice", "Bob"], "scores": [90, 85]}
deep_data = copy.deepcopy(data)
deep_data["names"].append("Charlie")
print(f"deep_data['names'].append('Charlie') 后:")
print(f"  data['names']:      {data['names']}")
print(f"  deep_data['names']: {deep_data['names']}")
```

运行结果：

```text
deep_data['names'].append('Charlie') 后:
  data['names']:      ['Alice', 'Bob']
  deep_data['names']: ['Alice', 'Bob', 'Charlie']
```

深拷贝不只处理列表——如果列表中嵌套了字典，字典中又嵌套了列表，`deepcopy` 会递归拷贝所有层级的所有可变对象。

### 2.5 深浅拷贝对比

**内存层次对比**

```text
浅拷贝的内存结构：               深拷贝的内存结构：

  original ──→ [ptr, ptr, ptr]     original ──→ [ptr, ptr, ptr]
                 │   │   │                           │   │   │
                 ↓   ↓   ↓                           ↓   ↓   ↓
               [1,2] [3,4] [5,6]                   [1,2] [3,4] [5,6]

  shallow  ──→ [ptr, ptr, ptr]     deep     ──→ [ptr, ptr, ptr]
                 │   │   │                           │   │   │
                 └───┴───┘                           ↓   ↓   ↓
                     │                             [1,2] [3,4] [5,6]
                     ↓                             (全部新建，独立)
               共享同一组子列表
```

浅拷贝的内层指针指向原列表的子列表（共享），深拷贝的内层指针指向新建的子列表（独立）。

**id 对比验证**

```python
import copy

original = [[1, 2], [3, 4], [5, 6]]
shallow = original.copy()
deep = copy.deepcopy(original)

print(f"original is shallow: {original is shallow}")
print(f"original is deep:     {original is deep}")
print(f"original[0] is shallow[0]: {original[0] is shallow[0]}")
print(f"original[0] is deep[0]:     {original[0] is deep[0]}")
```

运行结果：

```text
original is shallow: False
original is deep:     False
original[0] is shallow[0]: True
original[0] is deep[0]:     False
```

**修改内层元素的影响对比**

```python
shallow[0].append(99)
deep[0].append(88)
print(f"shallow[0].append(99) + deep[0].append(88) 后:")
print(f"  original[0]: {original[0]}  ← 浅拷贝的内层修改波及原列表!")
print(f"  shallow[0]:  {shallow[0]}")
print(f"  deep[0]:     {deep[0]}      ← 深拷贝的内层修改不影响原列表")
```

运行结果：

```text
shallow[0].append(99) + deep[0].append(88) 后:
  original[0]: [1, 2, 99]  ← 浅拷贝的内层修改波及原列表!
  shallow[0]:  [1, 2, 99]
  deep[0]:     [1, 2, 88]      ← 深拷贝的内层修改不影响原列表
```

**混合结构对比**

```python
complex_data = [
    {"name": "Alice", "tags": ["python", "dev"]},
    {"name": "Bob", "tags": ["java", "test"]},
]
shallow_complex = complex_data[:]
deep_complex = copy.deepcopy(complex_data)

# 修改浅拷贝内层
shallow_complex[0]["tags"].append("manager")
print(f"shallow_complex[0]['tags'].append('manager') 后:")
print(f"  complex_data[0]['tags']:       {complex_data[0]['tags']}")
print(f"  shallow_complex[0]['tags']:    {shallow_complex[0]['tags']}")
```

运行结果：

```text
shallow_complex[0]['tags'].append('manager') 后:
  complex_data[0]['tags']:       ['python', 'dev', 'manager']
  shallow_complex[0]['tags']:    ['python', 'dev', 'manager']
  浅拷贝影响了原数据!
```

```python
# 修改深拷贝内层
deep_complex[0]["tags"].append("lead")
print(f"deep_complex[0]['tags'].append('lead') 后:")
print(f"  complex_data[0]['tags']:       {complex_data[0]['tags']}")
print(f"  deep_complex[0]['tags']:       {deep_complex[0]['tags']}")
```

运行结果：

```text
deep_complex[0]['tags'].append('lead') 后:
  complex_data[0]['tags']:       ['python', 'dev', 'manager']
  deep_complex[0]['tags']:       ['python', 'dev', 'lead']
  深拷贝不影响原数据!
```

浅拷贝修改三维结构（列表→字典→列表）的内层时，原数据被波及。深拷贝修改任何层级都不影响原数据。

### 2.6 深拷贝对不可变对象的处理

`deepcopy` 不会复制不可变对象（如 `int`、`str`、`tuple`），而是直接引用——因为不可变对象不可能被修改，共享引用是安全的。

```python
import copy

# 整数
n = 42
deep_n = copy.deepcopy(n)
print(f"deepcopy(int): n is deep_n → {n is deep_n}")

# 字符串
s = "hello"
deep_s = copy.deepcopy(s)
print(f"deepcopy(str): s is deep_s → {s is deep_s}")

# 元组
tup = (1, 2, 3)
deep_tup = copy.deepcopy(tup)
print(f"deepcopy(tuple): tup is deep_tup → {tup is deep_tup}")
```

运行结果：

```text
deepcopy(int): n is deep_n → True
deepcopy(str): s is deep_s → True
deepcopy(tuple): tup is deep_tup → True
```

这三种不可变对象 `deepcopy` 后 `is` 为 `True`——共享同一个对象。这是 `deepcopy` 的优化设计：不可变对象无法被修改，拷贝它们没有意义，直接共享引用即可。

**含可变元素的元组例外**

```python
# 元组包含可变对象时，deepcopy 会拷贝可变对象
tup_with_list = (1, [2, 3], 4)
deep_tup2 = copy.deepcopy(tup_with_list)
print(f"tup_with_list is deep_tup2: {tup_with_list is deep_tup2}")
print(f"tup_with_list[1] is deep_tup2[1]: {tup_with_list[1] is deep_tup2[1]}")
deep_tup2[1].append(99)
print(f"deep_tup2[1].append(99) 后:")
print(f"  tup_with_list[1]: {tup_with_list[1]}")
print(f"  deep_tup2[1]:     {deep_tup2[1]}")
```

运行结果：

```text
tup_with_list is deep_tup2: False
tup_with_list[1] is deep_tup2[1]: False
deep_tup2[1].append(99) 后:
  tup_with_list[1]: [2, 3]
  deep_tup2[1]:     [2, 3, 99]
```

当元组中包含可变对象（如列表）时，`deepcopy` 会拷贝元组本身以及其中的可变对象——元组本身是新的，内层列表也是新的。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

| 场景 | 推荐写法 | 不推荐写法 | 原因 |
|------|---------|-----------|------|
| 一维列表拷贝 | `lst.copy()` 或 `lst[:]` | `lst = lst`（赋值） | 赋值不拷贝 |
| 嵌套列表拷贝 | `copy.deepcopy(lst)` | `lst.copy()`（浅拷贝） | 浅拷贝内层共享 |
| 初始化二维列表 | `[[] for _ in range(n)]` | `[[]] * n` | 乘法共享子列表 |
| 函数默认参数 | `def f(lst=None):` | `def f(lst=[]):` | 默认值只创建一次 |
| 函数内不修改传入列表 | 先 `copy()` 再操作 | 直接操作 | 避免副作用 |
| 只需遍历倒序 | `reversed(lst)` | `lst[::-1]` | reversed 不拷贝 |
| 浅层过滤 | `[x for x in lst if cond]` | 遍历+条件删除 | 推导式创建新列表 |

### 3.2 常见错误模式

**错误一：`[[]] * n` 创建共享引用**

```python
# 错误：n个子列表共享同一个对象
matrix_wrong = [[]] * 3
matrix_wrong[0].append(1)
print(f"[[]] * 3 后修改 [0]: {matrix_wrong}")
# [[1], [1], [1]]  ← 三个子列表都变了!

# 正确：用推导式创建独立子列表
matrix_right = [[] for _ in range(3)]
matrix_right[0].append(1)
print(f"[[] for _ in range(3)] 后修改 [0]: {matrix_right}")
# [[1], [], []]  ← 只有 [0] 变了
```

运行结果：

```text
[[]] * 3 后修改 [0]: [[1], [1], [1]]
[[] for _ in range(3)] 后修改 [0]: [[1], [], []]
```

`[[]] * 3` 把同一个空列表对象复制了 3 次——三个位置指向同一个空列表。`[[] for _ in range(3)]` 每次迭代都创建一个新的空列表——三个位置各自独立。

**错误二：函数默认参数使用可变对象**

```python
# 错误：默认参数在函数定义时创建一次，后续调用共享
def add_item_wrong(item, lst=[]):
    lst.append(item)
    return lst

print(f"add_item_wrong(1): {add_item_wrong(1)}")
print(f"add_item_wrong(2): {add_item_wrong(2)}")
# 每次调用都追加到同一个列表!

# 正确：使用 None 作为默认值
def add_item_right(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(f"add_item_right(1): {add_item_right(1)}")
print(f"add_item_right(2): {add_item_right(2)}")
# 每次调用都是独立的列表
```

运行结果：

```text
add_item_wrong(1): [1]
add_item_wrong(2): [1, 2]
  每次调用都追加到同一个列表!
add_item_right(1): [1]
add_item_right(2): [2]
  每次调用都是独立的列表
```

函数默认参数 `lst=[]` 只在函数定义时创建一次——后续每次调用共享同一个列表。标准做法是用 `None` 作为默认值，函数内部判断后创建新列表。

**错误三：列表乘法与可变对象**

```python
# 不可变元素：乘法安全
row = [0] * 3
row[0] = 1
print(f"[0] * 3 修改 [0]: {row}")
# [1, 0, 0]  ← 正常，因为 0 是不可变的

# 可变元素：乘法危险
cells = [{"count": 0}] * 3
cells[0]["count"] = 1
print(f"[{{'count':0}}] * 3 修改 [0]: {cells}")
# [{'count': 1}, {'count': 1}, {'count': 1}]  ← 所有字典都共享!
```

运行结果：

```text
[0] * 3 修改 [0]: [1, 0, 0]
[{'count':0}] * 3 修改 [0]: [{'count': 1}, {'count': 1}, {'count': 1}]
  所有字典都共享!
```

`[obj] * n` 当 `obj` 是可变对象时，`n` 个位置指向同一个对象。修改任意一个会影响所有。正确做法是用推导式：`[obj_copy for _ in range(n)]`。

**错误四：浅拷贝用于嵌套列表**

```python
# 错误：嵌套列表用浅拷贝
data = [[1, 2], [3, 4]]
copy_data = data.copy()  # 浅拷贝
copy_data[0].append(99)
print(f"data[0]: {data[0]}")  # [1, 2, 99]  ← 原数据被修改!

# 正确：嵌套列表用深拷贝
data2 = [[1, 2], [3, 4]]
deep_data2 = copy.deepcopy(data2)
deep_data2[0].append(99)
print(f"data2[0]: {data2[0]}")  # [1, 2]  ← 原数据不受影响
```

运行结果：

```text
data[0]: [1, 2, 99]
data2[0]: [1, 2]
```

**判断规则**：元素全是不可变对象（int、str、tuple 等）→ 浅拷贝足够；元素中有可变对象（list、dict、set 等）→ 需要深拷贝。

### 3.3 方法速查表

| 方式 | 语法 | 新建外层 | 新建内层 | 适用类型 | 性能 |
|------|------|---------|---------|---------|------|
| 赋值 | `a = b` | 否 | 否 | 所有 | O(1) |
| 切片 | `a = b[:]` | 是 | 否 | 序列 | O(n) |
| `list()` | `a = list(b)` | 是 | 否 | 可迭代 | O(n) |
| `list.copy()` | `a = b.copy()` | 是 | 否 | list | O(n) |
| `copy.copy()` | `a = copy.copy(b)` | 是 | 否 | 通用 | O(n) |
| `copy.deepcopy()` | `a = copy.deepcopy(b)` | 是 | 是 | 通用 | O(n*depth) |

### 3.4 性能对比

深拷贝比浅拷贝慢得多——因为需要递归遍历所有层级：

```python
import copy
import time

# 构建三层嵌套的大列表
data = [[[i * 100 + j * 10 + k for k in range(10)] for j in range(10)] for i in range(100)]

# 浅拷贝
start = time.perf_counter()
shallow = data.copy()
t_shallow = time.perf_counter() - start

# 深拷贝
start = time.perf_counter()
deep = copy.deepcopy(data)
t_deep = time.perf_counter() - start

print(f"浅拷贝: {t_shallow:.6f} 秒")
print(f"深拷贝: {t_deep:.6f} 秒")
print(f"深拷贝更慢: {t_deep / t_shallow:.1f}x")
```

运行结果：

```text
浅拷贝: 0.000026 秒
深拷贝: 0.001248 秒
深拷贝更慢: 47.5x
```

深拷贝比浅拷贝慢 47 倍——它需要递归遍历三层结构，为每个可变对象创建新对象。在不需要深拷贝的场景中，不要用 `deepcopy`。

## 4. 原理

### 4.1 Python 变量是引用

理解深浅拷贝的前提是理解 Python 的变量模型——**变量是引用（标签），不是容器**。变量不存储值，而是指向内存中的对象：

```text
Python 变量模型：

  代码: a = [1, 2, 3]

  内存中的状态:
    变量表                    堆内存
    ┌───────┐               ┌───────────────┐
    │ a ────┼──────────────→│ list [1,2,3]  │
    └───────┘               │ id: 0x1234    │
                            └───────────────┘

  代码: b = a

  内存中的状态:
    变量表                    堆内存
    ┌───────┐               ┌───────────────┐
    │ a ────┼──────────────→│ list [1,2,3]  │
    │ b ────┼──────────────→│ id: 0x1234    │
    └───────┘               └───────────────┘
    a 和 b 指向同一个 list 对象
```

赋值 `b = a` 只是让 `b` 也指向 `a` 指向的对象——没有创建新列表。这就是为什么修改 `b` 会影响 `a`。

### 4.2 浅拷贝的实现原理

浅拷贝创建一个新列表，然后把原列表中的元素引用逐个复制到新列表中：

```text
浅拷贝 copy = original[:] 的执行流程：

  原始状态:
    original ──→ [ptr→[1,2], ptr→[3,4], ptr→[5,6]]
                      ↑          ↑          ↑
                      │          │          │
                   子列表A     子列表B     子列表C

  执行 copy = original[:]:
    1. 创建新列表 new_list
    2. 遍历 original 的每个元素:
       new_list[0] = original[0]  (复制指针，指向子列表A)
       new_list[1] = original[1]  (复制指针，指向子列表B)
       new_list[2] = original[2]  (复制指针，指向子列表C)
    3. 返回 new_list

  结果:
    original ──→ [ptr→[1,2], ptr→[3,4], ptr→[5,6]]
                                ↑          ↑          ↑
                                │          │          │
    copy     ──→ [ptr→[1,2], ptr→[3,4], ptr→[5,6]]
                      ↑          ↑          ↑
                      │          │          │
                   共享子列表A  共享子列表B  共享子列表C
```

浅拷贝只复制了外层列表的指针——新旧列表的指针指向同一组内层子列表。这就是"外层独立，内层共享"的本质。

可以用代码验证：

```python
original = [[1, 2], [3, 4]]
shallow = original.copy()
# 外层不同
print(f"外层 is: {original is shallow}")
# 内层相同
print(f"内层[0] is: {original[0] is shallow[0]}")
print(f"内层[1] is: {original[1] is shallow[1]}")
```

运行结果：

```text
外层 is: False
内层[0] is: True
内层[1] is: True
```

### 4.3 深拷贝的递归与 memo 机制

深拷贝不只是复制外层——它对每个可变元素递归调用 `deepcopy`。同时，它维护一个 `memo` 字典记录已拷贝的对象，避免循环引用导致的无限递归：

```text
deepcopy 的执行流程（以 [[1,2],[3,4]] 为例）：

  1. 创建 memo = {}  ← 记录已拷贝对象

  2. deepcopy(外层列表):
     a. 创建 new_outer = []，memo[id(original)] = new_outer
     b. 遍历每个元素:
        元素 [1,2] 是列表(可变) → 递归 deepcopy([1,2])
          → 创建 new_inner1 = [1, 2]
          → memo[id([1,2])] = new_inner1
          → 返回 new_inner1
        元素 [3,4] 是列表(可变) → 递归 deepcopy([3,4])
          → 创建 new_inner2 = [3, 4]
          → memo[id([3,4])] = new_inner2
          → 返回 new_inner2
     c. new_outer = [new_inner1, new_inner2]
     d. 返回 new_outer

  结果:
    original ──→ [ptr→[1,2], ptr→[3,4]]    (旧对象)
    deep     ──→ [ptr→[1,2], ptr→[3,4]]    (全新对象)
                   ↑            ↑
                   全是新创建的子列表
```

**memo 机制处理循环引用**

```python
import copy

cyclic = [1, 2, 3]
cyclic.append(cyclic)

# deepcopy 执行:
# 1. 创建 new_list = [], memo = {}
# 2. memo[id(cyclic)] = new_list
# 3. 拷贝元素 1, 2, 3 → new_list = [1, 2, 3]
# 4. 拷贝元素 cyclic[3] = cyclic
#    → 查 memo: id(cyclic) 已在 memo 中
#    → 返回 memo[id(cyclic)] = new_list
#    → 不递归，直接引用已有拷贝
# 5. new_list = [1, 2, 3, new_list]  ← 循环引用正确处理

deep_cyclic = copy.deepcopy(cyclic)
print(f"deep_cyclic[3] is deep_cyclic: {deep_cyclic[3] is deep_cyclic}")
print(f"deep_cyclic[3] is cyclic: {deep_cyclic[3] is cyclic}")
```

运行结果：

```text
deep_cyclic[3] is deep_cyclic: True
deep_cyclic[3] is cyclic: False
```

`deepcopy` 在第 4 步发现 `id(cyclic)` 已在 `memo` 中，直接返回了已创建的 `new_list`——不会再次递归拷贝，从而避免了无限循环。`deep_cyclic` 和 `cyclic` 是两套独立的循环引用结构。

### 4.4 deepcopy 对不可变对象的优化

`deepcopy` 在遇到不可变对象时，不会创建新对象，而是直接引用原对象：

```text
deepcopy 遇到不可变对象的流程:

  deepcopy([1, "hello", (2, 3)]):
    1. 创建 new_list = []
    2. 拷贝元素 1 (int, 不可变):
       → 返回原对象 1（不创建新整数）
       → new_list.append(1)
    3. 拷贝元素 "hello" (str, 不可变):
       → 返回原对象 "hello"（不创建新字符串）
       → new_list.append("hello")
    4. 拷贝元素 (2, 3) (tuple, 不可变):
       → 返回原对象 (2, 3)（不创建新元组）
       → new_list.append((2, 3))
    5. 返回 [1, "hello", (2, 3)]
```

这样设计的原因是：不可变对象无法被修改，共享引用不会产生任何问题。跳过拷贝可以大幅提升性能。

```python
import copy

lst = [1, "hello", (2, 3)]
deep = copy.deepcopy(lst)
print(f"1 is deep[0]: {1 is deep[0]}")
print(f"'hello' is deep[1]: {'hello' is deep[1]}")
print(f"(2,3) is deep[2]: {(2,3) is deep[2]}")
```

运行结果：

```text
1 is deep[0]: True
'hello' is deep[1]: True
(2,3) is deep[2]: True
```

但是，当元组中包含可变对象时，`deepcopy` 会拷贝元组本身和其中的可变对象：

```python
tup = (1, [2, 3])
deep_tup = copy.deepcopy(tup)
print(f"tup is deep_tup: {tup is deep_tup}")
print(f"tup[1] is deep_tup[1]: {tup[1] is deep_tup[1]}")
```

运行结果：

```text
tup is deep_tup: False
tup[1] is deep_tup[1]: False
```

因为元组中的列表是可变的，如果共享引用，修改拷贝中的列表会影响原元组。所以 `deepcopy` 创建了新的元组和新的内部列表。

## 5. 总结

本文围绕列表拷贝的深浅区别展开，系统介绍了以下内容：

- **赋值与引用**：`a = b` 不是拷贝，而是让两个变量指向同一个列表对象；修改任一个另一个也变化；函数传参也是传引用，函数内修改会影响调用者的列表
- **浅拷贝的四种方式**：切片 `[:]`、`list()` 函数、`list.copy()` 方法、`copy.copy()` 函数，效果完全相同；创建新列表但拷贝的是元素引用，不递归拷贝内层
- **浅拷贝的内存模型**：外层独立，内层共享——修改外层（append/del）不影响原列表，修改内层（`copy[0].append()`）会影响原列表；替换外层索引（`copy[0] = []`）不等同于修改内层
- **深拷贝**：`copy.deepcopy()` 递归复制所有层级的可变对象，两个列表在所有层级上完全独立；能正确处理循环引用（通过 memo 字典）和字典中的列表
- **深拷贝对不可变对象的优化**：int、str、tuple 等不可变对象不拷贝，直接共享引用（安全且高效）；但含可变元素的元组会被拷贝
- **最佳实践**：推荐 vs 不推荐写法对比、4 种常见错误模式（`[[]] * n` 共享引用、函数默认参数可变对象、列表乘法与可变对象、浅拷贝用于嵌套列表）、方法速查表、性能对比（深拷贝比浅拷贝慢数十倍）
- **原理**：Python 变量是引用不是容器、浅拷贝只复制外层指针的机制、深拷贝递归 + memo 字典处理循环引用的机制、deepcopy 对不可变对象跳过拷贝的优化设计
