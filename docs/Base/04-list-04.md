# 列表与运算符

## 1. 介绍

列表是可变序列，Python 为它定义了丰富的运算符行为。你可以用 `+` 拼接两个列表、用 `*` 重复元素、用 `==` 比较两个列表是否相等、用 `in` 判断元素是否在列表中、用 `is` 判断两个变量是否指向同一个列表对象、用 `+=` 原地扩展列表……这些运算符让列表的操作既简洁又强大。

理解列表与运算符的关系，核心在于搞清楚三个层次：**运算的结果是什么类型**（创建新列表还是原地修改）、**比较的依据是什么**（值相等还是同一对象）、**真值判断的标准是什么**（空列表为 False 还是元素为 0 就为 False）。本文会逐一讲透这些细节。

**最简示例**

用 `+` 拼接列表，用 `*` 重复列表，用 `in` 判断成员：

```python
# + 拼接
combined = [1, 2] + [3, 4]
print(combined)        # [1, 2, 3, 4]

# * 重复
zeros = [0] * 3
print(zeros)           # [0, 0, 0]

# in 成员判断
print("banana" in ["apple", "banana", "cherry"])   # True
```

运行结果：

```text
[1, 2, 3, 4]
[0, 0, 0]
True
```

## 2. 核心内容

Python 列表支持的运算符可以分为以下几大类：

| 运算符类别 | 运算符 | 说明 |
|-----------|--------|------|
| 拼接与重复 | `+` `*` | 创建新列表，不修改原列表 |
| 比较运算符 | `==` `!=` `<` `>` `<=` `>=` | 按字典序逐元素比较 |
| 成员运算符 | `in` `not in` | 判断元素是否在列表中 |
| 身份运算符 | `is` `is not` | 判断是否为同一对象 |
| 逻辑运算符 | `and` `or` `not` | 列表真值性 + 短路求值 |
| 复合赋值 | `+=` `*=` | 原地修改，不创建新列表 |

下面逐一详细讲解。

### 2.1 拼接运算符 +

`+` 将两个列表的元素合并成一个新列表。关键要点：**`+` 创建新列表，不修改原来的两个列表**。

**语法**

```python
新列表 = 列表1 + 列表2
```

两个操作数都必须是列表类型，不能和其他类型混用。`[1, 2] + 3` 会报 `TypeError`。

**基本拼接**

```python
list_a = [1, 2, 3]
list_b = [4, 5, 6]
combined = list_a + list_b

print(f"[1,2,3] + [4,5,6] = {combined}")
print(f"原 list_a 不变: {list_a}")
print(f"原 list_b 不变: {list_b}")
```

运行结果：

```text
[1,2,3] + [4,5,6] = [1, 2, 3, 4, 5, 6]
原 list_a 不变: [1, 2, 3]
原 list_b 不变: [4, 5, 6]
```

`+` 的结果是一个全新的列表对象，`list_a` 和 `list_b` 都没有被修改。

**连续拼接**

`+` 可以连续使用，把多个列表拼在一起：

```python
all_parts = [1] + [2, 3] + [4, 5, 6]
print(f"连续拼接: {all_parts}")
```

运行结果：

```text
连续拼接: [1, 2, 3, 4, 5, 6]
```

**+ 不能拼接非列表类型**

```python
# 列表不能直接和整数拼接
try:
    result = [1, 2] + 3
except TypeError as e:
    print(f"[1,2] + 3 → TypeError: {e}")
```

运行结果：

```text
[1,2] + 3 → TypeError: can only concatenate list (not "int") to list
```

如果需要在末尾追加单个元素，应该用 `list.append()` 或 `list + [element]` 的方式：

```python
# 正确：用单元素列表拼接
lst = [1, 2] + [3]
print(f"[1,2] + [3] = {lst}")

# 正确：用 append
lst2 = [1, 2]
lst2.append(3)
print(f"append 后: {lst2}")
```

运行结果：

```text
[1,2] + [3] = [1, 2, 3]
append 后: [1, 2, 3]
```

### 2.2 重复运算符 *

`*` 将列表的元素重复 n 次，生成一个新列表。和 `+` 一样，**`*` 也创建新列表，不修改原列表**。

**语法**

```python
新列表 = 列表 * n
```

`n` 是整数。`n > 0` 重复 n 次，`n == 0` 得到空列表，`n < 0` 也得到空列表。

**基本重复**

```python
# 重复单个元素列表
zeros = [0] * 5
print(f"[0] * 5  = {zeros}")

# 重复多个元素列表
pattern = [1, 2] * 3
print(f"[1,2] * 3 = {pattern}")

# 重复 0 次
empty = [1, 2] * 0
print(f"[1,2] * 0 = {empty}")
```

运行结果：

```text
[0] * 5  = [0, 0, 0, 0, 0]
[1,2] * 3 = [1, 2, 1, 2, 1, 2]
[1,2] * 0 = []
```

`[1, 2] * 3` 把 `[1, 2]` 这个整体重复 3 次，结果是 `[1, 2, 1, 2, 1, 2]`——注意不是把每个元素重复 3 次。

**+ 和 * 的组合**

```python
# 先重复再拼接
border = ["-"] * 5
content = ["A", "B", "C"]
full = border + content + border
print(f"边框+内容+边框: {full}")
```

运行结果：

```text
边框+内容+边框: ['-', '-', '-', '-', '-', 'A', 'B', 'C', '-', '-', '-', '-', '-']
```

**实际场景：初始化数据**

```python
# 生成一周的空白座位表（5个场次 x 10个座位）
seats = [["空"] * 10 for _ in range(5)]
print(f"场次1座位: {seats[0]}")
```

运行结果：

```text
场次1座位: ['空', '空', '空', '空', '空', '空', '空', '空', '空', '空']
```

注意这里用的是列表推导式 `[[空] * 10 for _ in range(5)]`，而不是 `[["空"] * 10] * 5`。后者会导致 5 行共享同一个子列表，修改一行会影响所有行——这个陷阱在讲列表创建方式时已经详细讲过。

### 2.3 比较运算符

列表支持所有比较运算符：`==` `!=` `<` `>` `<=` `>=`。比较规则是**字典序**——从左到右逐元素比较，第一个不同的元素决定结果。

#### 2.3.1 相等比较 == 和 !=

`==` 判断两个列表的元素是否完全相同（长度相同、每个位置上的元素相等）。`!=` 是 `==` 的反义。

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = [1, 2, 4]
d = [1, 2]

print(f"[1,2,3] == [1,2,3]: {a == b}")     # True，元素完全相同
print(f"[1,2,3] != [1,2,4]: {a != c}")     # True
print(f"[1,2,3] == [1,2]:   {a == d}")    # False，长度不同
```

运行结果：

```text
[1,2,3] == [1,2,3]: True
[1,2,3] != [1,2,4]: True
[1,2,3] == [1,2]:   False
```

**类型不同直接返回 False**

列表和元组即使元素相同，`==` 也返回 False，因为类型不同：

```python
print(f"[1,2] == (1,2):   {[1, 2] == (1, 2)}")   # False
print(f"[1,2] == [1,2]:   {[1, 2] == [1, 2]}")     # True
```

运行结果：

```text
[1,2] == (1,2):   False
[1,2] == [1,2]:   True
```

#### 2.3.2 大小比较 < > <= >=

列表的大小比较遵循**字典序规则**，和字符串的比较逻辑一致：

1. 从左到右逐元素比较
2. 遇到第一个不相等的元素时，根据该元素的大小关系决定结果
3. 如果所有元素都相等，则较短的列表更小

```python
print(f"[1,2,3] < [1,2,4]:  {[1,2,3] < [1,2,4]}")   # True，3 < 4
print(f"[1,2]   < [1,2,3]:  {[1,2] < [1,2,3]}")      # True，短的更小
print(f"[1,2,3] < [1,2,3]: {[1,2,3] < [1,2,3]}")   # False，相等
print(f"[1,2,3] <= [1,2,3]: {[1,2,3] <= [1,2,3]}")   # True
print(f"[2,1]   > [1,9]:   {[2,1] > [1,9]}")        # True，2 > 1
```

运行结果：

```text
[1,2,3] < [1,2,4]:  True
[1,2]   < [1,2,3]:  True
[1,2,3] < [1,2,3]: False
[1,2,3] <= [1,2,3]: True
[2,1]   > [1,9]:   True
```

**字典序比较流程**

以 `[1, 2, 3]` 和 `[1, 2, 4]` 的比较为例：

```text
比较 [1,2,3] 和 [1,2,4]:

  第1步: 比较索引0 → 1 == 1 → 相等，继续
  第2步: 比较索引1 → 2 == 2 → 相等，继续
  第3步: 比较索引2 → 3 < 4 → 确定 [1,2,3] < [1,2,4]

  结果: True
```

`[2, 1]` 和 `[1, 9]` 的比较：第一个元素 `2 > 1`，就已经确定了结果，不需要比较第二个元素。这和字符串比较完全一致——`"ba" > "az"` 因为第一个字符 `'b' > 'a'`。

**实际场景：按版本号排序**

```python
versions = [
    [3, 0, 1],
    [2, 9, 0],
    [3, 1, 0],
    [2, 8, 5],
    [3, 0, 0],
]
versions.sort()
for v in versions:
    print(f"  v{'.'.join(map(str, v))}")
```

运行结果：

```text
  v2.8.5
  v2.9.0
  v3.0.0
  v3.0.1
  v3.1.0
```

版本号 `[3, 0, 1]` 就是一个列表，列表的大小比较天然适合做版本号排序——先比大版本号，再比小版本号，依次递进。

### 2.4 成员运算符 in 和 not in

`in` 判断一个元素是否在列表中，返回 `True` 或 `False`。`not in` 是 `in` 的反义。

**语法**

```python
元素 in 列表          # True / False
元素 not in 列表       # True / False
```

**基本用法**

```python
fruits = ["apple", "banana", "cherry", "date"]

print(f"'apple' in fruits:   {'apple' in fruits}")      # True
print(f"'grape' in fruits:   {'grape' in fruits}")      # False
print(f"'grape' not in fruits: {'grape' not in fruits}")  # True
```

运行结果：

```text
'apple' in fruits:   True
'grape' in fruits:   False
'grape' not in fruits: True
```

**检查子列表**

列表的元素可以是任何对象，包括子列表。`in` 检查的是"元素"是否等于列表中的某个元素，而不是"子序列"匹配：

```python
matrix = [[1, 2], [3, 4], [5, 6]]
print(f"[1,2] in matrix: {[1, 2] in matrix}")     # True
print(f"[3,4] in matrix: {[3, 4] in matrix}")     # True
print(f"[2,1] in matrix: {[2, 1] in matrix}")     # False，顺序不同
```

运行结果：

```text
[1,2] in matrix: True
[3,4] in matrix: True
[2,1] in matrix: False
```

`[1, 2] in matrix` 为 True 是因为 `matrix` 的第一个元素就是 `[1, 2]`。`[2, 1]` 为 False 是因为 `[2, 1]` 不等于 `matrix` 中的任何一个元素——尽管它包含的数字相同，但顺序不同。

**混合类型成员检查**

```python
mixed = [1, "hello", 3.14, True, None]
print(f"1 in mixed:       {1 in mixed}")            # True
print(f"'hello' in mixed: {'hello' in mixed}")        # True
print(f"3.14 in mixed:    {3.14 in mixed}")          # True
print(f"None in mixed:    {None in mixed}")         # True
print(f"[1] in mixed:     {[1] in mixed}")           # False
```

运行结果：

```text
1 in mixed:       True
'hello' in mixed: True
3.14 in mixed:    True
None in mixed:    True
[1] in mixed:     False
```

`[1] in mixed` 为 False 是因为它检查的是"列表 `[1]` 是否是 `mixed` 的一个元素"，而不是"1 是否在 `mixed` 中"。

**实际场景：权限检查**

```python
allowed_actions = ["read", "write", "execute"]
user_action = "delete"

if user_action in allowed_actions:
    print(f"允许执行: {user_action}")
else:
    print(f"拒绝执行: {user_action}（不在允许列表中）")
```

运行结果：

```text
拒绝执行: delete（不在允许列表中）
```

**实际场景：列表去重**

```python
raw_data = [1, 3, 2, 3, 1, 4, 2, 5, 3]
seen = []
for num in raw_data:
    if num not in seen:
        seen.append(num)
print(f"原始: {raw_data}")
print(f"去重: {seen}")
```

运行结果：

```text
原始: [1, 3, 2, 3, 1, 4, 2, 5, 3]
去重: [1, 3, 2, 4, 5]
```

用 `not in` 判断元素是否已出现过，从而达到去重效果。这种做法简单直观，但在数据量大时效率不高（因为 `in` 对列表是 O(n) 的线性扫描），大数据量去重推荐用集合。

### 2.5 身份运算符 is 和 is not

`is` 判断两个变量是否指向**同一个对象**（内存地址相同），`is not` 是 `is` 的反义。`is` 和 `==` 的区别是 Python 中最重要的概念之一。

#### 2.5.1 is vs == 的核心区别

```python
a = [1, 2, 3]
b = [1, 2, 3]     # 新列表，值相同但对象不同
c = a             # 同一个引用

print(f"a == b: {a == b}    # 值相同: True")
print(f"a is b: {a is b}    # 同一对象: False")
print(f"a == c: {a == c}    # 值相同: True")
print(f"a is c: {a is c}    # 同一对象: True")
```

运行结果：

```text
a == b: True    # 值相同: True
a is b: False    # 同一对象: False
a == c: True    # 值相同: True
a is c: True    # 同一对象: True
```

`a` 和 `b` 的值相同（`==` 为 True），但它们是两个不同的列表对象（`is` 为 False）。`c = a` 让 `c` 和 `a` 指向同一个对象（`is` 为 True）。

**用 id() 验证内存地址**

```python
print(f"id(a) = {id(a)}")
print(f"id(b) = {id(b)}")
print(f"id(c) = {id(c)}")
print(f"a 和 c 地址相同: {id(a) == id(c)}")
print(f"a 和 b 地址相同: {id(a) == id(b)}")
```

运行结果：

```text
id(a) = 4318398784
id(b) = 4318400640
id(c) = 4318398784
a 和 c 地址相同: True
a 和 b 地址相同: False
```

`id()` 返回对象的唯一标识（内存地址）。`a` 和 `c` 的 `id` 相同，说明它们指向同一块内存。

#### 2.5.2 修改验证引用关系

```python
original = [10, 20, 30]
alias = original          # 别名，指向同一对象
copy_list = original[:]   # 浅拷贝，新对象

original.append(40)
print(f"修改 original 后:")
print(f"  original: {original}")
print(f"  alias:    {alias}       (同一对象，跟着变了)")
print(f"  copy:     {copy_list}    (独立对象，不变)")

print(f"  original is alias: {original is alias}")
print(f"  original is copy:  {original is copy_list}")
```

运行结果：

```text
修改 original 后:
  original: [10, 20, 30, 40]
  alias:    [10, 20, 30, 40]       (同一对象，跟着变了)
  original is alias: True
  original is copy:  False
```

`alias` 是 `original` 的别名（同一对象），修改 `original` 后 `alias` 也变了。`copy_list` 是浅拷贝（独立对象），不受影响。

#### 2.5.3 空列表不共享

Python 不缓存空列表，每次 `[]` 都创建新对象：

```python
empty1 = []
empty2 = []
print(f"[] is []: {empty1 is empty2}")     # False
print(f"[] == []: {empty1 == empty2}")     # True
```

运行结果：

```text
[] is []: False
[] == []: True
```

这与小整数缓存（`a = 1; b = 1; a is b` 为 True）和字符串驻留不同——列表不会缓存。所以判断列表是否为空应该用 `==` 或真值判断，不能用 `is`。

**应该用 == 还是 is 判断列表相等？**

| 场景 | 使用的运算符 | 原因 |
|------|------------|------|
| 判断值是否相等 | `==` | 列表内容相同即为 True |
| 判断是否为同一对象 | `is` | 内存地址相同才为 True |
| 判断 `None` | `is` | None 是单例对象 |
| 判断空列表 | `not lst` 或 `lst == []` | 真值判断最 Pythonic |

### 2.6 逻辑运算符与列表真值判断

列表在布尔上下文中（如 `if`、`while`、`and`、`or`、`not`）有自己的真值性判断规则：**非空列表为 True，空列表为 False**。

#### 2.6.1 列表的真值性

```python
print(f"bool([])      = {bool([])}")           # False，空列表
print(f"bool([0])     = {bool([0])}")          # True，非空列表（哪怕元素是0）
print(f"bool([None])  = {bool([None])}")       # True，非空列表（哪怕元素是None）
print(f"bool([[]])    = {bool([[]])}")          # True，非空列表（哪怕元素是空列表）
print(f"bool([''])    = {bool([''])}")          # True，非空列表（哪怕元素是空字符串）
```

运行结果：

```text
bool([])      = False
bool([0])     = True
bool([None])  = True
bool([[]])    = True
bool([''])    = True
```

这里有一个容易混淆的要点：`bool([0])` 是 `True`，而 `bool(0)` 是 `False`。列表只要有元素就是非空的，不管元素本身是什么值。`[0]` 包含了一个元素（整数 `0`），所以是非空列表，真值为 True。

**if 中的真值判断**

```python
data = []
if data:
    print("data 非空")
else:
    print("data 为空")

data = [0]
if data:
    print("[0] 非空，if 判断为 True")
```

运行结果：

```text
data 为空
[0] 非空，if 判断为 True
```

直接把列表放在 `if` 条件中，Python 自动调用 `bool()` 转换。这是判断列表是否为空最简洁的方式。

#### 2.6.2 and 运算符

`and` 返回的不是 True/False，而是**操作数本身**，利用短路求值：如果左边为 False 就直接返回左边，不再计算右边：

```python
# [] 为 False，直接返回 []
result1 = [] and [1, 2, 3]
print(f"[] and [1,2,3]  = {result1}")

# [1] 为 True，返回右边的 [2,3]
result2 = [1] and [2, 3]
print(f"[1] and [2,3]   = {result2}")
```

运行结果：

```text
[] and [1,2,3]  = []
[1] and [2,3]   = [2, 3]
```

`[] and [1,2,3]`：`[]` 为 False，短路，直接返回 `[]`。`[1] and [2,3]`：`[1]` 为 True，继续看右边，返回 `[2,3]`。

#### 2.6.3 or 运算符

`or` 同样返回操作数本身：如果左边为 True 就直接返回左边，否则返回右边：

```python
# [] 为 False，返回右边的 [1,2,3]
result4 = [] or [1, 2, 3]
print(f"[] or [1,2,3]   = {result4}")

# [1] 为 True，直接返回 [1]
result5 = [1] or [2, 3]
print(f"[1] or [2,3]    = {result5}")
```

运行结果：

```text
[] or [1,2,3]   = [1, 2, 3]
[1] or [2,3]    = [1]
```

#### 2.6.4 not 运算符

`not` 返回布尔值 True/False（不像 `and`/`or` 返回操作数本身）：

```python
print(f"not []   = {not []}")        # True，空列表为 False，取反
print(f"not [1]  = {not [1]}")       # False，非空列表为 True，取反
```

运行结果：

```text
not []   = True
not [1]  = False
```

#### 2.6.5 实际场景：默认值设置

```python
user_tags = []
# 用 or 提供默认值
tags = user_tags or ["未分类"]
print(f"用户标签为空，使用默认值: {tags}")

user_tags = ["Python", "编程"]
tags = user_tags or ["未分类"]
print(f"用户标签非空，使用用户值: {tags}")
```

运行结果：

```text
用户标签为空，使用默认值: ['未分类']
用户标签非空，使用用户值: ['Python', '编程']
```

`user_tags or ["未分类"]` 利用了 `or` 的短路特性：`user_tags` 为空列表（False）时，返回右边的默认值 `["未分类"]`；非空（True）时，直接返回 `user_tags` 本身。这是 Python 中设置默认值的惯用模式。

### 2.7 复合赋值 += 和 *=

`+=` 和 `*=` 是列表的特殊运算符——它们对列表做**原地修改**，而等价的 `+` 和 `*` 会**创建新列表**。理解这个区别非常重要。

#### 2.7.1 + vs +=

```python
# + 创建新列表
list_a = [1, 2, 3]
original_id_a = id(list_a)
list_a = list_a + [4, 5]
print(f"+ 拼接后, id 变了: {id(list_a) != original_id_a}")
print(f"  结果: {list_a}")

# += 原地扩展
list_b = [1, 2, 3]
original_id_b = id(list_b)
list_b += [4, 5]
print(f"\n+= 扩展后, id 不变: {id(list_b) == original_id_b}")
print(f"  结果: {list_b}")
```

运行结果：

```text
+ 拼接后, id 变了: True
  结果: [1, 2, 3, 4, 5]

+= 扩展后, id 不变: True
  结果: [1, 2, 3, 4, 5]
```

`list_a = list_a + [4, 5]` 中，`list_a + [4, 5]` 创建了一个新列表，然后赋值给 `list_a`——`list_a` 指向了新对象，`id` 改变了。

`list_b += [4, 5]` 中，`+=` 调用的是 `list.__iadd__`，在原列表上原地扩展——`list_b` 还指向原来的对象，`id` 没变。

**+= 等价于 extend**

```python
lst1 = [1, 2, 3]
lst2 = [1, 2, 3]
lst1 += [4, 5]
lst2.extend([4, 5])
print(f"+= 结果:   {lst1}")
print(f"extend结果: {lst2}")
print(f"结果相同: {lst1 == lst2}")
```

运行结果：

```text
+= 结果:   [1, 2, 3, 4, 5]
extend结果: [1, 2, 3, 4, 5]
结果相同: True
```

`+=` 对列表来说完全等价于 `extend()`，都是原地追加元素。

#### 2.7.2 * vs *=

```python
# * 创建新列表
list_c = [1, 2]
original_id_c = id(list_c)
list_c = list_c * 3
print(f"* 重复后, id 变了: {id(list_c) != original_id_c}")
print(f"  结果: {list_c}")

# *= 原地重复
list_d = [1, 2]
original_id_d = id(list_d)
list_d *= 3
print(f"\n*= 重复后, id 不变: {id(list_d) == original_id_d}")
print(f"  结果: {list_d}")
```

运行结果：

```text
* 重复后, id 变了: True
  结果: [1, 2, 1, 2, 1, 2]

*= 重复后, id 不变: True
  结果: [1, 2, 1, 2, 1, 2]
```

`*` 创建新列表，`*=` 在原列表上原地重复。

#### 2.7.3 += 可以接受任何可迭代对象

由于 `+=` 等价于 `extend`，它可以接受任何可迭代对象：

```python
lst = [1, 2]
lst += [3, 4]           # 列表
print(f"追加列表: {lst}")
lst += (5, 6)            # 元组
print(f"追加元组: {lst}")
lst += "ab"              # 字符串（每个字符一个元素）
print(f"追加字符串: {lst}")
lst += range(7, 9)      # range
print(f"追加range: {lst}")
```

运行结果：

```text
追加列表: [1, 2, 3, 4]
追加元组: [1, 2, 3, 4, 5, 6]
追加字符串: [1, 2, 3, 4, 5, 6, 'a', 'b']
追加range: [1, 2, 3, 4, 5, 6, 'a', 'b', 7, 8]
```

而 `+` 只能拼接列表和列表，`[1] + (2, 3)` 会报 `TypeError`。这是 `+=` 和 `+` 的另一个重要区别。

#### 2.7.4 函数内修改外部列表

理解 `+=` 的原地修改特性，对于在函数中操作列表的副作用至关重要：

```python
def add_items(lst, items):
    """用 += 原地修改，影响调用者的列表"""
    lst += items

my_list = [1, 2, 3]
add_items(my_list, [4, 5])
print(f"函数调用后，外部列表: {my_list}")
```

运行结果：

```text
函数调用后，外部列表: [1, 2, 3, 4, 5]
```

`+=` 原地修改了传入的列表，函数调用后外部列表也被改了。

```python
def add_items_new(lst, items):
    """用 + 创建新列表，不影响调用者的原列表"""
    lst = lst + items
    return lst

my_list2 = [1, 2, 3]
new_list = add_items_new(my_list2, [4, 5])
print(f"+ 方式，原列表不变: {my_list2}")
print(f"+ 方式，返回新列表: {new_list}")
```

运行结果：

```text
+ 方式，原列表不变: [1, 2, 3]
+ 方式，返回新列表: [1, 2, 3, 4, 5]
```

`+` 创建新列表并赋值给局部变量 `lst`，不影响外部的 `my_list2`。函数内部修改全局列表的安全方式是利用 `+=` 的副作用（但要注意这会让函数有副作用），或者用 `+` 显式返回新列表让调用者决定是否覆盖。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

| 场景 | 推荐写法 | 不推荐写法 | 原因 |
|------|---------|-----------|------|
| 追加单个元素 | `lst.append(x)` | `lst = lst + [x]` | append 原地操作，不创建新列表 |
| 批量追加 | `lst.extend(items)` 或 `lst += items` | `for x in items: lst.append(x)` | extend/+= 在 C 层批量操作 |
| 合并列表 | `a + b` 如需新列表 | `a += b` 如不想改 a | 语义不同，按需选择 |
| 判断空列表 | `if not lst:` | `if len(lst) == 0:` 或 `if lst == []:` | 真值判断最 Pythonic |
| 判断值相等 | `a == b` | `a is b` | == 比值，is 比地址 |
| 判断 None | `x is None` | `x == None` | None 是单例，is 更安全 |
| 默认值 | `value = data or []` | `if data: value = data else: value = []` | or 短路更简洁 |
| 成员检查 | `x in lst` | 循环遍历查找 | in 运算符底层优化，更简洁 |

### 3.2 常见错误模式

**错误一：在函数中意外修改传入列表**

```python
# 不推荐：+= 修改了调用者的列表（副作用难以追踪）
def add_suffix(lst, suffix):
    lst += suffix  # 修改了原列表！

original = [1, 2, 3]
add_suffix(original, [4])
# original 变成了 [1, 2, 3, 4]！

# 推荐：如果不想修改原列表，用 + 或先拷贝
def add_suffix_safe(lst, suffix):
    return lst + suffix  # 创建新列表

original = [1, 2, 3]
result = add_suffix_safe(original, [4])
# original 仍是 [1, 2, 3]
```

**错误二：用 is 判断列表相等**

```python
# 不推荐：用 is 判断值相等
a = [1, 2]
b = [1, 2]
if a is b:  # False，即使值相同
    print("相同")

# 推荐：用 == 判断值相等
if a == b:  # True
    print("值相同")
```

**错误三：混淆 [0] 和 0 的真值性**

```python
# 误区：以为 [0] 是 False
lst = [0]
if not lst:  # False！因为 [0] 是非空列表
    print("空列表")  # 不会执行

# 正确理解
# bool([0]) = True  （列表有元素）
# bool(0)  = False  （0本身是 False）
# bool([]) = False  （空列表）
```

**错误四：用 + 追加单个元素**

```python
# 不推荐：用 + 追加单个元素，创建了不必要的中间列表
lst = [1, 2, 3]
lst = lst + [4]  # 创建新列表 + 单元素列表，再赋值

# 推荐：用 append
lst.append(4)    # 原地操作，不创建额外列表
```

**错误五：+ 只接受列表**

```python
# 错误：列表 + 非列表类型
result = [1, 2] + (3, 4)  # TypeError

# 正确：用 +=（接受可迭代对象）
lst = [1, 2]
lst += (3, 4)  # 正常，等价于 extend

# 或：先转列表再 +
result = [1, 2] + list((3, 4))
```

### 3.3 运算符速查表

| 运算符 | 操作 | 创建新列表 | 原地修改 | 接受可迭代对象 |
|--------|------|-----------|---------|---------------|
| `a + b` | 拼接 | 是 | 否 | 否（只接受 list） |
| `a * n` | 重复 | 是 | 否 | - |
| `a += b` | 原地扩展 | 否 | 是 | 是 |
| `a *= n` | 原地重复 | 否 | 是 | - |
| `a == b` | 值相等 | - | - | - |
| `a != b` | 值不等 | - | - | - |
| `a < b` | 字典序小于 | - | - | - |
| `a > b` | 字典序大于 | - | - | - |
| `x in a` | 成员判断 | - | - | - |
| `x not in a` | 非成员判断 | - | - | - |
| `a is b` | 同一对象 | - | - | - |
| `a is not b` | 不同对象 | - | - | - |

### 3.4 性能对比

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `a + b` | O(len(a) + len(b)) | 创建新列表，拷贝所有元素 |
| `a += b` | O(len(b)) | 原地扩展，只拷贝 b 的元素 |
| `a * n` | O(len(a) * n) | 创建新列表 |
| `a *= n` | O(len(a) * n) | 原地扩展 |
| `x in a` | O(n) | 线性扫描 |
| `a == b` | O(min(len(a), len(b))) | 逐元素比较，遇到不等即停 |
| `a < b` | O(min(len(a), len(b))) | 逐元素比较 |

`+` 和 `+=` 的性能差异在循环中累积时会非常明显：

```python
import time

# 不推荐：在循环中用 + 拼接（每次创建新列表）
lst = []
for i in range(10000):
    lst = lst + [i]  # O(n^2)，每次拷贝整个列表

# 推荐：用 += 或 append
lst = []
for i in range(10000):
    lst += [i]  # O(n)，每次只追加一个元素
```

## 4. 原理

### 4.1 运算符分派机制：特殊方法

Python 的运算符本质上是特殊方法的调用。每个运算符都对应一个 dunder 方法（双下划线方法），列表类型实现了这些方法来表达特定的运算行为：

| 运算符 | 调用的特殊方法 | 说明 |
|--------|--------------|------|
| `a + b` | `a.__add__(b)` | 拼接 |
| `a * n` | `a.__mul__(n)` | 重复 |
| `a += b` | `a.__iadd__(b)` | 原地拼接（就地加法） |
| `a *= n` | `a.__imul__(n)` | 原地重复 |
| `a == b` | `a.__eq__(b)` | 相等比较 |
| `a < b` | `a.__lt__(b)` | 小于比较 |
| `x in a` | `a.__contains__(x)` | 成员判断 |
| `len(a)` | `a.__len__()` | 长度 |
| `bool(a)` | `a.__bool__()` 或 `a.__len__()` | 真值判断 |

可以用代码验证这些方法的存在：

```python
lst = [1, 2, 3]
print(f"lst.__add__([4]):  {lst.__add__([4])}")
print(f"lst.__mul__(2):    {lst.__mul__(2)}")
print(f"lst.__contains__(2): {lst.__contains__(2)}")
print(f"lst.__len__():     {lst.__len__()}")
print(f"lst == [1,2,3] via __eq__: {lst.__eq__([1,2,3])}")
```

运行结果：

```text
lst.__add__([4]):  [1, 2, 3, 4]
lst.__mul__(2):    [1, 2, 3, 1, 2, 3]
lst.__contains__(2): True
lst.__len__():     3
lst == [1,2,3] via __eq__: True
```

### 4.2 + 和 += 底层差异

`+` 和 `+=` 的行为不同，根源在于它们调用的是不同的特殊方法：

**`a + b`** 调用 `__add__`：创建一个全新的列表，把 `a` 和 `b` 的元素拷贝进去。

```text
a + b 的执行流程：
  1. 调用 a.__add__(b)
  2. 创建新列表对象 new_list
  3. 把 a 的所有元素拷贝到 new_list
  4. 把 b 的所有元素追加到 new_list
  5. 返回 new_list
  → a 和 b 都不变
```

**`a += b`** 调用 `__iadd__`：在 `a` 原有内存上直接扩展，等价于 `a.extend(b)`。

```text
a += b 的执行流程：
  1. 调用 a.__iadd__(b)
  2. 在 a 的原有内存上扩展
  3. 把 b 的元素逐个追加到 a 的末尾
  4. 返回 a（自身）
  → a 被原地修改，内存地址不变
```

验证代码：

```python
lst = [1, 2, 3]
id_before = id(lst)

# + 方式
lst_copy = lst + [4]
print(f"+ 方式: id 变了 = {id(lst_copy) != id_before}")

# += 方式
result = lst
lst.__iadd__([5, 6])  # 等价于 lst += [5, 6]
print(f"+= 方式: id 不变 = {id(lst) == id_before}")
print(f"结果: {lst}")
```

运行结果：

```text
+ 方式: id 变了 = True
+= 方式: id 不变 = True
结果: [1, 2, 3, 5, 6]
```

### 4.3 列表真值判断的底层

当 Python 遇到 `if lst:` 时，会先调用 `bool(lst)`。`bool()` 函数查找对象的 `__bool__` 方法，如果定义了就用它；如果没定义 `__bool__`，则退而求其次使用 `__len__`——长度为 0 返回 False，大于 0 返回 True。

列表类型**没有定义 `__bool__` 方法**，因此使用 `__len__` 来确定真值：

```python
lst = [1, 2, 3]
print(f"有 __bool__ 方法吗: {hasattr(lst, '__bool__')}")
print(f"有 __len__ 方法吗: {hasattr(lst, '__len__')}")
print(f"bool(lst) 等价于: {bool(lst)}")
print(f"len(lst) > 0: {len(lst) > 0}")
```

运行结果：

```text
有 __bool__ 方法吗: False
有 __len__ 方法吗: True
bool(lst) 等价于: True
len(lst) > 0: True
```

`bool(lst)` 实际上等价于 `len(lst) > 0`。这就解释了为什么 `[0]` 的布尔值是 `True`——`len([0])` 是 1，大于 0，所以 `bool([0])` 为 True。列表的真值性取决于**有没有元素**，而不是元素本身的值。

### 4.4 and / or 返回操作数的原理

`and` 和 `or` 不返回 `True`/`False`，而是返回操作数本身——这是因为它们的设计目标是"短路返回，避免不必要的计算"。

```text
and 的求值规则：
  如果 bool(左) 为 False → 直接返回左操作数，不计算右
  如果 bool(左) 为 True  → 返回右操作数

or 的求值规则：
  如果 bool(左) 为 True  → 直接返回左操作数，不计算右
  如果 bool(左) 为 False → 返回右操作数
```

这样做的好处是：`or` 可以用来设置默认值（`a or default`），`and` 可以用来链式取值（`a and a.field`）。如果它们只返回 True/False，这些模式就无法实现了。

## 5. 总结

本文围绕列表与运算符展开，系统介绍了以下内容：

- **拼接 `+` 与重复 `*`**：`+` 合并两个列表为新列表，`*` 重复元素生成新列表，两者都不修改原列表
- **比较运算符**：`==` `!=` 判断值相等，`<` `>` `<=` `>=` 按字典序逐元素比较，类型不同直接返回 False
- **成员运算符 `in` / `not in`**：判断元素是否在列表中，底层是线性扫描，子列表按整体匹配
- **身份运算符 `is` / `is not`**：判断是否为同一对象（内存地址相同），与 `==` 比值不同，空列表不共享
- **逻辑运算符与真值判断**：非空列表为 True、空列表为 False，`and`/`or` 返回操作数本身并短路求值，`not` 返回布尔值
- **复合赋值 `+=` / `*=`**：原地修改不创建新列表，`+=` 等价于 `extend`，可接受任何可迭代对象，与 `+`/`*` 创建新列表的本质区别
- **最佳实践**：推荐 vs 不推荐写法对比、常见错误模式（函数副作用、is vs ==、[0] 真值陷阱、+ 只接受列表）、运算符速查表、性能对比
- **原理**：运算符分派到 `__add__`/`__eq__`/`__contains__` 等特殊方法、`+`（`__add__`）vs `+=`（`__iadd__`）底层差异、列表真值判断走 `__len__` 而非 `__bool__`、`and`/`or` 返回操作数的短路求值设计
