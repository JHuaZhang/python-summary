# defaultdict 默认值字典

## 1. 介绍

### 1.1 什么是 defaultdict

`defaultdict` 是 Python 标准库 `collections` 模块提供的一个字典子类，它在普通字典功能的基础上，**解决了访问不存在的键时抛出 `KeyError` 的问题**——当你访问一个不存在的键时，`defaultdict` 会自动调用一个工厂函数来生成默认值，并把这个值插入到字典中。

你可以把它理解为一个"自带兜底方案"的字典。普通字典你问它一个不存在的键，它直接报错给你看；`defaultdict` 问到一个不存在的键，它先自己造一个默认值填进去，再把值返回给你。

来看最直观的对比：

```python
from collections import defaultdict

# 普通 dict：访问不存在的键 → KeyError
normal = {}
try:
    normal['score']
except KeyError as e:
    print(f"普通 dict: KeyError({e})")

# defaultdict：访问不存在的键 → 自动创建默认值
dd = defaultdict(int)
val = dd['score']
print(f"defaultdict: score = {val}")
print(f"访问后字典内容: {dict(dd)}")
```

运行结果：

```text
普通 dict: KeyError('score')
defaultdict: score = 0
访问后字典内容: {'score': 0}
```

`defaultdict(int)` 在访问 `'score'` 时，发现这个键不存在，于是调用 `int()` 生成默认值 `0`，把 `('score', 0)` 插入字典，然后返回 `0`。整个过程不会报错。

### 1.2 在 Python 字典体系中的定位

`defaultdict` 位于 `collections` 模块中，是 `dict` 的子类。在整个 Python 字典体系中，它的定位如下：

```text
dict（普通字典）
  │
  ├── collections.OrderedDict    ← 有序字典，维护插入顺序
  ├── collections.defaultdict    ← 默认值字典，缺失键自动填充
  ├── collections.Counter         ← 计数字典，专门用于计数
  └── collections.ChainMap        ← 链式字典，合并多个字典视图
```

`defaultdict` 继承了 `dict` 的全部接口，所有普通字典支持的操作（`[]` 访问、`del` 删除、`in` 判断、`len()` 等）都能直接使用。它唯一增强的地方是重写了 `__missing__` 方法——当键不存在时，普通字典的 `__missing__` 直接抛出 `KeyError`，而 `defaultdict` 的 `__missing__` 会调用工厂函数生成默认值。

### 1.3 最简示例

用 `defaultdict(list)` 实现按首字母分组单词：

```python
from collections import defaultdict

words = ['apple', 'banana', 'apricot', 'blueberry', 'cherry']

groups = defaultdict(list)
for word in words:
    first = word[0]
    groups[first].append(word)

print(dict(groups))
```

运行结果：

```text
{'a': ['apple', 'apricot'], 'b': ['banana', 'blueberry'], 'c': ['cherry']}
```

如果用普通字典，每次 `append` 之前都需要先检查键是否存在、不存在则先初始化为空列表。`defaultdict(list)` 让你省掉了这个检查步骤——遇到新键时它自动给你造一个空列表。

## 2. 核心内容

### 2.1 创建 defaultdict

`defaultdict` 的构造函数签名为：

```python
defaultdict(default_factory=None, /, [key, value, ...])
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `default_factory` | 可调用对象或 `None` | 工厂函数，用于生成缺失键的默认值。为 `None` 时行为等同于普通 `dict` |
| `key, value, ...` | 键值对 | 可选的初始键值对（与普通字典初始化方式一致） |

`default_factory` 是 `defaultdict` 的核心参数，它决定了缺失键会得到什么默认值。

#### 2.1.1 用内置类型作为工厂函数

最常见的方式是传入一个无参可调用对象（通常是内置类型），调用它返回的值就是默认值：

```python
from collections import defaultdict

dd_int = defaultdict(int)       # 缺失键默认值: int() → 0
dd_list = defaultdict(list)     # 缺失键默认值: list() → []
dd_str = defaultdict(str)       # 缺失键默认值: str() → ''
dd_dict = defaultdict(dict)     # 缺失键默认值: dict() → {}
dd_set = defaultdict(set)       # 缺失键默认值: set() → set()

print(f"int:  {dd_int['x']}")
print(f"list: {dd_list['x']}")
print(f"str:  {dd_str['x']!r}")
print(f"dict: {dd_dict['x']}")
print(f"set:  {dd_set['x']}")
```

运行结果：

```text
int:  0
list: []
str:  ''
dict: {}
set:  set()
```

每种内置类型调用 `()` 时都有一个明确的"零值"：`int()` 返回 `0`，`list()` 返回 `[]`，`str()` 返回空字符串。`defaultdict` 在遇到缺失键时，就是调用这个工厂函数来生成默认值。

#### 2.1.2 用 lambda 或自定义函数作为工厂函数

当内置类型的零值不够用时，可以用 `lambda` 或自定义函数生成更复杂的默认值：

```python
from collections import defaultdict

# 用 lambda 指定固定默认值
dd_na = defaultdict(lambda: "N/A")
print(dd_na['unknown'])  # N/A

# 用 lambda 默认值 1（而非 int 的 0）
dd_one = defaultdict(lambda: 1)
print(dd_one['count'])   # 1

# 用自定义函数生成复合默认值
def make_default_config():
    return {"enabled": False, "priority": 0, "tags": []}

dd_config = defaultdict(make_default_config)
print(dd_config['new_module'])
# {'enabled': False, 'priority': 0, 'tags': []}
```

运行结果：

```text
N/A
1
{'enabled': False, 'priority': 0, 'tags': []}
```

**创建方式速查表**：

| 创建方式 | 代码示例 | 默认值 |
|---------|---------|--------|
| `int` 工厂 | `defaultdict(int)` | `0` |
| `list` 工厂 | `defaultdict(list)` | `[]` |
| `str` 工厂 | `defaultdict(str)` | `''` |
| `dict` 工厂 | `defaultdict(dict)` | `{}` |
| `set` 工厂 | `defaultdict(set)` | `set()` |
| `lambda` 工厂 | `defaultdict(lambda: 0)` | `lambda` 返回值 |
| 自定义函数 | `defaultdict(make_default)` | 函数返回值 |
| 无工厂 | `defaultdict()` | 无（行为等同普通 `dict`） |

#### 2.1.3 带初始值创建

`defaultdict` 也支持像普通字典一样传入初始键值对：

```python
from collections import defaultdict

# 从键值对字典创建
dd = defaultdict(int, {'a': 1, 'b': 2})
print(f"已有键 a: {dd['a']}")
print(f"缺失键 c: {dd['c']}")  # 自动创建默认值 0
print(f"完整内容: {dict(dd)}")
```

运行结果：

```text
已有键 a: 1
缺失键 c: 0
完整内容: {'a': 1, 'b': 2, 'c': 0}
```

初始键值对中的值保持不变，只有访问缺失键时才触发默认值创建。

### 2.2 default_factory 属性

`defaultdict` 对象有一个公开属性 `default_factory`，它记录了当前使用的工厂函数。你可以在运行时读取或修改它。

```python
from collections import defaultdict

dd = defaultdict(int)
print(f"当前工厂函数: {dd.default_factory}")

# 运行时修改工厂函数
dd.default_factory = list
print(f"修改后: {dd.default_factory}")
print(f"现在缺失键默认值: {dd['new_key']}")
```

运行结果：

```text
当前工厂函数: <class 'int'>
修改后: <class 'list'>
现在缺失键默认值: []
```

如果把 `default_factory` 设为 `None`，`defaultdict` 就退化成普通字典，访问缺失键会抛出 `KeyError`：

```python
dd = defaultdict(int)
dd.default_factory = None

try:
    _ = dd['missing']
except KeyError as e:
    print(f"工厂函数为 None: KeyError({e})")
```

运行结果：

```text
工厂函数为 None: KeyError('missing')
```

同理，创建 `defaultdict()` 时不传参数，`default_factory` 就是 `None`，行为等同普通字典。

### 2.3 常用工厂函数场景

不同的工厂函数适合不同的使用场景，下面逐一讲解最常用的几种。

#### 2.3.1 int 工厂：计数场景

`defaultdict(int)` 的默认值是 `0`，最常见的用途是**计数**——统计元素出现次数时，不需要先检查键是否存在。

```python
from collections import defaultdict

text = "abracadabra"
char_count = defaultdict(int)

for ch in text:
    char_count[ch] += 1

print(dict(char_count))
```

运行结果：

```text
{'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}
```

`char_count[ch] += 1` 这行代码的含义是：先读取 `char_count[ch]`（如果键不存在，自动返回 `0`），加 `1` 后再写回。整个过程一行代码搞定，不需要任何条件判断。

#### 2.3.2 list 工厂：分组收集场景

`defaultdict(list)` 的默认值是空列表 `[]`，最常见的用途是**分组**——把属于同一类别的元素收集到一起。

```python
from collections import defaultdict

employees = [
    ("Alice", "Engineering"),
    ("Bob", "Sales"),
    ("Charlie", "Engineering"),
    ("Diana", "Marketing"),
    ("Eve", "Sales"),
]

dept_groups = defaultdict(list)
for name, dept in employees:
    dept_groups[dept].append(name)

for dept, names in dept_groups.items():
    print(f"{dept}: {names}")
```

运行结果：

```text
Engineering: ['Alice', 'Charlie']
Sales: ['Bob', 'Eve']
Marketing: ['Diana']
```

每次遇到新部门，`defaultdict(list)` 自动创建一个空列表，后续直接 `append` 即可。

#### 2.3.3 set 工厂：去重收集场景

`defaultdict(set)` 的默认值是空集合 `set()`，适合需要**自动去重**的分组场景。

```python
from collections import defaultdict

enrollments = [
    ("Alice", "Math"),
    ("Alice", "Physics"),
    ("Alice", "Math"),       # 重复选课
    ("Bob", "Math"),
    ("Bob", "Chemistry"),
    ("Bob", "Math"),          # 重复
]

student_courses = defaultdict(set)
for student, course in enrollments:
    student_courses[student].add(course)

for student, courses in student_courses.items():
    print(f"{student}: {courses}")
```

运行结果：

```text
Alice: {'Physics', 'Math'}
Bob: {'Chemistry', 'Math'}
```

即使同一学生重复选了同一门课，`set` 会自动去重，最终每个学生的课程集合中没有重复元素。

#### 2.3.4 dict 工厂：嵌套字典场景

`defaultdict(dict)` 的默认值是空字典 `{}`，适合构建**嵌套字典**——外层字典的每个值本身又是一个字典。

```python
from collections import defaultdict

configs = [
    ("server", "host", "localhost"),
    ("server", "port", 8080),
    ("database", "host", "db.internal"),
    ("database", "port", 5432),
]

config_tree = defaultdict(dict)
for section, key, value in configs:
    config_tree[section][key] = value

for section, kv in config_tree.items():
    print(f"[{section}]: {kv}")
```

运行结果：

```text
[server]: {'host': 'localhost', 'port': 8080}
[database]: {'host': 'db.internal', 'port': 5432}
```

第一次访问 `config_tree['server']` 时自动创建空字典，然后可以直接对内层字典做 `['host'] = 'localhost'` 赋值。

#### 2.3.5 嵌套 defaultdict：多层自动初始化

`defaultdict` 可以嵌套使用，实现多层深度的自动初始化。内层用一个返回 `defaultdict` 的 `lambda` 作为工厂函数：

```python
from collections import defaultdict

# 二维自动初始化：外层 defaultdict 的工厂函数返回一个 defaultdict(list)
tree = defaultdict(lambda: defaultdict(list))

sales = [
    (2023, "Q1", "ProductA"),
    (2023, "Q1", "ProductB"),
    (2023, "Q2", "ProductC"),
    (2024, "Q1", "ProductA"),
    (2024, "Q3", "ProductD"),
]

for year, quarter, product in sales:
    tree[year][quarter].append(product)

for year in sorted(tree):
    print(f"{year}:")
    for quarter in sorted(tree[year]):
        print(f"  {quarter}: {tree[year][quarter]}")
```

运行结果：

```text
2023:
  Q1: ['ProductA', 'ProductB']
  Q2: ['ProductC']
2024:
  Q1: ['ProductA']
  Q3: ['ProductD']
```

`tree[year]` 返回一个 `defaultdict(list)`，`tree[year][quarter]` 返回一个 `list`。两层都不需要预先初始化。

**工厂函数场景速查表**：

| 工厂函数 | 默认值 | 典型场景 | 核心操作 |
|---------|--------|---------|---------|
| `int` | `0` | 计数 | `dd[key] += 1` |
| `list` | `[]` | 分组收集 | `dd[key].append(item)` |
| `set` | `set()` | 去重收集 | `dd[key].add(item)` |
| `dict` | `{}` | 嵌套字典 | `dd[key][inner_key] = value` |
| `lambda` | 自定义 | 固定默认值 | `dd[key]` 直接使用 |
| 嵌套 | 多层 | 多维分组 | `dd[k1][k2].append(...)` |

### 2.4 defaultdict 与普通 dict 对比

同一个任务，用普通字典和 `defaultdict` 分别实现，可以清楚地看到差异。

#### 2.4.1 计数任务三种写法

任务：统计文本中每个单词出现的次数。

```python
text = "the cat sat on the mat the cat ate the rat"

# 写法一：普通 dict + if 判断
count_normal = {}
for word in text.split():
    if word in count_normal:
        count_normal[word] += 1
    else:
        count_normal[word] = 1

# 写法二：普通 dict + setdefault
count_setdefault = {}
for word in text.split():
    count_setdefault.setdefault(word, 0)
    count_setdefault[word] += 1

# 写法三：defaultdict(int)
from collections import defaultdict
count_default = defaultdict(int)
for word in text.split():
    count_default[word] += 1

print(count_default)
```

运行结果：

```text
defaultdict(<class 'int'>, {'the': 4, 'cat': 2, 'sat': 1, 'on': 1, 'mat': 1, 'ate': 1, 'rat': 1})
```

三种写法结果完全一样，但代码复杂度递减：

| 写法 | 代码行数 | 需要条件判断 | 可读性 |
|------|---------|------------|--------|
| 普通 dict + if | 4 行 | 是（if-else） | 一般 |
| dict + setdefault | 2 行 | 否 | 较好 |
| defaultdict(int) | 1 行 | 否 | 最好 |

#### 2.4.2 分组任务三种写法

任务：按部门分组员工姓名。

```python
employees = [
    ("Alice", "Engineering"),
    ("Bob", "Sales"),
    ("Charlie", "Engineering"),
    ("Diana", "Marketing"),
    ("Eve", "Sales"),
]

# 写法一：普通 dict + if
groups_normal = {}
for name, dept in employees:
    if dept not in groups_normal:
        groups_normal[dept] = []
    groups_normal[dept].append(name)

# 写法二：dict + setdefault
groups_setdefault = {}
for name, dept in employees:
    groups_setdefault.setdefault(dept, []).append(name)

# 写法三：defaultdict(list)
from collections import defaultdict
groups_default = defaultdict(list)
for name, dept in employees:
    groups_default[dept].append(name)
```

`setdefault` 写法已经比较简洁了，但 `defaultdict(list)` 更进一步——你不需要每次写 `setdefault`，直接 `append` 就行。差别在于：`setdefault` 每次调用都会创建一个空列表（即使键已存在，虽然不会插入，但默认值参数已经被求值），而 `defaultdict` 只在键缺失时才调用工厂函数。

#### 2.4.3 defaultdict 的继承关系

`defaultdict` 是 `dict` 的子类，拥有 `dict` 的全部方法：

```python
from collections import defaultdict
import json

dd = defaultdict(int)
dd['a'] = 1
dd['b'] = 2

# isinstance 检查
print(f"是 dict 的实例: {isinstance(dd, dict)}")
print(f"是 defaultdict 的实例: {isinstance(dd, defaultdict)}")

# 类型转换：dict(dd) 会丢失 defaultdict 类型
plain = dict(dd)
print(f"转换后类型: {type(plain).__name__}")

# JSON 序列化：与普通 dict 完全一致
dd_list = defaultdict(list)
dd_list['fruits'].extend(['apple', 'banana'])
dd_list['veggies'].append('carrot')
print(f"JSON: {json.dumps(dd_list)}")
```

运行结果：

```text
是 dict 的实例: True
是 defaultdict 的实例: True
转换后类型: dict
JSON: {"fruits": ["apple", "banana"], "veggies": ["carrot"]}
```

需要注意的是，`dict(dd)` 会把 `defaultdict` 转成普通 `dict`，丢失默认值功能。如果需要保持 `defaultdict` 类型，应使用 `dd.copy()` 方法。

### 2.5 default_factory 为 None 的行为

当 `default_factory` 为 `None` 时（创建时不传参数，或运行时设为 `None`），`defaultdict` 的行为退化成普通字典——访问缺失键会抛出 `KeyError`。

```python
from collections import defaultdict

# 创建时不传工厂函数
dd = defaultdict()
print(f"default_factory: {dd.default_factory}")

try:
    _ = dd['missing']
except KeyError as e:
    print(f"访问缺失键: KeyError({e})")
```

运行结果：

```text
default_factory: None
访问缺失键: KeyError('missing')
```

这个特性有时用于"临时禁用默认值功能"——先用 `defaultdict` 的默认值机制构建字典，构建完成后把 `default_factory` 设为 `None`，后续访问就回到普通字典的行为，避免意外创建不需要的键。

### 2.6 copy 方法

`defaultdict` 的 `copy()` 方法返回一个浅拷贝，同时保留 `default_factory`：

```python
from collections import defaultdict

dd = defaultdict(int, {'a': 1, 'b': 2})
dd_copy = dd.copy()

print(f"原始类型: {type(dd).__name__}")
print(f"copy 类型: {type(dd_copy).__name__}")
print(f"copy 的 default_factory: {dd_copy.default_factory}")
print(f"copy 内容: {dict(dd_copy)}")
```

运行结果：

```text
原始类型: defaultdict
copy 类型: defaultdict
copy 的 default_factory: <class 'int'>
copy 内容: {'a': 1, 'b': 2}
```

`copy()` 返回的还是 `defaultdict` 类型，工厂函数也被复制了。这与 `dict(dd)` 不同——后者返回普通 `dict`。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法

**场景一：统计词频**

推荐写法——用 `defaultdict(int)` 一行搞定：

```python
from collections import defaultdict

text = "the cat sat on the mat the cat ate the rat"
count = defaultdict(int)
for word in text.split():
    count[word] += 1
```

不推荐写法——用普通字典 + if-else，代码冗余：

```python
count = {}
for word in text.split():
    if word in count:
        count[word] += 1
    else:
        count[word] = 1
```

**场景二：按 key 分组收集值**

推荐写法——用 `defaultdict(list)`：

```python
from collections import defaultdict

groups = defaultdict(list)
for name, dept in employees:
    groups[dept].append(name)
```

不推荐写法——用 `setdefault` 每次都创建临时空列表（即使键已存在）：

```python
groups = {}
for name, dept in employees:
    groups.setdefault(dept, []).append(name)
```

`setdefault` 的问题在于：即使键已存在，`[]` 也会被求值（虽然不会被插入），造成不必要的对象创建。`defaultdict` 只在键缺失时调用工厂函数，效率更高。

**场景三：仅判断键是否存在**

推荐写法——用 `in` 运算符，不会触发默认值创建：

```python
dd = defaultdict(int)
dd['a'] = 1
if 'a' in dd:
    print("a 存在")
if 'b' in dd:
    print("b 存在")
# 此时 dd 只有 {'a': 1}，没有产生副作用
```

不推荐写法——直接用 `dd[key]` 判断，会产生意外的副作用：

```python
dd = defaultdict(int)
if dd['b']:  # 访问 dd['b'] 返回 0，同时往字典里插入了 'b': 0
    print("b 有值")
else:
    print("b 无值")
# 此时 dd 变成了 {'b': 0}，这不是我们的意图
```

### 3.2 常见陷阱

#### 3.2.1 访问缺失键的副作用

`defaultdict` 最大的特性也是最大的陷阱——**任何对缺失键的访问都会自动创建一个条目**。如果你只是想"检查键是否存在"或"安全地读取值"，用 `dd[key]` 会意外修改字典。

```python
from collections import defaultdict

dd = defaultdict(int)

# 仅仅检查 dd['x'] 是否为真值，就往字典里插入了 'x': 0
if dd['x']:
    print("x 有值")
else:
    print("x 无值")

print(f"检查后字典内容: {dict(dd)}")  # {'x': 0} —— 意外的副作用
```

运行结果：

```text
x 无值
检查后字典内容: {'x': 0}
```

**正确做法**：

- 检查键是否存在 → 用 `key in dd`
- 安全读取值不修改字典 → 用 `dd.get(key)`（返回 `None` 或指定默认值，不修改字典）
- 确实需要自动创建默认值 → 用 `dd[key]`

#### 3.2.2 可变默认值共享问题

用 `lambda` 作为工厂函数时，要注意是否每次调用都返回**新对象**。

**错误用法**——`lambda` 返回同一个可变对象，所有键的值指向同一个列表：

```python
from collections import defaultdict

shared_list = []
dd_bad = defaultdict(lambda: shared_list)

dd_bad['a'].append(1)
dd_bad['b'].append(2)

print(dict(dd_bad))  # {'a': [1, 2], 'b': [1, 2]} —— 所有键共享同一个列表
```

**正确用法**——`lambda` 每次调用都创建新对象：

```python
dd_good = defaultdict(lambda: [])

dd_good['a'].append(1)
dd_good['b'].append(2)

print(dict(dd_good))  # {'a': [1], 'b': [2]} —— 各键独立
```

内置类型 `list`、`dict`、`set` 本身每次调用 `()` 都会创建新对象，所以 `defaultdict(list)` 不存在这个问题。只有当你用 `lambda` 包装一个已存在的可变对象时才会出问题。

#### 3.2.3 dict() 转换丢失类型

`dict(dd)` 会把 `defaultdict` 转成普通 `dict`，丢失默认值功能：

```python
from collections import defaultdict

dd = defaultdict(int, {'a': 1, 'b': 2})
plain = dict(dd)

print(f"原始类型: {type(dd).__name__}, factory: {dd.default_factory}")
print(f"转换类型: {type(plain).__name__}, factory: {getattr(plain, 'default_factory', '无')}")
```

运行结果：

```text
原始类型: defaultdict, factory: <class 'int'>
转换类型: dict, factory: 无
```

如果需要保持 `defaultdict` 类型，用 `dd.copy()`。

### 3.3 性能考量

`defaultdict` 与普通 `dict` 在核心操作上的时间复杂度一致：

| 操作 | `defaultdict` | `dict` |
|------|--------------|--------|
| 查找 `dd[key]`（键存在） | O(1) | O(1) |
| 查找 `dd[key]`（键缺失） | O(1) + 工厂调用 | O(1)（返回 `KeyError`） |
| 插入 `dd[key] = v` | O(1) | O(1) |
| `get(key)` | O(1) | O(1) |
| `in` 判断 | O(1) | O(1) |
| 删除 `del dd[key]` | O(1) | O(1) |

`defaultdict` 在键缺失时多了一次工厂函数调用（如 `int()` → `0`），但这是一次非常轻量的操作。与 `setdefault` 相比，`defaultdict` 只在键缺失时调用工厂函数，而 `setdefault` 每次都会对默认值参数求值——在大数据量下 `defaultdict` 更高效。

## 4. 原理

### 4.1 __missing__ 方法：defaultdict 的核心机制

`defaultdict` 能够自动创建默认值的秘密在于它重写了 `__missing__` 方法。

Python 字典的查找流程如下：

```text
dd[key] 的查找流程：

  1. 在哈希表中查找 key
  │
  ├── key 存在 → 返回对应的 value
  │
  └── key 不存在 → 调用 __missing__(key)
                    │
                    ├── dict.__missing__      → 抛出 KeyError
                    │
                    └── defaultdict.__missing__ → 调用 default_factory()
                                              │
                                              ├── factory 为 None → 抛出 KeyError
                                              │
                                              └── factory 不为 None → 
                                                    value = default_factory()
                                                    dd[key] = value
                                                    return value
```

普通 `dict` 没有重写 `__missing__`（实际上 `dict.__missing__` 不存在，Python 在键缺失时直接抛出 `KeyError`）。`defaultdict` 重写了这个方法，在键缺失时调用工厂函数生成默认值并插入字典。

`defaultdict.__missing__` 的核心逻辑可以用以下伪代码表示：

```python
def __missing__(self, key):
    if self.default_factory is None:
        raise KeyError(key)
    value = self.default_factory()
    self[key] = value
    return value
```

### 4.2 工厂函数的调用时机

工厂函数**只在键缺失时被调用**，不会在键已存在时被调用。这一点与 `setdefault` 有着本质区别：

```python
from collections import defaultdict

call_count = 0

def factory():
    global call_count
    call_count += 1
    return []

dd = defaultdict(factory)
dd['a'].append(1)   # 'a' 不存在 → 调用 factory()
dd['a'].append(2)   # 'a' 已存在 → 不调用 factory()
dd['b'].append(3)   # 'b' 不存在 → 调用 factory()

print(f"factory 被调用了 {call_count} 次")  # 2 次
print(dict(dd))
```

运行结果：

```text
factory 被调用了 2 次
{'a': [1, 2], 'b': [3]}
```

对比 `setdefault` 的行为——即使键已存在，默认值参数也会被求值：

```python
call_count = 0

def make_list():
    global call_count
    call_count += 1
    return []

d = {}
d.setdefault('a', make_list())  # 调用 make_list()
d.setdefault('a', make_list())  # 'a' 已存在，但 make_list() 仍然被调用了
d.setdefault('a', make_list())  # 同上

print(f"make_list 被调用了 {call_count} 次")  # 3 次
```

运行结果：

```text
make_list 被调用了 3 次
```

这就是 `defaultdict` 比 `setdefault` 高效的根本原因——`defaultdict` 只在需要时才调用工厂函数，`setdefault` 每次都会对默认值参数求值。

### 4.3 defaultdict 与 dict 的方法差异

`defaultdict` 与普通 `dict` 的方法几乎完全一致，只有一个差异：

| 方法/属性 | `dict` | `defaultdict` | 说明 |
|----------|--------|--------------|------|
| `__missing__` | 无（直接 `KeyError`） | 有（调用 `default_factory`） | 核心差异 |
| `default_factory` | 无 | 有 | 公开属性，可读写 |
| `copy()` | 返回 `dict` | 返回 `defaultdict`（保留 `factory`） | 类型保持 |
| `__repr__()` | `{'a': 1}` | `defaultdict(int, {'a': 1})` | 显示格式 |
| 其他所有方法 | — | 完全继承 `dict` | 行为一致 |

`defaultdict` 没有添加任何新方法，它只是重写了 `__missing__`、`copy` 和 `__repr__`，其余全部继承自 `dict`。

### 4.4 自定义 __missing__：模拟 defaultdict

理解了 `__missing__` 的原理后，你可以通过继承 `dict` 并重写 `__missing__` 来实现自己的"默认值字典"：

```python
class CaseInsensitiveDict(dict):
    """键查找时自动转为小写，实现大小写不敏感的字典"""

    def __missing__(self, key):
        lower_key = key.lower()
        if lower_key in self:
            return self[lower_key]
        raise KeyError(key)

ci = CaseInsensitiveDict({"name": "Alice", "age": 30})
print(ci['NAME'])   # Alice —— 自动转小写查找
print(ci['Name'])   # Alice
print(ci['Age'])    # 30
```

运行结果：

```text
Alice
Alice
30
```

这个例子展示了 `__missing__` 的灵活性——它不一定非得是"创建默认值"，也可以是"用另一种方式查找键"。`defaultdict` 只是对 `__missing__` 的一种特定实现：调用工厂函数创建默认值。

## 5. 总结

本文围绕 `defaultdict` 展开，主要介绍了以下内容：

- `defaultdict` 是 `collections` 模块提供的字典子类，在访问缺失键时自动调用工厂函数生成默认值并插入字典，不会抛出 `KeyError`
- 创建方式：传入工厂函数（如 `int`、`list`、`set`、`dict`、`lambda`、自定义函数）作为 `default_factory`，也可以带初始键值对
- `int` 工厂适合计数（默认值 `0`），`list` 工厂适合分组收集（默认值 `[]`），`set` 工厂适合去重收集（默认值 `set()`），`dict` 工厂适合嵌套字典（默认值 `{}`）
- `default_factory` 属性可在运行时读取和修改，设为 `None` 后 `defaultdict` 退化为普通字典行为
- 与普通字典的三种写法对比（if-else / setdefault / defaultdict），`defaultdict` 在代码简洁度和执行效率上均优于 `setdefault`
- 核心陷阱：用 `dd[key]` 判断键是否存在会产生副作用（自动插入默认值），应改用 `in` 运算符或 `get` 方法
- `lambda` 作为工厂函数时需确保每次调用返回新对象，避免可变默认值共享问题
- 底层原理：`defaultdict` 重写了 `__missing__` 方法，在键缺失时调用 `default_factory()` 生成默认值；工厂函数只在键缺失时调用，而 `setdefault` 每次都会对默认值参数求值，这是 `defaultdict` 更高效的根本原因
