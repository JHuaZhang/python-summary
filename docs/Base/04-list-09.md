# sort 与 sorted 排序

## 1. 介绍

Python 提供了两种排序方式：`list.sort()` 是列表方法，原地修改列表，返回 `None`；`sorted()` 是内置函数，返回新的已排序列表，不修改原数据。两者都支持 `key` 参数（自定义排序规则）和 `reverse` 参数（控制升序或降序），且底层都使用 Timsort 算法，时间复杂度为 O(n log n)。

理解排序的核心在于搞清楚三个层次：**哪种方式**（原地修改还是返回新列表）、**按什么排**（默认按元素本身，还是用 `key` 函数指定排序依据）、**什么方向**（升序还是降序）。此外，Python 的排序是**稳定的**——相同 key 的元素保持原来的相对顺序，这个特性是实现多条件排序的基础。

**最简示例**

用 `sort()` 原地排序列表、用 `sorted()` 返回排序后的新列表：

```python
# list.sort()：原地排序，返回 None
nums = [3, 1, 4, 1, 5]
nums.sort()
print(nums)        # [1, 1, 3, 4, 5]

# sorted()：返回新列表，原列表不变
words = ["banana", "apple", "cherry"]
result = sorted(words)
print(result)      # ['apple', 'banana', 'cherry']
print(words)       # ['banana', 'apple', 'cherry']  原列表不变
```

运行结果：

```text
[1, 1, 3, 4, 5]
['apple', 'banana', 'cherry']
['banana', 'apple', 'cherry']
```

## 2. 核心内容

Python 的两种排序方式的对比如下：

| 特性 | `list.sort()` | `sorted()` |
|------|--------------|-----------|
| 类型 | 列表方法 | 内置函数 |
| 返回值 | `None` | 新列表 |
| 是否修改原列表 | 是（原地修改） | 否 |
| 可排序类型 | 仅 `list` | 所有可迭代对象 |
| 支持 `key` 参数 | 是 | 是 |
| 支持 `reverse` 参数 | 是 | 是 |
| 时间复杂度 | O(n log n) | O(n log n) |
| 稳定性 | 稳定 | 稳定 |

下面逐一详细讲解。

### 2.1 list.sort() 方法

`list.sort()` 是列表的内置方法，对列表进行**原地排序**——直接修改列表本身，不创建新列表，返回 `None`。语法如下：

```python
列表.sort(key=None, reverse=False)
```

- **key**：排序依据函数，接收一个元素返回一个用于比较的值（默认 `None`，按元素本身排序）
- **reverse**：是否降序，`True` 为降序，`False` 为升序（默认）

**基本用法**

```python
numbers = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
print(f"排序前: {numbers}")

result = numbers.sort()
print(f"sort() 后: {numbers}")
print(f"返回值: {result}")
```

运行结果：

```text
排序前: [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
sort() 后: [1, 1, 2, 3, 3, 4, 5, 5, 5, 6, 9]
返回值: None
```

`sort()` 原地修改了列表，`numbers` 变成了升序排列。返回值是 `None`——这是 Python 的设计惯例，所有原地修改方法都返回 `None`，以避免使用者误以为创建了新列表。

**sort() 返回 None 的陷阱**

```python
lst = [3, 1, 2]
# 错误写法：把 sort 的返回值赋给变量
lst = lst.sort()  # lst 变成 None！
print(lst)        # None
```

运行结果：

```text
None
```

`lst = lst.sort()` 是常见的初学者错误——`sort()` 返回 `None`，所以 `lst` 被赋值为 `None`，原来的列表丢失了。正确写法是直接调用 `lst.sort()`，不接收返回值。

**字符串排序**

```python
words = ["banana", "apple", "cherry", "date"]
words.sort()
print(f"字符串排序: {words}")
```

运行结果：

```text
字符串排序: ['apple', 'banana', 'cherry', 'date']
```

字符串按 Unicode 码点排序，即按字典序比较——`'a' < 'b'`，`'apple' < 'banana'`。

**字符串数字排序的陷阱**

```python
str_nums = ["10", "2", "1", "20", "3"]
str_nums.sort()
print(f"字符串数字排序: {str_nums}")
```

运行结果：

```text
字符串数字排序: ['1', '10', '2', '20', '3']
```

对字符串形式的数字排序，结果是字典序而非数值序——`"10"` 排在 `"2"` 前面，因为比较的是第一个字符 `'1' < '2'`。要按数值排序，需要用 `key=int`：

```python
str_nums2 = ["10", "2", "1", "20", "3"]
str_nums2.sort(key=int)
print(f"按数值排序: {str_nums2}")
```

运行结果：

```text
按数值排序: ['1', '2', '3', '10', '20']
```

**sort() 原地修改验证**

```python
original = [5, 3, 1, 4, 2]
ref = original
original.sort()
print(f"original: {original}")
print(f"ref 同步变化: {ref}")
print(f"original is ref: {original is ref}")
```

运行结果：

```text
original: [1, 2, 3, 4, 5]
ref 同步变化: [1, 2, 3, 4, 5]
original is ref: True
```

`sort()` 原地修改意味着所有指向同一个列表的引用都会看到排序后的结果——`ref` 和 `original` 指向同一个列表对象，`sort()` 后两者都变成有序的。

### 2.2 sorted() 函数

`sorted()` 是 Python 内置函数，接收任何可迭代对象，返回一个新的已排序列表，**不修改原数据**。语法如下：

```python
sorted(iterable, key=None, reverse=False)
```

- **iterable**：可迭代对象（列表、元组、字符串、字典、range 等）
- **key**：排序依据函数（同 `sort`）
- **reverse**：是否降序（同 `sort`）

**列表排序**

```python
numbers = [3, 1, 4, 1, 5, 9, 2, 6]
print(f"原始列表: {numbers}")
sorted_nums = sorted(numbers)
print(f"sorted() 结果: {sorted_nums}")
print(f"原列表不变: {numbers}")
print(f"是不同对象: {sorted_nums is not numbers}")
```

运行结果：

```text
原始列表: [3, 1, 4, 1, 5, 9, 2, 6]
sorted() 结果: [1, 1, 2, 3, 4, 5, 6, 9]
原列表不变: [3, 1, 4, 1, 5, 9, 2, 6]
是不同对象: True
```

`sorted()` 创建了一个全新的列表，原列表完全不变。这是 `sorted()` 与 `sort()` 最重要的区别。

**sorted() 接受多种类型**

与 `sort()` 只能用于列表不同，`sorted()` 可以接受任何可迭代对象：

```python
# 元组
tup = (5, 2, 8, 1, 9)
sorted_tup = sorted(tup)
print(f"元组 sorted: {sorted_tup}, 类型: {type(sorted_tup).__name__}")

# 字符串
s = "python"
sorted_s = sorted(s)
print(f"字符串 sorted: {sorted_s}")
print(f"join 后: {''.join(sorted_s)}")

# 字典（按 key 排序）
d = {"banana": 3, "apple": 1, "cherry": 2}
sorted_d = sorted(d)
print(f"字典 sorted: {sorted_d}")

# range
sorted_r = sorted(range(5, 0, -1))
print(f"range sorted: {sorted_r}")
```

运行结果：

```text
元组 sorted: [1, 2, 5, 8, 9], 类型: list
字符串 sorted: ['h', 'n', 'o', 'p', 't', 'y']
join 后: hnopty
字典 sorted: ['apple', 'banana', 'cherry']
range sorted: [1, 2, 3, 4, 5]
```

无论输入什么类型的可迭代对象，`sorted()` 的**返回值总是列表**。对元组排序返回列表，对字符串排序返回字符列表，对字典排序返回键的列表。如果需要保留原类型，需要额外转换：

```python
# 元组排序后转回元组
tup = (5, 2, 8, 1, 9)
sorted_tup = tuple(sorted(tup))
print(f"元组排序: {sorted_tup}, 类型: {type(sorted_tup).__name__}")
```

运行结果：

```text
元组排序: (1, 2, 5, 8, 9), 类型: tuple
```

### 2.3 key 参数与自定义排序

`key` 是排序中最强大也最常用的参数。它接收一个函数，对每个元素调用该函数，用返回值作为排序依据——**排的是 key 函数的返回值，但结果中的元素仍然是原始元素**。

**按字符串长度排序**

```python
words = ["python", "is", "awesome", "and", "fun"]
sorted_by_len = sorted(words, key=len)
print(f"原始: {words}")
print(f"按长度排序: {sorted_by_len}")
```

运行结果：

```text
原始: ['python', 'is', 'awesome', 'and', 'fun']
按长度排序: ['is', 'and', 'fun', 'python', 'awesome']
```

`key=len` 让排序按每个字符串的 `len()` 返回值排列。`"is"` 长度 2 最短排第一，`"awesome"` 长度 7 最长排最后。注意：结果列表中的元素仍是原始字符串，不是长度数字。

**按绝对值排序**

```python
nums = [-5, 3, -1, 4, -2, 0]
sorted_abs = sorted(nums, key=abs)
print(f"原始: {nums}")
print(f"按绝对值排序: {sorted_abs}")
```

运行结果：

```text
原始: [-5, 3, -1, 4, -2, 0]
按绝对值排序: [0, -1, -2, 3, 4, -5]
```

`key=abs` 按绝对值排序：`0 < |-1| < |-2| < |3| < |4| < |-5|`，但结果中保留原始值（含负号）。

**忽略大小写排序**

```python
names = ["Alice", "bob", "Charlie", "david", "Eve"]
sorted_case = sorted(names, key=str.lower)
print(f"原始: {names}")
print(f"忽略大小写: {sorted_case}")
```

运行结果：

```text
原始: ['Alice', 'bob', 'Charlie', 'david', 'Eve']
忽略大小写: ['Alice', 'bob', 'Charlie', 'david', 'Eve']
```

`key=str.lower` 把每个字符串转为小写后再比较，`"alice" < "bob" < "charlie" < "david" < "eve"`，但结果中保留原始大小写。

**按元组的某元素排序**

```python
students = [("Alice", 90), ("Bob", 85), ("Charlie", 78), ("Diana", 95)]
sorted_by_score = sorted(students, key=lambda x: x[1])
sorted_by_name = sorted(students, key=lambda x: x[0])
print(f"按分数升序: {sorted_by_score}")
print(f"按姓名升序: {sorted_by_name}")
```

运行结果：

```text
按分数升序: [('Charlie', 78), ('Bob', 85), ('Alice', 90), ('Diana', 95)]
按姓名升序: [('Alice', 90), ('Bob', 85), ('Charlie', 78), ('Diana', 95)]
```

`lambda x: x[1]` 取元组的第二个元素（分数）作为排序依据，`lambda x: x[0]` 取第一个元素（姓名）。

**按字典的某字段排序**

```python
people = [
    {"name": "Alice", "age": 30, "city": "Beijing"},
    {"name": "Bob", "age": 25, "city": "Shanghai"},
    {"name": "Charlie", "age": 35, "city": "Guangzhou"},
]
sorted_by_age = sorted(people, key=lambda p: p["age"])
print("按年龄排序:")
for p in sorted_by_age:
    print(f"  {p['name']}: {p['age']}岁, {p['city']}")
```

运行结果：

```text
按年龄排序:
  Bob: 25岁, Shanghai
  Alice: 30岁, Beijing
  Charlie: 35岁, Guangzhou
```

`lambda p: p["age"]` 提取字典中的 `"age"` 字段作为排序键。

**使用 operator.itemgetter 替代 lambda**

```python
from operator import itemgetter

students2 = [("Alice", 90), ("Bob", 85), ("Charlie", 78)]
sorted_getter = sorted(students2, key=itemgetter(1))
print(f"itemgetter 排序: {sorted_getter}")
```

运行结果：

```text
itemgetter 排序: [('Charlie', 78), ('Bob', 85), ('Alice', 90)]
```

`itemgetter(1)` 等价于 `lambda x: x[1]`，但性能更好——因为它在 C 层面实现，避免了 Python 函数调用的开销。在简单取索引的场景中，推荐用 `itemgetter` 代替 `lambda`。

**复杂 key 函数**

```python
products = [("苹果", 5.5, 100), ("香蕉", 3.0, 200), ("橙子", 4.0, 150), ("葡萄", 8.0, 50)]

# 按总价（单价 * 数量）排序
sorted_by_total = sorted(products, key=lambda x: x[1] * x[2])
print("按总价排序:")
for name, price, qty in sorted_by_total:
    print(f"  {name}: 单价{price} x {qty} = {price * qty}")
```

运行结果：

```text
按总价排序:
  葡萄: 单价8.0 x 50 = 400.0
  苹果: 单价5.5 x 100 = 550.0
  香蕉: 单价3.0 x 200 = 600.0
  橙子: 单价4.0 x 150 = 600.0
```

`key` 函数可以执行任意计算——`lambda x: x[1] * x[2]` 计算总价（单价乘以数量），按总价排序。

**自定义排序函数（非 lambda）**

```python
def by_word_complexity(word):
    """按复杂度排序：元音字母少的排前面，元音相同时短的排前面"""
    vowels = "aeiouAEIOU"
    vowel_count = sum(1 for c in word if c in vowels)
    return (vowel_count, len(word))

words = ["hello", "sky", "beautiful", "fly", "aeiou"]
sorted_complex = sorted(words, key=by_word_complexity)
print(f"按元音+长度排序: {sorted_complex}")
```

运行结果：

```text
按元音+长度排序: ['sky', 'fly', 'hello', 'aeiou', 'beautiful']
```

`key` 函数不一定要是 lambda——任何普通函数都可以作为 `key`，只要它接收一个参数返回一个用于比较的值。这里 `by_word_complexity` 返回一个元组 `(vowel_count, length)`，Python 会先按元音数排，元音数相同时再按长度排。

### 2.4 reverse 参数与降序排序

`reverse` 是一个布尔参数，控制排序方向：`False`（默认）为升序，`True` 为降序。

**基本降序排序**

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
asc = sorted(nums)
desc = sorted(nums, reverse=True)
print(f"升序: {asc}")
print(f"降序: {desc}")
```

运行结果：

```text
升序: [1, 1, 2, 3, 4, 5, 6, 9]
降序: [9, 6, 5, 4, 3, 2, 1, 1]
```

**list.sort() 降序**

```python
nums2 = [5, 2, 8, 1, 9, 3]
nums2.sort(reverse=True)
print(f"sort(reverse=True): {nums2}")
```

运行结果：

```text
sort(reverse=True): [9, 8, 5, 3, 2, 1]
```

**key + reverse 组合**

```python
words = ["python", "is", "awesome", "and", "fun"]
sorted_len_desc = sorted(words, key=len, reverse=True)
print(f"按长度降序: {sorted_len_desc}")
```

运行结果：

```text
按长度降序: ['awesome', 'python', 'and', 'fun', 'is']
```

`key=len` 先按长度排序，`reverse=True` 将结果反转——最长的在前，最短的在后。

**按分数降序排序**

```python
students = [("Alice", 90), ("Bob", 85), ("Charlie", 78), ("Diana", 95)]
sorted_score_desc = sorted(students, key=lambda x: x[1], reverse=True)
print("按分数降序:")
for name, score in sorted_score_desc:
    print(f"  {name}: {score}")
```

运行结果：

```text
按分数降序:
  Diana: 95
  Alice: 90
  Bob: 85
  Charlie: 78
```

**实现降序的三种方式**

```python
nums = [3, 1, 4, 1, 5]

# 方式1: reverse=True
r1 = sorted(nums, reverse=True)

# 方式2: 先升序再反转
r2 = sorted(nums)[::-1]

# 方式3: 用负 key 实现降序（仅适用于数字 key）
r3 = sorted(nums, key=lambda x: -x)

print(f"reverse=True:      {r1}")
print(f"sorted()[::-1]:    {r2}")
print(f"key=lambda x: -x:  {r3}")
```

运行结果：

```text
reverse=True:      [5, 4, 3, 1, 1]
sorted()[::-1]:    [5, 4, 3, 1, 1]
key=lambda x: -x:  [5, 4, 3, 1, 1]
```

三种方式结果相同，但适用场景不同：

- `reverse=True`：最通用、最推荐，适用于所有类型
- `[::-1]`：创建了额外的列表切片，不如 `reverse=True` 高效
- `key=lambda x: -x`：只适用于数字 key，对字符串不适用（`-"abc"` 会报错）

### 2.5 稳定排序与多条件排序

Python 的排序是**稳定的**——当两个元素的 key 相同时，它们保持在原列表中的相对顺序。这个特性是实现多条件排序的基础。

#### 2.5.1 稳定排序验证

```python
data = [("A", 3), ("B", 1), ("C", 3), ("D", 2), ("E", 3)]
sorted_by_val = sorted(data, key=lambda x: x[1])
print(f"原始: {data}")
print(f"按值排序: {sorted_by_val}")
```

运行结果：

```text
原始: [('A', 3), ('B', 1), ('C', 3), ('D', 2), ('E', 3)]
按值排序: [('B', 1), ('D', 2), ('A', 3), ('C', 3), ('E', 3)]
```

`A(3)`、`C(3)`、`E(3)` 三个元素的 key 都是 3，排序后它们保持了原始顺序 `A → C → E`，没有被打乱。这就是稳定排序。

#### 2.5.2 多条件排序——元组 key

当需要按多个条件排序时，最简洁的方式是用元组 key——`key` 函数返回一个元组，Python 按元组的各元素依次比较：

```python
students = [
    ("Charlie", 85), ("Alice", 90), ("Bob", 85),
    ("Diana", 90), ("Eve", 85),
]
# 先按分数升序，分数相同的按姓名升序
sorted_tuple = sorted(students, key=lambda x: (x[1], x[0]))
print(f"元组key一次排: {sorted_tuple}")
```

运行结果：

```text
元组key一次排: [('Bob', 85), ('Charlie', 85), ('Eve', 85), ('Alice', 90), ('Diana', 90)]
```

`key=lambda x: (x[1], x[0])` 返回元组 `(分数, 姓名)`，Python 先按分数比较，分数相同时再按姓名比较。85 分的三人按姓名排序为 Bob → Charlie → Eve。

#### 2.5.3 多条件排序——利用稳定性分步排

当不同条件需要不同方向（如分数升序 + 姓名降序）时，元组 key 就不够用了——`reverse=True` 会同时反转所有条件。这时可以利用稳定排序的特性，分步排序：

```python
# 需求：分数升序 + 姓名降序
students2 = [
    ("Charlie", 85), ("Alice", 90), ("Bob", 85),
    ("Diana", 90), ("Eve", 85),
]

# 第1步：先按次要条件排（姓名降序）
sorted_name_desc = sorted(students2, key=lambda x: x[0], reverse=True)
# 第2步：再按主要条件排（分数升序）——稳定排序保证姓名降序不被打乱
sorted_mixed = sorted(sorted_name_desc, key=lambda x: x[1])

print(f"分数升序+姓名降序: {sorted_mixed}")
```

运行结果：

```text
分数升序+姓名降序: [('Eve', 85), ('Charlie', 85), ('Bob', 85), ('Diana', 90), ('Alice', 90)]
```

分步排序的原理：

1. 先按次要条件（姓名降序）排好 → `Eve, Diana, Charlie, Bob, Alice`
2. 再按主要条件（分数升序）排 → 稳定排序保证相同分数的人保持第 1 步的顺序
3. 85 分的三人保持 `Eve → Charlie → Bob`（第 1 步的姓名降序），90 分的两人保持 `Diana → Alice`

**规则记忆：多步排序时，从最低优先级的条件开始排，最后排最高优先级的条件。**

#### 2.5.4 多级排序实战

```python
class_data = [
    {"name": "Alice", "class": "B", "score": 90},
    {"name": "Bob", "class": "A", "score": 85},
    {"name": "Charlie", "class": "B", "score": 90},
    {"name": "Diana", "class": "A", "score": 85},
    {"name": "Eve", "class": "B", "score": 85},
]

# 要求：先按班级升序(A<B)，再按分数降序，再按姓名升序
sorted_name = sorted(class_data, key=lambda x: x["name"])           # 3. 姓名升序
sorted_score = sorted(sorted_name, key=lambda x: x["score"], reverse=True)  # 2. 分数降序
sorted_class = sorted(sorted_score, key=lambda x: x["class"])       # 1. 班级升序

print("多级排序结果（班级A<B, 分数降序, 姓名升序）:")
for s in sorted_class:
    print(f"  {s['class']}班 {s['name']}: {s['score']}")
```

运行结果：

```text
多级排序结果（班级A<B, 分数降序, 姓名升序）:
  A班 Bob: 85
  A班 Diana: 85
  B班 Alice: 90
  B班 Charlie: 90
  B班 Eve: 85
```

三级排序时，从最低优先级（姓名）开始排，最后排最高优先级（班级）。`A` 班排在 `B` 班前面，班级内分数高的在前，分数相同的按姓名升序。

### 2.6 sort() 与 sorted() 的选择

| 场景 | 推荐使用 | 原因 |
|------|---------|------|
| 不需要保留原列表 | `list.sort()` | 原地修改，省内存 |
| 需要保留原列表 | `sorted()` | 不修改原数据 |
| 列表很大，想省内存 | `list.sort()` | 不创建新列表 |
| 排序非列表类型 | `sorted()` | `sort()` 只能用于 list |
| 在表达式中使用排序结果 | `sorted()` | 返回值可直接使用 |
| 在函数链式调用中 | `sorted()` | 返回值可以继续操作 |

```python
# sorted() 在表达式中的优势
top3 = sorted(scores, reverse=True)[:3]  # 直接取前3名
# sort() 不行，因为它返回 None
# top3 = scores.sort()[:3]  # TypeError: 'NoneType' is not subscriptable
```

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

| 场景 | 推荐写法 | 不推荐写法 | 原因 |
|------|---------|-----------|------|
| 简单升序 | `lst.sort()` 或 `sorted(lst)` | 冒泡排序手写 | 内置排序快得多 |
| 保留原列表 | `sorted(lst)` | `lst[:]; lst.sort()` | sorted 更简洁 |
| 自定义排序 | `sorted(lst, key=fn)` | `for` 循环 + 手动比较 | key 函数更直观 |
| 降序排序 | `sorted(lst, reverse=True)` | `sorted(lst)[::-1]` | reverse 避免额外切片 |
| 取 Top N | `sorted(lst, reverse=True)[:N]` | `lst.sort(); lst[-N:]` | sorted 不改原列表 |
| 多条件同向 | `sorted(lst, key=lambda x: (x[1], x[0]))` | 多次 sort 分步 | 元组 key 一步到位 |
| 多条件异向 | 分步排序（先次要后主要） | 尝试用元组 key + reverse | reverse 会影响所有 |
| 按索引取值 | `key=itemgetter(1)` | `key=lambda x: x[1]` | itemgetter 更快 |
| 按属性取值 | `key=attrgetter('name')` | `key=lambda x: x.name` | attrgetter 更快 |
| 忽略大小写 | `key=str.lower` | `key=lambda x: x.lower()` | 直接传方法引用更快 |

### 3.2 常见错误模式

**错误一：把 sort() 的返回值赋给变量**

```python
# 错误：sort() 返回 None
lst = [3, 1, 2]
lst = lst.sort()  # lst 变成 None！
print(lst)        # None

# 正确：不要接收返回值
lst = [3, 1, 2]
lst.sort()
print(lst)        # [1, 2, 3]
```

运行结果：

```text
None
[1, 2, 3]
```

**错误二：对字符串数字排序**

```python
# 错误：按字符串排序，不是数值排序
str_nums = ["10", "2", "1", "20", "3"]
str_nums.sort()
print(f"字符串排序: {str_nums}")  # ['1', '10', '2', '20', '3']

# 正确：用 key=int 按数值排序
str_nums2 = ["10", "2", "1", "20", "3"]
str_nums2.sort(key=int)
print(f"数值排序: {str_nums2}")  # ['1', '2', '3', '10', '20']
```

运行结果：

```text
字符串排序: ['1', '10', '2', '20', '3']
数值排序: ['1', '2', '3', '10', '20']
```

**错误三：多条件异向排序用 reverse=True**

```python
# 错误：reverse=True 会反转所有条件
students = [("Alice", 90), ("Bob", 85), ("Charlie", 90)]
# 想要：分数降序 + 姓名升序
wrong = sorted(students, key=lambda x: (x[1], x[0]), reverse=True)
# 结果变成：分数降序 + 姓名降序（两个都反了）
print(f"错误结果: {wrong}")

# 正确：分步排序（先姓名升序，再分数降序）
right = sorted(sorted(students, key=lambda x: x[0]), key=lambda x: x[1], reverse=True)
print(f"正确结果: {right}")
```

运行结果：

```text
错误结果: [('Charlie', 90), ('Alice', 90), ('Bob', 85)]
正确结果: [('Alice', 90), ('Charlie', 90), ('Bob', 85)]
```

**错误四：对混合类型列表排序**

```python
# Python 3 不支持不同类型直接比较
mixed = [1, "hello", 3, "world"]
try:
    mixed.sort()
except TypeError as e:
    print(f"混合类型排序 -> TypeError: {e}")

# 解决：用 key 转为统一类型
mixed2 = [1, "hello", 3, "world"]
mixed2.sort(key=str)
print(f"按字符串排序: {mixed2}")
```

运行结果：

```text
混合类型排序 -> TypeError: '<' not supported between instances of 'str' and 'int'
按字符串排序: [1, 3, 'hello', 'world']
```

Python 3 不再支持不同类型之间的隐式比较（Python 2 可以比较任意类型）。用 `key=str` 统一转为字符串比较是一种解决方案。

**错误五：在循环中重复排序**

```python
# 不推荐：每次添加后都排序
data = []
for i in [5, 3, 8, 1]:
    data.append(i)
    data.sort()  # 每次都排序，O(n * n*log(n))
print(data)

# 推荐：全部添加后一次排序
data2 = [5, 3, 8, 1]
data2.sort()  # 一次排序，O(n*log(n))
print(data2)
```

运行结果：

```text
[1, 3, 5, 8]
[1, 3, 5, 8]
```

如果只需要最终排序结果，先收集所有数据再一次性排序，比每次插入后就排序高效得多。

|----------|------|--------|----------|---------|--------|

### 3.4 key 参数常用模式速查

| 排序需求 | key 写法 | 示例 |
|---------|---------|------|
| 按长度 | `key=len` | `sorted(words, key=len)` |
| 按绝对值 | `key=abs` | `sorted(nums, key=abs)` |
| 忽略大小写 | `key=str.lower` | `sorted(words, key=str.lower)` |

### 3.5 性能对比

`list.sort()` 和 `sorted()` 都使用 Timsort 算法，时间复杂度为 O(n log n)。但 `list.sort()` 略快，因为它不需要创建新列表：

```python
import time

N = 100000
data = list(range(N, 0, -1))  # 逆序列表

# list.sort()
data_copy1 = data[:]
start = time.perf_counter()
data_copy1.sort()
time_sort = time.perf_counter() - start

# sorted()
data_copy2 = data[:]
start = time.perf_counter()
result_sorted = sorted(data_copy2)
time_sorted = time.perf_counter() - start

print(f"列表大小: {N}")
print(f"list.sort():  {time_sort:.6f} 秒")
print(f"sorted():     {time_sorted:.6f} 秒")
print(f"sort 更快: {time_sorted / time_sort:.2f}x")
```

运行结果：

```text
列表大小: 100000
list.sort():  0.000171 秒
sorted():     0.000325 秒
sort 更快: 1.91x
```

`list.sort()` 比 `sorted()` 快约 1.5-2 倍，因为 `sorted()` 需要额外创建一个新列表并拷贝元素。在大数据量排序时，如果不需要保留原列表，优先用 `list.sort()`。

## 4. 原理

### 4.1 Timsort 算法简介

Python 的排序底层使用 **Timsort** 算法，由 Tim Peters 在 2002 年为 Python 设计。Timsort 是一种混合排序算法，结合了归并排序和插入排序的优点：

```text
Timsort 的核心思想：

  1. 扫描列表，识别已经有序的片段（"run"）
     - 升序片段：直接使用
     - 降序片段：反转后使用
     - 太短的片段（< 64 个元素）：用插入排序扩展到足够长

  2. 将这些有序片段用归并排序合并
     - 两两合并，直到只剩一个完整有序的列表
     - 归并时利用已经有序的特性，避免重复比较

时间复杂度：
  - 最好情况（已排好序）：O(n)  ← 只需扫描一次，不交换
  - 最坏情况（完全逆序）：O(n log n)
  - 平均情况：O(n log n)

空间复杂度：O(n)  ← 需要临时数组辅助归并
```

Timsort 的优势在于**对部分有序的数据特别快**——如果列表已经基本有序，Timsort 接近 O(n) 的性能。这比纯归并排序或快速排序更实用，因为实际数据往往是有部分有序性的。

**Timsort 的稳定性**

Timsort 是**稳定排序**——当两个元素的 key 相同时，它们保持在原列表中的相对顺序。Timsort 的归并操作在遇到相等元素时，总是先取左侧（原序列中靠前的）元素，从而保证了稳定性。

```python
# 验证稳定性
pairs = [(1, "a"), (2, "b"), (1, "c"), (2, "d"), (1, "e")]
sorted_pairs = sorted(pairs, key=lambda x: x[0])
print(f"原始: {pairs}")
print(f"排序: {sorted_pairs}")
```

运行结果：

```text
原始: [(1, 'a'), (2, 'b'), (1, 'c'), (2, 'd'), (1, 'e')]
排序: [(1, 'a'), (1, 'c'), (1, 'e'), (2, 'b'), (2, 'd')]
```

key 为 1 的三个元素 `(1,a)`、`(1,c)`、`(1,e)` 保持了原始顺序 `a → c → e`；key 为 2 的两个元素 `(2,b)`、`(2,d)` 也保持了原始顺序 `b → d`。

### 4.2 key 函数的调用机制

`key` 参数的工作方式是：对每个元素调用一次 `key` 函数，把返回值缓存起来作为排序依据。排序完成后，按 key 缓存的值排列原始元素：

```text
key 函数的执行流程（以 sorted(["python", "is", "fun"], key=len) 为例）：

  1. 对每个元素调用 key 函数，缓存结果：
     "python" -> len("python") = 6
     "is"     -> len("is")     = 2
     "fun"    -> len("fun")    = 3

  2. 按 key 缓存值排序：
     2 ("is") < 3 ("fun") < 6 ("python")

  3. 返回原始元素（按 key 排好的顺序）：
     ["is", "fun", "python"]
```

关键点：**每个元素只调用一次 key 函数**——不是在每次比较时都调用。这是 Python 排序的一个重要优化，称为"Schwartzian Transform"（施瓦茨变换）。如果对 n 个元素排序，不做 key 缓存的话，key 函数会被调用 O(n log n) 次；做了缓存后只调用 n 次。

```python
# 验证 key 函数只调用一次
call_count = 0
def counting_key(x):
    global call_count
    call_count += 1
    return x

data = [3, 1, 4, 1, 5]
sorted(data, key=counting_key)
print(f"列表长度: {len(data)}, key 调用次数: {call_count}")
```

运行结果：

```text
列表长度: 5, key 调用次数: 5
```

5 个元素，key 函数被调用 5 次——每个元素一次。

### 4.3 sort() 返回 None 的设计原因

Python 的排序方法 `list.sort()` 返回 `None` 而不是排序后的列表，这是有意为之的设计——它遵循了 Python 的"原地修改方法返回 None"惯例：

```text
Python 中所有原地修改方法都返回 None：

  lst.sort()        → None（原地排序）
  lst.append(x)     → None（原地追加）
  lst.extend(iter)  → None（原地扩展）
  lst.reverse()     → None（原地反转）

  vs.

  sorted(lst)        → 新列表（不修改原列表）
  lst + [x]          → 新列表（不修改原列表）
  reversed(lst)      → 新迭代器（不修改原列表）
```

这个惯例的目的是**防止误用**——如果 `sort()` 返回排序后的列表，使用者可能误以为它创建了一个新列表，而原列表没有被修改：

```python
# 如果 sort() 返回新列表（假设的行为，Python 不是这样设计的）
original = [3, 1, 2]
sorted_copy = original.sort()  # 如果这行创建了新列表...
# original 仍然是 [3, 1, 2]  ← 使用者可能误以为原列表没变
# 但实际上 original 已经被原地修改了 [1, 2, 3]！

# Python 的设计：返回 None 让你明确知道"这是原地操作"
original = [3, 1, 2]
result = original.sort()
# result is None → 你知道 sort 不会返回新列表
# original is [1, 2, 3] → 原列表被修改了
```

### 4.4 `__lt__` 与 key 的关系

如果不提供 `key` 参数，Python 的排序默认使用元素自身的比较方法——具体来说是比较运算符 `<`（即 `__lt__` 方法）：

```text
默认排序流程（无 key 参数）：
  比较 a 和 b → 调用 a < b → 调用 a.__lt__(b)

有 key 参数的排序流程：
  不直接比较元素本身，而是比较 key(a) 和 key(b)
  key(a) < key(b) → key(a).__lt__(key(b))
```

这意味着自定义类可以通过实现 `__lt__` 方法来控制排序行为：

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def __repr__(self):
        return f"{self.name}({self.score})"

    def __lt__(self, other):
        # 定义小于：分数低的"更小"（排前面）
        return self.score < other.score

students = [Student("Alice", 90), Student("Bob", 78), Student("Charlie", 95)]

# 方式1：用 key 函数排序
by_key = sorted(students, key=lambda s: s.score)
print(f"key 排序: {by_key}")

# 方式2：利用 __lt__ 方法直接排序（不需要 key）
by_lt = sorted(students)
print(f"__lt__ 排序: {by_lt}")
```

运行结果：

```text
key 排序: [Bob(78), Alice(90), Charlie(95)]
__lt__ 排序: [Bob(78), Alice(90), Charlie(95)]
```

两种方式结果相同。`key` 函数是"临时指定排序依据"，`__lt__` 是"类自行定义排序行为"——如果类的自然排序就是按某个属性，实现 `__lt__` 更自然；如果只是临时按某属性排序，用 `key` 更灵活。

### 4.5 版本号排序的实现原理

版本号如 `"3.0.1"` 是点分字符串，直接用字符串排序会得到错误结果。正确的做法是将版本号解析为整数元组后再排序：

```python
versions = ["3.0.1", "2.9.0", "3.1.0", "2.8.5", "3.0.0", "1.5.2"]

def version_key(v):
    """将 '3.0.1' 转为 (3, 0, 1)，用元组比较"""
    return tuple(int(x) for x in v.split("."))

sorted_versions = sorted(versions, key=version_key)
print("版本号排序:")
for v in sorted_versions:
    print(f"  v{v}")
```

运行结果：

```text
版本号排序:
  v1.5.2
  v2.8.5
  v2.9.0
  v3.0.0
  v3.0.1
  v3.1.0
```

`version_key` 把 `"3.0.1"` 转成 `(3, 0, 1)`，Python 的元组比较是逐元素比较——先比 3 和 2，`3 > 2` 直接决定结果，不需要比较后面的部分。这与字典序对字符串的比较行为一致，但用的是整数比较而非字符比较。

## 5. 总结

本文围绕 Python 的两种排序方式——`list.sort()` 和 `sorted()`——展开，系统介绍了以下内容：

- **list.sort() 方法**：列表原地排序，返回 `None`，不创建新列表；适用于不需要保留原列表的场景；注意不能把返回值赋给变量
- **sorted() 函数**：内置函数，返回新的已排序列表，不修改原数据；适用于所有可迭代对象（列表、元组、字符串、字典、range 等）；返回值始终是列表
- **key 参数**：指定排序依据函数，对每个元素调用一次返回排序键；支持 `len`、`abs`、`str.lower` 等内置函数、`lambda` 表达式、`operator.itemgetter` / `attrgetter` 以及自定义函数
- **reverse 参数**：控制升序（`False`，默认）或降序（`True`）；适用于所有类型；`key=lambda x: -x` 只对数字有效，不如 `reverse=True` 通用
- **稳定排序**：Python 排序是稳定的，相同 key 的元素保持原始顺序；这是多条件排序的基础
- **多条件排序**：同方向用元组 key 一步到位（`key=lambda x: (x[1], x[0])`）；异方向用分步排序（先排次要条件，最后排主要条件，利用稳定性保证）
- **sort() vs sorted() 选择**：不需要保留原列表用 `sort()`（省内存、略快）；需要保留原列表或排序非列表类型用 `sorted()`
- **最佳实践**：推荐 vs 不推荐写法对比、5 种常见错误模式（`sort()` 返回值赋值、字符串数字排序、多条件异向用 reverse、混合类型排序、循环中重复排序）、方法速查表、key 参数常用模式速查、性能对比（`sort()` 比 `sorted()` 快约 1.9 倍）
- **原理**：Timsort 算法（混合归并+插入排序，部分有序数据 O(n)，稳定）、key 函数调用机制（Schwartzian Transform，每个元素只调用一次 key）、`sort()` 返回 `None` 的设计原因（防止误用原地修改方法）、`__lt__` 与 key 的关系（自定义类通过 `__lt__` 定义自然排序）、版本号排序原理（字符串转整数元组后排序）
