# 字典的 keys / values / items 方法

## 1. 介绍

### 1.1 什么是 keys / values / items

在 Python 中，`keys()`、`values()`、`items()` 是字典的三个核心方法，分别用于获取字典的**所有键**、**所有值**和**所有键值对**。它们是你与字典数据交互的"三把钥匙"——遍历、查找、统计、过滤，几乎所有针对字典的批量操作都离不开这三个方法。

在 Python 2 中，这三个方法返回的是**列表**——一份完整的拷贝，字典改动后列表不会变。从 Python 3 开始，它们返回的是**视图对象（view object）**——一个动态的窗口，透过它看到的永远是字典的实时状态。这个变化不仅节省了内存，还带来了集合运算等新能力。

三个方法返回的类型分别是 `dict_keys`、`dict_values`、`dict_items`，它们都不属于 Python 的基本数据类型，而是字典专用的视图类型。

### 1.2 解决什么问题

假设你正在管理一个班级的学生信息，需要完成这些任务：

- 获取所有学生的姓名列表（`keys()`）
- 统计全班的平均分（`values()`）
- 逐一查看每个学生的详细信息（`items()`）
- 检查某个学生是否在班级中（`keys()` + `in`）
- 找出成绩低于 60 分的学生（`items()` + 过滤）

这些场景在日常开发中无处不在。`keys()`、`values()`、`items()` 就是 Python 为你提供的三个标准入口，让你不必写循环手工提取数据。

### 1.3 最简示例

用一个最小的例子，一次看清三个方法各自返回什么：

```python
student = {"name": "张三", "age": 20, "city": "北京"}

print(student.keys())    # 返回所有键
print(student.values())  # 返回所有值
print(student.items())   # 返回所有键值对
```

**运行结果**：

```text
dict_keys(['name', 'age', 'city'])
dict_values(['张三', 20, '北京'])
dict_items([('name', '张三'), ('age', 20), ('city', '北京')])
```

三个方法分别返回了 `dict_keys`、`dict_values`、`dict_items` 三种视图对象。它们的 `print` 结果看起来像列表，但类型完全不同——视图是动态的，列表是静态的，这个区别会影响你的代码行为。

## 2. 核心内容

### 2.1 keys() 方法

`keys()` 返回字典中所有键的视图对象。它是三个方法中最常用的一个，因为你对字典的大部分操作——遍历、成员判断、集合运算——都围绕键展开。

#### 2.1.1 基本用法与返回类型

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

keys_view = student.keys()
print(f"返回值: {keys_view}")
print(f"返回值类型: {type(keys_view)}")
```

**运行结果**：

```text
返回值: dict_keys(['name', 'age', 'city', 'score'])
返回值类型: <class 'dict_keys'>
```

**关键点**：

- `keys()` 不接受任何参数，调用时只需 `dict.keys()`。
- 返回值是 `dict_keys` 视图对象，不是列表。直接对它进行索引访问 `keys_view[0]` 会抛出 `TypeError`。
- 视图对象是可迭代的，可以直接用于 `for` 循环、`in` 判断、`list()` 转换。

#### 2.1.2 成员判断

`in` 运算符配合 `keys()` 可以检查某个键是否存在于字典中：

```python
student = {"name": "张三", "age": 20, "city": "北京"}

# 用 keys() 判断键是否存在
print(f"'name' in keys: {'name' in student.keys()}")
print(f"'score' in keys: {'score' in student.keys()}")
```

**运行结果**：

```text
'name' in keys: True
'score' in keys: False
```

**简写形式**：在 Python 中，`key in dict` 等价于 `key in dict.keys()`。直接用字典本身更简洁，是社区约定俗成的写法：

```python
# 等价写法，更简洁
print(f"'name' in dict: {'name' in student}")
print(f"'score' in dict: {'score' in student}")
```

**运行结果**：

```text
'name' in dict: True
'score' in dict: False
```

**关键点**：`in` 操作在字典上的时间复杂度是 O(1)，无论字典有多大，判断速度都一样快。这是因为字典底层用哈希表实现，查找一个键不需要遍历全部数据。而 `in` 在列表上是 O(n)——列表越大越慢。这就是字典相比列表的巨大优势。

#### 2.1.3 遍历 keys()

`keys()` 返回的视图是可迭代的，可以直接用于 `for` 循环：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

for key in student.keys():
    print(f"键: {key}")
```

**运行结果**：

```text
键: name
键: age
键: city
键: score
```

**关键点**：在 Python 3 中，直接遍历字典 `for key in student` 等价于 `for key in student.keys()`。两种写法效果完全相同，但前者更简洁，是更常见的写法。`keys()` 写法在需要显式表达"我在遍历键"时更有可读性。

#### 2.1.4 转换为列表

视图对象不支持索引访问和切片。当你需要按位置访问元素、排序、或多次遍历时，需要将视图转换为列表：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

keys_list = list(student.keys())
print(f"转列表: {keys_list}")
print(f"类型: {type(keys_list)}")
print(f"第一个键: {keys_list[0]}")
print(f"键的数量: {len(keys_list)}")

# 排序后访问
sorted_keys = sorted(student.keys())
print(f"排序后的键: {sorted_keys}")
```

**运行结果**：

```text
转列表: ['name', 'age', 'city', 'score']
类型: <class 'list'>
第一个键: name
键的数量: 4
排序后的键: ['age', 'city', 'name', 'score']
```

**关键点**：

- `list(student.keys())` 创建一份键的列表快照。转换后，原字典的变化不会反映到这个列表中。
- `sorted()` 可以直接对视图排序，返回一个排好序的新列表，不需要先转 `list`。
- 在 Python 3.7+ 中，字典保持插入顺序，所以 `list(student.keys())` 的顺序就是键的插入顺序。

#### 2.1.5 集合运算

`dict_keys` 视图有一个独特的能力——它支持集合运算。因为字典的键是唯一的（无重复），视图的行为类似集合：

```python
# 场景：两个用户的权限配置，找出共有权限和独有权限
user_a_permissions = {"read": True, "write": True, "delete": False}
user_b_permissions = {"read": True, "write": False, "admin": True}

keys_a = user_a_permissions.keys()
keys_b = user_b_permissions.keys()

print(f"用户A的权限: {set(keys_a)}")
print(f"用户B的权限: {set(keys_b)}")

# 交集：两个用户共有的权限
print(f"共有权限 (&): {keys_a & keys_b}")

# 并集：所有权限的集合
print(f"所有权限 (|): {keys_a | keys_b}")

# 差集：用户A有但用户B没有的权限
print(f"用户A独有 (-): {keys_a - keys_b}")

# 对称差集：只在一个用户中出现的权限
print(f"独占权限 (^): {keys_a ^ keys_b}")
```

**运行结果**：

```text
用户A的权限: {'read', 'write', 'delete'}
用户B的权限: {'read', 'write', 'admin'}
共有权限 (&): {'read', 'write'}
所有权限 (|): {'read', 'write', 'delete', 'admin'}
用户A独有 (-): {'delete'}
独占权限 (^): {'delete', 'admin'}
```

**关键点**：

- `keys()` 视图支持 `&`（交集）、`|`（并集）、`-`（差集）、`^`（对称差集）四种集合运算。
- 集合运算的结果是 `set` 类型，不是 `dict_keys`。
- 运算双方可以是 `dict_keys` 和 `set`，也可以都是 `dict_keys`。
- 这是 `keys()` 相比 `list(dict.keys())`（先转列表）的独有优势——列表不支持集合运算。

### 2.2 values() 方法

`values()` 返回字典中所有值的视图对象。它的用法和 `keys()` 类似，但有两个关键区别：值可以重复，且 `dict_values` 不支持集合运算。

#### 2.2.1 基本用法与返回类型

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

values_view = student.values()
print(f"返回值: {values_view}")
print(f"返回值类型: {type(values_view)}")
```

**运行结果**：

```text
返回值: dict_values(['张三', 20, '北京', 95])
返回值类型: <class 'dict_values'>
```

**关键点**：`values()` 不接受任何参数。返回的 `dict_values` 视图和 `dict_keys` 一样是动态的——原字典改了值，视图立刻反映。

#### 2.2.2 成员判断

`in` 配合 `values()` 可以检查某个值是否存在于字典中：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

# 检查某个值是否在字典的值中
print(f"20 in values: {20 in student.values()}")
print(f"100 in values: {100 in student.values()}")
print(f"'张三' in values: {'张三' in student.values()}")
```

**运行结果**：

```text
20 in values: True
100 in values: False
'张三' in values: True
```

**重要区别**：`in dict` 判断的是**键**，不是值。这是初学者常犯的混淆点：

```python
# 'in dict' 判断的是键，不是值！
print(f"'张三' in dict (判断的是键): {'张三' in student}")    # False！张三是值不是键
print(f"'name' in dict (判断的是键): {'name' in student}")    # True
```

**运行结果**：

```text
'张三' in dict (判断的是键): False
'name' in dict (判断的是键): True
```

**关键点**：

- `key in dict` → 在键中查找（O(1)，哈希查找）
- `value in dict.values()` → 在值中查找（O(n)，需要遍历所有值）
- 值查找比键查找慢得多，因为值没有索引，必须逐个比较。如果需要频繁按值查找，应考虑反向构建一个"值→键"的映射字典。

#### 2.2.3 遍历 values()

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

for value in student.values():
    print(f"值: {value}")
```

**运行结果**：

```text
值: 张三
值: 20
值: 北京
值: 95
```

**关键点**：遍历 `values()` 时的顺序就是字典的插入顺序（Python 3.7+）。当你只关心值、不关心键时，用 `values()` 比遍历整个字典再取值更直接。

#### 2.2.4 转换为列表与统计

`values()` 的一个高频场景是统计数据——求和、最大值、最小值、平均值：

```python
scores = {"math": 95, "chinese": 88, "english": 92, "physics": 78}

values_list = list(scores.values())
print(f"转列表: {values_list}")
print(f"类型: {type(values_list)}")

# 统计：最高分、最低分、平均分
print(f"最高分: {max(values_list)}")
print(f"最低分: {min(values_list)}")
print(f"平均分: {sum(values_list) / len(values_list):.1f}")

# 从高到低排序
sorted_values = sorted(scores.values(), reverse=True)
print(f"从高到低排序: {sorted_values}")
```

**运行结果**：

```text
转列表: [95, 88, 92, 78]
类型: <class 'list'>
最高分: 95
最低分: 78
平均分: 88.3
从高到低排序: [95, 92, 88, 78]
```

**关键点**：`max()`、`min()`、`sum()`、`sorted()` 都可以直接接受视图对象作为参数，不需要先转列表。只有需要索引访问或切片时才需要 `list()` 转换。

#### 2.2.5 值不唯一与去重

字典的键是唯一的，但值可以重复。这意味着 `values()` 视图中可能有重复元素：

```python
scores = {"math": 95, "chinese": 95, "english": 88, "physics": 78}

values_list = list(scores.values())
print(f"所有值: {values_list}")
print(f"95 出现了 {values_list.count(95)} 次")

# 去重：转 set
unique_values = set(scores.values())
print(f"去重后的值: {unique_values}")
```

**运行结果**：

```text
所有值: [95, 95, 88, 78]
95 出现了 2 次
去重后的值: {88, 78, 95}
```

**关键点**：

- `dict_values` **不支持集合运算**——因为值可能有重复，而且值不一定是可哈希类型（如值是列表时就不可哈希）。
- 需要对值做集合运算时，先转 `set`：`set(dict.values())`。前提是所有值都是可哈希的。
- 如果值包含不可哈希类型（如列表、字典），转 `set` 会抛出 `TypeError`。

### 2.3 items() 方法

`items()` 返回字典中所有键值对的视图对象。每个键值对在视图中以**二元组（tuple）**的形式存在。它是遍历字典最强大的方式，因为同时拿到了键和值。

#### 2.3.1 基本用法与返回类型

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

items_view = student.items()
print(f"返回值: {items_view}")
print(f"返回值类型: {type(items_view)}")
```

**运行结果**：

```text
返回值: dict_items([('name', '张三'), ('age', 20), ('city', '北京'), ('score', 95)])
返回值类型: <class 'dict_items'>
```

**关键点**：`items()` 不接受任何参数。返回的 `dict_items` 视图中，每个元素是一个 `(key, value)` 元组。元组的第一个元素是键，第二个元素是值。

#### 2.3.2 遍历与元组解包

遍历 `items()` 时，最常见的做法是使用元组解包，直接把键和值分别赋给两个变量：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

# 元组解包：同时获取键和值
print("遍历键值对（解包访问）:")
for key, value in student.items():
    print(f"  {key}: {value}")
```

**运行结果**：

```text
遍历键值对（解包访问）:
  name: 张三
  age: 20
  city: 北京
  score: 95
```

不解包时，每次迭代拿到的是一个完整的元组：

```python
# 不解包：拿到的是元组
print("遍历键值对（不解包）:")
for item in student.items():
    print(f"  {item} (类型: {type(item)})")
```

**运行结果**：

```text
遍历键值对（不解包）:
  ('name', '张三') (类型: <class 'tuple'>)
  ('age', 20) (类型: <class 'tuple'>)
  ('city', '北京') (类型: <class 'tuple'>)
  ('score', 95) (类型: <class 'tuple'>)
```

**关键点**：元组解包写法 `for key, value in dict.items()` 是遍历字典最常用、最 Pythonic 的方式。当你同时需要键和值时，这种写法比先遍历键再 `dict[key]` 取值更高效（避免重复哈希查找），也更易读。

#### 2.3.3 过滤键值对

`items()` 配合字典推导式，可以灵活地过滤出满足条件的键值对：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95, "grade": "A"}

# 过滤出值类型为字符串的键值对
str_items = {k: v for k, v in student.items() if isinstance(v, str)}
print(f"字符串值的键值对: {str_items}")

# 过滤出数值大于等于 90 的键值对
high_scores = {k: v for k, v in student.items() if isinstance(v, (int, float)) and v >= 90}
print(f"高分键值对: {high_scores}")

# 过滤出特定前缀的键
filtered = {k: v for k, v in student.items() if k.startswith("a")}
print(f"以 'a' 开头的键: {filtered}")
```

**运行结果**：

```text
字符串值的键值对: {'name': '张三', 'city': '北京', 'grade': 'A'}
高分键值对: {'score': 95}
以 'a' 开头的键: {'age': 20}
```

**关键点**：`items()` + 字典推导式是处理字典数据的"黄金组合"。通过修改条件表达式，可以实现各种复杂的过滤逻辑，而不需要写多行循环代码。

#### 2.3.4 转换为列表

```python
student = {"name": "张三", "age": 20, "city": "北京"}

items_list = list(student.items())
print(f"转列表: {items_list}")
print(f"类型: {type(items_list)}")
print(f"第一个元素: {items_list[0]} (类型: {type(items_list[0])})")

# 通过索引访问元组内的键和值
first_item = items_list[0]
print(f"第一个键: {first_item[0]}")
print(f"第一个值: {first_item[1]}")
```

**运行结果**：

```text
转列表: [('name', '张三'), ('age', 20), ('city', '北京')]
类型: <class 'list'>
第一个元素: ('name', '张三') (类型: <class 'tuple'>)
第一个键: name
第一个值: 张三
```

**关键点**：`list(dict.items())` 返回的是一个列表，列表中的每个元素是一个二元组。转换后可以通过索引访问特定位置的键值对，但代价是创建了一份完整的数据拷贝。

#### 2.3.5 集合运算

当所有值都是可哈希类型时，`dict_items` 视图也支持集合运算。集合运算以**完整的键值对**为单位进行比较：

```python
dict_a = {"name": "Alice", "age": 30}
dict_b = {"name": "Alice", "age": 25, "city": "NYC"}

items_a = dict_a.items()
items_b = dict_b.items()

# 交集：两个字典中完全相同的键值对
common_items = items_a & items_b
print(f"交集 (&): {common_items}")

# 并集：所有键值对的集合（键冲突时后者覆盖）
all_items = items_a | items_b
print(f"并集 (|): {all_items}")

# 差集：dict_a 有但 dict_b 没有的键值对
diff_items = items_a - items_b
print(f"差集 (-): {diff_items}")
```

**运行结果**：

```text
交集 (&): {('name', 'Alice')}
并集 (|): {('name', 'Alice'), ('age', 30), ('age', 25), ('city', 'NYC')}
差集 (-): {('age', 30)}
```

**关键点**：

- 集合运算以**(键, 值)二元组**为单位比较。`('name', 'Alice')` 和 `('name', 'Bob')` 是不同的元素。
- `&` 交集返回两个字典中**键和值都完全相同**的键值对。
- 四种集合运算（`&`、`|`、`-`、`^`）的结果都是 `set` 类型，包含 `(key, value)` 元组。即使 `|` 并集返回了 `(key, value)` 元组，不会合并为字典——它就是一个普通的集合。
- `|` 并集中如果同一个键有不同的值，两个元组都会保留（如 `('age', 30)` 和 `('age', 25)` 都在结果中），因为它们是不同的元素。
- 如果值包含不可哈希类型（如列表），集合运算会抛出 `TypeError`。

#### 2.3.6 根据值反查键

`items()` 是根据值反查键的最佳工具——遍历所有键值对，找到值匹配的键：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

target_value = 95
# 找到值为 95 的所有键
keys = [k for k, v in student.items() if v == target_value]
print(f"值为 {target_value} 的键: {keys}")

# 找到值为字符串的键
str_keys = [k for k, v in student.items() if isinstance(v, str)]
print(f"值为字符串的键: {str_keys}")
```

**运行结果**：

```text
值为 95 的键: ['score']
值为字符串的键: ['name', 'city']
```

**关键点**：字典本身只能通过键查值（O(1)），反向通过值查键需要遍历（O(n)）。如果反向查找很频繁，应该考虑维护一个反向映射字典 `{v: k}`，将 O(n) 降到 O(1)。

### 2.4 视图的动态特性

视图对象最核心的特征是**动态性**——它不是字典数据的快照拷贝，而是一个实时反映字典状态的窗口。理解这一点，才能正确使用这三个方法。

#### 2.4.1 实时反映字典变化

```python
student = {"name": "张三", "age": 20, "city": "北京"}

# 获取三个视图
keys_view = student.keys()
values_view = student.values()
items_view = student.items()

print("--- 修改字典前 ---")
print(f"keys:   {list(keys_view)}")
print(f"values: {list(values_view)}")
print(f"items:  {list(items_view)}")

# 修改原字典：添加一个新键值对
student["score"] = 95

print("\n--- 添加 score=95 后 ---")
print(f"keys:   {list(keys_view)}")
print(f"values: {list(values_view)}")
print(f"items:  {list(items_view)}")

# 修改原字典：改一个已有键的值
student["age"] = 21

print("\n--- 修改 age=21 后 ---")
print(f"keys:   {list(keys_view)}")
print(f"values: {list(values_view)}")
print(f"items:  {list(items_view)}")

# 删除一个键
del student["city"]

print("\n--- 删除 city 后 ---")
print(f"keys:   {list(keys_view)}")
print(f"values: {list(values_view)}")
print(f"items:  {list(items_view)}")
```

**运行结果**：

```text
--- 修改字典前 ---
keys:   ['name', 'age', 'city']
values: ['张三', 20, '北京']
items:  [('name', '张三'), ('age', 20), ('city', '北京')]

--- 添加 score=95 后 ---
keys:   ['name', 'age', 'city', 'score']
values: ['张三', 20, '北京', 95]
items:  [('name', '张三'), ('age', 20), ('city', '北京'), ('score', 95)]

--- 修改 age=21 后 ---
keys:   ['name', 'age', 'city', 'score']
values: ['张三', 21, '北京', 95]
items:  [('name', '张三'), ('age', 21), ('city', '北京'), ('score', 95)]

--- 删除 city 后 ---
keys:   ['name', 'age', 'score']
values: ['张三', 21, 95]
items:  [('name', '张三'), ('age', 21), ('score', 95)]
```

**关键点**：三个视图都没有重新获取，但每次打印都反映的是字典的最新状态。这就是"视图"的含义——它是字典的一个窗口，透过窗口看到的始终是字典的实时内容。

视图动态特性的底层原理可以用以下流程图理解：

```text
  字典 (内存中)
  ┌──────────────────────────┐
  │ name → '张三'             │
  │ age  → 20                 │    视图对象不复制数据
  │ city → '北京'             │    只是持有一个指向字典的引用
  │ score → 95  ← 新增        │
  └──────────────────────────┘
          ▲
          │ 指向同一块内存
    ┌─────┼─────────────────┐
    │     │                 │
    ▼     ▼                 ▼
 dict_keys   dict_values   dict_items
  (窗口)      (窗口)        (窗口)

当你访问视图时 → 它去字典里实时读取 → 看到的永远是最新数据
```

#### 2.4.2 视图 vs 列表快照

将视图转换为列表会创建一份**静态快照**——此后字典的变化不会反映到快照中：

```python
student = {"name": "张三", "age": 20, "city": "北京"}

# 列表快照：转列表后固定不变
keys_snapshot = list(student.keys())
# 视图：随字典实时变化
keys_view = student.keys()

print(f"初始 keys_snapshot: {keys_snapshot}")
print(f"初始 keys_view:    {list(keys_view)}")

# 修改字典
student["score"] = 95

print("\n--- 添加 score=95 后 ---")
print(f"列表快照 keys_snapshot: {keys_snapshot}")
print(f"视图    keys_view:       {list(keys_view)}")
```

**运行结果**：

```text
初始 keys_snapshot: ['name', 'age', 'city']
初始 keys_view:    ['name', 'age', 'city']

--- 添加 score=95 后 ---
列表快照 keys_snapshot: ['name', 'age', 'city']
视图    keys_view:       ['name', 'age', 'city', 'score']
```

**关键点**：

- `list(dict.keys())` 创建一份独立于字典的新列表，之后字典的变化不影响这个列表。
- `dict.keys()` 返回的视图始终反映字典的最新状态。
- 如果你需要"某一时刻的快照"（如遍历过程中字典会被修改），用 `list()` 转换。
- 如果你需要"实时反映字典变化"的窗口，用视图本身。

#### 2.4.3 遍历时修改字典的陷阱

因为视图是实时的，遍历视图时如果修改字典大小（增删键），会触发 `RuntimeError`：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95}

print("遍历时删除元素会触发 RuntimeError:")
try:
    for key in student.keys():
        if key == "age":
            del student[key]
except RuntimeError as e:
    print(f"  报错: RuntimeError: {e}")

print(f"  字典当前状态: {student}")
```

**运行结果**：

```text
遍历时删除元素会触发 RuntimeError:
  报错: RuntimeError: dictionary changed size during iteration
  字典当前状态: {'name': '张三', 'city': '北京', 'score': 95}
```

**安全删除方式**：先收集要删除的键，遍历结束后再删：

```python
student = {"name": "张三", "age": 20, "city": "北京", "score": 95, "grade": "A"}

# 正确做法：先收集要删除的键，遍历结束后再删
keys_to_remove = [k for k in student.keys() if isinstance(student[k], (int, float))]
for key in keys_to_remove:
    del student[key]

print(f"删除数值类型的键后: {student}")
```

**运行结果**：

```text
删除数值类型的键后: {'name': '张三', 'city': '北京', 'grade': 'A'}
```

**关键点**：

- 遍历视图时，字典的**大小不能变**（不能增删键），否则触发 `RuntimeError`。
- 修改已有键的**值**不会改变字典大小，不会报错。但仍然不推荐在遍历时修改值，可能导致逻辑混乱。
- 安全的做法是"先收集，后操作"——遍历时只读，遍历结束后再增删。

### 2.5 三种视图对比

`dict_keys`、`dict_values`、`dict_items` 三种视图有很多共同点，也有各自的特点：

| 维度 | `dict_keys` | `dict_values` | `dict_items` |
|------|-------------|---------------|--------------|
| 返回内容 | 所有键 | 所有值 | 所有 (key, value) 元组 |
| 元素唯一性 | 唯一（键不重复） | 可能重复 | 可能重复（值不同时） |
| 支持集合运算 | 是 | 否（值可能重复/不可哈希） | 是（值可哈希时） |
| `in` 查找 | O(1)（哈希查找） | O(n)（遍历查找） | O(n)（遍历查找） |
| 可迭代 | 是 | 是 | 是 |
| 动态反映字典变化 | 是 | 是 | 是 |
| 支持 `len()` | 是 | 是 | 是 |
| 支持索引访问 | 否 | 否 | 否 |
| 支持 `list()` 转换 | 是 | 是 | 是 |

**为什么 `values()` 不支持集合运算**：

集合运算要求元素是唯一的、可哈希的。但字典的值可以有重复（两个键对应同一个值），而且值不一定是可哈希类型（如值是列表或字典时）。因此 `dict_values` 没有实现集合运算接口。如果需要对值做集合运算，先转 `set`，前提是所有值都是可哈希的且不需要保留重复。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

**场景 1：遍历字典时同时需要键和值**

```python
student = {"name": "张三", "age": 20, "city": "北京"}

# 推荐：items() 解包遍历，一步到位
for key, value in student.items():
    print(f"{key}: {value}")

# 不推荐：遍历键再通过键取值，多一次哈希查找
for key in student.keys():
    print(f"{key}: {student[key]}")

# 不推荐：遍历键列表，写法冗长且性能差
for key in list(student.keys()):
    print(f"{key}: {student[key]}")
```

| 写法 | 性能 | 可读性 | 问题 |
|------|------|--------|------|
| `for k, v in dict.items()` | 最优（同时取键值） | 高，意图清晰 | 无 |
| `for k in dict.keys(): dict[k]` | 次优（多一次哈希查找） | 中 | 无 |
| `for k in list(dict.keys()): dict[k]` | 最差（多创建列表 + 多次查找） | 低 | 多余的列表转换 |

**场景 2：成员判断**

```python
student = {"name": "张三", "age": 20}

# 推荐：直接用字典判断键
if "name" in student:
    print("存在")

# 不推荐：多余的 .keys() 调用
if "name" in student.keys():
    print("存在")

# 不推荐：遍历键列表判断
if "name" in list(student.keys()):
    print("存在")
```

| 写法 | 性能 | 可读性 | 问题 |
|------|------|--------|------|
| `"key" in dict` | O(1)，最快 | 高 | 无 |
| `"key" in dict.keys()` | O(1)，同速 | 中 | 多余的 `.keys()` |
| `"key" in list(dict.keys())` | O(n)，最慢 | 低 | 多余的列表转换 |

**场景 3：遍历时修改字典**

```python
student = {"name": "张三", "age": 20, "city": "北京"}

# 推荐：先收集要删除的键，遍历结束后再删
keys_to_remove = [k for k in student if isinstance(student[k], int)]
for key in keys_to_remove:
    del student[key]

# 不推荐：遍历时直接删除，触发 RuntimeError
# for key in student.keys():
#     del student[key]  # RuntimeError!
```

### 3.2 常见错误模式

**错误 1：对视图使用索引访问**

```python
student = {"name": "张三", "age": 20}

# 视图不支持索引
# student.keys()[0]  # TypeError: 'dict_keys' object is not subscriptable

# 修正：先转列表
first_key = list(student.keys())[0]
print(f"第一个键: {first_key}")
```

**错误 2：遍历时修改字典大小**

```python
student = {"name": "张三", "age": 20, "city": "北京"}

# 遍历时删除元素
try:
    for key in student:
        del student[key]
except RuntimeError as e:
    print(f"报错: {e}")

# 修正：先收集后删除
student = {"name": "张三", "age": 20, "city": "北京"}
keys_to_delete = list(student.keys())  # 创建静态快照
for key in keys_to_delete:
    del student[key]
print(f"删除后: {student}")
```

**运行结果**：

```text
报错: dictionary changed size during iteration
删除后: {}
```

**错误 3：误以为 `in dict` 判断的是值**

```python
student = {"name": "张三", "age": 20}

# 误以为 '张三' in student 是在判断值
print(f"'张三' in student: {'张三' in student}")  # False！判断的是键

# 修正：判断值用 .values()
print(f"'张三' in student.values(): {'张三' in student.values()}")  # True
```

**运行结果**：

```text
'张三' in student: False
'张三' in student.values(): True
```

**错误 4：对 `dict_values` 使用集合运算**

```python
scores = {"math": 95, "chinese": 95, "english": 88}

# dict_values 不支持集合运算
try:
    result = scores.values() & {88}
except TypeError as e:
    print(f"报错: {e}")

# 修正：先转 set
result = set(scores.values()) & {88}
print(f"交集: {result}")
```

**运行结果**：

```text
报错: unsupported operand type(s) for &: 'dict_values' and 'set'
交集: {88}
```

**错误 5：`items()` 集合运算时值不可哈希**

```python
# 值是列表（不可哈希）
data = {"a": [1, 2], "b": [3, 4]}

try:
    result = data.items() & {("a", [1, 2])}
except TypeError as e:
    print(f"报错: {e}")

# 修正：值不可哈希时不能用集合运算，改用普通遍历比较
```

**运行结果**：

```text
报错: unhashable type: 'list'
```

### 3.3 性能对比

三种视图在不同操作下的性能特征：

| 操作 | `keys()` | `values()` | `items()` |
|------|----------|------------|-----------|
| 创建视图 | O(1) | O(1) | O(1) |
| `in` 查找 | O(1) | O(n) | O(n) |
| 遍历 | O(n) | O(n) | O(n) |
| 转 `list` | O(n) | O(n) | O(n) |
| `len()` | O(1) | O(1) | O(1) |
| 集合运算 | O(n) | 不支持 | O(n) |

**关键点**：

- 创建视图本身是 O(1)——视图不复制数据，只是持有一个字典引用。
- `keys()` 的 `in` 查找是 O(1)，因为键有哈希索引。
- `values()` 和 `items()` 的 `in` 查找是 O(n)，因为值没有索引，需要逐个比较。
- 转 `list` 是 O(n)，因为需要遍历所有元素并创建新列表。
- 在性能敏感的场景（如高频请求中的参数检查），优先用 `in dict` 而非 `in dict.values()`。

### 3.4 何时用哪种方法

根据具体场景选择最合适的方法：

| 场景 | 推荐方法 | 原因 |
|------|---------|------|
| 只需要键 | `keys()` 或直接遍历字典 | 不需要多余的值数据 |
| 只需要值 | `values()` | 不需要键信息时更直接 |
| 同时需要键和值 | `items()` + 解包 | 一步到位，避免二次查找 |
| 判断键是否存在 | `in dict` | O(1) 最快，写法简洁 |
| 判断值是否存在 | `in dict.values()` | 必须遍历，O(n) |
| 求和/最值/排序 | `values()` + `sum/max/sorted` | 直接传视图即可 |
| 过滤键值对 | `items()` + 字典推导式 | 黄金组合 |
| 两个字典键的交集/并集 | `keys()` + `&` / `|` | 视图原生支持 |
| 根据值反查键 | `items()` + 列表推导式 | 遍历匹配 |
| 遍历时字典可能被修改 | 先 `list()` 转快照 | 避免 RuntimeError |
| 需要按索引访问键 | `list(keys())` | 视图不支持索引 |

## 4. 原理

### 4.1 为什么返回视图而不是列表

在 Python 2 中，`keys()`、`values()`、`items()` 返回的是列表——一份完整的拷贝。Python 3 改为返回视图对象，这个设计变化有三个核心动机：

**1. 内存效率**

列表返回意味着每次调用 `keys()` 都要创建一份完整的键拷贝。如果字典有 100 万个键，每次 `keys()` 都要复制 100 万个引用。视图只是持有一个指向字典的引用，不复制任何数据，创建开销为 O(1)。

```text
Python 2: dict.keys() → 创建新列表，复制所有键 → O(n) 内存 + 时间
Python 3: dict.keys() → 创建视图，持有字典引用 → O(1) 内存 + 时间
```

**2. 动态反映**

视图实时反映字典的变化，这在"获取一次视图、后续字典可能被修改"的场景中很有用。如果是列表快照，每次修改字典后都需要重新获取一次列表，容易遗漏导致数据不一致。

**3. 集合运算能力**

`dict_keys` 实现了集合协议（Set ABC），可以直接进行 `&`、`|`、`-`、`^` 运算。这在 Python 2 中需要先 `set(dict.keys())` 转换，多一步开销。Python 3 的视图原生支持，更自然也更高效。

### 4.2 视图对象的底层实现

视图对象的简化等价实现，帮助理解其内部机制：

```python
class dict_keys:
    def __init__(self, ref):
        self._dict_ref = ref  # 持有字典的引用，不复制数据

    def __iter__(self):
        return iter(self._dict_ref)  # 迭代时直接遍历字典的键

    def __contains__(self, key):
        return key in self._dict_ref  # 成员判断委托给字典

    def __len__(self):
        return len(self._dict_ref)  # 长度委托给字典

    def __and__(self, other):
        # 交集：返回在两边都存在的键
        return set(self) & set(other)

    def __or__(self, other):
        # 并集：返回所有键的集合
        return set(self) | set(other)

    def __sub__(self, other):
        # 差集：返回 self 有但 other 没有的键
        return set(self) - set(other)
```

```text
视图创建过程：
  dict.keys()
      │
      ▼
  创建 dict_keys 对象
  ┌──────────────────────┐
  │  _dict_ref → 字典引用 │  ← 只存一个引用，不复制数据
  └──────────────────────┘
      │
      │  访问视图时（遍历/in/len）
      ▼
  委托给底层的字典操作
  ┌──────────────────────┐
  │  字典 (内存中的真身)   │  ← 实时读取字典的当前状态
  └──────────────────────┘
```

**关键点**：

- 视图对象内部只持有一个指向字典的**弱引用**（实际上是普通引用），不存储任何数据副本。
- 所有操作（迭代、成员判断、长度）都委托给底层字典执行，因此始终反映字典的最新状态。
- 这也解释了为什么遍历视图时修改字典会触发 `RuntimeError`——迭代器和修改操作同时作用于同一块内存，Python 检测到字典大小变化后主动报错，避免数据损坏。

### 4.3 集合运算的实现原理

`dict_keys` 和 `dict_items` 支持集合运算，而 `dict_values` 不支持。原因在于 Python 的集合运算协议：

```python
from collections.abc import Set

# dict_keys 注册为 Set 的子类
print(isinstance({}.keys(), Set))   # True

# dict_values 没有注册
print(isinstance({}.values(), Set)) # False

# dict_items 注册为 Set 的子类（当值可哈希时）
print(isinstance({}.items(), Set))  # True
```

**运行结果**：

```text
True
False
True
```

**设计原因**：

| 类型 | 是否实现集合协议 | 原因 |
|------|----------------|------|
| `dict_keys` | 是 | 键唯一且可哈希，天然满足集合要求 |
| `dict_values` | 否 | 值可能重复、可能不可哈希 |
| `dict_items` | 是 | (key, value) 元组天然唯一且可哈希（值可哈希时） |

集合运算要求元素满足两个条件：**唯一性**和**可哈希性**。键天然满足这两个条件（字典的键不能重复、必须是可哈希类型），所以 `dict_keys` 实现了集合协议。值不满足唯一性（可以重复），也不一定可哈希（值可以是列表等不可哈希类型），所以 `dict_values` 不实现集合协议。

`dict_items` 的元素是 `(key, value)` 二元组，每个元组天然唯一（因为键唯一），且当值可哈希时元组也可哈希。因此 `dict_items` 实现了集合协议，但运算过程中如果值不可哈希会抛出 `TypeError`。

## 5. 总结

本文围绕字典的 `keys()`、`values()`、`items()` 三个方法展开，主要介绍了以下内容：

- `keys()` 返回 `dict_keys` 视图对象，包含字典所有键；支持 `in` 成员判断（O(1)）、遍历、转列表、集合运算（`&`、`|`、`-`、`^`）
- `values()` 返回 `dict_values` 视图对象，包含字典所有值；支持 `in` 成员判断（O(n)）、遍历、统计运算（`sum/max/min/sorted`）；值可以重复，不支持集合运算
- `items()` 返回 `dict_items` 视图对象，包含所有 (key, value) 二元组；遍历时可用元组解包同时获取键和值；配合字典推导式可灵活过滤键值对；支持集合运算（值可哈希时）；可用于根据值反查键
- 视图的动态特性：视图是字典的实时窗口，不复制数据，字典改动后视图自动反映最新状态；`list()` 转换创建静态快照，不受字典变化影响
- 遍历视图时修改字典大小（增删键）会触发 `RuntimeError`，安全做法是先收集要操作的键列表，遍历结束后再增删
- 三种视图对比：`keys()` 支持集合运算且 `in` 为 O(1)，`values()` 不支持集合运算且 `in` 为 O(n)，`items()` 支持集合运算且 `in` 为 O(n)
- 最佳实践：同时需要键值用 `items()` 解包遍历，判断键用 `in dict`，判断值用 `in dict.values()`，过滤用 `items()` + 字典推导式
- 常见错误：对视图使用索引访问（TypeError）、遍历时修改字典大小（RuntimeError）、误以为 `in dict` 判断的是值、对 `dict_values` 使用集合运算
- 性能特征：创建视图 O(1)，`keys()` 的 `in` 查找 O(1)，`values()` 和 `items()` 的 `in` 查找 O(n)，转列表 O(n)
- 原理层面：Python 3 用视图替代列表是为了内存效率、动态反映和集合运算能力；视图内部只持有字典引用，所有操作委托给底层字典执行；`dict_keys` 和 `dict_items` 实现了集合协议，`dict_values` 因值可能重复和不可哈希而未实现
