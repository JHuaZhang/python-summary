## 1. 介绍

### 1.1 什么是集合

集合（set）是 Python 内置的**无序不重复元素容器**，用花括号表达，底层由哈希表实现。集合的核心语义是"成员归属"与"去重"：一个元素要么在集合中、要么不在，没有"第几个"的概念。集合中的每个元素必须是**可哈希**（hashable）的——这和字典的键的要求完全一致，因为集合底层就是只有键没有值的哈希表。

```python
# 最基本的集合：用花括号包裹元素，逗号分隔
ids = {101, 102, 103}
print(ids)          # 输出：{101, 102, 103}
print(type(ids))    # 输出：<class 'set'>
```

集合的用途非常广泛：去掉序列中的重复元素、快速判断一个值是否属于某个群体、在两个集合之间进行交并补运算（比对权限、标签、交集等）、作为图的节点集合管理拓扑遍历状态。

```python
# 集合的核心能力：去重与成员判断
user_ids = [1001, 1002, 1001, 1003, 1002]
unique_ids = set(user_ids)
print(unique_ids)            # 输出：{1001, 1002, 1003}

is_admin = 1001 in unique_ids
print(is_admin)              # 输出：True
```

创建集合是这个知识点最基础也最容易被忽视的部分。尤其是"空集合怎么建"这个问题——刚接触 Python 的人几乎都会踩进 `{}` 是字典这个坑里。

### 1.2 集合的约束：元素必须可哈希

由于集合底层是哈希表，集合的每个元素都必须是**可哈希**（hashable）的。可哈希对象必须满足：
- 在其生命周期内 `hash()` 值不变
- 能通过 `__eq__()` 判断相等

Python 中常见可哈希类型：`int`、`float`、`str`、`bytes`、`tuple`（所有元素必须可哈希）、`frozenset`、`None`、`bool`。

不可哈希类型：`list`、`set`、`dict`——它们可变，哈希值无法稳定保持。

```python
# 可哈希的元素可以放入集合
valid_set = {1, 3.14, "hello", (0, 0), None, False}
print(valid_set)
# 输出可能是：{False, 1, 3.14, None, 'hello', (0, 0)}
# 注意：集合无序，输出顺序不固定

# 不可哈希的元素会报错
# invalid_set = {[1, 2], "a"}   # TypeError: unhashable type: 'list'
# invalid_set = {set()}          # TypeError: unhashable type: 'set'
# invalid_set = {{"a": 1}}       # TypeError: unhashable type: 'dict'
```

一个容易忽略的边界情况：**元组只有在所有元素都可哈希时才能放入集合**。元组内如果包含列表等可变类型，元组本身还是不可哈希的。

```python
# 元组内元素都可哈希 -> 可放入集合
point = (1, 2)
valid_set = {point, (0, 0)}
print(valid_set)   # 输出：{(0, 0), (1, 2)}

# 元组内包含列表 -> 元组不可哈希
nested_tuple = ([1, 2], 3)
# invalid_set = {nested_tuple}   # TypeError: unhashable type: 'list'
```

**可哈希性约束**贯穿所有集合创建方式，无论是字面量、构造函数还是集合推导式，只要传入了不可哈希元素都会抛 `TypeError`。这条规则不是"有时成立"，而是无例外的硬性约束，你在后续所有 demo 中需要时刻保持警惕。

### 1.3 最小用法：两种核心创建语法

Python 提供两种最基础的集合创建方式：

```python
# 方式一：花括号字面量（集合内直接写元素）
tags = {"python", "data", "ml"}
print(tags)              # 输出：{'data', 'python', 'ml'}

# 方式二：set() 构造函数
tags2 = set(["python", "data", "ml"])
print(tags2)             # 输出：{'ml', 'data', 'python'}

# 两种方式结果等价
print(tags == tags2)     # 输出：True
```

但有一个**致命的语法区别**：

```python
# 空花括号是字典，不是集合！
empty = {}
print(type(empty))       # 输出：<class 'dict'>

# 空集合必须用 set()
empty_set = set()
print(type(empty_set))   # 输出：<class 'set'>
```

这是 Python 从 2.x 时代就留下来的语法占用问题。花括号 `{}` 在 Python 的语法解析器中优先被识别为空字典字面量；集合字面量则必须包含至少一个元素（如 `{1, 2, 3}`）。当花括号内出现冒号时被解析为字典，没有冒号时被解析为集合——但空花括号没有冒号也没有元素，就**只能**被解释为字典。这个设计决策在 Python 社区有长期讨论，最终因为向后兼容的原因没有更改。

**核心记忆口诀**：`set()` 是空集合的惟一写法。

### 1.4 集合创建方式总览表

在进入第 2 章的详细讲解之前，先用一个表总览所有集合创建方式：

| 创建方式 | 语法示例 | 适用场景 | 注意事项 |
|---------|---------|---------|---------|
| 空集合 | `set()` | 需要逐步 `add()` 新增元素的起点 | `{}` 是空字典，不是空集合 |
| 字面量 | `{1, 2, 3}` | 元素数量少且已知 | 元素必须可哈希 |
| 从可迭代对象 | `set(iterable)` | 转换列表/元组/字符串为集合 | 会遍历整个可迭代对象，自动去重 |
| 集合推导式 | `{expr for x in iter}` | 从序列中筛选/转换后生成集合 | 与列表推导式类似，但结果无序去重 |
| 空集合推导式 | `set()` | 没有其他方式可生成空集合 | 无推导式空语法 |

## 2. 核心内容

本章从最基本到最进阶逐一讲解每种集合创建方式，每节遵循"方式说明 → 详细 demo → 运行结果说明 → 陷阱提示"的结构展开。

### 2.1 字面量创建：花括号语法

当你知道集合的初始元素时，用花括号字面量是最直接、最 Pythonic 的方式。**语法规则**：一对花括号内，用逗号分隔元素，不能包含冒号（否则变成字典）。

```python
# 最基础的用法：直接列出元素
colors = {"red", "green", "blue"}
print(colors)
# 输出：{'blue', 'red', 'green'}
# 注意：集合无序，输出顺序可能与定义顺序不同

# 混合类型元素
mixed = {1, 2.5, "text", (0, 0)}
print(mixed)
# 输出：{1, 2.5, 'text', (0, 0)}
```

**元素会自动去重**——这是集合语义的必然行为，不是特性，而是集合的定义本身就不允许重复元素：

```python
# 重复元素在创建时就会被去重
duplicates = {1, 2, 2, 3, 1, 3, 1}
print(duplicates)
# 输出：{1, 2, 3}

# 去重发生在哈希层面，而非值层面
# "1"（字符串）和 1（整数）不是同一个对象
distinct = {1, "1", 1.0}   # 1 和 1.0 哈希值相同且相等
print(distinct)
# 输出：{1, '1'}
# 注意：1 和 1.0 在 Python 中 hash(1) == hash(1.0) 且 1 == 1.0，所以被视为同一个元素
```

**边界情况：单元素集合**

```python
# 单元素集合的写法不会混淆
single = {42}
print(single)           # 输出：{42}
print(type(single))     # 输出：<class 'set'>

# 注意与字典的区别：{42} 是集合，{42: "value"} 才是字典
```

**边界情况：元素必须是可哈希的**

```python
# 字面量中含不可哈希元素 -> 立即报错
# bad = {[1, 2], "a"}            # TypeError: unhashable type: 'list'
# bad2 = {{1, 2}, "a"}           # TypeError: unhashable type: 'set'
# bad3 = {{"key": "val"}, "a"}   # TypeError: unhashable type: 'dict'

# frozenset 是可哈希的，可以放入集合
nested = {frozenset({1, 2}), frozenset({3, 4})}
print(nested)
# 输出：{frozenset({3, 4}), frozenset({1, 2})}
```

**适用场景**：写死的、元素个数有限且已知的配置集合，如权限标签、状态码集合、允许的选项集合。

```python
# 实际场景：定义允许的状态
ALLOWED_STATUS = {"active", "pending", "completed"}
input_status = "active"
if input_status in ALLOWED_STATUS:
    print(f"状态 '{input_status}' 合法")
# 输出：状态 'active' 合法
```

### 2.2 `set()` 构造函数：从可迭代对象创建

`set()` 是 Python 的一个内置类型构造函数，可以接收零个或一个参数。当不传参时创建空集合，传一个可迭代对象时从该对象中提取元素。

**签名**：`set(iterable=None)`

```python
# 无参数 -> 空集合
empty = set()
print(empty, type(empty))
# 输出：set() <class 'set'>

# 传入列表
from_list = set([3, 1, 4, 1, 5, 9, 2, 6])
print(from_list)
# 输出：{1, 2, 3, 4, 5, 6, 9}
# 同时完成了：转换 + 去重 + 无序化

# 传入元组
from_tuple = set((10, 20, 30, 20, 10))
print(from_tuple)
# 输出：{10, 20, 30}

# 传入字符串（每个字符成为元素）
from_str = set("hello")
print(from_str)
# 输出：{'e', 'h', 'l', 'o'}
# 注意：重复字符 'l' 被去重，只剩一个
```

**传入空的可迭代对象**

```python
# 空列表
print(set([]))       # 输出：set()

# 空元组
print(set(()))       # 输出：set()

# 空字符串
print(set(""))       # 输出：set()

# 空 range
print(set(range(0))) # 输出：set()
```

**传入不可哈希元素的可迭代对象**——这是最常见的 TypeError 来源：

```python
# 列表中有不可哈希元素
# bad = set([[1, 2], [3, 4]])   # TypeError: unhashable type: 'list'

# 列表中有字典
# bad2 = set([{"a": 1}])        # TypeError: unhashable type: 'dict'

# 除非列表元素本身是可哈希的
ok = set([(1, 2), (3, 4)])
print(ok)   # 输出：{(1, 2), (3, 4)}
```

**set() 与其他内置类型构造函数的对比**

```python
data = [1, 2, 2, 3, 3, 3]

print(set(data))     # 输出：{1, 2, 3}    —— 去重、无序
print(list(data))    # 输出：[1, 2, 2, 3, 3, 3] —— 保留原始顺序和重复
print(tuple(data))   # 输出：(1, 2, 2, 3, 3, 3) —— 和列表类似，不可变
```

**实际场景示例：从日志中提取所有用户 ID**

```python
# 模拟日志中的用户 ID（可能有重复）
raw_logs = [1001, 1003, 1001, 1005, 1003, 1001, 1002]

# 方式一：用 set() 转换去重
active_users = set(raw_logs)
print(f"活跃用户数：{len(active_users)}，用户 ID：{active_users}")
# 输出：活跃用户数：4，用户 ID：{1001, 1002, 1003, 1005}

# 方式二：如果后续需要唯一列表，可以再转回列表
unique_user_list = list(set(raw_logs))
print(unique_user_list)
# 输出：[1001, 1002, 1003, 1005]（顺序不确定）
```

### 2.3 `set()` 在各类可迭代对象上的行为详解

`set()` 的输入可以是任何一个可迭代对象（实现了 `__iter__()` 或 `__getitem__()`）。下面逐一举例。

**2.3.1 从字符串创建**

字符串逐字符迭代，集合对每个字符去重：

```python
text = "abracadabra"
chars = set(text)
print(chars)
# 输出：{'a', 'b', 'c', 'd', 'r'}
# 所有字符去重后剩 5 个唯一字符

# 中文字符串同样逐字符
chinese = set("集合创建")
print(chinese)
# 输出：{'创', '合', '集', '建'}

# 特殊字符也可作为元素
symbols = set("a\nb\tc")   # 包含换行符和制表符
print(symbols)
# 输出：{'\t', '\n', 'a', 'b', 'c'}
# 注意：特殊字符也是单独的字符
```

**2.3.2 从 range 对象创建**

```python
# range 对象惰性产生整数序列
numbers = set(range(1, 6))
print(numbers)     # 输出：{1, 2, 3, 4, 5}

# range 带步长
evens = set(range(0, 10, 2))
print(evens)       # 输出：{0, 2, 4, 6, 8}

# range 反向
rev = set(range(5, 0, -1))
print(rev)         # 输出：{1, 2, 3, 4, 5}
```

**2.3.3 从字典创建**

```python
# set(dict) 只取键，不取值
user_info = {"name": "Alice", "age": 30, "city": "Beijing"}
keys = set(user_info)
print(keys)
# 输出：{'name', 'age', 'city'}

# 如果想取值 -> 用 set(user_info.values())
values = set(user_info.values())
print(values)
# 输出：{'Beijing', 'Alice', 30}

# 如果想取键值对元组 -> 用 set(user_info.items())
items = set(user_info.items())
print(items)
# 输出：{('name', 'Alice'), ('city', 'Beijing'), ('age', 30)}
```

**2.3.4 从生成器表达式创建**

```python
# 生成器表达式惰性求值，传入 set() 后一次性遍历
squares = set(x * x for x in range(5))
print(squares)
# 输出：{0, 1, 4, 9, 16}

# 配合条件过滤
even_squares = set(x * x for x in range(10) if x % 2 == 0)
print(even_squares)
# 输出：{0, 4, 16, 36, 64}
```

**2.3.5 从 frozenset 创建**

```python
# frozenset 也是可迭代对象，从它创建 set 是浅拷贝
fs = frozenset([1, 2, 3])
s = set(fs)
print(s)           # 输出：{1, 2, 3}
print(type(s))     # 输出：<class 'set'>
```

**2.3.6 从自定义可迭代对象创建**

```python
# 实现 __iter__ 的类
class UserIDs:
    def __init__(self):
        self._ids = [101, 102, 103, 101]

    def __iter__(self):
        return iter(self._ids)

ids_container = UserIDs()
unique_ids = set(ids_container)
print(unique_ids)
# 输出：{101, 102, 103}
```

### 2.4 创建空集合的陷阱

这是整个知识点中**最常用也最容易犯错**的问题。

**陷阱**：`{}` 在 Python 中创建的是一个空字典，而非空集合。

```python
# 错误写法（极其常见）
result = {}              # 你以为这是空集合
print(type(result))      # 输出：<class 'dict'> —— 出乎意料！

# 错误行为演示
result.add(1)            # AttributeError: 'dict' object has no attribute 'add'
```

**问题根源**：

Python 在设计时面临一个选择：花括号既要表示字典字面量，又要表示集合字面量。Python 的语法解析器通过花括号内的内容来区分：

- `{}` —— 没有内容 → 字典（只有它没有歧义）
- `{1, 2, 3}` —— 没有冒号 → 集合
- `{"a": 1}` —— 有冒号 → 字典

空花括号没有足够的语法信息来判断意图，最终 Python 设计者选择将其解释为字典——因为在 Python 的早期版本（2.x）中，集合是通过 `Set` 类（位于 `sets` 模块中）实现的，后来才升级为内置类型。`{}` 作为字典的语法在集合成为内置类型之前就已经被广泛使用，所以保留了这个设定。

```python
# 正确创建空集合的唯一方式
my_set = set()
print(type(my_set))      # 输出：<class 'set'>
print(len(my_set))       # 输出：0
```

**影响的常见场景**：在函数中初始化一个结果集合时：

```python
def find_duplicates(items):
    seen = set()         # 正确：用 set()
    duplicates = set()   # 正确：用 set()
    for item in items:
        if item in seen:
            duplicates.add(item)
        else:
            seen.add(item)
    return duplicates

# 测试
items = [1, 2, 3, 2, 4, 3, 5]
print(find_duplicates(items))
# 输出：{2, 3}

# ===== 错误示范：用 {} 初始化 =====
def wrong_find_duplicates(items):
    seen = {}            # bug: 这是字典！
    duplicates = {}      # bug: 这是字典！
    for item in items:
        if item in seen:           # 不会报错，但语义不对
            duplicates.add(item)   # AttributeError！
        else:
            seen.add(item)         # AttributeError！
    return duplicates

# 这个函数会直接崩溃
# wrong_find_duplicates([1, 2, 3])
```

**注意对比**：非空集合的创建没有此陷阱。只要花括号内有元素（不含冒号），Python 就能正确识别为集合：

```python
# 这些都是集合
print(type({1}))         # 输出：<class 'set'>
print(type({1, 2}))      # 输出：<class 'set'>
print(type({"a"}))       # 输出：<class 'set'>

# 只有空花括号是字典
print(type({}))          # 输出：<class 'dict'>
```

**记忆技巧**：`set()` 是动词（创建），`{}` 是名词（容器）。当你要创建一个空容器时，"做动作"要用 `set()`，"写内容"用 `{}`——但 `{}` 里必需要有冒号（字典）或元素（集合），什么都没有就只能是字典。

### 2.5 集合推导式

集合推导式（set comprehension）是用推导式的语法生成集合的方式。它的语法与列表推导式几乎相同，区别在于外层使用花括号而非方括号。

**语法**：`{expression for item in iterable if condition}`

```python
# 基本用法：计算平方并生成集合
squares = {x * x for x in range(5)}
print(squares)
# 输出：{0, 1, 4, 9, 16}

# 带条件过滤
evens = {x for x in range(10) if x % 2 == 0}
print(evens)
# 输出：{0, 2, 4, 6, 8}

# 字符串处理：提取句中不重复单词的首字母
sentence = "the quick brown fox jumps over the lazy dog"
first_letters = {word[0].upper() for word in sentence.split()}
print(first_letters)
# 输出：{'B', 'D', 'F', 'J', 'L', 'O', 'Q', 'T'}
# 注意：集合无序，且 'the' 出现两次但首字母只出现一次
```

**集合推导式 vs 列表推导式 vs set(生成器)**

```python
data = [1, 2, 3, 2, 4, 1, 5]

# 列表推导式 -> 保留重复
list_comp = [x * 10 for x in data]
print(list_comp)
# 输出：[10, 20, 30, 20, 40, 10, 50]

# 集合推导式 -> 自动去重
set_comp = {x * 10 for x in data}
print(set_comp)
# 输出：{10, 20, 30, 40, 50}

# set() + 生成器表达式 -> 结果等价于集合推导式
set_from_gen = set(x * 10 for x in data)
print(set_from_gen)
# 输出：{10, 20, 30, 40, 50}
```

**三层嵌套推导式（含条件、表达式、映射）**

```python
# 实际场景：从用户列表中提取所有活跃用户的部门（去重）
users = [
    {"name": "Alice", "dept": "Engineering", "active": True},
    {"name": "Bob", "dept": "Design", "active": False},
    {"name": "Carol", "dept": "Engineering", "active": True},
    {"name": "Dave", "dept": "Marketing", "active": True},
    {"name": "Eve", "dept": "Design", "active": False},
]

active_depts = {user["dept"] for user in users if user["active"]}
print(active_depts)
# 输出：{'Engineering', 'Marketing'}
# 只有 active 为 True 的部门，且自动去重
```

**双重循环推导式**

```python
# 笛卡尔积：生成所有坐标组合
coords = {(x, y) for x in range(3) for y in range(3)}
print(coords)
# 输出：{(0, 0), (0, 1), (0, 2), (1, 0), (1, 1), (1, 2), (2, 0), (2, 1), (2, 2)}

# 带条件的笛卡尔积
diagonal = {(x, y) for x in range(4) for y in range(4) if x == y}
print(diagonal)
# 输出：{(0, 0), (1, 1), (2, 2), (3, 3)}
```

**集合推导式中不可哈希元素问题**

```python
# 如果表达式生成不可哈希的对象，创建时会报错
# bad = {[x, x * 2] for x in range(3)}   # TypeError: unhashable type: 'list'

# 解决方案：用可哈希的类型替代，如 tuple
ok = {(x, x * 2) for x in range(3)}
print(ok)
# 输出：{(0, 0), (1, 2), (2, 4)}
```

**适用场景**：当你需要对一个序列进行变换或过滤，并且最终需要"唯一值集合"时，集合推导式比 `set()` 配合生成器的写法更紧凑、更 Pythonic。但如果只是简单地去重（无需变换），直接用 `set(iterable)` 更清晰。

### 2.6 从文件/迭代器创建集合

`set()` 可以接收任何可迭代对象，包括文件对象、数据库游标、网络流等。

```python
# 模拟从文件中逐行读取并去重
# 假设文件内容如下（模拟数据）：
simulated_lines = [
    "apple\n",
    "banana\n",
    "apple\n",
    "cherry\n",
    "banana\n",
]

# 用 set() 接收迭代器，自动逐行读取并去重
unique_fruits = set(line.strip() for line in simulated_lines)
print(unique_fruits)
# 输出：{'banana', 'cherry', 'apple'}
```

### 2.7 创建包含 frozenset 的 set

`frozenset` 是可哈希的，因此可以作为集合的元素。通过创建包含 `frozenset` 的集合，可以实现"集合的集合"。

```python
# 直接创建：用字面量
nested = {frozenset({1, 2}), frozenset({3, 4}), frozenset({1, 2})}
print(nested)
# 输出：{frozenset({3, 4}), frozenset({1, 2})}
# frozenset({1, 2}) 重复了，被去重

# 通过 set() 从 frozenset 列表创建
groups = [frozenset({1, 2}), frozenset({3, 4}), frozenset({1, 2})]
unique_groups = set(groups)   # frozenset 列表作为可迭代对象
print(unique_groups)
# 输出：{frozenset({3, 4}), frozenset({1, 2})}

# 混合使用：用推导式生成 frozenset 集合
edges = [(1, 2), (2, 3), (3, 1), (1, 2)]
edge_sets = {frozenset(e) for e in edges}
print(edge_sets)
# 输出：{frozenset({1, 2}), frozenset({2, 3}), frozenset({1, 3})}
# (1, 2) 重复了一次，被去重
```

**实际场景：记录无向图的边**

```python
# 无向图中，(1, 2) 和 (2, 1) 是同一条边
pairs = [(1, 2), (2, 1), (2, 3), (3, 2), (1, 3)]
undirected_edges = {frozenset(p) for p in pairs}
print(undirected_edges)
# 输出：{frozenset({1, 3}), frozenset({1, 2}), frozenset({2, 3})}
# 注意：(1, 2) 和 (2, 1) 被识别为同一条边
```

### 2.8 从字节对象创建集合

```python
# 从 bytes 逐字节创建
byte_data = b"abcabc"
byte_set = set(byte_data)
print(byte_set)
# 输出：{97, 98, 99}
# 每个元素是整数（对应字节的 ASCII 码值）

# 从 bytearray 创建
```


### 2.10 性能对比：不同创建方式的效率

虽然通常情况下创建集合的开销微乎其微，但在循环或高频调用场景下，选择高效的创建方式仍然有意义。

```python
import timeit

# 测试：字面量 vs set() 构造函数（非空）
literal_time = timeit.timeit("{1, 2, 3, 4, 5}", number=1_000_000)

print(f"set([...]) × 1,000,000：{constructor_time:.4f} 秒")
# 输出示例（具体数值因机器而异）：
# 字面量 × 1,000,000：0.1123 秒
# set([...]) × 1,000,000：0.3456 秒
# 字面量比构造函数快约 3 倍

# 为什么？字面量在字节码层面直接创建集合，set() 需要额外的函数调用和参数遍历
```

```python
# 性能差异的根本原因：字节码层面的不同
import dis

# 查看字面量的字节码
print("【字面量】")
dis.dis("{1, 2, 3}")

# 查看构造函数的字节码

dis.dis("set([1, 2, 3])")
```

**结论**：已知元素固定时用字面量 `{...}` 更快；需要从可迭代对象转换时用 `set(iterable)`；空集合只能用 `set()`。

## 3. 最佳实践

### 3.1 空集合初始化：永远用 `set()`，不用 `{}`

这是最重要的最佳实践。

```python
# 推荐 ✓
result = set()

# 不推荐 ✗
result = {}       # 这是字典！后面调用 add() 会崩溃
```

**为什么**：这条规则不是风格偏好，而是语法层面的硬性区分。`{}` 是字典，会静默地产生一个错误类型的对象——直到你调用 `add()` 或 `discard()` 时才崩溃。这种"延迟报错"比"立即报错"更难排查。

### 3.2 已知固定元素用字面量，从序列转换用 `set()`

```python
# 场景一：定义一组已知的常量，用字面量
VALID_ROLES = {"admin", "editor", "viewer"}
SUPPORTED_EXTENSIONS = {".py", ".js", ".ts", ".go"}

# 场景二：从已有的序列去重，用 set()
user_input = ["a", "b", "a", "c"]
unique_input = set(user_input)
```

**为什么**：字面量更短、更快、可读性更好。`set(sequence)` 则明确表达了"转换"的语义。不必要的 `set([...])` 写法（例如 `set([1, 2, 3])`）既慢又啰嗦——直接用 `{1, 2, 3}`。

### 3.3 不要在集合中放置不可哈希元素

这是一个运行时错误，但可以提前防范：

```python
# 错误：把列表放入集合
# tags = {"python", ["data", "science"]}     # TypeError

# 正确：用元组替代列表
tags = {"python", ("data", "science")}

# 错误：把集合放入集合
# data = {1, 2, {3, 4}}                       # TypeError

# 正确：用 frozenset
data = {1, 2, frozenset({3, 4})}
```

**防御性编程**：在不确定元素可哈希性时，可以用 `isinstance()` 检查，或者用 `try-except` 捕获：

```python
def safe_set_creation(items):
    """安全创建 set，过滤不可哈希元素"""
    result = set()
    for item in items:
        try:
            hash(item)
            result.add(item)
        except TypeError:
            print(f"警告：跳过不可哈希元素 {item}")
            continue
    return result

# 测试
mixed = [1, "text", [1, 2], (3, 4), {"key": "val"}]
safe = safe_set_creation(mixed)
print(safe)
# 输出：
# 警告：跳过不可哈希元素 [1, 2]
# 警告：跳过不可哈希元素 {'key': 'val'}
# {1, 'text', (3, 4)}
```

### 3.4 集合推导式中慎用复杂表达式

```python
# 可读性较好
result = {process(item) for item in large_dataset if condition(item)}

# 可读性差：太长的推导式会让人难以理解
# result = {a + b for x in data1 for y in data2 if check(x, y) and validate(a, b) for a in x for b in y}

# 解决方案：分步处理
temp1 = set()
for x in data1:
    for y in data2:
        if check(x, y):
            for a in x:
                for b in y:
                    if validate(a, b):
                        temp1.add(a + b)
result = temp1
```

### 3.5 利用集合推导式替代 `set()` + 生成器

当需要"从序列中提取变换后的唯一值"时，集合推导式比 `set()` + 生成器表达式更清晰：

```python
data = [1, 2, 3, 4, 5, 1, 2]

# 推荐：集合推导式 ✓
result = {x * 2 for x in data}

# 也可以：set() + 生成器（语义等价）
result_alt = set(x * 2 for x in data)
```

两者性能几乎无差异，风格选择以可读性为准。简单变换且推导式不嵌套时用集合推导式；涉及复杂逻辑时，考虑到可读性可拆分为多步。

### 3.6 不要依赖集合元素的顺序

集合是无序的。虽然 Python 3.7+ 的 CPython 实现中，集合的迭代顺序在某些情况下看起来是"有序"的（与插入顺序相关），但这属于实现细节，**不是语言契约**。

```python
# 不要依赖这样的行为：
# 在某些版本中，set([3, 1, 2]) 的输出可能是 {1, 2, 3}
# 这是巧合，不是保证！

# 正确做法：如果需要有序唯一集合，用 dict.fromkeys()
items = [3, 1, 2, 1, 3]
ordered_unique = list(dict.fromkeys(items))
print(ordered_unique)
# 输出：[3, 1, 2]
# dict.fromkeys() 保留插入顺序（Python 3.7+）
```

### 3.7 调试技巧：快速检查是否为 set 类型

```python
def ensure_set(obj):
    """确保传入的是 set 类型，必要时转换"""
    if not isinstance(obj, set):
        if hasattr(obj, '__iter__'):
            return set(obj)
        raise TypeError(f"无法将 {type(obj).__name__} 转换为集合")
    return obj

# 测试
print(ensure_set([1, 2, 3]))         # 输出：{1, 2, 3}
print(ensure_set({1, 2, 3}))         # 输出：{1, 2, 3}
print(ensure_set("abc"))             # 输出：{'a', 'b', 'c'}
# print(ensure_set(42))              # TypeError
```

**常见误区：用 `type(obj) == set` 判断类型**

```python
# 不推荐：不处理子类
class MySet(set):
    pass

s1 = set()
s2 = MySet()

print(type(s1) == set)     # 输出：True
print(type(s2) == set)     # 输出：False —— 不识别子类！

# 推荐：用 isinstance
print(isinstance(s1, set)) # 输出：True
print(isinstance(s2, set)) # 输出：True  —— 正确识别子类
```

## 4. 原理

### 4.1 集合的底层数据结构：哈希表

集合的底层实现与字典的键存储完全一致——**哈希表**（hash table）。理解哈希表的工作机制，就能理解集合创建的几乎所有行为。

**哈希表的核心结构**：Python 的集合使用一个稀疏数组（entries 数组），每个槽位存储一个元素的哈希值和一个指向实际对象的指针。当你要向集合添加元素时：

1. 计算元素的 `hash()` 值
2. 根据哈希值计算槽位索引
3. 检查该槽位：如果为空，直接放入；如果被占用，用 `==` 比较是否相等
4. 相等则覆盖，不等则使用开放寻址法找下一个槽位

```python
# 当执行 {1, 2, 3} 时，Python 底层大致做了这些事：
# 1. 分配一个初始容量的哈希表
# 2. 对每个元素计算 hash：hash(1) = 1, hash(2) = 2, hash(3) = 3
# 3. 按 hash 值分配到对应槽位
# 4. 如果有 hash 冲突，用开放寻址法解决
```

**这就解释了集合的哪些行为**：

1. **元素必须可哈希**：因为需要 `hash()` 来确定存储位置
2. **元素唯一性**：因为哈希值相同且相等的元素会被存储在同一个槽位
3. **无序性**：因为槽位索引由哈希值决定，而非插入顺序
4. **去重能力**：因为相同元素最终落在同一个槽位

### 4.2 空集合 `set()` 的内存表示

```python
# 空集合在内存中是一个"已初始化但零元素"的哈希表
empty = set()
print(f"空集合大小：{empty.__sizeof__()} 字节")
# 输出示例：空集合大小：216 字节
# 这个空间是哈希表本身的固定开销，不是元素空间

# 加入一个元素后
empty.add(1)
print(f"一个元素后的集合大小：{empty.__sizeof__()} 字节")
# 输出示例：一个元素后的集合大小：216 字节
# 哈希表在容量范围内不会重新分配
```

**空集合 vs 空字典的内存对比**

```python
print(f"set() 占用：{set().__sizeof__()} 字节")
print(f"{{}} 占用：{{}.__sizeof__()} 字节")
# 输出示例：
# set() 占用：216 字节
# {} 占用：72 字节
# 空字典比空集合占用少很多，因为字典可以延迟分配哈希表
```

### 4.3 `{}` 字面量判定字典的语法解析原理

CPython 语法解析器（Grammar/Grammar 文件）定义了如何区分 `{}`、`{1, 2, 3}` 和 `{"a": 1}`：

- `dict` 规则：`'{' [key_value_pair_list] '}'` —— 是否有冒号是关键
- `set` 规则：`'{' element_list '}'` —— 只有元素，没有冒号

当解析器遇到 `{` 时，会向前看（peek）下一个 token：
- 如果看到 `}` —— 空花括号，匹配 `dict` 规则（空字典）
- 如果看到 `identifier :` 或 `string :` 等——匹配 `dict` 规则
- 如果看到元素值（数字、字符串等）且没有 `:`——匹配 `set` 规则

**为什么不能特例化 `{}` 为集合**？如果修改 Python 语法让 `{}` 表示空集合，那么现有所有使用 `{}` 创建空字典的代码都会崩溃——这被视为不可接受的破坏性变更。

```python
# 以下代码在 Python 中广泛使用，如果 {} 变为空集合……
config = {}          # 几乎所有 Python 代码都依赖 {} 是字典
counts = {}          # 计数模式：{element: count}
cache = {}           # 缓存：{key: value}
```

### 4.4 集合推导式的底层执行

集合推导式 `{expr for x in iterable}` 在 CPython 字节码层面等价于：

```python
# 集合推导式的行为等价于：
def _set_comprehension(iterable):
    result = set()
    for x in iterable:
        result.add(expr)
    return result

# 实际的字节码会创建一个临时函数（代码对象）并立即执行，
# 因此推导式内部的变量不会泄露到外部作用域
```

```python
# 变量作用域隔离演示
outer_var = 10
result = {x + outer_var for x in range(3)}
print(result)          # 输出：{10, 11, 12}
print(x)               # NameError: name 'x' is not defined —— 推导式变量不会泄露
```

### 4.5 哈希碰撞对创建性能的影响

当创建集合时传入的元素分布不佳（大量元素产生相同的哈希值），会严重影响性能。

```python
# 极端情况：所有元素哈希值相同
class BadHash:
    def __init__(self, val):
        self.val = val

    def __hash__(self):
        return 42      # 所有实例哈希值相同

    def __repr__(self):
        return f"BadHash({self.val})"

# 创建包含 BadHash 实例的集合会导致大量哈希碰撞
# 因为所有对象的哈希值都是 42，需要频繁使用开放寻址
bad_set = {BadHash(i) for i in range(100)}
print(f"集合大小：{len(bad_set)}")            # 输出：集合大小：100
print(f"集合元素：{bad_set}")
# 输出示例：{BadHash(0), BadHash(1), ...}（顺序不定）

# 性能对比（不精确，仅示意概念）
import time

def measure_creation(cls, count):
    start = time.perf_counter()
    s = {cls(i) for i in range(count)}
    elapsed = time.perf_counter() - start
    return len(s), elapsed

# 由于 BadHash 哈希碰撞，创建时间会显著长于 str（哈希分布均匀）
# 实际运行可能差异巨大，此处只演示原理
```

### 4.6 `set()` 内部对可迭代对象的遍历机制

当调用 `set(iterable)` 时，CPython 内部调用了 `set_update()` 函数（C 实现），流程如下：

1. 检查参数是否已有 `__set__` 方法——如果是另一个集合，直接走优化路径
2. 否则调用 `PyObject_GetIter()` 获取迭代器
3. 对每个元素调用 `set_add_key()` 过程：
   - 计算 `hash(element)`
   - 尝试插入哈希表
   - 如果 `TypeError`，直接向上传播

```python
# set() 内部优化路径演示
# 当传入另一个 set 时，set() 会复用底层的 C 函数
s1 = {1, 2, 3}
s2 = set(s1)       # 内部调用 set_copy() 或 set_update() 的优化路径
print(s2)          # 输出：{1, 2, 3}

# 传入 list 时则逐元素插入
s3 = set([1, 2, 3])  # 内部调用 set_update() 并遍历列表
print(s3)          # 输出：{1, 2, 3}
```

### 4.7 CPython 版本间的实现差异

不同 CPython 版本中，集合的底层实现有所不同，但创建方式的接口保持一致：

- **Python 3.6 之前**：集合使用与字典类似但更精简的哈希表结构，无序性更强
- **Python 3.6+**：字典保留了插入顺序（PEP 520），但**集合仍然是无序的**
- **Python 3.7+**：字典的插入顺序成为语言规范，但集合仍未获得顺序保证

```python
# 集合始终无序，这不会改变
s = {3, 1, 2}
print(s)
# 永远不要假设输出是 {1, 2, 3}
# 实际输出可能是 {1, 2, 3}、{3, 1, 2} 等
```

## 5. 总结

### 5.1 本文内容要点

1. **集合创建方式**
   - 字面量 `{1, 2, 3}` —— 元素已知且固定时使用，性能最优
   - 构造函数 `set()` —— 从可迭代对象创建，空集合的唯一创建方式
   - 集合推导式 `{expr for x in iter}` —— 需要变换/过滤后生成集合时使用

2. **空集合陷阱**
   - `{}` 是**空字典**，不是空集合
   - 创建空集合的**唯一正确方式**是 `set()`
   - 这是 Python 语法历史的遗留设计，不会更改

3. **元素可哈希性约束**
   - 集合元素必须是可哈希类型（`int`、`str`、`tuple`、`frozenset` 等）
   - 不可哈希类型（`list`、`set`、`dict`）放入集合会抛出 `TypeError`
   - 元组内包含不可哈希元素时，元组自身也不可哈希

4. **集合特性**
   - 自动去重：重复元素在创建时就会被合并
   - 无序：集合不维护元素顺序，遍历顺序不可预测
   - 成员判断高效：`in` 操作平均 O(1) 时间复杂度

5. **最佳实践**
   - 空集合用 `set()` 初始化
   - 已知固定元素用字面量 `{...}`
   - 从序列转换用 `set(iterable)`
   - 需要有序唯一集合时使用 `dict.fromkeys()`
   - 集合推导式适合简单变换的场景，复杂逻辑应拆解
