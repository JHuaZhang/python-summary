# 字典常用技巧与惯用法

## 1. 介绍

### 1.1 什么是字典技巧与惯用法

字典（dict）是 Python 中使用频率最高的数据结构之一。掌握了字典的基本增删改查之后，你会发现在实际开发中，有大量重复出现的模式：按某个字段分组、统计频次、安全取值、合并配置、排序输出等。这些模式经过社区多年的沉淀，形成了一套公认的"惯用法"（idiom）——即那些被广泛认可、简洁高效、可读性强的写法。

惯用法不是语法规定，而是经验总结。用惯用法写出来的代码，其他 Python 开发者一眼就能看懂意图；不用惯用法，虽然也能实现功能，但代码往往更冗长、更容易出 bug。

打个比方：字典的基本操作就像认识汉字的笔画，而惯用法就像学会了写成语——同样的意思，用成语表达更精准、更简洁、更有表现力。

### 1.2 本篇涵盖的技巧范围

本篇聚焦于日常开发中最常用的 8 类字典技巧：

| 序号 | 技巧 | 解决的问题 |
|------|------|-----------|
| 1 | 字典推导式 | 用一行代码构建/变换字典 |
| 2 | setdefault 与 defaultdict | 优雅处理"键不存在"场景 |
| 3 | Counter 计数器 | 频次统计与排名 |
| 4 | get() 安全取值 | 避免 KeyError |
| 5 | 字典合并与解包 | 合并多个字典 |
| 6 | 字典排序 | 按 key 或 value 排序输出 |
| 7 | 字典视图与遍历 | 高效遍历与集合运算 |
| 8 | 综合实战 | 串联所有技巧解决真实问题 |

### 1.3 最简示例

在深入每个技巧之前，先看一个"惯用法 vs 原始写法"的对比，感受惯用法的价值。

场景：把一组单词按首字母分组。

**原始写法**（手动判断）：

```python
words = ["apple", "ant", "banana", "bear", "cat"]
groups = {}
for word in words:
    key = word[0]
    if key not in groups:
        groups[key] = []
    groups[key].append(word)
print(groups)
```

**运行结果**：

```text
{'a': ['apple', 'ant'], 'b': ['banana', 'bear'], 'c': ['cat']}
```

**惯用法**（setdefault）：

```python
words = ["apple", "ant", "banana", "bear", "cat"]
groups = {}
for word in words:
    groups.setdefault(word[0], []).append(word)
print(groups)
```

**运行结果**：

```text
{'a': ['apple', 'ant'], 'b': ['banana', 'bear'], 'c': ['cat']}
```

同样的结果，惯用法把 4 行缩成了 1 行，意图也更清晰：`setdefault(word[0], [])` 表达了"如果这个 key 不存在就给个空列表"的语义，`append(word)` 直接追加。这就是惯用法的价值——更少代码、更少出错、更好理解。

## 2. 核心内容

### 2.1 字典推导式

字典推导式（dict comprehension）是用一行表达式从可迭代对象构建字典的语法。它的基本形式是：

```text
{key_expr: value_expr for item in iterable if condition}
```

可以类比为列表推导式的"字典版"——列表推导式生成列表，字典推导式生成字典，语法结构完全对称。

#### 2.1.1 基础用法：列表转字典

最常见的需求之一是把一个列表转成字典，用元素本身作为 key，用索引作为 value。

```python
students = ["Alice", "Bob", "Charlie"]
student_dict = {name: idx for idx, name in enumerate(students)}
print(student_dict)
```

**运行结果**：

```text
{'Alice': 0, 'Bob': 1, 'Charlie': 2}
```

`enumerate(students)` 同时产生索引和元素，推导式把它们分别映射为 key 和 value。

#### 2.1.2 带条件过滤

在推导式末尾加 `if` 条件，可以只保留满足条件的元素。

```python
students = ["Alice", "Bob", "Charlie"]
# 只保留名字长度 > 3 的
filtered = {name: idx for idx, name in enumerate(students) if len(name) > 3}
print(filtered)
```

**运行结果**：

```text
{'Alice': 0, 'Charlie': 2}
```

"Bob" 长度为 3，不满足 `> 3` 的条件，被过滤掉了。

#### 2.1.3 两个列表 zip 成字典

当你有两个平行列表——一个作 key、一个作 value——用 `zip()` 配合推导式是最简洁的写法。

```python
keys = ["name", "age", "city"]
values = ["Alice", 30, "Beijing"]
person = {k: v for k, v in zip(keys, values)}
print(person)
```

**运行结果**：

```text
{'name': 'Alice', 'age': 30, 'city': 'Beijing'}
```

**为什么不直接 `dict(zip(keys, values))`？** 确实可以，`dict(zip(...))` 更短。推导式的优势在于你可以在构建过程中做变换或过滤，比如只保留 age 字段：

```python
# 只保留以 'a' 开头的 key
filtered_person = {k: v for k, v in zip(keys, values) if k.startswith("a")}
print(filtered_person)
```

**运行结果**：

```text
{'age': 30}
```

#### 2.1.4 翻转字典的 key 和 value

把字典的 key 和 value 互换位置，也是一个常见需求——比如从"名字→编号"变成"编号→名字"。

```python
original = {"a": 1, "b": 2, "c": 3}
flipped = {v: k for k, v in original.items()}
print(flipped)
```

**运行结果**：

```text
{1: 'a', 2: 'b', 3: 'c'}
```

**注意事项**：如果原字典有重复的 value，翻转后只保留最后一个 key，因为字典的 key 必须唯一。例如：

```python
dup = {"a": 1, "b": 1}
flipped_dup = {v: k for k, v in dup.items()}
print(flipped_dup)  # {1: 'b'} — 'a' 被覆盖了
```

#### 2.1.5 对 value 做变换

推导式可以在构建字典的同时对 value 进行计算。

```python
prices = {"apple": 5.0, "banana": 3.0, "cherry": 8.0}
# 所有价格打八折
discounted = {fruit: round(price * 0.8, 2) for fruit, price in prices.items()}
print(discounted)
```

**运行结果**：

```text
{'apple': 4.0, 'banana': 2.4, 'cherry': 6.4}
```

#### 2.1.6 从嵌套结构提取

实际开发中经常遇到列表里嵌套字典的情况，推导式可以优雅地提取。

```python
rows = [
    {"name": "Alice", "dept": "eng"},
    {"name": "Bob", "dept": "sales"},
    {"name": "Charlie", "dept": "eng"},
]
name_to_dept = {row["name"]: row["dept"] for row in rows}
print(name_to_dept)
```

**运行结果**：

```text
{'Alice': 'eng', 'Bob': 'sales', 'Charlie': 'eng'}
```

**关键点**：推导式的表达式部分可以访问 `row` 的任意字段，非常灵活。如果数据量大，这种写法比 `for` 循环更简洁且性能相当。

### 2.2 setdefault 与 defaultdict

在操作字典时，"键不存在"是最常见的边界情况。`setdefault()` 方法和 `defaultdict` 类是 Python 提供的两种处理这一情况的惯用工具。

#### 2.2.1 setdefault() 的行为与用法

`setdefault(key, default)` 的行为是：

- 如果 `key` 已存在，返回已有的 value，**不做任何修改**
- 如果 `key` 不存在，将 `key: default` 插入字典，然后返回 `default`

用一个简单例子验证：

```python
d = {"a": 1}

# key 已存在 → 返回已有值，不覆盖
val1 = d.setdefault("a", 100)
print(f"已存在 key: 返回 {val1}, 字典 = {d}")

# key 不存在 → 插入默认值
val2 = d.setdefault("b", 200)
print(f"不存在 key: 返回 {val2}, 字典 = {d}")
```

**运行结果**：

```text
已存在 key: 返回 1, 字典 = {'a': 1}
不存在 key: 返回 200, 字典 = {'a': 1, 'b': 200}
```

#### 2.2.2 setdefault 的经典场景：分组

`setdefault` 最经典的用途是分组——把元素按某个 key 归类到列表中。

```python
words = ["apple", "ant", "banana", "bear", "cat", "cherry"]
groups = {}
for word in words:
    groups.setdefault(word[0], []).append(word)
print(groups)
```

**运行结果**：

```text
{'a': ['apple', 'ant'], 'b': ['banana', 'bear'], 'c': ['cat', 'cherry']}
```

`setdefault(word[0], [])` 确保了：如果首字母还没有对应的列表就创建一个空列表。然后 `.append(word)` 把单词追加进去。一行代码就完成了"检查→初始化→追加"三个动作。

#### 2.2.3 defaultdict 的行为与用法

`defaultdict` 是 `collections` 模块提供的字典子类。创建时传入一个"工厂函数"（factory function），当访问不存在的 key 时，它会自动调用工厂函数生成默认值并插入。

```python
from collections import defaultdict

# list 作为工厂函数 → 不存在的 key 默认值为空列表
d = defaultdict(list)
d["a"].append(1)
d["a"].append(2)
d["b"].append(3)
print(dict(d))
```

**运行结果**：

```text
{'a': [1, 2], 'b': [3]}
```

对比 `setdefault` 的写法，`defaultdict` 不需要每次访问都写 `.setdefault(key, [])`，直接 `d[key].append(...)` 即可，因为默认值是自动生成的。

#### 2.2.4 defaultdict 的三种常见工厂函数

| 工厂函数 | 默认值 | 典型场景 |
|---------|--------|---------|
| `list` | `[]` | 分组：把元素收集到列表 |
| `int` | `0` | 计数：累加出现次数 |
| `set` | `set()` | 去重分组：收集唯一元素 |

**场景 1：分组（list）**

```python
from collections import defaultdict

words2 = ["dog", "duck", "cat", "cow", "bird"]
grouped = defaultdict(list)
for word in words2:
    grouped[word[0]].append(word)
print(dict(grouped))
```

**运行结果**：

```text
{'d': ['dog', 'duck'], 'c': ['cat', 'cow'], 'b': ['bird']}
```

**场景 2：计数（int）**

```python
text = "the quick brown fox jumps over the lazy dog the"
word_count = defaultdict(int)
for word in text.split():
    word_count[word] += 1
print(dict(word_count))
```

**运行结果**：

```text
{'the': 3, 'quick': 1, 'brown': 1, 'fox': 1, 'jumps': 1, 'over': 1, 'lazy': 1, 'dog': 1}
```

`int()` 返回 0，所以 `word_count[word] += 1` 在 key 不存在时等价于 `0 + 1 = 1`，不需要任何判断。

**场景 3：去重分组（set）**

```python
pairs = [("fruit", "apple"), ("fruit", "banana"), ("fruit", "apple"), ("veg", "carrot")]
category_set = defaultdict(set)
for category, item in pairs:
    category_set[category].add(item)
print({k: v for k, v in category_set.items()})
```

**运行结果**：

```text
{'fruit': {'banana', 'apple'}, 'veg': {'carrot'}}
```

注意 "apple" 出现了两次但 set 自动去重了。

#### 2.2.5 setdefault vs defaultdict 对比

| 维度 | setdefault | defaultdict |
|------|-----------|-------------|
| 声明方式 | 普通字典 `{}` | `defaultdict(工厂函数)` |
| 每次访问 | 需写 `.setdefault(key, default)` | 直接 `d[key]` |
| 代码简洁度 | 中等 | 高（循环中更简洁） |
| 适用场景 | 偶尔需要默认值 | 大量需要默认值的循环 |
| 意外副作用 | 低（仅显式调用时触发） | 略高（任何读取都会创建 key） |

**选择建议**：如果你只在个别地方需要默认值，用 `setdefault` 更明确；如果你在循环中频繁操作，`defaultdict` 更清爽。

**defaultdict 的副作用提醒**：`defaultdict` 会在你 merely 检查 `d["x"]` 时就创建 `x` 这个 key（即使你只是想检查它是否存在）。如果你只是想知道一个 key 是否存在，应该用 `key in d` 而不是 `d[key]`。

### 2.3 Counter 计数器

`Counter` 是 `collections` 模块提供的字典子类，专门用于计数。它不仅自动处理"键不存在返回 0"，还提供 `most_common()`、算术运算等计数场景常用功能。

#### 2.3.1 基础计数

`Counter` 接受任何可迭代对象，自动统计每个元素的出现次数。

```python
from collections import Counter

# 统计词频
text = "the quick brown fox jumps over the lazy dog the the the"
counter = Counter(text.split())
print(counter)
```

**运行结果**：

```text
Counter({'the': 5, 'quick': 1, 'brown': 1, 'fox': 1, 'jumps': 1, 'over': 1, 'lazy': 1, 'dog': 1})
```

**字符级统计**——直接传字符串，Counter 会逐字符计数：

```python
char_counter = Counter("abracadabra")
print(char_counter)
```

**运行结果**：

```text
Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
```

#### 2.3.2 most_common(n)：取前 N 高频元素

`most_common(n)` 返回频次最高的 n 个元素，按频次降序排列，结果为 `(element, count)` 元组列表。

```python
print(counter.most_common(3))
print(char_counter.most_common(2))
```

**运行结果**：

```text
[('the', 5), ('quick', 1), ('brown', 1)]
[('a', 5), ('b', 2)]
```

不传参数时返回全部元素按频次降序排列：

```python
print(counter.most_common())
```

**运行结果**：

```text
[('the', 5), ('quick', 1), ('brown', 1), ('fox', 1), ('jumps', 1), ('over', 1), ('lazy', 1), ('dog', 1)]
```

#### 2.3.3 Counter 的算术运算

Counter 支持加减和集合运算，可以方便地合并或对比两个计数结果。

```python
c1 = Counter(a=3, b=1)
c2 = Counter(a=1, b=2)

print("相加:", c1 + c2)     # Counter({'a': 4, 'b': 3})
print("相减:", c1 - c2)     # Counter({'a': 2})  — b 会变成 -1，被丢弃
print("交集:", c1 & c2)     # Counter({'a': 1, 'b': 1})  — 取最小值
print("并集:", c1 | c2)     # Counter({'a': 3, 'b': 2})  — 取最大值
```

**运行结果**：

```text
相加: Counter({'a': 4, 'b': 3})
相减: Counter({'a': 2})
交集: Counter({'a': 1, 'b': 1})
并集: Counter({'a': 3, 'b': 2})
```

**运算规则总结**：

| 运算 | 规则 | 结果中 value < 0 的处理 |
|------|------|----------------------|
| `c1 + c2` | 两个 Counter 的 value 相加 | 保留 |
| `c1 - c2` | value 相减 | 丢弃（不保留 ≤ 0 的） |
| `c1 & c2` | 取两个 Counter 中 value 的最小值 | 只保留 > 0 的 |
| `c1 \| c2` | 取两个 Counter 中 value 的最大值 | 只保留 > 0 的 |

#### 2.3.4 实际场景：日志级别统计

```python
from collections import Counter

log_lines = [
    "INFO startup",
    "ERROR db_timeout",
    "INFO request_done",
    "WARN slow_query",
    "ERROR db_timeout",
    "INFO request_done",
    "ERROR null_pointer",
]
level_counter = Counter(line.split()[0] for line in log_lines)
print("日志级别统计:", level_counter)
print("错误次数:", level_counter["ERROR"])
```

**运行结果**：

```text
日志级别统计: Counter({'INFO': 3, 'ERROR': 3, 'WARN': 1})
错误次数: 3
```

这里用生成器表达式 `line.split()[0] for line in log_lines` 作为 Counter 的输入，提取每行第一个词（日志级别）。Counter 自动完成计数，不需要手动初始化。

### 2.4 get() 安全取值

`dict.get(key, default)` 是避免 `KeyError` 的最直接工具。当 key 不存在时返回 `default`（默认为 `None`），而不是抛出异常。

#### 2.4.1 基础用法

```python
config = {"host": "localhost", "port": 8080, "debug": True}

# 直接索引：key 不存在会 KeyError
# bad = config["timeout"]  # ← 会报错

# get() 不带默认值：key 不存在返回 None
print(config.get("timeout"))      # None

# get() 带默认值：key 不存在返回指定默认值
print(config.get("timeout", 30))  # 30

# key 存在时直接返回对应值
print(config.get("host", "0.0.0.0"))  # localhost
```

**运行结果**：

```text
None
30
localhost
```

#### 2.4.2 实场景：解析可选的查询参数

Web 开发中，查询参数经常是可选的——用户可能传了 `sort` 参数，也可能没传。用 `get()` 可以优雅地提供默认值。

```python
query_params = {"page": "1", "size": "20"}  # 用户没传 sort 参数

page = int(query_params.get("page", 1))
size = int(query_params.get("size", 10))
sort = query_params.get("sort", "created_at")
order = query_params.get("order", "desc")
print(f"分页参数: page={page}, size={size}, sort={sort}, order={order}")
```

**运行结果**：

```text
分页参数: page=1, size=20, sort=created_at, order=desc
```

如果没有 `get()`，你需要为每个参数写 `if key in params: ... else: ...`，代码量翻几倍。

#### 2.4.3 嵌套字典的安全取值

当字典嵌套时，直接索引会层层传播 `KeyError`。用 `get()` 链可以安全地访问嵌套字段。

```python
user = {
    "name": "Alice",
    "address": {"city": "Beijing", "zip": "100000"},
}

# 安全写法：链式 get，任一层不存在都不会报错
city = user.get("address", {}).get("city", "Unknown")
print(f"城市: {city}")

# address 字段存在但 city 不存在的情况
user2 = {"name": "Bob", "address": {}}
city2 = user2.get("address", {}).get("city", "Unknown")
print(f"城市 (address 为空): {city2}")
```

**运行结果**：

```text
城市: Beijing
城市 (address 为空): Unknown
```

**关键理解**：`user.get("address", {})` 返回一个空字典 `{}`（当 `address` 不存在时），然后 `.get("city", "Unknown")` 在这个空字典上取值，自然返回 `"Unknown"`。如果 `address` 存在，返回实际的嵌套字典，再从中取 `city`。两层 `get` 串联，任何一层缺失都不会报错。

#### 2.4.4 get() 实现单次计数

`get()` 也可以用来实现计数，虽然不如 `defaultdict(int)` 和 `Counter` 优雅，但在不方便导入 `collections` 的场景下是可用的惯用法。

```python
letters = "aabbbcccc"
count = {}
for ch in letters:
    count[ch] = count.get(ch, 0) + 1
print(count)
```

**运行结果**：

```text
{'a': 2, 'b': 3, 'c': 4}
```

`count.get(ch, 0)` 在 key 不存在时返回 0，加 1 后再赋值回去。不过在实际开发中，更推荐用 `defaultdict(int)` 或 `Counter`，代码更清晰。

#### 2.4.5 get() vs 直接索引的选择

| 场景 | 推荐方式 | 原因 |
|------|---------|------|
| key 必须存在，不存在是 bug | 直接索引 `d[key]` | 让 KeyError 暴露问题 |
| key 可能不存在，有合理默认值 | `d.get(key, default)` | 避免异常，代码更流畅 |
| key 不存在需要复杂处理逻辑 | `if key in d:` | get 的默认值不够灵活时 |

**核心原则**：不要无脑用 `get()`。如果某个 key 理应存在，直接索引让它尽早暴露 KeyError 反而是好事——异常是发现 bug 的信号，静默返回 None 可能掩盖问题。

### 2.5 字典合并与解包

合并两个或多个字典是配置管理、数据整合等场景的高频操作。Python 提供了多种合并方式，每种有不同的行为特点和版本要求。

#### 2.5.1 update() 方法

`update()` 是最传统的合并方式，它将另一个字典的 key-value 对合并到当前字典中，相同 key 的 value 会被覆盖。

```python
defaults = {"host": "localhost", "port": 8080, "timeout": 30}
overrides = {"port": 9000, "debug": True}

# update() 会原地修改，所以先 copy
merged = defaults.copy()
merged.update(overrides)
print("update() 合并:", merged)
print("原 defaults 未被修改:", defaults)
```

**运行结果**：

```text
update() 合并: {'host': 'localhost', 'port': 9000, 'timeout': 30, 'debug': True}
原 defaults 未被修改: {'host': 'localhost', 'port': 8080, 'timeout': 30}
```

**关键点**：`update()` 是原地操作，会修改调用者。如果你不想修改原字典，必须先 `.copy()` 再 `update()`。`port` 被 overrides 的 9000 覆盖了，`debug` 是新增的。

#### 2.5.2 `{**d1, **d2}` 解包合并

Python 3.5+ 支持用 `**` 操作符在字典字面量中解包其他字典。写法非常直观，且生成新字典不修改原字典。

```python
defaults = {"host": "localhost", "port": 8080, "timeout": 30}
overrides = {"port": 9000, "debug": True}

# 解包合并：后面的 key 覆盖前面的
merged = {**defaults, **overrides}
print("** 解包合并:", merged)

# 可以同时加入额外 key
merged_extra = {**defaults, **overrides, "retries": 3}
print("解包合并 + 额外 key:", merged_extra)
```

**运行结果**：

```text
** 解包合并: {'host': 'localhost', 'port': 9000, 'timeout': 30, 'debug': True}
解包合并 + 飞外 key: {'host': 'localhost', 'port': 9000, 'timeout': 30, 'debug': True, 'retries': 3}
```

合并规则与 `update()` 一致：后面的字典的 key 覆盖前面的。额外 key 直接写在花括号里即可。

#### 2.5.3 `|` 运算符（Python 3.9+）

Python 3.9 引入了字典合并运算符 `|` 和原地合并运算符 `|=`，语义更接近数学集合运算。

```python
defaults = {"host": "localhost", "port": 8080, "timeout": 30}
overrides = {"port": 9000, "debug": True}

# | 生成新字典
merged_pipe = defaults | overrides
print("| 运算符合并:", merged_pipe)

# |= 原地合并
config = {"a": 1, "b": 2}
config |= {"b": 3, "c": 4}
print("|= 原地合并:", config)
```

**运行结果**：

```text
| 运算符合并: {'host': 'localhost', 'port': 9000, 'timeout': 30, 'debug': True}
|= 原地合并: {'a': 1, 'b': 3, 'c': 4}
```

`|` 和 `|=` 之间的关系，就像 `+` 和 `+=` 之于数字：`|` 生成新对象，`|=` 原地修改。

#### 2.5.4 多个字典合并

解包和 `|` 运算符都支持链式合并多个字典。

```python
d1 = {"a": 1}
d2 = {"b": 2}
d3 = {"c": 3}
d4 = {"a": 100}  # 与 d1 有相同 key

# 解包方式
multi_unpack = {**d1, **d2, **d3, **d4}
print("多字典解包合并:", multi_unpack)

# | 运算符链式
multi_pipe = d1 | d2 | d3 | d4
print("多字典 | 合并:", multi_pipe)
```

**运行结果**：

```text
多字典解包合并: {'a': 100, 'b': 2, 'c': 3}
多字典 | 合并: {'a': 100, 'b': 2, 'c': 3}
```

`d4` 的 `a: 100` 覆盖了 `d1` 的 `a: 1`，因为 d4 在链式合并中排在最后。

#### 2.5.5 合并方式对比

| 方式 | 是否原地修改 | 版本要求 | 可读性 | 适用场景 |
|------|------------|---------|--------|---------|
| `update()` | 是 | 所有版本 | 中等 | 需要原地修改时 |
| `{**d1, **d2}` | 否 | 3.5+ | 高 | 生成新字典 |
| `d1 \| d2` | 否 | 3.9+ | 高 | 生成新字典 |
| `d1 \|= d2` | 是 | 3.9+ | 高 | 原地修改 |

**推荐**：如果你的 Python 版本 >= 3.9，优先用 `|` 和 `|=`；如果 >= 3.5，用 `{**d1, **d2}`；如果需要兼容更老版本，用 `update()` + `copy()`。

### 2.6 字典排序

Python 3.7+ 中 `dict` 保持插入顺序，但这个顺序是"插入顺序"而非"排序顺序"。如果需要按 key 或 value 排序，需要用 `sorted()` 函数生成一个新的排好序的字典。

#### 2.6.1 按 value 排序

`sorted()` 接受一个可迭代对象并返回排序后的列表。对字典的 `items()` 排序时，通过 `key` 参数指定排序依据。

```python
scores = {"Alice": 85, "Bob": 92, "Charlie": 78, "David": 96, "Eve": 88}

# 按 value 升序
by_value_asc = dict(sorted(scores.items(), key=lambda item: item[1]))
print("按分数升序:", by_value_asc)

# 按 value 降序
by_value_desc = dict(sorted(scores.items(), key=lambda item: item[1], reverse=True))
print("按分数降序:", by_value_desc)
```

**运行结果**：

```text
按分数升序: {'Charlie': 78, 'Alice': 85, 'Eve': 88, 'Bob': 92, 'David': 96}
按分数降序: {'David': 96, 'Bob': 92, 'Eve': 88, 'Alice': 85, 'Charlie': 78}
```

**关键理解**：`scores.items()` 返回的是 `(key, value)` 元组的视图。`lambda item: item[1]` 表示用元组的第二个元素（即 value）作为排序依据。`sorted()` 返回一个列表，`dict()` 把排序后的列表转回字典。

#### 2.6.2 按 key 排序

```python
unordered = {"zebra": 1, "apple": 2, "mango": 3, "banana": 4}

# 按 key 字母序排序
by_key = dict(sorted(unordered.items()))
print("按 key 排序:", by_key)

# 按 key 长度排序
by_key_len = dict(sorted(unordered.items(), key=lambda item: len(item[0])))
print("按 key 长度排序:", by_key_len)
```

**运行结果**：

```text
按 key 排序: {'apple': 2, 'banana': 4, 'mango': 3, 'zebra': 1}
按 key 长度排序: {'zebra': 1, 'apple': 2, 'mango': 3, 'banana': 4}
```

不传 `key` 参数时，`sorted()` 默认按元组的第一个元素（即 key）排序，所以 `sorted(unordered.items())` 等价于 `sorted(unordered.items(), key=lambda item: item[0])`。

#### 2.6.3 复合排序条件

当排序条件有多个维度时，`key` 函数返回一个元组，`sorted()` 会按元组中元素的先后顺序依次比较。

```python
data = {"b": 3, "a": 3, "c": 1, "d": 2}

# 先按 value 降序（用负数实现），value 相同再按 key 升序
compound = dict(sorted(data.items(), key=lambda item: (-item[1], item[0])))
print("复合排序 (value降→key升):", compound)
```

**运行结果**：

```text
复合排序 (value降→key升): {'a': 3, 'b': 3, 'd': 2, 'c': 1}
```

`a` 和 `b` 的 value 都是 3（最高），按 key 升序排列，所以 `a` 在 `b` 前面。`-item[1]` 是一个常用技巧：对数字取负数可以把升序变降序，这样在一个元组中就能混合升序和降序。

#### 2.6.4 排序后取前 N

`sorted()` 返回列表，可以用切片取前 N 个再转成字典。

```python
scores = {"Alice": 85, "Bob": 92, "Charlie": 78, "David": 96, "Eve": 88}

top3 = dict(sorted(scores.items(), key=lambda item: item[1], reverse=True)[:3])
print("前三名:", top3)
```

**运行结果**：

```text
前三名: {'David': 96, 'Bob': 92, 'Eve': 88}
```

#### 2.6.5 按 value 的属性排序

当字典的 value 是复杂对象（列表、字典等）时，可以在 `key` 函数中访问其属性。

```python
tags = {
    "python": ["coding", "snake"],
    "java": ["coffee", "island", "programming"],
    "go": ["board_game"],
}

# 按 value（列表）的长度排序
by_list_len = dict(sorted(tags.items(), key=lambda item: len(item[1]), reverse=True))
print("按 value 列表长度排序:", by_list_len)
```

**运行结果**：

```text
按 value 列表长度排序: {'java': ['coffee', 'island', 'programming'], 'python': ['coding', 'snake'], 'go': ['board_game']}
```

### 2.7 字典视图与遍历

字典的 `keys()`、`values()`、`items()` 方法返回的不是列表的副本，而是"视图对象"（view object）。理解视图的特性对于高效遍历和集合运算至关重要。

#### 2.7.1 三种视图对象

```python
d = {"apple": 5, "banana": 3, "cherry": 8}

keys_view = d.keys()
values_view = d.values()
items_view = d.items()

print("keys 视图:", keys_view)
print("values 视图:", values_view)
print("items 视图:", items_view)
print("类型:", type(keys_view))
```

**运行结果**：

```text
keys 视图: dict_keys(['apple', 'banana', 'cherry'])
values 视图: dict_values([5, 3, 8])
items 视图: dict_items([('apple', 5), ('banana', 3), ('cherry', 8)])
类型: <class 'dict_keys'>
```

#### 2.7.2 视图是动态的

视图不是快照副本，而是对字典内容的实时映射——字典发生变化时，视图的内容会同步更新。

```python
d = {"apple": 5, "banana": 3, "cherry": 8}
keys_view = d.keys()

print(f"修改前 keys: {list(keys_view)}")
d["date"] = 10
print(f"添加 date 后 keys: {list(keys_view)}")
del d["apple"]
print(f"删除 apple 后 keys: {list(keys_view)}")
```

**运行结果**：

```text
修改前 keys: ['apple', 'banana', 'cherry']
添加 date 后 keys: ['apple', 'banana', 'cherry', 'date']
删除 apple 后 keys: ['banana', 'cherry', 'date']
```

视图随着字典的增删自动更新，不需要重新调用 `keys()`。这在某些场景下很有用——比如你保存了一个 keys 视图，之后字典被修改了，你拿到的还是最新的 keys。

#### 2.7.3 遍历的最佳实践

```python
d2 = {"a": 1, "b": 2, "c": 3}

# 只需要 key
for key in d2:  # 等价于 d2.keys()
    print(f"  key={key}")

# 同时需要 key 和 value（最常用）
for key, value in d2.items():
    print(f"  {key} = {value}")

# 只需要 value
for value in d2.values():
    print(f"  value={value}")
```

**运行结果**：

```text
  key=a
  key=b
  key=c
  a = 1
  b = 2
  c = 3
  value=1
  value=2
  value=3
```

**遍历建议**：

- 默认遍历 `for key in d` 等价于遍历 keys，最简洁
- 需要 key+value 时用 `d.items()`，避免在循环体内再 `d[key]` 取值
- 只需要 value 时用 `d.values()`，避免不必要的 key

#### 2.7.4 用视图做集合运算

`keys()` 和 `items()` 返回的视图支持集合运算（交集、并集、差集），这在比较两个字典时非常方便。注意 `values()` 视图不支持集合运算，因为值可以重复。

```python
d3 = {"a": 1, "b": 2, "c": 3}
d4 = {"b": 20, "c": 30, "d": 40}

# 交集：两个字典都有的 key
common_keys = d3.keys() & d4.keys()
print(f"共同 key: {common_keys}")

# 差集：d3 有但 d4 没有的 key
only_d3 = d3.keys() - d4.keys()
print(f"只在 d3 的 key: {only_d3}")

# 并集：所有 key
all_keys = d3.keys() | d4.keys()
print(f"所有 key: {all_keys}")

# items 也支持集合运算
common_items = d3.items() & d4.items()
print(f"共同 items: {common_items}")
```

**运行结果**：

```text
共同 key: {'b', 'c'}
只在 d3 的 key: {'a'}
所有 key: {'d', 'b', 'a', 'c'}
共同 items: set()
```

`common_items` 为空集，因为虽然 `b` 和 `c` 的 key 相同，但 value 不同（`d3` 中 `b: 2`，`d4` 中 `b: 20`），所以 items 没有交集。

#### 2.7.5 遍历时安全删除

**直接在遍历字典的同时删除 key 会导致 RuntimeError**，因为字典在遍历期间被修改了。有两种安全做法。

**正确做法 1：先收集要删的 key，遍历完再删**

```python
d5 = {"a": 1, "b": 2, "c": 3, "d": 4}
to_remove = [k for k, v in d5.items() if v < 3]
for key in to_remove:
    del d5[key]
print("删除 value<3 后:", d5)
```

**运行结果**：

```text
删除 value<3 后: {'c': 3, 'd': 4}
```

**正确做法 2：字典推导式重建**

```python
d6 = {"a": 1, "b": 2, "c": 3, "d": 4}
d6 = {k: v for k, v in d6.items() if v >= 3}
print("推导式过滤后:", d6)
```

**运行结果**：

```text
推导式过滤后: {'c': 3, 'd': 4}
```

推导式方式更简洁且不修改原字典（生成新字典），但会创建新对象。如果字典很大且只需要删除少量 key，先收集再删除的方式内存效率更高。

**错误做法（会报错）**：

```python
# for key in d5:
#     if d5[key] < 3:
#         del d5[key]  # RuntimeError: dictionary changed size during iteration
```

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

#### 3.1.1 分组场景

**不推荐**（手动判断）：

```python
groups = {}
for word in words:
    key = word[0]
    if key not in groups:
        groups[key] = []
    groups[key].append(word)
```

**推荐**（defaultdict）：

```python
from collections import defaultdict
groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)
```

**原因**：`defaultdict` 消除了手动判断 `if key not in`，代码更简洁，意图更明确（"我需要一个以列表为默认值的字典"）。

#### 3.1.2 计数场景

**不推荐**（手动判断）：

```python
count = {}
for word in text.split():
    if word in count:
        count[word] += 1
    else:
        count[word] = 1
```

**推荐**（Counter）：

```python
from collections import Counter
count = Counter(text.split())
```

**原因**：`Counter` 一行搞定，且提供 `most_common()` 等便捷方法。

#### 3.1.3 安全取值场景

**不推荐**（先检查再取值）：

```python
if "timeout" in config:
    timeout = config["timeout"]
else:
    timeout = 30
```

**推荐**（get 方法）：

```python
timeout = config.get("timeout", 30)
```

**原因**：一行代替四行，消除分支逻辑，可读性更高。

#### 3.1.4 字典合并场景

**不推荐**（循环合并）：

```python
merged = {}
for k, v in d1.items():
    merged[k] = v
for k, v in d2.items():
    merged[k] = v
```

**推荐**（解包合并）：

```python
merged = {**d1, **d2}
```

**原因**：解包语法直观表达"合并"意图，且性能优于循环。

#### 3.1.5 遍历取值场景

**不推荐**（遍历 key 再索引取 value）：

```python
for key in d:
    value = d[key]
    process(key, value)
```

**推荐**（直接遍历 items）：

```python
for key, value in d.items():
    process(key, value)
```

**原因**：遍历 `items()` 避免了每次循环中的字典查找，性能更好且代码更简洁。

### 3.2 常见错误模式及修正

| 错误模式 | 后果 | 修正方式 |
|---------|------|---------|
| 遍历时直接 `del d[key]` | `RuntimeError` | 先收集 key 再删，或用推导式重建 |
| 翻转有重复 value 的字典 | 数据丢失 | 先检查 value 是否唯一 |
| defaultdict 只检查不写入 | 意外创建 key | 用 `key in d` 检查存在性 |
| `get()` 无脑用于必然存在的 key | 掩盖 bug | 必然存在的 key 用直接索引 |
| 排序后忘记 `dict()` 转换 | 拿到的是列表不是字典 | `dict(sorted(...))` |

### 3.3 性能取舍建议

| 操作 | 时间复杂度 | 建议 |
|------|-----------|------|
| `d[key]` 取值/赋值 | O(1) | 首选，字典的核心优势 |
| `key in d` | O(1) | 检查存在性首选，不要用 `key in d.keys()` |
| `d.get(key)` | O(1) | 安全取值首选 |
| `sorted(d.items())` | O(n log n) | 排序无法更快，但只在需要时排序 |
| `dict(d1, **d2)` | O(n) | 合并大量字典时注意总大小 |
| 字典推导式 | O(n) | 与 for 循环性能相当，但更简洁 |

## 4. 原理

### 4.1 字典的底层结构：哈希表

Python 字典的底层实现是哈希表（hash table）。理解哈希表的基本原理，有助于你理解为什么字典的查找是 O(1)、为什么 key 必须可哈希、为什么遍历顺序与插入顺序一致。

#### 4.1.1 哈希表的基本工作流程

存入一个 key-value 对时，Python 做以下操作：

```text
1. 计算 key 的哈希值：hash(key)
2. 根据哈希值定位存储位置：index = hash(key) % table_size
3. 将 key-value 对存入该位置
```

查找时：

```text
1. 计算待查找 key 的哈希值
2. 定位到存储位置
3. 比较该位置的 key 是否与目标 key 相等
4. 相等 → 返回 value；不等 → 处理冲突
```

这就是为什么查找是 O(1)——不需要遍历所有元素，直接通过哈希值定位。

#### 4.1.2 为什么 key 必须可哈希

字典的 key 必须是不可变类型（如 `str`、`int`、`tuple`），不能是可变类型（如 `list`、`dict`）。原因是哈希值在 key 存入字典后不能改变——如果 key 的内容变了，哈希值也变了，字典就找不到原来的存储位置了。

```python
# 不可变类型可以作为 key
d = {42: "int", "name": "str", (1, 2): "tuple"}
print(d[(1, 2)])

# 可变类型不能作为 key
# d = {[1, 2]: "list"}  # TypeError: unhashable type: 'list'
```

**运行结果**：

```text
tuple
```

#### 4.1.3 Python 3.7+ 的有序字典

从 Python 3.7 开始，字典保证按插入顺序维护 key。这不是语言规范的偶然，而是 CPython 3.6 引入的"紧凑字典"（compact dict）实现的特性，在 3.7 中被正式纳入语言规范。

原理简述：紧凑字典用两个数组分别存储索引和 key-value 对。插入时按顺序追加到 key-value 数组，索引数组记录哈希值对应的位置。遍历时按 key-value 数组的物理顺序遍历，自然就是插入顺序。

```python
d = {}
d["first"] = 1
d["second"] = 2
d["third"] = 3
print(list(d.keys()))  # 顺序与插入顺序一致
```

**运行结果**：

```text
['first', 'second', 'third']
```

#### 4.1.4 视图对象为什么不复制

`keys()`、`values()`、`items()` 返回的视图对象不复制字典数据，而是维护一个对字典的引用。每次访问视图时，视图直接读取字典的当前状态。这样设计的好处是：

1. **零拷贝**：调用 `keys()` 不会产生内存复制，无论字典多大都只是 O(1) 操作
2. **实时性**：视图始终反映字典的最新状态

这就是为什么前面演示的 `keys_view` 在字典修改后自动更新的原因。

### 4.2 defaultdict 的工作原理

`defaultdict` 是 `dict` 的子类，它重写了 `__missing__` 方法。当访问一个不存在的 key 时，普通 dict 会抛出 `KeyError`，而 defaultdict 会调用 `__missing__` 方法，该方法使用创建时传入的工厂函数生成默认值并插入字典，然后返回这个默认值。

```python
from collections import defaultdict

d = defaultdict(list)
# d["x"] 不存在 → 触发 __missing__ → 调用 list() 得到 [] → 插入 d["x"] = [] → 返回 []
d["x"].append(1)
print(d["x"])  # [1]
print("x" in d)  # True — 已经被创建了
```

**运行结果**：

```text
[1]
True
```

**这就是 defaultdict 副作用的根源**：即使你只是 `d["x"]` 检查一下（而不是 `d.get("x")`），也会触发 `__missing__` 创建这个 key。如果你只是想检查 key 是否存在，一定要用 `"x" in d`。

本文围绕字典的常用技巧与惯用法展开，主要介绍了以下内容：

- **字典推导式**：用一行表达式构建、过滤、变换、翻转字典，语法与列表推导式对称
- **setdefault 与 defaultdict**：两种处理"键不存在"的惯用法，setdefault 适合偶尔使用，defaultdict 适合循环中大量使用
- **Counter 计数器**：专用于计数的字典子类，提供 most_common() 和算术运算，是频次统计的首选工具
- **get() 安全取值**：避免 KeyError 的最直接方式，支持链式调用实现嵌套字典的安全访问
- **字典合并与解包**：update()、{**d1, **d2}、| 运算符三种方式，各有不同的版本要求和适用场景
- **字典排序**：用 sorted() 配合 key 函数实现按 key/value/复合条件排序，注意 dict() 转换
- **字典视图与遍历**：keys/values/items 返回动态视图，支持集合运算；遍历时删除需先收集或用推导式重建
- **最佳实践与原理**：推荐写法 vs 不推荐写法对比，底层哈希表机制，defaultdict 的 __missing__ 原理
