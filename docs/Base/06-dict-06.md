# 字典推导式

## 1. 介绍

### 1.1 什么是字典推导式

字典推导式（Dictionary Comprehension）是 Python 中一种用简洁语法快速创建字典的表达式。它的核心思想是：遍历一个可迭代对象，对每个元素计算出一个键和一个值，把这些键值对收集成一个新的字典。

你可以把它理解为"for 循环构建字典"的压缩写法。传统的 for 循环需要先建一个空字典，再逐个添加键值对，代码至少三行起步；字典推导式把整个过程浓缩成一行，而且更接近自然语言的表达方式。

```python
# 传统 for 循环写法
result = {}
for k, v in [("a", 1), ("b", 2), ("c", 3)]:
    result[k] = v

# 字典推导式——一行搞定
result = {k: v for k, v in [("a", 1), ("b", 2), ("c", 3)]}
```

两种写法完全等价，结果都是 `{'a': 1, 'b': 2, 'c': 3}`。但推导式更紧凑，也更符合 Python 的声明式风格——你描述的是"结果是什么样的"，而不是"怎么一步步构建的"。

### 1.2 解决什么问题

字典推导式主要解决三类问题：

| 问题场景 | 举例 | 推导式的优势 |
|---------|------|-------------|
| 批量创建 | 从两个列表组合成字典 | 一行代替三行 for 循环 |
| 批量转换 | 把字典所有值转为字符串 | 在创建的同时完成转换 |
| 批量过滤 | 只保留值大于 10 的项 | 在创建的同时完成过滤 |

如果用 dict() 构造函数，你能创建字典但无法同时做转换和过滤；推导式把"创建 + 转换 + 过滤"三件事合为一个表达式，这是它最大的价值。

### 1.3 最简示例

先用一个最简单的例子建立感性认识：

```python
# 从键值对列表创建字典
pairs = [("a", 1), ("b", 2), ("c", 3)]
d = {k: v for k, v in pairs}
print(d)   # {'a': 1, 'b': 2, 'c': 3}
```

读法：对于 `pairs` 中的每一对 `k, v`，把 `k: v` 放进新字典。花括号 `{}` 表示结果是字典，`k: v` 是键值对的表达式，`for k, v in pairs` 是遍历的来源。

## 2. 核心内容

### 2.1 基本语法

字典推导式的基本语法格式如下：

```text
{key_expr: value_expr for item in iterable}
```

- `key_expr`：键的表达式，可以是 item 本身，也可以是从 item 计算出来的值
- `value_expr`：值的表达式，同样可以是 item 本身或计算值
- `for item in iterable`：遍历可迭代对象，和普通 for 循环语法一致

**从键值对列表创建**

最基础的用法——从一个包含元组的列表创建字典：

```python
pairs = [("a", 1), ("b", 2), ("c", 3)]
d = {k: v for k, v in pairs}
print(d)   # {'a': 1, 'b': 2, 'c': 3}
```

这里的 `for k, v in pairs` 使用了元组解包，每一对 `("a", 1)` 被拆成 `k="a"` 和 `v=1`，然后 `k: v` 即 `"a": 1` 被放入新字典。

**从两个列表创建**

当你有 keys 和 values 两个分开的列表时，配合 `zip` 使用推导式：

```python
keys = ["name", "age", "city"]
values = ["张三", 20, "北京"]

d = {k: v for k, v in zip(keys, values)}
print(d)   # {'name': '张三', 'age': 20, 'city': '北京'}
```

`zip(keys, values)` 把两个列表"拉链"成 `[("name", "张三"), ("age", 20), ("city", "北京")]`，推导式再把这些元组转成字典。

**从已有字典创建（浅拷贝）**

遍历原字典的 `items()`，重新组装一个新字典：

```python
original = {"a": 1, "b": 2, "c": 3}
copy_d = {k: v for k, v in original.items()}
print(copy_d)   # {'a': 1, 'b': 2, 'c': 3}

# 验证是独立的对象
copy_d["a"] = 99
print(original)   # {'a': 1, 'b': 2, 'c': 3}  ← 原字典不受影响
print(copy_d)     # {'a': 99, 'b': 2, 'c': 3}
```

注意这是浅拷贝——如果值是可变对象（如列表、字典），新字典中的引用仍指向同一个对象。

**等价的 for 循环写法**

理解推导式最有效的方法是对比等价的 for 循环：

```python
# 推导式
d_comp = {k: v for k, v in [("x", 10), ("y", 20)]}

# 等价的 for 循环
d_loop = {}
for k, v in [("x", 10), ("y", 20)]:
    d_loop[k] = v

print(d_comp)   # {'x': 10, 'y': 20}
print(d_loop)   # {'x': 10, 'y': 20}
print(d_comp == d_loop)   # True
```

两者结果完全相同。推导式只是把三行（建空字典、循环、赋值）压成了一行。

**键和值可以是表达式**

推导式的强大之处在于：键和值不限于直接传过来的值，可以是任意表达式：

```python
nums = [1, 2, 3, 4, 5]

# 键是数字，值是平方
squares = {n: n ** 2 for n in nums}
print(squares)   # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 键是平方，值是原数
reverse_squares = {n ** 2: n for n in nums}
print(reverse_squares)   # {1: 1, 4: 2, 9: 3, 16: 4, 25: 5}

# 键是字符串，值是字符串长度
words = ["apple", "banana", "cherry"]
word_lengths = {w: len(w) for w in words}
print(word_lengths)   # {'apple': 5, 'banana': 6, 'cherry': 6}
```

这就远超 dict() 构造函数的能力——dict() 只能把给定的键值对原封不动地放进字典，而推导式可以在放入的同时做计算。

**键重复时后者覆盖前者**

和 dict() 一样，如果遍历过程中出现了重复的键，后出现的值会覆盖先出现的值：

```python
data = [("a", 1), ("b", 2), ("a", 3)]
d = {k: v for k, v in data}
print(d)   # {'a': 3, 'b': 2}  ← 'a' 的值被后出现的 3 覆盖
```

利用这个特性，可以用推导式实现"去重保留最后值"的逻辑。

**从 range 和 enumerate 创建**

```python
# 从 range 创建：数字 → 立方
d_range = {i: i ** 3 for i in range(1, 6)}
print(d_range)   # {1: 1, 2: 8, 3: 27, 4: 64, 5: 125}

# 从 enumerate 创建：索引 → 元素
items = ["apple", "banana", "cherry"]
indexed = {index: fruit for index, fruit in enumerate(items)}
print(indexed)   # {0: 'apple', 1: 'banana', 2: 'cherry'}

# 从字符串创建字符索引（注意重复字符会覆盖）
s = "hello"
char_index = {ch: i for i, ch in enumerate(s)}
print(char_index)   # {'h': 0, 'e': 1, 'l': 3, 'o': 4}
# 'l' 重复，后出现的 index=3 覆盖了 index=2
```

**与列表推导式的对比**

```python
nums = [1, 2, 3]

# 列表推导式：方括号，产出列表
list_comp = [n ** 2 for n in nums]        # [1, 4, 9]

# 字典推导式：花括号，产出字典，需要 key: value 对
dict_comp = {n: n ** 2 for n in nums}     # {1: 1, 2: 4, 3: 9}

print(f"列表推导式: {list_comp} (类型: {type(list_comp).__name__})")
print(f"字典推导式: {dict_comp} (类型: {type(dict_comp).__name__})")
```

区别只在两点：用 `{}` 而不是 `[]`，表达式中需要 `key: value` 对而不是单个值。

### 2.2 条件过滤

在基本语法的基础上加一个 `if` 子句，就能在创建字典的同时做条件过滤：

```text
{key_expr: value_expr for item in iterable if condition}
```

只有满足 `condition` 的元素才会被放入新字典，不满足的会被跳过。

**基本条件过滤**

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}

# 只保留值大于 2 的项
filtered = {k: v for k, v in d.items() if v > 2}
print(filtered)   # {'c': 3, 'd': 4, 'e': 5}

# 只保留值小于等于 2 的项
small = {k: v for k, v in d.items() if v <= 2}
print(small)   # {'a': 1, 'b': 2}
```

**过滤键**

根据键的特征进行过滤，在数据处理中非常实用：

```python
d2 = {"name": "张三", "age": 20, "email": "test@test.com", "phone": "123"}

# 只保留非敏感信息（排除 email 和 phone）
public = {k: v for k, v in d2.items() if k not in ("email", "phone")}
print(public)   # {'name': '张三', 'age': 20}

# 只保留白名单中的键
allowed_keys = {"name", "email"}
selected = {k: v for k, v in d2.items() if k in allowed_keys}
print(selected)   # {'name': '张三', 'email': 'test@test.com'}

# 键名包含特定前缀
d3 = {"user_name": "张三", "user_age": 20, "admin_role": "super", "user_email": "a@b.com"}
user_fields = {k: v for k, v in d3.items() if k.startswith("user_")}
print(user_fields)   # {'user_name': '张三', 'user_age': 20, 'user_email': 'a@b.com'}
```

**过滤值**

根据值的类型或特征过滤，在混合类型字典中特别有用：

```python
mixed = {"a": 1, "b": "hello", "c": 3.14, "d": [1, 2], "e": True, "f": None}

# 只保留数字类型的值（排除 bool，因为 bool 是 int 的子类）
nums = {k: v for k, v in mixed.items() if isinstance(v, (int, float)) and not isinstance(v, bool)}
print(nums)   # {'a': 1, 'c': 3.14}

# 排除 None 值
no_none = {k: v for k, v in mixed.items() if v is not None}
print(no_none)   # {'a': 1, 'b': 'hello', 'c': 3.14, 'd': [1, 2], 'e': True}
```

**多条件组合**

使用 `and`、`or` 组合多个条件，实现复杂过滤逻辑：

```python
d4 = {"apple": 3.5, "banana": 2.8, "cherry": 8.0, "date": 6.5, "fig": 1.2}

# 价格 > 3 且 < 7 的水果
mid_range = {k: v for k, v in d4.items() if 3 < v < 7}
print(mid_range)   # {'apple': 3.5, 'date': 6.5}

# 价格 > 6 或 < 2 的水果
extremes = {k: v for k, v in d4.items() if v > 6 or v < 2}
print(extremes)   # {'cherry': 8.0, 'date': 6.5, 'fig': 1.2}

# 价格 > 2 且键名以 a 开头
custom = {k: v for k, v in d4.items() if v > 2 and k.startswith("a")}
print(custom)   # {'apple': 3.5}
```

**过滤同时进行值转换**

条件过滤和值转换可以在一个表达式中完成：

```python
d5 = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}

# 保留偶数值，并将值放大 10 倍
even_x10 = {k: v * 10 for k, v in d5.items() if v % 2 == 0}
print(even_x10)   # {'b': 20, 'd': 40}

# 保留奇数值，值转为字符串
odd_str = {k: f"奇数{v}" for k, v in d5.items() if v % 2 != 0}
print(odd_str)   # {'a': '奇数1', 'c': '奇数3', 'e': '奇数5'}
```

**从列表中过滤并创建字典**

```python
words = ["apple", "cat", "banana", "dog", "cherry", "hi"]

# 只保留长度 > 3 的单词及其长度
long_words = {w: len(w) for w in words if len(w) > 3}
print(long_words)   # {'apple': 5, 'banana': 6, 'cherry': 6}

# 从数字列表创建，只保留偶数及其平方
nums = list(range(1, 11))
even_squares = {n: n ** 2 for n in nums if n % 2 == 0}
print(even_squares)   # {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
```

**等价 for 循环对比**

```python
d6 = {"a": 1, "b": 2, "c": 3, "d": 4}

# 推导式
result_comp = {k: v for k, v in d6.items() if v > 2}

# 等价 for 循环
result_loop = {}
for k, v in d6.items():
    if v > 2:
        result_loop[k] = v

print(result_comp)   # {'c': 3, 'd': 4}
print(result_loop)   # {'c': 3, 'd': 4}
print(result_comp == result_loop)   # True
```

**复杂条件示例**

实际业务中，条件往往涉及嵌套字典的字段判断：

```python
students = {
    "张三": {"score": 85, "status": "active"},
    "李四": {"score": 92, "status": "active"},
    "王五": {"score": 78, "status": "inactive"},
    "赵六": {"score": 95, "status": "active"},
}

# 活跃且成绩 > 80 的学生，键为姓名，值为成绩
active_top = {
    name: info["score"]
    for name, info in students.items()
    if info["status"] == "active" and info["score"] > 80
}
print(active_top)   # {'张三': 85, '李四': 92, '赵六': 95}
```

### 2.3 键值转换

推导式最强大的能力之一是：在创建字典的同时，对键和值进行任意转换。这比用 dict() 创建后再遍历修改高效得多。

**反转键值对**

最常见的转换场景——键变值，值变键：

```python
original = {"a": 1, "b": 2, "c": 3}
reversed_d = {v: k for k, v in original.items()}
print(reversed_d)   # {1: 'a', 2: 'b', 3: 'c'}
```

反转时要特别注意两点：

```python
# 注意一：值必须可哈希才能作为新键
d_with_list = {"a": [1, 2], "b": [3]}
# {v: k for k, v in d_with_list.items()}  # TypeError: unhashable type: 'list'

# 注意二：值有重复时，后出现的覆盖前面的
d_dup = {"a": 1, "b": 2, "c": 1}
reversed_dup = {v: k for k, v in d_dup.items()}
print(reversed_dup)   # {1: 'c', 2: 'b'}  ← 'c' 覆盖了 'a'
```

**键的转换**

统一修改键名格式，在数据规范化中经常用到：

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# 键名统一转为大写
upper_keys = {k.upper(): v for k, v in d.items()}
print(upper_keys)   # {'NAME': '张三', 'AGE': 20, 'CITY': '北京'}

# 键名添加前缀
prefixed = {f"user_{k}": v for k, v in d.items()}
print(prefixed)   # {'user_name': '张三', 'user_age': 20, 'user_city': '北京'}

# 键名下划线转横线
d2 = {"first_name": "张", "last_name": "三", "full_name": "张三"}
renamed = {k.replace("_", "-"): v for k, v in d2.items()}
print(renamed)   # {'first-name': '张', 'last-name': '三', 'full-name': '张三'}
```

**值的转换**

对值进行类型转换或数学运算：

```python
# 所有值转为字符串
d3 = {"a": 1, "b": 2.5, "c": True, "d": None}
str_values = {k: str(v) for k, v in d3.items()}
print(str_values)   # {'a': '1', 'b': '2.5', 'c': 'True', 'd': 'None'}

# 字符串值转为浮点
str_nums = {"a": "3.14", "b": "2.718", "c": "1.414"}
float_values = {k: float(v) for k, v in str_nums.items()}
print(float_values)   # {'a': 3.14, 'b': 2.718, 'c': 1.414}

# 价格打折
d4 = {"apple": 3.5, "banana": 2.8, "cherry": 8.0}
discounted = {k: round(v * 0.9, 2) for k, v in d4.items()}
print(discounted)   # {'apple': 3.15, 'banana': 2.52, 'cherry': 7.2}
```

**同时转换键和值**

键和值的表达式彼此独立，可以同时修改：

```python
d5 = {"a": 1, "b": 2, "c": 3}

# 键大写，值乘以 10
transformed = {k.upper(): v * 10 for k, v in d5.items()}
print(transformed)   # {'A': 10, 'B': 20, 'C': 30}

# 从数字列表创建，键为带前缀的字符串，值为平方
nums = [1, 2, 3, 4, 5]
num_squares = {f"num_{n}": n ** 2 for n in nums}
print(num_squares)   # {'num_1': 1, 'num_2': 4, 'num_3': 9, 'num_4': 16, 'num_5': 25}
```

**嵌套值的提取**

从嵌套字典中提取特定字段，构建一个更精简的字典：

```python
students = {
    "001": {"name": "张三", "score": 85, "age": 20},
    "002": {"name": "李四", "score": 92, "age": 22},
    "003": {"name": "王五", "score": 78, "age": 21},
}

# 提取姓名和成绩（去掉 age）
name_score = {
    sid: {"name": info["name"], "score": info["score"]}
    for sid, info in students.items()
}
print(name_score)
# {'001': {'name': '张三', 'score': 85}, '002': {'name': '李四', 'score': 92}, '003': {'name': '王五', 'score': 78}}

# 以姓名为键，成绩为值
name_to_score = {info["name"]: info["score"] for info in students.values()}
print(name_to_score)   # {'张三': 85, '李四': 92, '王五': 78}
```

**值的默认值处理**

将 None 值替换为默认值，在数据清洗中很常见：

```python
d6 = {"a": 1, "b": None, "c": 3, "d": None, "e": 5}

# None 替换为 0
no_none = {k: (v if v is not None else 0) for k, v in d6.items()}
print(no_none)   # {'a': 1, 'b': 0, 'c': 3, 'd': 0, 'e': 5}

# 布尔值转整数
d7 = {"debug": True, "verbose": False, "cache": True}
bool_to_int = {k: int(v) for k, v in d7.items()}
print(bool_to_int)   # {'debug': 1, 'verbose': 0, 'cache': 1}
```

**值是列表时的批量转换**

```python
d8 = {"group_a": [1, 2, 3], "group_b": [4, 5, 6], "group_c": [7, 8, 9]}

# 每个列表求和
sums = {k: sum(v) for k, v in d8.items()}
print(sums)   # {'group_a': 6, 'group_b': 15, 'group_c': 24}

# 每个列表取最大值
maxes = {k: max(v) for k, v in d8.items()}
print(maxes)   # {'group_a': 3, 'group_b': 6, 'group_c': 9}

# 每个列表取长度
lengths = {k: len(v) for k, v in d8.items()}
print(lengths)   # {'group_a': 3, 'group_b': 3, 'group_c': 3}
```

### 2.4 嵌套推导式

推导式可以嵌套使用，创建嵌套字典（字典的字典），或者用两层 for 循环展平嵌套结构。

**创建嵌套字典**

外层推导式产出字典，内层推导式也产出字典作为外层的值：

```python
import random
random.seed(42)

classes = ["一班", "二班", "三班"]
students_per_class = {
    "一班": ["张三", "李四"],
    "二班": ["王五", "赵六"],
    "三班": ["钱七", "孙八"],
}

grades = {
    cls: {student: random.randint(60, 100) for student in students}
    for cls, students in students_per_class.items()
}
print("嵌套字典（班级→学生→分数）：")
for cls, students in grades.items():
    print(f"  {cls}: {students}")
# 一班: {'张三': 61, '李四': 86}
# 二班: {'王五': 92, '赵六': 72}
# 三班: {'钱七': 76, '孙八': 88}
```

**双层循环展平嵌套结构**

在推导式中使用多个 for 子句，可以展平嵌套的数据结构：

```python
matrix = {
    "row1": {"a": 1, "b": 2},
    "row2": {"a": 3, "b": 4},
}

# 展平为 "row1_a": 1 格式
flattened = {
    f"{outer}_{inner}": value
    for outer, inner_dict in matrix.items()
    for inner, value in inner_dict.items()
}
print(flattened)   # {'row1_a': 1, 'row1_b': 2, 'row2_a': 3, 'row2_b': 4}
```

多个 for 子句的执行顺序和嵌套 for 循环一致——左边的 for 是外层，右边的 for 是内层，先执行完内层再回到外层。

**笛卡尔积**

利用双层 for 可以生成两个列表的笛卡尔积：

```python
sizes = ["S", "M", "L"]
colors = ["红", "蓝", "绿"]

# 元组键
inventory = {(size, color): f"{size}{color}款" for size in sizes for color in colors}
for key, val in inventory.items():
    print(f"  {key}: {val}")
# ('S', '红'): S红款, ('S', '蓝'): S蓝款, ('S', '绿'): S绿款
# ('M', '红'): M红款, ('M', '蓝'): M蓝款, ('M', '绿'): M绿款
# ('L', '红'): L红款, ('L', '蓝'): L蓝款, ('L', '绿'): L绿款

# 字符串键
inventory_str = {f"{size}-{color}": f"{size}{color}款" for size in sizes for color in colors}
print(inventory_str)
# {'S-红': 'S红款', 'S-蓝': 'S蓝款', 'S-绿': 'S绿款', 'M-红': 'M红款', ...}
```

**从嵌套字典提取并转换**

```python
company = {
    "dept_a": {"employees": 50, "budget": 100000, "level": 3},
    "dept_b": {"employees": 30, "budget": 80000, "level": 2},
    "dept_c": {"employees": 100, "budget": 200000, "level": 4},
}

# 提取每个部门的人均预算
per_capita = {
    dept: round(info["budget"] / info["employees"], 2)
    for dept, info in company.items()
}
print(per_capita)   # {'dept_a': 2000.0, 'dept_b': 2666.67, 'dept_c': 2000.0}

# 提取部门信息并添加派生字段
enhanced = {
    dept: {
        **info,
        "per_capita_budget": round(info["budget"] / info["employees"], 2),
    }
    for dept, info in company.items()
}
print("增强信息：")
for dept, info in enhanced.items():
    print(f"  {dept}: {info}")
# dept_a: {'employees': 50, 'budget': 100000, 'level': 3, 'per_capita_budget': 2000.0}
# dept_b: {'employees': 30, 'budget': 80000, 'level': 2, 'per_capita_budget': 2666.67}
# dept_c: {'employees': 100, 'budget': 200000, 'level': 4, 'per_capita_budget': 2000.0}
```

**多数据源合并为嵌套结构**

当数据分散在多个平铺字典中，需要按某个共同键合并成嵌套字典：

```python
names = {"001": "张三", "002": "李四", "003": "王五"}
ages = {"001": 20, "002": 22, "003": 21}
scores = {"001": 85, "002": 92, "003": 78}

merged = {
    sid: {
        "name": names[sid],
        "age": ages[sid],
        "score": scores[sid],
    }
    for sid in names
}
print(merged)
# {'001': {'name': '张三', 'age': 20, 'score': 85},
#  '002': {'name': '李四', 'age': 22, 'score': 92},
#  '003': {'name': '王五', 'age': 21, 'score': 78}}
```

**嵌套推导式与条件结合**

```python
nested_grades = {
    cls: {student: score for student, score in students.items() if score >= 70}
    for cls, students in grades.items()
}
print("及格学生：")
for cls, students in nested_grades.items():
    print(f"  {cls}: {students}")
```

注意这里有两层条件：内层 `if score >= 70` 过滤每个班级内不及格的学生，外层遍历所有班级。

**展平并过滤**

展平的同时加上条件：

```python
matrix2 = {
    "row1": {"a": 1, "b": 2},
    "row2": {"a": 3, "b": 4},
    "row3": {"a": 5, "b": 6},
}

# 展平并只保留偶数值
even_flat = {
    f"{outer}_{inner}": value
    for outer, inner_dict in matrix2.items()
    for inner, value in inner_dict.items()
    if value % 2 == 0
}
print(even_flat)   # {'row1_b': 2, 'row2_b': 4, 'row3_b': 6}
```

**可读性建议**

当推导式嵌套层数过多、逻辑过于复杂时，使用 for 循环更清晰：

```python
# 推导式写法（可读性开始下降）
result_comp = {
    f"{outer}_{inner}": value * 10
    for outer, inner_dict in matrix2.items()
    for inner, value in inner_dict.items()
    if value > 2
}

# for 循环写法（更清晰）
result_loop = {}
for outer, inner_dict in matrix2.items():
    for inner, value in inner_dict.items():
        if value > 2:
            result_loop[f"{outer}_{inner}"] = value * 10

print(result_comp)   # {'row1_b': 20, 'row2_a': 30, 'row2_b': 40, 'row3_a': 50, 'row3_b': 60}
print(result_loop)   # {'row1_b': 20, 'row2_a': 30, 'row2_b': 40, 'row3_a': 50, 'row3_b': 60}
print(result_comp == result_loop)   # True
```

两行以内的 for 子句通常可读性不错；超过两个 for 或混合复杂条件时，for 循环更容易维护。

### 2.5 与 dict() 构造函数对比

dict() 构造函数也能创建字典，且在简单场景下更简洁。理解两者的差异，才能在正确的场景选择正确的工具。

**四种创建方式对比**

```python
# 方式一：dict() 从键值对列表
d1 = dict([("a", 1), ("b", 2), ("c", 3)])

# 方式二：字典推导式
d2 = {k: v for k, v in [("a", 1), ("b", 2), ("c", 3)]}

# 方式三：dict() + zip
d3 = dict(zip(["a", "b", "c"], [1, 2, 3]))

# 方式四：dict() 关键字参数
d4 = dict(a=1, b=2, c=3)

print(d1 == d2 == d3 == d4)   # True
```

**各方式的适用场景**

| 方式 | 适用场景 | 限制 |
|------|---------|------|
| `dict(a=1, b=2)` | 键是合法标识符的少量键值对 | 键必须是合法 Python 标识符，不能含空格或特殊字符 |
| `dict(zip(keys, values))` | 从两个列表组合成字典 | 两列表长度必须一致 |
| `dict(pairs)` | 从键值对列表创建，无转换 | 不能做值转换或条件过滤 |
| `{k: v for ...}` | 需要值转换、条件过滤，或两者兼顾 | 语法稍长 |

关键差异在于：dict() 只能原封不动地放入键值对，而推导式可以同时做转换和过滤。

**带转换时——推导式优势明显**

```python
data = {"a": 1, "b": 2.5, "c": True}

# dict() 无法一步完成值转换，最终还是要靠推导式
d_str_comp = {k: str(v) for k, v in data.items()}
print(d_str_comp)   # {'a': '1', 'b': '2.5', 'c': 'True'}
```

**带过滤时——推导式是唯一选择**

```python
original = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}

# 推导式一步到位
filtered = {k: v for k, v in original.items() if v > 2}
print(filtered)   # {'c': 3, 'd': 4, 'e': 5}

# dict() 方式必须先生成过滤后的列表，再 dict()
temp = [(k, v) for k, v in original.items() if v > 2]
d_filtered = dict(temp)
print(d_filtered)   # {'c': 3, 'd': 4, 'e': 5}
# 两种方式结果相同，但 dict() 方式需要两步
```

**性能对比**

在不需要转换和过滤的纯创建场景下，dict() 通常比推导式更快，因为 dict() 直接在 C 层面构建字典：

```python
import time

pairs = [(str(i), i) for i in range(100000)]

# dict() 性能
start = time.perf_counter()
d_dict = dict(pairs)
time_dict = time.perf_counter() - start

# 推导式性能
start = time.perf_counter()
d_comp = {k: v for k, v in pairs}
time_comp = time.perf_counter() - start

print(f"dict():    {time_dict:.4f}s")
print(f"推导式:    {time_comp:.4f}s")
```

```text
dict():    0.0042s
推导式:    0.0078s
```

dict() 通常快 30%~50%。但在需要转换时，推导式反而更快：

```python
# dict() + 生成器表达式
start = time.perf_counter()
d_trans_dict = dict((k, v * 2) for k, v in pairs)
time_trans_dict = time.perf_counter() - start

# 推导式
start = time.perf_counter()
d_trans_comp = {k: v * 2 for k, v in pairs}
time_trans_comp = time.perf_counter() - start

print(f"dict(gen): {time_trans_dict:.4f}s")
print(f"推导式:     {time_trans_comp:.4f}s")
```

```text
dict(gen): 0.0123s
推导式:     0.0091s
```

推导式带转换时通常比 `dict(generator)` 快，因为推导式是在 Python 字节码层面直接构造字典，而生成器表达式多了一层迭代器开销。

**选择建议**

| 场景 | 推荐方式 |
|------|---------|
| 键是合法标识符，少量键值对 | `dict(a=1, b=2)` |
| 两个列表组合 | `dict(zip(keys, values))` |
| 纯键值对列表，无转换过滤 | `dict(pairs)` |
| 需要值转换 | `{k: f(v) for k, v in ...}` |
| 需要条件过滤 | `{k: v for k, v in ... if cond}` |
| 需要同时转换和过滤 | `{k: f(v) for k, v in ... if cond}` |
| 需要反转键值 | `{v: k for k, v in d.items()}` |

**词频统计**

```python
text = "the quick brown fox jumps over the lazy dog the fox runs"
words = text.split()

# 用推导式 + set 统计词频
word_freq = {w: words.count(w) for w in set(words)}
for word, count in sorted(word_freq.items(), key=lambda x: -x[1]):
    print(f"  {word}: {count}")
```

```text
  the: 3
  fox: 2
  quick: 1
  brown: 1
  jumps: 1
  over: 1
  lazy: 1
  dog: 1
  runs: 1
```

注意：这种方式在大数据量下效率较低，因为 `count()` 每次都遍历整个列表。更高效的方式是用 `collections.Counter`:

```python
from collections import Counter

word_freq2 = dict(Counter(words))
```

## 3. 最佳实践

### 3.1 推荐写法 vs 不推荐写法

| 场景 | 推荐写法 | 不推荐写法 | 原因 |
|------|---------|-----------|------|
| 简单创建 | `{k: v for k, v in pairs}` | `dict((k, v) for k, v in pairs)` | 推导式更直观，且带转换时更快 |
| 条件过滤 | `{k: v for k, v in d.items() if v > 0}` | 先 dict 再遍历删除 | 推导式一步到位，避免修改字典大小 |
| 键值反转 | `{v: k for k, v in d.items()}` | 手动 for 循环逐个赋值 | 推导式更简洁 |
| 嵌套 ≥ 3 层 | for 循环 | 多层嵌套推导式 | 嵌套过深可读性急剧下降 |
| 大数据量无转换 | `dict(pairs)` | `{k: v for k, v in pairs}` | dict() 更快 |

### 3.2 常见错误

**错误一：值不可哈希时反转**

```python
# 不推荐：值是列表，反转会报错
d = {"a": [1, 2], "b": [3]}
# {v: k for k, v in d.items()}  # TypeError: unhashable type: 'list'

# 修正：将列表转为元组再反转
reversed_d = {tuple(v): k for k, v in d.items()}
print(reversed_d)   # {(1, 2): 'a', (3,): 'b'}
```

**错误二：反转时值重复导致数据丢失**

```python
d = {"a": 1, "b": 2, "c": 1}
reversed_d = {v: k for k, v in d.items()}
print(reversed_d)   # {1: 'c', 2: 'b'}  ← 'a' 的映射丢失了
```

值有重复时，反转后只有最后一个键保留下来。如果要保留所有映射，值应改为列表：

```python
from collections import defaultdict

reverse_map = defaultdict(list)
for k, v in d.items():
    reverse_map[v].append(k)
print(dict(reverse_map))   # {1: ['a', 'c'], 2: ['b']}
```

**错误三：忽略 bool 是 int 子类**

```python
mixed = {"a": 1, "b": True, "c": 3.14}

# 不推荐：True == 1，isinstance(True, int) 为 True
nums = {k: v for k, v in mixed.items() if isinstance(v, int)}
print(nums)   # {'a': 1, 'b': True}  ← True 被误判为数字

# 修正：排除 bool
nums_correct = {k: v for k, v in mixed.items() if isinstance(v, int) and not isinstance(v, bool)}
print(nums_correct)   # {'a': 1}
```

### 3.3 可读性与复杂度的取舍

推导式的核心价值是简洁。但当逻辑复杂度超过了"一眼能看懂"的阈值，就应该退回到 for 循环。一个实用的判断标准：

| 推导式特征 | 建议 |
|------------|------|
| 单层 for，无 if | 推导式 |
| 单层 for + 单个 if | 推导式 |
| 单层 for + 键值转换 + if | 推导式 |
| 双层 for（笛卡尔积/展平） | 推导式，但加注释说明 |
| 双层 for + if + 转换 | for 循环更清晰 |
| 嵌套字典推导（字典套字典） | for 循环更清晰 |

```python
# 推导式——清晰
squares = {n: n ** 2 for n in range(10) if n % 2 == 0}

# 推导式——勉强可读
flattened = {f"{r}_{c}": v for r, row in matrix.items() for c, v in row.items()}

# 推导式——太复杂，改用 for 循环
result = {
    f"{r}_{c}": v * 10
    for r, row in matrix.items()
    for c, v in row.items()
    if v > 5 and r.startswith("row")
}
# ↓ 改为
result = {}
for r, row in matrix.items():
    for c, v in row.items():
        if v > 5 and r.startswith("row"):
            result[f"{r}_{c}"] = v * 10
```

## 4. 原理

### 4.1 推导式的执行过程

字典推导式在 Python 中是一种语法糖，编译后等价于一段 for 循环 + 赋值代码。了解其执行过程有助于理解为什么推导式能做转换和过滤，而 dict() 做不到。

以 `{k: v for k, v in pairs if v > 0}` 为例，编译后的等价逻辑是：

```python
result = {}
for k, v in pairs:
    if v > 0:
        result[k] = v
```

执行流程图：

```text
开始
  ↓
遍历 iterable 取出第一个 item
  ↓
计算 if 条件（有 if 子句时）
  ├─ False → 跳过，取下一个 item
  └─ True ↓（无 if 子句则直接继续）
计算 key_expr 和 value_expr
  ↓
将 key: value 存入新字典
  ↓
还有更多 item？ ──有──→ 回到"取出 item"
  │
  无
  ↓
返回完整字典
```

dict() 构造函数的流程更简单：

```text
遍历 iterable 取出 item
  ↓
直接将 item 作为 key: value 存入字典
  ↓
返回完整字典
```

区别在于推导式多了一个"计算"步骤——key_expr 和 value_expr 不是直接用 item，而是经过表达式计算后再存入。这就解释了为什么推导式能做转换和过滤，而 dict() 做不到。

### 4.2 推导式的作用域

Python 3 中，字典推导式（以及列表推导式、集合推导式）有自己的作用域。在推导式内部定义的变量不会"泄漏"到外部：

```python
pairs = [("a", 1), ("b", 2)]
d = {k: v for k, v in pairs}

# k 和 v 不在外部可见
# print(k)  # NameError: name 'k' is not defined
```

这和普通 for 循环不同——for 循环中的循环变量在循环结束后仍然可见：

```python
for k, v in pairs:
    pass
print(k)   # 'b'  ← 循环结束后变量仍然存在
```

这个设计避免了推导式中的临时变量污染外部命名空间，是一个有意为之的设计决策。

### 4.3 性能差异的原因

dict() 构造函数在纯创建场景下比推导式快，原因是 dict() 的核心实现在 CPython 的 C 层面，直接调用 `dict_merge` 等 C 函数，跳过了 Python 字节码循环。推导式虽然也在 C 层面有优化，但仍需逐个执行 key_expr 和 value_expr 的 Python 字节码。

```python
import dis

# dict() 的字节码更少
dis.dis("dict(pairs)")

# 推导式有额外的 LOAD 和 STORE 操作
dis.dis("{k: v for k, v in pairs}")
```

```text
# dict(pairs) 的字节码
  1           0 LOAD_NAME                0 (dict)
              2 LOAD_NAME                1 (pairs)
              4 CALL_FUNCTION            1
              6 RETURN_VALUE

# 推导式的字节码（简化版）
  1           0 BUILD_MAP                0
              2 LOAD_NAME                0 (pairs)  ← 遍历源
              4 GET_ITER
        >>    6 FOR_ITER                14 (to 24)  ← 循环开始
              8 UNPACK_SEQUENCE          2
             10 STORE_NAME               1 (k)
             12 STORE_NAME               2 (v)
             14 LOAD_NAME                1 (k)
             16 LOAD_NAME                2 (v)
             18 MAP_ADD                  2           ← 存入字典
             20 JUMP_ABSOLUTE            6           ← 回到循环
        >>   24 RETURN_VALUE
```

dict() 只有一条 CALL_FUNCTION 指令，推导式有完整的循环逻辑。这就是纯创建场景下 dict() 更快的原因。

但在需要转换时，dict() 需要先构造一个生成器或列表，再传入 dict()，多了一层中间开销。推导式直接在循环中计算并存入，省去了中间步骤，所以带转换时反而更快。

## 5. 总结

本文围绕字典推导式展开，主要介绍了以下内容：

- 字典推导式是一种用简洁语法快速创建字典的表达式，把"for 循环建字典"浓缩为一行声明式代码
- 基本语法 `{key_expr: value_expr for item in iterable}`，可从键值对列表、zip、已有字典、range、enumerate 等多种来源创建字典
- 条件过滤通过 `if` 子句实现，支持按键过滤、按值过滤、多条件组合，还能与值转换同时进行
- 键值转换包括键值反转、键名格式化、值类型转换、数学运算、嵌套值提取、默认值替换等场景
- 嵌套推导式可创建嵌套字典，或用双层 for 展平嵌套结构、生成笛卡尔积
- 与 dict() 构造函数相比，推导式在需要转换和过滤时不可替代，但纯创建场景下 dict() 更快
- 实用场景涵盖词频统计、配置合并、数据分组、ASCII 映射、CSV 转字典、矩阵转置等模式
- 最佳实践核心：简单场景用推导式，复杂场景退回 for 循环，注意值可哈希性和重复键覆盖问题
