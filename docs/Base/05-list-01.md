## 1. 介绍

### 1.1 什么是列表创建

列表创建是 Python 中生成 `list` 对象的各种方式的总称。当你写 `[]`、`list()`、`[1, 2, 3]` 或 `[x**2 for x in range(10)]` 时,都是在创建一个新列表。列表作为 Python 最基础、最常用的可变序列类型,其创建方式直接影响代码的简洁度、可读性和性能。

```python
# 各种创建方式一览
print([])                          # [] —— 字面量创建空列表
print(list())                      # [] —— 构造函数创建空列表
print([1, 2, 3])                   # [1, 2, 3] —— 字面量直接填充
print(list("abc"))                 # ['a', 'b', 'c'] —— 从可迭代对象创建
print([0] * 5)                     # [0, 0, 0, 0, 0] —— 乘法重复
print([x for x in range(3)])       # [0, 1, 2] —— 列表推导式
```

Python 提供多种列表创建方式,这些方式在**语义、性能、使用场景**上有明显差异。掌握正确的选择标准是写好 Python 代码的基础:

- **`[]` vs `list()`**:空列表该用哪个?性能有差异吗?
- **字面量 vs 构造函数**:`[1,2,3]` 和 `list((1,2,3))` 有何不同?
- ****重复陷阱**: `[ [ ] ] * n` 为什么会产生隐蔽的 bug?**
- **推导式的时机**:什么情况下该用 `[x for x in iter]` 而不是 `list(iter)`?

这些问题看似简单,但涉及 Python 的对象模型、内存分配、可变对象引用等核心概念。本篇系统讲解 Python 列表的 6 大创建方式及其适用场景、性能差异、陷阱规避。

### 1.2 列表创建方式全表

下面这张表是本篇的总纲,后续每一节逐一展开。

| 创建方式 | 语法示例 | 适用场景 | 性能 | 注意事项 |
|---------|---------|---------|------|---------|
| 空字面量 | `[]` | 创建空列表(首选) | 最快 | 字面量,无函数调用开销 |
| 构造函数 | `list()` | 代码可读性优先时 | 较慢 | 有函数调用开销 |
| 填充字面量 | `[1, 2, 3]` | 已知元素的列表 | 快 | 直接、可读 |
| 从可迭代对象 | `list(iter)` | 转换其他序列为列表 | 中等 | 会遍历整个可迭代对象 |
| 乘法重复 | `[0] * n` | 创建同值填充的列表 | 快 | ⚠️ 可变对象重复是引用陷阱 |
| 列表推导式 | `[expr for x in iter]` | 需要转换/过滤元素 | 快 | 最 Pythonic 的创建方式 |
| 生成器转换 | `list(gen)` | 惰性计算后转为列表 | 中等 | 生成器只能遍历一次 |

**性能维度**是选择创建方式的重要依据:`[]` 是字节码层面的字面量,无运行时开销;`list()` 是函数调用,有额外开销;推导式虽快但会立即执行全部计算;乘法重复虽快但有引用陷阱。

### 1.3 列表的内存模型基础

理解列表创建,需要先理解列表在内存中的形态。**列表是引用数组**:一个列表对象内部维护一个指针数组,每个指针指向一个元素对象。列表本身不存储元素值,只存储引用。

```python
# 列表 = 引用数组的可视化理解
a = [1, "hello", [3, 4]]
# 内存结构示意:
# 列表对象 a
#   ├─ 指向 int(1) 的引用
#   ├─ 指向 str("hello") 的引用
#   └─ 指向 list([3, 4]) 的引用
```

这个模型解释了所有列表创建的关键行为:

- **创建列表** = 分配一块内存存放引用数组
- **元素赋值** = 在对应位置写入对象引用
- **乘法重复** = 把同一个引用复制多份(引发`[[ ]] * n`陷阱)
- **拷贝问题** = 浅拷贝只复制引用数组,深拷贝递归复制对象

⚠️ **可变 vs 不可变元素**:列表可以包含任意类型。当元素是不可变对象(`int`、`str`、`tuple`)时,引用复制不会引发问题;当元素是可变对象(`list`、`dict`)时,多个引用指向同一个对象会导致"一改全改"的副作用。

```python
# 不可变元素:引用复制无问题
a = [1, 2, 3]
b = a          # b 引用同一列表
b[0] = 100     # 修改 b,影响 a (列表本身可变)
print(a)       # [100, 2, 3]

# 可变元素:引用复制是陷阱
rows = [[0]] * 3  # 三个引用指向同一个内部列表
rows[0][0] = 1   # 一改全改
print(rows)      # [[1], [1], [1]] —— 不是 [[1], [0], [0]]!
```

理解"列表是引用数组",就理解了列表创建的全部陷阱和性能特性。这是「列表深度剖析」大章节的首篇,后续的列表操作、切片、拷贝、排序都建立在此基础之上。

## 2. 核心内容

本章逐个详解 6 种主要的列表创建方式,每节遵循"方式说明 → demo → 性能对比 → 陷阱 → 场景"展开。

### 2.1 空列表创建:`[]` vs `list()`

创建空列表有两种方式:字面量 `[]` 和构造函数 `list()`。两者结果相同,但语义和性能有差异。

**语法对比**:

```python
# 方式一:字面量(推荐)
empty1 = []

# 方式二:构造函数
empty2 = list()
```

**性能差异**:

```python
import timeit

# 测试执行 1000 万次的耗时
print(timeit.timeit('[]', number=10000000))        # 约 0.15 秒
print(timeit.timeit('list()', number=10000000))    # 约 0.35 秒
```

`[]` 比 `list()` 快 **2 倍以上**。原因:

- `[]` 是字节码 `BUILD_LIST 0`(直接构建空列表,无函数调用)
- `list()` 是函数调用,需解析全局名称、压栈参数、执行 C 函数

字节码层面验证:

```python
import dis
dis.dis('[]')
#   0 BUILD_LIST               0
#   2 RETURN_VALUE

dis.dis('list()')
#   0 LOAD_NAME                0 (list)
#   2 CALL_FUNCTION            0
#   4 RETURN_VALUE
```

**选择建议**:

| 场景 | 推荐写法 | 理由 |
|-----|---------|------|
| 空列表初始化 | `[]` | 性能最优,约定俗成 |
| 类型标注场景 | `list()` | 显式表达意图,但较少见 |

```python
# 推荐:简洁、快速
result = []
for x in range(10):
    result.append(x)

# 可读性优先时(少见):强调"创建一个列表"
result = list()
```

⚠️ 在类型提示密集的代码中,`list()` 可能让类型更明确,但现代 IDE 和类型检查器对 `[]` 的推断已非常完善。除非团队规范特别要求,否则**一律用 `[]`**。

### 2.2 填充字面量 `[element1, element2, ...]`

当列表元素已知时,直接用字面量列出是最直观的方式。

```python
# 基础类型
numbers = [1, 2, 3, 4, 5]
fruits = ["apple", "banana", "cherry"]
mixed = [1, "two", 3.0, True, None]

# 嵌套结构
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
table = [
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 25},
]
```

**换行风格**:

```python
# 短列表:单行
short = [1, 2, 3]

# 长列表:尾随逗号 + 换行(方便 diff 和追加)
long = [
    "first_item",
    "second_item",
    "third_item",   # 尾随逗号:追加新行时 diff 更清晰
]
```

**从其他序列转换**:当已有元组、集合、range 等,需要转为列表时,直接用 `list()` 构造函数。

```python
# 从元组转列表(需要修改时)
t = (1, 2, 3)
lst = list(t)           # [1, 2, 3]

# 从集合转列表(需要索引访问时)
s = {3, 1, 2}
lst = list(s)           # [1, 2, 3] —— 顺序不保证

# 从 range 转列表
lst = list(range(5))    # [0, 1, 2, 3, 4]

# 从字符串转列表(拆成字符)
lst = list("abc")       # ['a', 'b', 'c']
```

**性能**:字面量创建是最快的方式之一,元素在编译期就解析为常量,运行时直接构建。

### 2.3 列表推导式 `[expression for item in iterable]`

列表推导式(List Comprehension)是 Python 最 Pythonic 的列表创建方式,用于**基于已有可迭代对象创建新列表**。

**基本语法**:

```python
[expression for item in iterable]
[expression for item in iterable if condition]
```

**典型用法对比**:

```python
# ❌ 传统循环方式(冗长)
squares = []
for x in range(10):
    squares.append(x ** 2)

# ✅ 列表推导式(简洁、快速)
squares = [x ** 2 for x in range(10)]
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

**带条件的推导**:

```python
# 过滤:只保留偶数
evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

# 条件表达式:奇数保留原值,偶数翻倍
processed = [x * 2 if x % 2 == 0 else x for x in range(10)]
# [0, 1, 4, 3, 8, 5, 12, 7, 16, 9]
```

**嵌套推导**(处理多维):

```python
# 展平二维列表
matrix = [[1, 2, 3], [4, 5, 6]]
flat = [x for row in matrix for x in row]
# [1, 2, 3, 4, 5, 6] —— 相当于嵌套循环:先遍历 row,再遍历 x

# 矩阵转置(行列互换)
transposed = [[row[i] for row in matrix] for i in range(3)]
# [[1, 4], [2, 5], [3, 6]]
```

**性能优势**:推导式比手动循环快 **1.5~2 倍**,因为迭代在 C 层完成,无需 Python 层的 `append` 调用开销。

```python
import timeit

# 推导式 vs 循环
print(timeit.timeit('[x**2 for x in range(1000)]', number=10000))
# 约 0.35 秒

code = '''
squares = []
for x in range(1000):
    squares.append(x**2)
'''
print(timeit.timeit(code, number=10000))
# 约 0.60 秒
```

**何时不该用推导式**:

| 场景 | 原因 | 替代方案 |
|-----|------|---------|
| 副作用操作 | 推导式应纯函数式 | 用循环 |
| 过于复杂的嵌套 | 可读性下降 | 用循环或生成器 |
| 巨大数据量(内存紧张) | 推导式立即生成全部 | 用生成器表达式 `()` |

```python
# ❌ 不推荐:推导式里有副作用
[print(x) for x in range(3)]  # 能跑,但 print 返回 None,结果 [None, None, None]

# ✅ 推荐:副作用用循环
for x in range(3):
    print(x)

# ❌ 过于复杂,可读性差
result = [[x * y for x in range(100) if x % 2 == 0] for y in range(100) if y % 3 == 0]

# ✅ 换成循环更清晰
even_products = []
for y in range(100):
    if y % 3 == 0:
        row = [x * y for x in range(100) if x % 2 == 0]
        even_products.append(row)
```

### 2.4 乘法重复 `[value] * n`

用乘法创建包含相同值的列表,语法简洁但需警惕**引用陷阱**。

**基础用法**:

```python
# 创建 n 个相同值的列表
zeros = [0] * 5           # [0, 0, 0, 0, 0]
flags = [False] * 3       # [False, False, False]
strings = ["pending"] * 4  # ['pending', 'pending', 'pending', 'pending']
```

**性能**:乘法重复极快,因为只创建一个元素对象,然后复制引用 n 次。

```python
import timeit
print(timeit.timeit('[0] * 10000', number=10000))     # 极快
print(timeit.timeit('[0 for _ in range(10000)]', number=10000))  # 慢 10 倍以上
```

**⚠️ 引用陷阱(重点)**:

当重复的元素是可变对象时,所有位置引用**同一个对象**,一改全改:

```python
# 陷阱 1:嵌套列表
rows = [[]] * 3           # 看起来是 [[], [], []]
rows[0].append(1)         # 期望 [[1], [], []]
print(rows)               # 实际是 [[1], [1], [1]]! 三个引用指向同一个 []

# 陷阱 2:字典列表
dicts = [{}] * 2
dicts[0]["key"] = "val"
print(dicts)              # [{'key': 'val'}, {'key': 'val'}]
```

**内存模型解释**:

```
[[]] * 3 的内存结构:

列表对象
  ├─ 引用0 ──→ 列表A([])
  ├─ 引用1 ──→ 列表A(同一个!)
  └─ 引用2 ──→ 列表A(同一个!)

rows[0].append(1) 修改了 列表A
所以三个引用看到的变化相同
```

**正确创建独立对象的写法**:

```python
# ✅ 列表推导式:每次迭代创建新对象
rows = [[] for _ in range(3)]
rows[0].append(1)
print(rows)              # [[1], [], []]

# ✅ 循环创建
dicts = []
for _ in range(2):
    dicts.append({})      # 每次 append 一个全新的 {}
dicts[0]["a"] = 1
print(dicts)             # [{'a': 1}, {}]
```

**适用范围总结**:

| 元素类型 | 乘法重复安全? | 示例 |
|---------|--------------|------|
| `int`、`float`、`str`、`bool`、`None` | ✅ 安全 | `[0] * 5`、`["x"] * 3` |
| `tuple`(不可变) | ✅ 安全 | `[(0, 0)] * 4` |
| `list`、`dict`、`set`(可变) | ❌ 陷阱 | `[[]] * n`、`[{}] * n` |
| 自定义可变对象 | ❌ 陷阱 | `[MyClass()] * n` |

### 2.5 从可迭代对象创建 `list(iterable)`

`list()` 构造函数接受任意可迭代对象,遍历其元素创建列表。

**适用场景**:

```python
# 将其他序列转为列表(需要修改)
t = (1, 2, 3)
lst = list(t)           # 需要添加/删除元素时

# 将集合转为列表(需要索引)
s = {3, 1, 4, 1, 5}
lst = list(s)           # 注意:顺序不保证 [1, 3, 4, 5]

# 将字典转为列表(keys)
d = {"a": 1, "b": 2}
keys = list(d)          # ['a', 'b']
values = list(d.values())  # [1, 2]
items = list(d.items())    # [('a', 1), ('b', 2)]

# 将 range 转为列表
lst = list(range(5))    # [0, 1, 2, 3, 4]
lst = list(range(0, 10, 2))  # [0, 2, 4, 6, 8]

# 将字符串拆成字符列表
lst = list("hello")       # ['h', 'e', 'l', 'l', 'o']

# 将生成器结果收集为列表
gen = (x**2 for x in range(5))
lst = list(gen)           # [0, 1, 4, 9, 16]
```

**对比推导式**:

当需要对元素进行转换时,列表推导式往往更优:

```python
# 简单转换,两者等价
lst1 = list(range(10))           # [0, 1, 2, ..., 9]
lst2 = [x for x in range(10)]    # 等价,但稍慢

# 需要转换元素时,推导式更简洁
squares1 = list(x**2 for x in range(10))  # 需要额外的生成器语法
squares2 = [x**2 for x in range(10)]      # 更 Pythonic
```

**性能**:直接 `list(iter)` 比 `[x for x in iter]` 略快(约 10%),因为省去了 Python 层的表达式求值开销。但差距不大,优先保证可读性。

### 2.6 综合对比与选择指南

不同场景下的最佳选择:

| 场景 | 推荐方式 | 示例 | 理由 |
|-----|---------|------|------|
| 需要空列表 | `[]` | `result = []` | 最快,最简洁 |
| 元素已确定 | 字面量 | `[1, 2, 3]` | 最直观 |
| 同值填充(不可变) | 乘法 | `[0] * 10` | 最快 |
| 同值填充(可变) | 推导式 | `[[] for _ in range(10)]` | 避免引用陷阱 |
| 转换+过滤/映射 | 推导式 | `[x*2 for x in items if x>0]` | 最 Pythonic |
| 简单转换 | `list()` | `list(range(5))` | 略快于推导式 |
| 转换其他序列 | `list()` | `list(tuple_obj)` | 标准做法 |

**综合示例**:

```python
# 实战:创建一个 3x3 矩阵,初始化为 0
# ❌ 错误:乘法陷阱
matrix_wrong = [[0] * 3] * 3
matrix_wrong[0][0] = 1
print(matrix_wrong)     # [[1, 0, 0], [1, 0, 0], [1, 0, 0]] —— 全改了!

# ✅ 正确:推导式创建独立行
matrix_right = [[0] * 3 for _ in range(3)]
matrix_right[0][0] = 1
print(matrix_right)     # [[1, 0, 0], [0, 0, 0], [0, 0, 0]]

# 实战:过滤日志中的错误行
logs = [
    "INFO: started",
    "ERROR: connection failed",
    "INFO: processing",
    "ERROR: timeout",
]
errors = [line for line in logs if line.startswith("ERROR")]
print(errors)           # ['ERROR: connection failed', 'ERROR: timeout']

# 实战:提取字典键值对
config = {"host": "localhost", "port": 8080, "debug": True}
# 方式 1:直接遍历(最简洁)
keys = list(config)              # ['host', 'port', 'debug']
# 方式 2:显式调用 keys()
keys = list(config.keys())       # 效果相同,更明确

# 实战:创建指定长度的默认配置
n_servers = 5
default_configs = [{"status": "inactive", "port": 8000 + i} for i in range(n_servers)]
print(default_configs)
# [{'status': 'inactive', 'port': 8000}, ... , {'status': 'inactive', 'port': 8004}]
```

## 3. 最佳实践

### 3.1 空列表一律用 `[]`,不要用 `list()`

```python
# 推荐:快 2 倍以上
result = []

# 不推荐:函数调用开销没必要
result = list()
```

除非是类型提示密集且团队规范特别要求,否则永远用 `[]`。

### 3.2 `[[]] * n` 是经典陷阱,用推导式代替

```python
# ❌ 危险:所有子列表是同一个对象
rows = [[]] * 3

# ✅ 正确:每行独立
rows = [[] for _ in range(3)]

# ✅ 也可以用循环
rows = []
for _ in range(3):
    rows.append([])
```

这条规则同样适用于 `[{}] * n`、自定义可变对象。

### 3.3 列表推导式优于手动循环,但避免副作用

```python
# ✅ 推荐:纯计算,无副作用
squares = [x**2 for x in range(10)]

# ❌ 不推荐:推导式里有副作用(仍生成无用的 [None, None, ...])
[print(x) for x in range(10)]

# ✅ 副作用放循环里
for x in range(10):
    print(x)
```

### 3.4 复杂逻辑别硬塞进推导式,拆成循环

```python
# ❌ 可读性差
result = [[complex_op(x, y) for x in range(100) if some_filter(x)] 
          for y in range(100) if another_filter(y)]

# ✅ 拆成循环清晰
result = []
for y in range(100):
    if not another_filter(y):
        continue
    row = []
    for x in range(100):
        if some_filter(x):
            row.append(complex_op(x, y))
    result.append(row)
```

### 3.5 大数据量考虑生成器,不要无脑转列表

```python
# ❌ 1000 万个元素全进内存,可能撑爆
big_list = [process(x) for x in range(10_000_000)]

# ✅ 用生成器惰性处理
for item in (process(x) for x in range(10_000_000)):
    # 处理一个,释放一个,内存友好
    pass

# ✅ 或只在需要时转为列表
chunks = []
for chunk in batched(range(10_000_000), 1000):
    chunks.append(list(chunk))  # 分批处理
```

### 3.6 类型转换优先用 `list()`,简洁清晰

```python
# ✅ 标准转换写法
t = (1, 2, 3)
lst = list(t)

# 与推导式等价,但意图更明确(只是转换,不做计算)
lst = [x for x in t]  # 冗余
```

### 3.7 矩阵/多维列表用推导式,不要用乘法

```python
# ❌ 乘法陷阱
matrix = [[0] * cols] * rows

# ✅ 安全的推导式
matrix = [[0] * cols for _ in range(rows)]

# 或使用 numpy(科学计算场景)
import numpy as np
matrix = np.zeros((rows, cols))  # 更专业
```

### 3.8 创建后检查长度,避免空列表误用

```python
# 防御式编程
results = [x for x in items if satisfies_condition(x)]
if not results:  # 或 len(results) == 0
    print("警告:没有符合条件的元素")
else:
    process(results[0])  # 安全使用
```

## 4. 原理

### 4.1 为什么 `[]` 比 `list()` 快:字节码层面分析

`[]` 和 `list()` 的性能差异源于 Python 编译器和虚拟机的实现:

```python
import dis

# [] 的字节码
dis.dis('[]')
#  1           0 BUILD_LIST               0
#              2 RETURN_VALUE

# list() 的字节码
dis.dis('list()')
#  1           0 LOAD_NAME                0 (list)
#              2 CALL_FUNCTION            0
#              4 RETURN_VALUE
```

`BUILD_LIST 0` 是一条专用指令,C 层直接创建空列表对象。而 `list()` 需要:

1. `LOAD_NAME`:查找名称空间里 `list` 绑定的对象
2. `CALL_FUNCTION`:压栈参数、解析参数、调用函数
3. C 函数执行:检查参数、创建列表

多出的步骤带来了额外开销,在大量创建时累积成显著差距。

### 4.2 列表的内部结构:PyListObject

CPython 中,列表由 `PyListObject` 结构体实现:

```c
// 简化示意
typedef struct {
    PyObject_VAR_HEAD    // 引用计数 + 类型指针 + ob_size(元素数)
    PyObject **ob_item;  // 指向指针数组的指针
    Py_ssize_t allocated; // 当前分配的容量
} PyListObject;
```

关键设计:

- **ob_item**:指向一个 `PyObject*` 数组(引用数组),列表不直接存储值
- **allocated**:容量(可放多少元素),大于 `ob_size`(当前元素数)时支持 append 不重新分配
- **过度分配**:append 时容量按指数增长(约 1.125 倍),换取 O(1) 均摊复杂度

这个结构解释了:

- 索引 `lst[i]` = 访问 `ob_item[i]` → O(1)
- 乘法重复 = 复制 `ob_item` 里的指针( `[0] * 5` 的 5 个位置都指向同一个 0 对象)
- 可变对象陷阱 = 多个位置指针指向同一个可变对象

### 4.3 乘法重复的内存模型:为什么 `[[ ]] * n` 会出问题

```python
# 执行 [[0]] * 3 的内存变化:

# Step 1: 创建 [0]
# 列表A: ob_item → [指向 int(0)]

# Step 2: 执行乘法
# 新列表B分配容量 3
# ob_item = [列表A引用, 列表A引用, 列表A引用]
# 三个位置是同一个指针值!

# Step 3: rows[0].append(1)
# 修改的是 列表A
# 所以三个引用看到的都是 [0, 1]
```

对比安全写法:

```python
# [[] for _ in range(3)]

# 每次迭代:
#   执行 [] → 创建新的空列表
#   添加到结果列表
# 结果:三个独立的空列表对象
```

### 4.4 列表推导式的速度优势:静态分析与 C 层循环

推导式快于手动循环的原因:

1. **静态分析**:编译期确定循环结构,生成优化的字节码 `LIST_APPEND`
2. **C 层迭代**:元素遍历和列表增长在 C 层完成,无 Python 层的 `append` 方法调用开销
3. **预分配**:推导式能预估结果大小(并非总是),减少内存重新分配

字节码对比:

```python
dis.dis('[x for x in range(3)]')
#  BUILD_LIST
#  LOAD_CONST (range(3))
#  GET_ITER
#  FOR_ITER
#  STORE_NAME (x)
#  LOAD_NAME (x)
#  LIST_APPEND  <--- 专用指令,比 append 方法快

dis.dis('''
lst = []
for x in range(3):
    lst.append(x)
''')
#  ...
#  LOAD_ATTR (append)  <--- 属性查找
#  CALL_METHOD         <--- Python 层函数调用
```

### 4.5 可迭代协议:为什么 `list()` 能接收任意可迭代对象

`list(iterable)` 能工作的核心是可迭代协议(Iterable Protocol):

```python
# 任何实现了 __iter__ 或 __getitem__ 的对象都是可迭代的

# list() 创建时的内部逻辑(简化):
def list(iterable=None):
    if iterable is None:
        return 空列表
    
    result = 预分配列表
    iterator = iter(iterable)  # 调用 iterable.__iter__()
    
    while True:
        try:
            item = next(iterator)  # 调用 iterator.__next__()
            result.append(item)
        except StopIteration:
            break
    
    return result
```

这就是 `list()` 能处理 `tuple`、`set`、`str`、`range`、`dict`、`file`、`generator` 等的原理——它们都实现了迭代器协议。

## 5. 总结

### 5.1 本文内容回顾

- **列表创建方式全表**:6 种主要方式——`[]`、`list()`、`[1,2,3]`、`list(iter)`、`[x] * n`、列表推导式,覆盖从空列表到复杂转换的全部场景。

- **空列表创建**:一律用 `[]`,比 `list()` 快 2 倍以上;字节码层面 `BUILD_LIST` 直接构造,无函数调用开销。

- **填充字面量**:已知元素时用字面量 `[1, 2, 3]` 最直观;从其他序列转用 `list()` 是标准做法。

- **列表推导式**:最 Pythonic 的创建方式,用于转换/过滤元素;比手动循环快 1.5~2 倍;但避免在里面做副作用操作;复杂逻辑拆成循环。

- **乘法重复 `[x] * n`**:创建同值填充列表的最快方式,但**可变对象重复是引用陷阱**;`[[ ]] * n` 导致一改全改;可变元素用推导式 `[[] for _ in range(n)]`。

- **从可迭代对象创建 `list(iter)`**:利用可迭代协议将任意可迭代对象转为列表;简单转换时比推导式略快,但更推荐推导式表达转换语义。

- **内存模型**:列表是**引用数组**,理解这一点就理解了"为何乘法重复可变对象会出错";`int`、`str`等不可变元素重复安全,`list`、`dict`等可变元素重复危险。

- **最佳实践**:空列表用 `[]`、避免乘法重复可变对象、推导式优于循环(纯计算场景)、复杂逻辑拆循环、大数据量考虑生成器。

- **原理**:字节码差异(`BUILD_LIST` vs `CALL_FUNCTION`)、`PyListObject` 结构(引用数组 + 容量)、迭代器协议(`__iter__`/`__next__`)。
