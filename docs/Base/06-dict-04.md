# 字典的增删改操作

## 1. 介绍

字典（dict）是 Python 中最常用的可变容器类型之一。与列表通过"索引位置"访问元素不同，字典通过"键"来访问"值"，这种键值对映射结构让数据组织更加灵活。

在实际开发中，对字典的操作可以归纳为三大类：**增**（添加新的键值对）、**删**（移除已有键值对）、**改**（修改已有键的值）。这三类操作统称为 CRUD 中的 C（Create）、U（Update）、D（Delete），加上 R（Read）查询操作，构成了字典日常使用的核心。

Python 为字典增删改提供了丰富的 API——从最简单的 `d[key] = value` 赋值操作，到批量更新的 `update()`，再到安全添加的 `setdefault()`，以及多种删除方式 `del`、`pop()`、`popitem()`、`clear()`。每种 API 都有其适用场景和注意事项，理解它们的差异是写出健壮代码的前提。

先来看一个最简示例，感受字典增删改的基本操作：

```python
# 创建一个字典
student = {"name": "张三", "age": 20}

# 增：添加新键
student["city"] = "北京"

# 改：修改已有键
student["age"] = 21

# 删：删除键值对
del student["city"]

print(student)  # {'name': '张三', 'age': 21}
```

这个示例展示了字典增删改最基本的写法。下面我们来逐一深入学习每种操作的 API 和使用技巧。

## 2. 核心内容

### 2.1 增加键值对

#### 2.1.1 直接赋值新增

对字典中不存在的键进行赋值，即可新增一个键值对。这是最基本、最直观的新增方式。

```python
d = {"name": "张三", "age": 20}

# 对不存在的键赋值 → 新增
d["city"] = "北京"
print(d)  # {'name': '张三', 'age': 20, 'city': '北京'}

# 值可以是任意类型
d["scores"] = [85, 92, 78]      # 列表
d["info"] = {"major": "CS"}     # 嵌套字典
d["active"] = True               # 布尔值
print(d)
# {'name': '张三', 'age': 20, 'city': '北京', 'scores': [85, 92, 78], 'info': {'major': 'CS'}, 'active': True}
```

**关键点**：`d[key] = value` 既能新增也能修改——当 key 不存在时是新增，当 key 已存在时是修改。如果你只想在 key 不存在时添加（避免覆盖已有值），应该用 `setdefault()`。

#### 2.1.2 setdefault()：键不存在时才新增

`setdefault(key, default=None)` 方法在键不存在时添加键值对并返回 default 值，在键已存在时不做任何修改并返回已有值。

```python
d = {"name": "张三", "age": 20}

# 键不存在 → 添加并返回设置的值
result = d.setdefault("city", "北京")
print(f"setdefault 返回: {result}")  # 北京
print(d)  # {'name': '张三', 'age': 20, 'city': '北京'}

# 键已存在 → 不做任何操作，返回已有值
result = d.setdefault("name", "李四")
print(f"setdefault 返回: {result}")  # 张三（已有值，不覆盖）
print(d)  # name 仍然是 "张三"

# 不传默认值时，默认用 None
d.setdefault("email")
print(d)  # 新增 email: None
```

**运行结果**：

```text
setdefault 返回: 北京
{'name': '张三', 'age': 20, 'city': '北京'}
setdefault 返回: 张三
{'name': '张三', 'age': 20, 'city': '北京'}
{'name': '张三', 'age': 20, 'city': '北京', 'email': None}
```

`setdefault()` 最经典的使用场景是**分组**——按某个属性对数据进行分组归类：

```python
# 场景：按部门对员工分组
groups = {}
for name, dept in [("张三", "CS"), ("李四", "Math"), ("王五", "CS")]:
    groups.setdefault(dept, []).append(name)
print(f"分组结果: {groups}")
# {'CS': ['张三', '王五'], 'Math': ['李四']}
```

这个写法比每次都要判断 `if dept not in groups` 优雅得多。`setdefault(dept, [])` 确保了 departments 键存在且关联一个列表，然后直接 `append`。

#### 2.1.3 update()：批量新增

`update()` 方法可以一次性添加多个键值对。它支持四种参数形式，灵活性很高。

```python
d = {"a": 1, "b": 2}

# 形式一：传入字典
d.update({"c": 3, "d": 4})
print(d)  # {'a': 1, 'b': 2, 'c': 3, 'd': 4}

# 形式二：传入关键字参数
d.update(e=5, f=6)
print(d)  # {..., 'e': 5, 'f': 6}

# 形式三：传入键值对序列（列表或元组）
d.update([("g", 7), ("h", 8)])
print(d)  # {..., 'g': 7, 'h': 8}

# 形式四：传入 zip 对象
d.update(zip(["i", "j"], [9, 10]))
print(d)  # {..., 'i': 9, 'j': 10}
```

**四种参数形式对比**：

| 形式 | 写法 | 适用场景 |
|------|------|---------|
| 字典 | `d.update({"k": v})` | 最常见，已有字典对象 |
| 关键字参数 | `d.update(k=v)` | 键是合法标识符时最简洁 |
| 键值对序列 | `d.update([("k", v)])` | 数据来自遍历、文件解析等 |
| zip 对象 | `d.update(zip(keys, vals))` | 两个列表组合成字典 |

**注意事项**：关键字参数形式的键必须是合法的 Python 标识符（不能含空格、数字开头等），所以 `d.update("key with space"=1)` 会报语法错误。遇到这类键时只能用字典或序列形式。

#### 2.1.4 新增时的顺序行为

Python 3.7+ 保证了字典的插入顺序——新增的键始终追加到字典末尾，不会插入到中间位置。

```python
d = {}
d["banana"] = 2
d["apple"] = 1
d["cherry"] = 3
print(list(d.keys()))  # ['banana', 'apple', 'cherry'] ← 按添加顺序
```

这个特性在处理有序数据时非常有用，比如构建有序配置、按时间顺序记录事件等。

#### 2.1.5 动态构建字典的常见场景

**场景一：从用户输入逐步构建**

```python
user_profile = {}
user_profile["name"] = "张三"
user_profile["age"] = 25
user_profile["email"] = "zhang@example.com"
user_profile["roles"] = ["user", "editor"]
print(f"用户信息: {user_profile}")
```

**场景二：循环中条件性添加**

```python
data = [("apple", 3.5), ("banana", 2.8), ("cherry", 8.0)]
fruit_dict = {}
for name, price in data:
    if price > 3:  # 只添加价格大于 3 的
        fruit_dict[name] = price
print(f"筛选后的字典: {fruit_dict}")  # {'apple': 3.5, 'cherry': 8.0}
```

### 2.2 修改键值对

#### 2.2.1 直接赋值修改

对字典中已存在的键进行赋值，即可修改其对应的值。与新增操作写法完全相同，区别仅在于键是否已存在。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# 对已存在的键赋值 → 修改
d["age"] = 21
print(d)  # {'name': '张三', 'age': 21, 'city': '北京'}

# 修改为完全不同的类型也完全可以
d["city"] = ["北京", "上海"]  # 从 str 改为 list
print(d)  # {'name': '张三', 'age': 21, 'city': ['北京', '上海']}
```

Python 是动态类型语言，字典的值类型不固定。你可以把一个字符串改成列表、字典或任何其他类型，Python 不会报错。但在实际开发中，随意改变值的类型会让代码难以维护，应尽量避免。

#### 2.2.2 复合赋值修改

对于数值类型的值，可以使用 `+=`、`-=` 等复合赋值运算符进行修改。

```python
d = {"score": 85, "count": 10}

d["score"] += 5   # 等价于 d["score"] = d["score"] + 5
d["count"] -= 3
print(d)  # {'score': 90, 'count': 7}
```

这种写法在计数器、累加器场景中很常见，比如统计单词出现次数、投票计数等。

#### 2.2.3 update() 批量修改

`update()` 不仅能新增，还能批量修改。对已有键，update 会覆盖其值；对不存在的键，update 会新增。

```python
d = {"a": 1, "b": 2, "c": 3}

# update 对已有键 → 修改；对不存在键 → 新增
d.update({"a": 99, "b": 88, "d": 4})
print(d)  # {'a': 99, 'b': 88, 'c': 3, 'd': 4}
# a 被修改为 99, b 被修改为 88, c 未涉及保持不变, d 是新增
```

**合并修改：覆盖优先级**

`update()` 的覆盖规则是：后传入的数据覆盖已有值。这在配置合并场景中非常实用：

```python
defaults = {"host": "localhost", "port": 80, "debug": False}
user_config = {"port": 8080, "debug": True}
defaults.update(user_config)
print(f"合并后配置: {defaults}")
# {'host': 'localhost', 'port': 8080, 'debug': True}
# user_config 中的 port 和 debug 覆盖了 defaults 中的值
```

这种"默认配置 + 用户配置合并"的模式在实际项目中极其常见，比如 Web 框架的配置加载。

#### 2.2.4 嵌套字典的修改

当字典中嵌套了字典或列表时，修改需要逐层访问到目标层级再赋值。

```python
school = {
    "name": "清华大学",
    "departments": {
        "cs": {"students": 500, "budget": 1000000},
        "math": {"students": 200, "budget": 500000},
    }
}

# 修改嵌套字典中的值
school["departments"]["cs"]["students"] = 550
print(f"CS学生: {school['departments']['cs']['students']}")  # 550

# 嵌套字典中新增键
school["departments"]["cs"]["head"] = "张教授"
print(f"CS信息: {school['departments']['cs']}")
# {'students': 550, 'budget': 1000000, 'head': '张教授'}

# 修改嵌套列表中的值
d = {"names": ["张三", "李四", "王五"]}
d["names"][0] = "赵六"
print(d)  # {'names': ['赵六', '李四', '王五']}
```

**关键点**：嵌套修改的本质是"先访问到可变对象，再对它进行操作"。`school["departments"]` 返回一个字典，`["cs"]` 再返回一个字典，最后 `["students"] = 550` 修改的是最内层字典的值。

#### 2.2.5 修改时的顺序不变性

修改已有键的值不会改变键在字典中的位置。这是与"删除再添加"的重要区别：

```python
d = {"a": 1, "b": 2, "c": 3}
print(f"修改前: {list(d.keys())}")  # ['a', 'b', 'c']

d["a"] = 99
d["c"] = 999
print(f"修改后: {list(d.keys())}")  # ['a', 'b', 'c'] ← 顺序不变

# 对比：删除再添加 → 键移动到末尾
d["b"] = 2
del d["b"]
d["b"] = 2
print(f"删后重加: {list(d.keys())}")  # ['a', 'c', 'b'] ← b 移到末尾了
```

如果你需要保持字典中键的顺序不变，用直接赋值修改；如果不在意顺序，删除再添加也可以，但不推荐。

### 2.3 删除键值对

Python 提供了四种删除字典键值对的方式，每种方式的行为和返回值各不相同。

#### 2.3.1 del 关键字

`del` 是 Python 的关键字（不是方法），用于删除字典中指定键的键值对。删除不存在的键会触发 `KeyError`。

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4}

del d["a"]
print(d)  # {'b': 2, 'c': 3, 'd': 4}

# 删除不存在的键 → KeyError
try:
    del d["a"]  # "a" 已经被删除了
except KeyError as e:
    print(f"KeyError: {e}")  # KeyError: 'a'
```

**关键点**：`del` 不返回被删的值。如果你需要获取被删除的值，应该用 `pop()` 而不是 `del`。

#### 2.3.2 pop()：删除并返回值

`pop(key[, default])` 方法删除指定键并返回其对应的值。如果键不存在且未指定默认值，触发 `KeyError`；如果指定了默认值，则返回默认值。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# pop 删除键并返回对应的值
removed = d.pop("age")
print(f"被删除的值: {removed}")  # 20
print(d)  # {'name': '张三', 'city': '北京'}

# pop 键不存在 → KeyError
try:
    d.pop("age")  # "age" 已经被删了
except KeyError as e:
    print(f"KeyError: {e}")  # KeyError: 'age'

# pop 键不存在时指定默认值 → 不报错
result = d.pop("phone", "不存在")
print(f"pop 默认值: {result}")  # 不存在
print(d)  # 字典不受影响
```

**pop() 三种用法对比**：

| 用法 | 键不存在时行为 | 适用场景 |
|------|-------------|---------|
| `d.pop(key)` | 抛出 KeyError | 确定键一定存在时 |
| `d.pop(key, None)` | 返回 None | 不确定键是否存在，不需要区分 |
| `d.pop(key, default)` | 返回 default | 不确定键是否存在，需要自定义默认值 |

#### 2.3.3 popitem()：删除最后一个

`popitem()` 方法删除并返回字典中最后一个键值对（以元组 `(key, value)` 形式返回）。在空字典上调用会触发 `KeyError`。

```python
d = {"a": 1, "b": 2, "c": 3}

# popitem 删除并返回最后一个键值对（LIFO 顺序）
last = d.popitem()
print(f"弹出: {last}")  # ('c', 3)
print(d)  # {'a': 1, 'b': 2}

last = d.popitem()
print(f"弹出: {last}")  # ('b', 2)
print(d)  # {'a': 1}

# 空字典调用 popitem → KeyError
empty = {}
try:
    empty.popitem()
except KeyError as e:
    print(f"空字典 popitem: KeyError: {e}")
```

`popitem()` 的设计初衷是实现 LIFO（后进先出）式的消耗。当字典按插入顺序排列时，`popitem()` 总是弹出最后插入的键值对。

#### 2.3.4 clear()：清空字典

`clear()` 方法删除字典中所有键值对，使其变成空字典。清空后字典对象的 id 不变（就地清空，不是创建新对象）。

```python
d = {"a": 1, "b": 2, "c": 3}
print(f"清空前: {d}")

d.clear()
print(f"清空后: {d}")  # {}

# clear 后 id 不变
d2 = {"a": 1, "b": 2}
original_id = id(d2)
d2.clear()
print(f"id不变: {id(d2) == original_id}")  # True
print(f"类型: {type(d2)}")  # <class 'dict'>
```

**clear() vs 重新赋空字典**：

```python
# 方式一：clear() → 就地清空，id 不变
d = {"a": 1}
other_ref = d
d.clear()
print(other_ref is d)  # True，other_ref 也变成了空字典

# 方式二：重新赋值 → 创建新对象，id 变化
d = {"a": 1}
other_ref = d
d = {}  # d 指向新对象，other_ref 仍然指向原字典
print(other_ref is d)  # False
print(other_ref)  # {'a': 1} ← other_ref 仍持有原数据
```

如果有其他变量引用了同一个字典，用 `clear()` 能让所有引用都看到清空效果；用 `d = {}` 只会让当前变量指向新对象，其他引用不受影响。

#### 2.3.5 四种删除方式对比

| 方式 | 语法 | 返回值 | 适用场景 |
|------|------|--------|---------|
| `del` | `del d[key]` | 无 | 确定键存在，不需要返回值 |
| `pop()` | `d.pop(key[, default])` | 被删的值 | 需要获取被删值，或不确定键是否存在 |
| `popitem()` | `d.popitem()` | (key, value) 元组 | 弹出最后一个，LIFO 消耗 |
| `clear()` | `d.clear()` | None | 清空整个字典 |

#### 2.3.6 批量删除满足条件的键

在实际开发中，经常需要删除满足某些条件的多个键。遍历字典时直接删除会触发 `RuntimeError`，需要用安全的方式处理。

```python
d = {"apple": 3.5, "banana": 2.8, "cherry": 8.0, "date": 6.5, "fig": 1.2}

# 方式一：先记录要删的键，再逐个删除（安全）
to_delete = [k for k, v in d.items() if v < 3]
for k in to_delete:
    del d[k]
print(f"删除低价水果后: {d}")  # {'apple': 3.5, 'cherry': 8.0, 'date': 6.5}

# 方式二：用推导式过滤（创建新字典）
d2 = {"apple": 3.5, "banana": 2.8, "cherry": 8.0, "date": 6.5, "fig": 1.2}
d2 = {k: v for k, v in d2.items() if v >= 3}
print(f"推导式过滤后: {d2}")  # {'apple': 3.5, 'cherry': 8.0, 'date': 6.5}
```

**危险写法——遍历时直接删除（会报错）**：

```python
# d = {"a": 1, "b": 2, "c": 3}
# for k in d:
#     if d[k] < 2:
#         del d[k]   # RuntimeError: dictionary changed size during iteration
```

遍历字典时修改字典的大小（增删键值对）会触发 `RuntimeError`。这是因为迭代器内部维护了字典的大小信息，一旦大小改变，迭代器就会检测到不一致并报错。解决方法就是上面两种：要么先收集要删的键再统一删除，要么用推导式创建新字典。

### 2.4 update() 方法详解

`update()` 是字典中最全能的方法之一，同时具备"增"和"改"的能力。前面在新增和修改章节都提到了它，这里做一个系统性的梳理。

#### 2.4.1 四种参数形式

```python
d = {"a": 1, "b": 2}

# 形式一：传入字典
d.update({"c": 3, "d": 4})
print(f"字典参数: {d}")  # {'a': 1, 'b': 2, 'c': 3, 'd': 4}

# 形式二：传入关键字参数
d.update(e=5, f=6)
print(f"关键字参数: {d}")  # {..., 'e': 5, 'f': 6}

# 形式三：传入键值对序列
d.update([("g", 7), ("h", 8)])
print(f"序列参数: {d}")  # {..., 'g': 7, 'h': 8}

# 形式四：传入 zip 对象
d.update(zip(["i", "j"], [9, 10]))
print(f"zip参数: {d}")  # {..., 'i': 9, 'j': 10}
```

#### 2.4.2 覆盖行为

`update()` 的核心规则是：已有键 → 覆盖（修改），不存在键 → 新增。

```python
base = {"host": "localhost", "port": 80, "debug": False}

# 覆盖已有键 + 新增键
base.update({"port": 8080, "retries": 3})
print(f"update后: {base}")
# {'host': 'localhost', 'port': 8080, 'debug': False, 'retries': 3}
```

#### 2.4.3 update() 与 | 运算符（Python 3.9+）

Python 3.9 引入了字典合并运算符 `|` 和原地合并运算符 `|=`，提供了更简洁的字典合并方式。

```python
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}

# update 返回 None（原地修改）
result = d1.update(d2)
print(f"update 返回值: {result}")  # None
print(f"d1 更新后: {d1}")  # {'a': 1, 'b': 3, 'c': 4}

# | 运算符创建新字典（不修改原字典）
d3 = {"a": 1, "b": 2}
d4 = {"b": 3, "c": 4}
merged = d3 | d4
print(f"merged: {merged}")  # {'a': 1, 'b': 3, 'c': 4}
print(f"d3 不变: {d3}")  # {'a': 1, 'b': 2}  ← 原字典不受影响

# |= 原地合并（等价于 update）
d5 = {"a": 1, "b": 2}
d5 |= {"b": 3, "c": 4}
print(f"|= 后: {d5}")  # {'a': 1, 'b': 3, 'c': 4}
```

**update() vs | vs |= 对比**：

| 方式 | 是否修改原字典 | 返回值 | Python 版本 |
|------|-------------|--------|------------|
| `d.update(other)` | 是（原地修改） | None | 所有版本 |
| `d \| other` | 否（创建新字典） | 新字典 | 3.9+ |
| `d \|= other` | 是（原地修改） | None | 3.9+ |

#### 2.4.4 参数混合与优先级

`update()` 可以同时接受位置参数（字典/序列）和关键字参数。如果同键冲突，关键字参数优先。

```python
d = {"a": 1}
# 同时传位置参数和关键字参数
d.update({"b": 2}, c=3)
print(f"混合参数: {d}")  # {'a': 1, 'b': 2, 'c': 3}

# 关键字参数覆盖位置参数中的同键
d.update({"d": 10}, d=99)
print(f"关键字覆盖: {d}")  # d=99（关键字参数优先）
```

#### 2.4.5 链式合并多个字典

当需要将多个字典按优先级合并时，可以链式调用 `update()`：

```python
config = {}
defaults = {"host": "localhost", "port": 80}
env_config = {"port": 8080, "debug": True}
user_config = {"debug": False, "workers": 4}

# 链式 update 合并多个字典
config.update(defaults)
config.update(env_config)
config.update(user_config)
# 后合并的覆盖先合并的
print(f"最终配置: {config}")
# {'host': 'localhost', 'port': 8080, 'debug': False, 'workers': 4}
```

这种"默认配置 → 环境配置 → 用户配置"的合并顺序保证了优先级：用户配置 > 环境配置 > 默认配置。

#### 2.4.6 update() 与引用共享

`update()` 传入的字典中的可变值是引用共享的，修改一方会影响另一方。

```python
source = {"items": [1, 2, 3]}
target = {"x": 0}
target.update(source)

# 修改 target 中的列表会影响 source
target["items"].append(4)
print(f"target: {target}")  # {'x': 0, 'items': [1, 2, 3, 4]}
print(f"source: {source}")  # {'items': [1, 2, 3, 4]}  ← 也变了！（浅引用）
```

这是因为 `update()` 只做了浅拷贝——值本身（包括列表对象的引用）被直接传递，没有递归拷贝。如果需要完全独立，应该用 `copy.deepcopy()`。

### 2.5 就地修改与 id 验证

字典是可变类型，增删改操作都是"就地修改"，不会创建新的字典对象。理解这一点对于掌握字典的引用行为至关重要。

#### 2.5.1 字典 id 不变验证

```python
d = {"a": 1, "b": 2}
print(f"原始 id: {id(d)}")

d["c"] = 3       # 增
print(f"增后 id: {id(d)}")   # 同一个 id

d["a"] = 99      # 改
print(f"改后 id: {id(d)}")   # 同一个 id

del d["b"]       # 删
print(f"删后 id: {id(d)}")   # 同一个 id

d.clear()         # 清空
print(f"清空后 id: {id(d)}")  # 同一个 id
```

所有操作前后，`id(d)` 始终不变——这证明字典的增删改都是在原对象上进行的，没有创建新对象。

#### 2.5.2 对比不可变类型（str）

字符串（str）是不可变类型，每次"修改"实际上都创建了新对象：

```python
s = "hello"
original_id = id(s)
s += " world"  # 看似修改，实则创建新字符串
print(f"str 修改前 id: {original_id}")
print(f"str 修改后 id: {id(s)}")  # 不同 id（新对象）
```

这就是可变类型（dict、list）和不可变类型（str、tuple）的核心区别：可变类型就地修改，id 不变；不可变类型每次"修改"都创建新对象，id 变化。

#### 2.5.3 引用传递：多变量指向同一字典

当两个变量指向同一个字典时，通过一个变量修改字典，另一个变量也能看到变化。

```python
d1 = {"a": 1, "b": 2}
d2 = d1  # 不是拷贝，而是引用同一个对象

print(f"d1 is d2: {d1 is d2}")  # True

# 通过 d2 修改，d1 也看到变化
d2["c"] = 3
print(f"d1: {d1}")  # {'a': 1, 'b': 2, 'c': 3}  ← d1 也变了
print(f"d2: {d2}")  # {'a': 1, 'b': 2, 'c': 3}

# 通过 d1 删除，d2 也受影响
del d1["a"]
print(f"d1: {d1}")  # {'b': 2, 'c': 3}
print(f"d2: {d2}")  # {'b': 2, 'c': 3}  ← 同一个对象
```

#### 2.5.4 函数参数中的引用传递

字典作为函数参数传递时，函数内部对字典的修改会影响外部传入的原始字典。

```python
def add_item(d, key, value):
    """函数内修改字典，影响外部传入的字典"""
    d[key] = value

config = {"host": "localhost"}
add_item(config, "port", 8080)
print(f"函数修改后: {config}")
# {'host': 'localhost', 'port': 8080}  ← 函数内修改影响了外部字典

def remove_item(d, key):
    """函数内删除字典键"""
    d.pop(key, None)

remove_item(config, "host")
print(f"函数删除后: {config}")  # {'port': 8080}
```

这种行为在 Python 中非常普遍——可变对象作为函数参数时，函数内的修改对外部可见。如果你不希望函数修改原始字典，应该在函数内部创建副本。

#### 2.5.5 浅拷贝与深拷贝

**浅拷贝**只拷贝字典的第一层，嵌套的可变对象仍然是引用共享：

```python
original = {"a": 1, "b": 2}
shallow_copy = original.copy()

shallow_copy["c"] = 3
print(f"浅拷贝修改后:")
print(f"  original: {original}")  # {'a': 1, 'b': 2}  ← 不受影响
print(f"  copy: {shallow_copy}")  # {'a': 1, 'b': 2, 'c': 3}
```

第一层修改互不影响，但嵌套的可变对象就不同了：

```python
d_original = {"names": ["张三", "李四"], "info": {"age": 20}}
d_shallow = d_original.copy()

# 修改第一层键值对 → 互不影响
d_shallow["level"] = 1
print(f"第一层修改:")
print(f"  original: {d_original}")  # 没有 "level" 键
print(f"  shallow: {d_shallow}")    # 有 "level" 键

# 修改嵌套的可变对象 → 都受影响！
d_shallow["names"].append("王五")
print(f"嵌套修改:")
print(f"  original names: {d_original['names']}")  # ['张三', '李四', '王五'] ← 也变了！
print(f"  shallow names: {d_shallow['names']}")    # ['张三', '李四', '王五']
```

**深拷贝**递归拷贝所有层级，完全独立：

```python
import copy

d_deep_original = {"names": ["张三", "李四"], "info": {"age": 20}}
d_deep = copy.deepcopy(d_deep_original)

d_deep["names"].append("王五")
d_deep["info"]["age"] = 25

print(f"深拷贝修改:")
print(f"  original: {d_deep_original}")  # 嵌套不变
print(f"  deep: {d_deep}")              # 嵌套独立修改
```

**三种拷贝方式对比**：

| 方式 | 语法 | 第一层独立 | 嵌套层独立 |
|------|------|----------|----------|
| 赋值 | `d2 = d1` | 否（同一对象） | 否 |
| 浅拷贝 | `d.copy()` 或 `dict(d)` | 是 | 否 |
| 深拷贝 | `copy.deepcopy(d)` | 是 | 是 |

```python
# 模拟数据库
students = {}

# ========== Create: 创建学生 ==========
def create_student(students, student_id, name, age, major):
    """新增学生记录"""
    if student_id in students:
        return f"学号 {student_id} 已存在，创建失败"
    students[student_id] = {
        "name": name,
        "age": age,
        "major": major,
        "scores": {},
    }
    return f"创建成功: {name} (学号: {student_id})"

# ========== Read: 查询学生 ==========
def read_student(students, student_id):
    """查询单个学生"""
    student = students.get(student_id)
    if student is None:
        return f"学号 {student_id} 不存在"
    return f"{student['name']} | {student['age']}岁 | 专业: {student['major']} | 成绩: {student['scores']}"

def list_students(students):
    """列出所有学生"""
    if not students:
        return "暂无学生记录"
    result = []
    for sid, info in students.items():
        result.append(f"  {sid}: {info['name']} - {info['major']}")
    return "\n".join(result)

# ========== Update: 修改学生 ==========
def update_student(students, student_id, **kwargs):
    """修改学生信息（支持批量修改）"""
    if student_id not in students:
        return f"学号 {student_id} 不存在，修改失败"
    students[student_id].update(kwargs)
    return f"修改成功: {student_id} 更新字段 {list(kwargs.keys())}"

def add_score(students, student_id, subject, score):
    """给学生添加成绩（嵌套字典的新增/修改）"""
    if student_id not in students:
        return f"学号 {student_id} 不存在"
    students[student_id]["scores"][subject] = score
    return f"成绩录入: {students[student_id]['name']} {subject}={score}"

# ========== Delete: 删除学生 ==========
def delete_student(students, student_id):
    """删除学生记录"""
    if student_id not in students:
        return f"学号 {student_id} 不存在，删除失败"
    name = students[student_id]["name"]
    del students[student_id]
    return f"删除成功: {name} (学号: {student_id})"
```

**批量操作**

```python
# 批量导入学生
batch_data = [
    ("010", {"name": "赵六", "age": 23, "major": "化学"}),
    ("011", {"name": "钱七", "age": 24, "major": "生物"}),
    ("012", {"name": "孙八", "age": 22, "major": "地理"}),
]
for sid, info in batch_data:
    students[sid] = {**info, "scores": {}}
print(f"批量导入后学生数: {len(students)}")

# 批量删除没有成绩记录的学生
no_scores = [sid for sid, info in students.items() if not info["scores"]]
print(f"无成绩记录的学生: {no_scores}")
for sid in no_scores:
    print(delete_student(students, sid))
print(f"删除后学生数: {len(students)}")
```

这里用到了一个技巧：`{**info, "scores": {}}`。`**info` 是字典解包语法，将 `info` 中的所有键值对展开，然后追加一个 `"scores": {}` 键。这比 `dict(info)` 再赋值 `["scores"] = {}` 更简洁。

**字典作为缓存的使用模式**

```python
_fib_cache = {}

def fib(n):
    """带缓存的斐波那契数列"""
    if n in _fib_cache:
        return _fib_cache[n]
    if n <= 1:
        result = n
    else:
        result = fib(n - 1) + fib(n - 2)
    _fib_cache[n] = result  # 缓存计算结果
    return result

print(f"fib(10) = {fib(10)}")
print(f"fib(20) = {fib(20)}")
print(f"缓存大小: {len(_fib_cache)}")
```

缓存模式是字典增删改的经典应用场景：先查缓存（`in` 判断），命中则返回，未命中则计算并存入缓存（赋值新增）。通过"空间换时间"大幅提升递归性能。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

#### 新增键值对

| 场景 | 不推荐 | 推荐 | 原因 |
|------|--------|------|------|
| 安全添加（不覆盖） | `if key not in d: d[key] = val` | `d.setdefault(key, val)` | setdefault 是原子操作，一行搞定 |
| 批量添加 | 循环逐个赋值 | `d.update(other)` | update 内部用 C 实现，效率更高 |
| 条件添加 | `d[key] = val if key not in d else d[key]` | `d.setdefault(key, val)` | 更简洁、可读性更好 |

#### 修改键值对

| 场景 | 不推荐 | 推荐 | 原因 |
|------|--------|------|------|
| 修改已有键 | `d.update({key: val})` | `d[key] = val` | 单个修改用赋值更直观 |
| 批量修改 | 循环逐个赋值 | `d.update(other)` | 一行代码完成批量操作 |
| 嵌套修改 | 多行 if-else 判断 | 直接逐层赋值 | 嵌套字典不需要额外判断 |

#### 删除键值对

| 场景 | 不推荐 | 推荐 | 原因 |
|------|--------|------|------|
| 删除不确定存在的键 | `if key in d: del d[key]` | `d.pop(key, None)` | 一行搞定，无 KeyError 风险 |
| 需要被删的值 | `val = d[key]; del d[key]` | `val = d.pop(key)` | pop 一步完成取值和删除 |
| 清空字典 | `d = {}` | `d.clear()` | clear 保持 id 不变，其他引用可见 |
| 批量删除 | 遍历时直接 del | 先收集键再删除，或用推导式 | 遍历时修改会 RuntimeError |

### 3.2 常见错误模式及修正

**错误一：遍历时修改字典大小**

```python
# 错误
d = {"a": 1, "b": 2, "c": 3}
for k in d:
    if d[k] < 2:
        del d[k]  # RuntimeError: dictionary changed size during iteration

# 正确
d = {"a": 1, "b": 2, "c": 3}
to_delete = [k for k, v in d.items() if v < 2]
for k in to_delete:
    del d[k]
```

**错误二：删除不存在的键**

```python
# 错误（如果不确定键是否存在）
del d["maybe_key"]  # 可能 KeyError

# 正确
d.pop("maybe_key", None)  # 键不存在时安静返回 None
```

**错误三：误用 setdefault 覆盖已有值**

```python
# 错误（如果意图是"不存在才设值"，用了赋值会覆盖已有值）
d["key"] = "new_value"  # 不管 key 是否存在都覆盖

# 正确
d.setdefault("key", "new_value")  # key 已存在时不覆盖
```

**错误四：浅拷贝后修改嵌套对象**

```python
# 错误（浅拷贝的嵌套对象是共享的）
original = {"items": [1, 2, 3]}
copy_dict = original.copy()
copy_dict["items"].append(4)  # original["items"] 也变了！

# 正确
import copy
original = {"items": [1, 2, 3]}
deep = copy.deepcopy(original)
deep["items"].append(4)  # original 不受影响
```

### 3.3 性能对比：update() vs 逐个赋值

`update()` 底层用 C 实现，在批量操作时性能优于 Python 循环逐个赋值。

```python
import time

d = {}
other = {str(i): i for i in range(100000)}

start = time.perf_counter()
d.update(other)
update_time = time.perf_counter() - start

d2 = {}
start = time.perf_counter()
for k, v in other.items():
    d2[k] = v
loop_time = time.perf_counter() - start

print(f"update 10万键值对: {update_time:.4f} 秒")
print(f"逐个赋值 10万键值对: {loop_time:.4f} 秒")
# update 略快，因为 C 层面直接遍历，减少了 Python 循环开销
```

对于少量键值对（几个到几十个），两种方式性能差异可以忽略。但在处理大量数据时，`update()` 是更优选择。

## 4. 原理

### 4.1 字典的可变性原理

Python 的字典底层是基于哈希表实现的。哈希表是一个数组，每个位置称为一个"桶"（bucket）。当你执行 `d[key] = value` 时，Python 会：

1. 计算 key 的哈希值：`hash(key)`
2. 根据哈希值定位桶的位置：`hash(key) % table_size`
3. 将键值对存入对应的桶中

这个过程不需要移动其他元素，只需要在哈希表的对应位置写入数据。这就是为什么字典的增删改操作的平均时间复杂度是 O(1)。

```text
d = {"name": "张三", "age": 20}

哈希表结构：
┌─────────────────────────────────┐
│ 索引  │ 哈希值  │ 键      │ 值    │
├───────┼────────┼────────┼───────┤
│  0    │        │        │       │  ← 空桶
│  1    │ 8234   │ "name" │ "张三"│
│  2    │        │        │       │  ← 空桶
│  3    │ 5678   │ "age"  │ 20    │
│  ...  │        │        │       │
└─────────────────────────────────┘

d["city"] = "北京"  →  hash("city") 定位到索引 5 → 存入空桶
d["age"] = 21       →  hash("age") 定位到索引 3 → 覆盖原值
del d["name"]       →  hash("name") 定位到索引 1 → 标记为"已删除"
```

因为修改和删除都是直接定位到桶后操作该桶的数据，不涉及其他桶的移动，所以 id 不变——始终是同一个哈希表对象。

### 4.2 为什么遍历时不能修改字典大小

Python 字典的迭代器内部维护了对哈希表的引用和一个"已访问位置"的游标。如果在遍历过程中增删键值对，哈希表的结构发生变化（比如桶被标记为删除、或者触发了 rehash 扩容），迭代器之前记录的游标位置可能变得无效，导致跳过元素、重复访问或访问到已删除的元素。

为了防止这种数据不一致的问题，Python 在字典内部维护了一个版本号（`ma_version_tag`），每次增删改都会递增版本号。迭代器在每次 `__next__` 调用时检查版本号，如果发现版本号变化了，就抛出 `RuntimeError: dictionary changed size during iteration`。

这是一个安全保护机制，确保迭代过程中数据的一致性。

### 4.3 哈希冲突与有序字典

当你对两个不同的键计算哈希值时，有可能得到相同的桶位置——这叫做"哈希冲突"。Python 使用"开放寻址法"处理冲突：如果目标桶被占用，就向后探测下一个空桶。

```text
hash("abc") % 8 = 3
hash("xyz") % 8 = 3  ← 冲突！与 "abc" 映射到同一个桶

解决方式：
索引 3: "abc" → "张三"
索引 4: "xyz" → "李四"  ← 向后探测到下一个空桶
```

Python 3.6+ 对字典做了优化，使用两个数组分别存储"索引数组"和"键值对数组"，实现了紧凑的内存布局。这也是 Python 3.7+ 保证字典插入顺序的底层基础——键值对按插入顺序排列在数组中，遍历时按数组顺序访问即可。

## 5. 总结

本文围绕字典的增删改操作展开，主要介绍了以下内容：

- **增加键值对**：直接赋值 `d[key] = value` 最基本；`setdefault()` 适合"不存在才添加"的安全场景；`update()` 适合批量新增，支持字典、关键字参数、序列、zip 四种形式
- **修改键值对**：直接赋值修改最直观；复合赋值（`+=`、`-=`）适合计数场景；`update()` 批量修改并合并配置；嵌套字典需逐层访问再赋值
- **删除键值对**：`del` 最直接但不返回值；`pop()` 删除并返回值，支持默认值防 KeyError；`popitem()` 弹出最后一个键值对；`clear()` 清空字典且保持 id 不变
- **update() 详解**：四种参数形式、覆盖规则、与 `|` / `|=` 运算符的关系、链式合并配置、引用共享的注意事项
- **就地修改特性**：字典是可变类型，增删改都在原对象上进行，id 不变；引用传递导致多变量共享同一字典；浅拷贝只隔离第一层，深拷贝完全独立
- **最佳实践**：安全删除用 `pop(key, None)`、安全添加用 `setdefault()`、批量操作用 `update()`、遍历时修改需先收集键再操作
- **底层原理**：字典基于哈希表实现，增删改平均 O(1)；遍历时修改触发版本检测机制抛出 RuntimeError；哈希冲突用开放寻址法解决
