# 列表与栈和队列

## 1. 介绍

栈和队列是最基础的数据结构，Python 的列表天然可以充当栈和队列。栈是后进先出（LIFO）——用 `append()` 入栈、`pop()` 出栈，都是末尾操作，O(1) 复杂度，非常高效。队列是先进先出（FIFO）——用 `append()` 入队、`pop(0)` 出队，但 `pop(0)` 是 O(n) 操作，因为列表底层是动态数组，从头部删除需要移动所有元素。

对于队列场景，Python 标准库提供了 `collections.deque`（双端队列），它的 `append()` / `appendleft()` / `pop()` / `popleft()` 四个操作都是 O(1)，是替代 `pop(0)` 的最佳方案。理解列表在栈和队列中的适用边界，以及 `deque` 的优势，是正确选择数据结构的关键。

**最简示例**

用列表实现栈——`append()` 入栈、`pop()` 出栈：

```python
stack = []
stack.append("A")   # 入栈
stack.append("B")
stack.append("C")
print(stack.pop())  # C（后进先出）
print(stack.pop())  # B
```

运行结果：

```text
C
B
```

用 `deque` 实现队列——`append()` 入队、`popleft()` 出队：

```python
from collections import deque
queue = deque()
queue.append("A")       # 入队
queue.append("B")
queue.append("C")
print(queue.popleft())  # A（先进先出）
print(queue.popleft())  # B
```

运行结果：

```text
A
B
```

## 2. 核心内容

列表和 deque 在栈/队列操作上的对比如下：

| 操作 | `list` | `deque` | 时间复杂度 |
|------|--------|---------|-----------|
| 末尾添加 `append(x)` | `lst.append(x)` | `dq.append(x)` | O(1) |
| 末尾弹出 `pop()` | `lst.pop()` | `dq.pop()` | O(1) |
| 头部添加 | `lst.insert(0, x)` | `dq.appendleft(x)` | list O(n) / deque O(1) |
| 头部弹出 | `lst.pop(0)` | `dq.popleft()` | list O(n) / deque O(1) |
| 随机访问 `x[i]` | `lst[i]` | `dq[i]` | list O(1) / deque O(n) |
| 切片 `x[a:b]` | `lst[a:b]` | 不支持 | list O(1) |
| maxlen 限制 | 不支持 | `deque(maxlen=n)` | - |

下面逐一详细讲解。

### 2.1 用列表实现栈

栈是**后进先出**（LIFO, Last In First Out）的数据结构——最后放入的元素最先被取出。就像一摞盘子：你只能在顶部放盘子、从顶部取盘子。

列表实现栈非常自然——`append()` 在末尾添加元素（入栈），`pop()` 从末尾弹出元素（出栈），两者都是 O(1) 操作。

**栈操作图示**

```text
栈（后进先出 LIFO）：

  入栈 push →  [C]  ← 出栈 pop
              [B]
              [A]

  push 顺序: A → B → C
  pop  顺序: C → B → A  （后进入的先出来）
```

**基本实现**

```python
stack = []

# 入栈
stack.append("页面A")
stack.append("页面B")
stack.append("页面C")
print(f"栈: {stack}")
print(f"栈顶: {stack[-1]}")

# 出栈
top = stack.pop()
print(f"弹出: {top}, 剩余: {stack}")

top = stack.pop()
print(f"弹出: {top}, 剩余: {stack}")
```

运行结果：

```text
栈: ['页面A', '页面B', '页面C']
栈顶: 页面C
弹出: 页面C, 剩余: ['页面A', '页面B']
弹出: 页面B, 剩余: ['页面A']
```

`stack[-1]` 查看栈顶元素但不弹出，`stack.pop()` 弹出栈顶元素并返回。

**封装为 Stack 类**

```python
class Stack:
    """基于列表的栈实现"""

    def __init__(self):
        self._items = []

    def push(self, item):
        """入栈"""
        self._items.append(item)

    def pop(self):
        """出栈"""
        if self.is_empty():
            raise IndexError("pop from empty stack")
        return self._items.pop()

    def peek(self):
        """查看栈顶（不弹出）"""
        if self.is_empty():
            raise IndexError("peek from empty stack")
        return self._items[-1]

    def is_empty(self):
        """判断栈是否为空"""
        return len(self._items) == 0

    def size(self):
        """返回栈大小"""
        return len(self._items)


stack = Stack()
for item in ["A", "B", "C"]:
    stack.push(item)
    print(f"  push({item}) → 栈大小: {stack.size()}, 栈顶: {stack.peek()}")

print("  --- 开始出栈 ---")
while not stack.is_empty():
    print(f"  pop() → {stack.pop()}, 剩余大小: {stack.size()}")
```

运行结果：

```text
  push(A) → 栈大小: 1, 栈顶: A
  push(B) → 栈大小: 2, 栈顶: B
  push(C) → 栈大小: 3, 栈顶: C
  --- 开始出栈 ---
  pop() → C, 剩余大小: 2
  pop() → B, 剩余大小: 1
  pop() → A, 剩余大小: 0
```

**浏览器后退模拟**

栈最直观的应用是浏览器后退按钮——每访问一个页面就 `push`，点后退就 `pop`：

```python
history = []

# 浏览页面 → 入栈
for page in ["首页", "产品列表", "产品详情", "购物车"]:
    history.append(page)
    print(f"  访问: {page}")

print("  --- 点击后退 ---")
while history:
    current = history.pop()
    print(f"  回到: {current} 之后可选页: {history}")
```

运行结果：

```text
  访问: 首页
  访问: 产品列表
  访问: 产品详情
  访问: 购物车
  --- 点击后退 ---
  回到: 购物车 之后可选页: ['首页', '产品列表', '产品详情']
  回到: 产品详情 之后可选页: ['首页', '产品列表']
  回到: 产品列表 之后可选页: ['首页']
  回到: 首页 之后可选页: []
```

### 2.2 用列表实现队列

队列是**先进先出**（FIFO, First In First Out）的数据结构——最先放入的元素最先被取出。就像排队买票：先排队的人先服务。

列表实现队列时，`append()` 在末尾添加元素（入队），`pop(0)` 从开头弹出元素（出队）。`append()` 是 O(1)，但 `pop(0)` 是 O(n)——因为列表底层是动态数组，删除第一个元素后需要把后面所有元素向前移动一位。

**队列操作图示**

```text
队列（先进先出 FIFO）：

  入队 enqueue → [A][B][C] → 出队 dequeue
  （尾部添加）    队首    队尾  （头部弹出）

  enqueue 顺序: A → B → C
  dequeue 顺序: A → B → C  （先进入的先出来）
```

**基本实现**

```python
queue = []

# 入队
queue.append("任务1")
queue.append("任务2")
queue.append("任务3")
print(f"队列: {queue}")
print(f"队首: {queue[0]}")

# 出队
first = queue.pop(0)
print(f"出队: {first}, 剩余: {queue}")

second = queue.pop(0)
print(f"出队: {second}, 剩余: {queue}")
```

运行结果：

```text
队列: ['任务1', '任务2', '任务3']
队首: 任务1
出队: 任务1, 剩余: ['任务2', '任务3']
出队: 任务2, 剩余: ['任务3']
```

`queue[0]` 查看队首元素但不弹出，`queue.pop(0)` 弹出队首元素并返回。

**封装为 Queue 类**

```python
class Queue:
    """基于列表的队列实现"""

    def __init__(self):
        self._items = []

    def enqueue(self, item):
        """入队"""
        self._items.append(item)

    def dequeue(self):
        """出队"""
        if self.is_empty():
            raise IndexError("dequeue from empty queue")
        return self._items.pop(0)

    def front(self):
        """查看队首"""
        if self.is_empty():
            raise IndexError("front from empty queue")
        return self._items[0]

    def is_empty(self):
        return len(self._items) == 0

    def size(self):
        return len(self._items)


queue = Queue()
for task in ["任务A", "任务B", "任务C"]:
    queue.enqueue(task)
    print(f"  enqueue({task}) → 队列大小: {queue.size()}, 队首: {queue.front()}")

print("  --- 开始出队 ---")
while not queue.is_empty():
    item = queue.dequeue()
    print(f"  dequeue() → {item}, 剩余大小: {queue.size()}")
```

运行结果：

```text
  enqueue(任务A) → 队列大小: 1, 队首: 任务A
  enqueue(任务B) → 队列大小: 2, 队首: 任务A
  enqueue(任务C) → 队列大小: 3, 队首: 任务A
  --- 开始出队 ---
  dequeue() → 任务A, 剩余大小: 2
  dequeue() → 任务B, 剩余大小: 1
  dequeue() → 任务C, 剩余大小: 0
```

**打印机任务队列模拟**

```python
printer = []

# 提交打印任务 → 入队
for doc in ["文档A", "文档B", "图片C"]:
    printer.append(doc)
    print(f"  提交打印: {doc} → 队列: {printer}")

print("  --- 开始打印 ---")
while printer:
    current = printer.pop(0)
    print(f"  正在打印: {current} → 剩余: {printer}")
```

运行结果：

```text
  提交打印: 文档A → 队列: ['文档A']
  提交打印: 文档B → 队列: ['文档A', '文档B']
  提交打印: 图片C → 队列: ['文档A', '文档B', '图片C']
  --- 开始打印 ---
  正在打印: 文档A → 剩余: ['文档B', '图片C']
  正在打印: 文档B → 剩余: ['图片C']
  正在打印: 图片C → 剩余: []
```

### 2.3 collections.deque 双端队列

`collections.deque`（双端队列）是一个两端都能高效操作的数据结构。与列表不同，`deque` 的头部和尾部操作都是 O(1)——它底层不是连续数组，而是双向链表式的链块结构，不需要移动元素。

**创建 deque**

```python
from collections import deque

d1 = deque()              # 空 deque
d2 = deque([1, 2, 3])     # 从列表创建
d3 = deque("hello")       # 从字符串创建
d4 = deque(range(5))       # 从 range 创建
print(f"d1: {d1}")
print(f"d2: {d2}")
print(f"d3: {d3}")
print(f"d4: {d4}")
```

运行结果：

```text
d1: deque([])
d2: deque([1, 2, 3])
d3: deque(['h', 'e', 'l', 'l', 'o'])
d4: deque([0, 1, 2, 3, 4])
```

`deque` 和 `list` 一样接受可迭代对象作为构造参数，但结果类型是 `deque` 而不是 `list`。

**两端操作**

```python
d = deque([2, 3, 4])
print(f"初始: {d}")

# 右端操作（和 list 完全一样）
d.append(5)       # 右端添加
print(f"append(5) → {d}")
d.pop()           # 右端弹出
print(f"pop()     → {d}")

# 左端操作（deque 独有，O(1)）
d.appendleft(1)   # 左端添加
print(f"appendleft(1) → {d}")
d.popleft()       # 左端弹出
print(f"popleft()     → {d}")
```

运行结果：

```text
初始: deque([2, 3, 4])
append(5) → deque([2, 3, 4, 5])
pop()     → deque([2, 3, 4])
appendleft(1) → deque([1, 2, 3, 4])
popleft()     → deque([2, 3, 4])
```

`deque` 同时拥有右端和左端操作。`appendleft()` 在头部添加元素，`popleft()` 从头部弹出元素——两者都是 O(1)。

**用 deque 实现栈**

```python
# deque 实现栈：用 append + pop（和 list 一样的末尾操作）
stack = deque()
stack.append("A")
stack.append("B")
stack.append("C")
print(f"入栈后: {list(stack)}")
print(f"出栈: {stack.pop()} → {list(stack)}")
print(f"出栈: {stack.pop()} → {list(stack)}")
```

运行结果：

```text
入栈后: ['A', 'B', 'C']
出栈: C → ['A', 'B']
出栈: B → ['A']
```

用 `deque` 实现栈和用 `list` 完全一样——`append()` 入栈、`pop()` 出栈，都是末尾 O(1) 操作。

**用 deque 实现队列**

```python
# deque 实现队列：用 append + popleft（头部 O(1) 出队）
queue = deque()
queue.append("任务1")
queue.append("任务2")
queue.append("任务3")
print(f"入队后: {list(queue)}")
print(f"出队: {queue.popleft()} → {list(queue)}")
print(f"出队: {queue.popleft()} → {list(queue)}")
```

运行结果：

```text
入队后: ['任务1', '任务2', '任务3']
出队: 任务1 → ['任务2', '任务3']
出队: 任务2 → ['任务3']
```

用 `deque` 实现队列用 `append()` 入队、`popleft()` 出队——和 `list` 的 `append()` + `pop(0)` 写法对应，但 `popleft()` 是 O(1) 而 `pop(0)` 是 O(n)。

**maxlen 限制长度**

```python
# maxlen=3 的 deque，满后自动丢弃最老的元素
limited = deque(maxlen=3)
for i in range(5):
    limited.append(i)
    print(f"  append({i}) → {list(limited)}")
```

运行结果：

```text
  append(0) → [0]
  append(1) → [0, 1]
  append(2) → [0, 1, 2]
  append(3) → [1, 2, 3]
  append(4) → [2, 3, 4]
```

`deque(maxlen=n)` 会自动限制队列长度——当队列已满时再添加元素，最老的元素（队首）会被自动丢弃。这在滑动窗口、限制历史记录等场景中非常有用。

**rotate 旋转**

```python
d = deque([1, 2, 3, 4, 5])
print(f"初始: {list(d)}")

d.rotate(2)    # 右转2位
print(f"rotate(2): {list(d)}")

d.rotate(-1)   # 左转1位
print(f"rotate(-1): {list(d)}")
```

运行结果：

```text
初始: [1, 2, 3, 4, 5]
rotate(2): [4, 5, 1, 2, 3]
rotate(-1): [5, 1, 2, 3, 4]
```

`rotate(n)` 把 deque 中的元素向右转 n 位（n>0 右转，n<0 左转）。这比手动切片和拼接高效得多。

### 2.4 栈的实际应用

栈的"后进先出"特性使它在很多场景中是天然的选择——括号匹配、撤销重做、表达式求值、函数调用栈等。

**应用1：括号匹配检测**

括号匹配是栈的经典应用：遍历字符串，遇到左括号入栈，遇到右括号与栈顶匹配。如果栈为空说明匹配成功。

```python
def is_balanced(expr):
    """检测括号是否匹配（支持 () [] {}）"""
    stack = []
    pairs = {")": "(", "]": "[", "}": "{"}

    for char in expr:
        if char in "([{":
            stack.append(char)
        elif char in ")]}":
            if not stack:
                return False  # 右括号多了
            top = stack.pop()
            if top != pairs[char]:
                return False  # 括号不匹配

    return len(stack) == 0  # 栈空=匹配成功


tests = ["()", "()[]{}", "({[]})", "([)]", "((()))", "((())", "a(b[c]{d})e"]
for expr in tests:
    print(f"  '{expr}' → {is_balanced(expr)}")
```

运行结果：

```text
  '()' → True
  '()[]{}' → True
  '({[]})' → True
  '([)]' → False
  '((()))' → True
  '((())' → False
  'a(b[c]{d})e' → True
```

算法的核心是：左括号入栈，右括号出栈匹配。最后栈为空说明所有括号都匹配成功。

**应用2：撤销/重做（双栈实现）**

用两个栈实现撤销和重做：`undo_stack` 记录操作历史，`redo_stack` 记录被撤销的操作。

```python
class TextEditor:
    """文本编辑器：支持撤销和重做"""

    def __init__(self):
        self.undo_stack = []
        self.redo_stack = []
        self.text = ""

    def type_text(self, text):
        self.undo_stack.append(("type", text, len(self.text)))
        self.text += text
        self.redo_stack.clear()
        print(f"  输入 '{text}' → '{self.text}'")

    def delete(self, n):
        deleted = self.text[-n:] if n > 0 else ""
        self.undo_stack.append(("delete", deleted, len(self.text) - n))
        self.text = self.text[:-n]
        self.redo_stack.clear()
        print(f"  删除{n}字符 → '{self.text}'")

    def undo(self):
        if not self.undo_stack:
            print("  无可撤销")
            return
        op, data, pos = self.undo_stack.pop()
        if op == "type":
            self.redo_stack.append(("type", data, pos))
            self.text = self.text[:pos]
        elif op == "delete":
            self.redo_stack.append(("delete", data, pos))
            self.text = self.text[:pos] + data
        print(f"  撤销 → '{self.text}'")

    def redo(self):
        if not self.redo_stack:
            print("  无可重做")
            return
        op, data, pos = self.redo_stack.pop()
        if op == "type":
            self.undo_stack.append(("type", data, pos))
            self.text = self.text[:pos] + data
        elif op == "delete":
            self.undo_stack.append(("delete", data, pos))
            self.text = self.text[:pos]
        print(f"  重做 → '{self.text}'")


editor = TextEditor()
editor.type_text("Hello")
editor.type_text(" World")
editor.delete(6)
editor.undo()
editor.undo()
editor.undo()
editor.redo()
editor.redo()
editor.type_text("!")
```

运行结果：

```text
  输入 'Hello' → 'Hello'
  输入 ' World' → 'Hello World'
  删除6字符 → 'Hello'
  撤销 → 'Hello World'
  撤销 → 'Hello'
  撤销 → ''
  重做 → 'Hello'
  重做 → 'Hello World'
  输入 '!' → 'Hello World!'
```

撤销/重做的核心是双栈协作：新操作压入 `undo_stack`，撤销时从 `undo_stack` 弹出到 `redo_stack`，重做时反向操作。新操作会清空 `redo_stack`——因为撤销后的新操作使得旧的"重做"路径不再有效。

**应用3：后缀表达式求值**

后缀表达式（逆波兰表示法）不需要括号，用栈即可完成计算。遍历表达式：数字入栈，运算符弹出两个操作数计算后结果入栈。

```python
def eval_postfix(expr):
    """计算后缀表达式"""
    stack = []
    ops = {
        "+": lambda a, b: a + b,
        "-": lambda a, b: a - b,
        "*": lambda a, b: a * b,
        "/": lambda a, b: a / b,
    }
    for token in expr.split():
        if token in ops:
            b = stack.pop()
            a = stack.pop()
            result = ops[token](a, b)
            stack.append(result)
            print(f"  {a} {token} {b} = {result}")
        else:
            stack.append(int(token))
    return stack.pop()


print(f"  '3 4 + 5 *' → {eval_postfix('3 4 + 5 *')}")
print()
print(f"  '5 1 2 + 4 * + 3 -' → {eval_postfix('5 1 2 + 4 * + 3 -')}")
```

运行结果：

```text
  3 + 4 = 7
  7 * 5 = 35
  '3 4 + 5 *' → 35

  1 + 2 = 3
  3 * 4 = 12
  5 + 12 = 17
  17 - 3 = 14
  '5 1 2 + 4 * + 3 -' → 14
```

后缀表达式的求值过程完美利用了栈：遇到数字压入栈，遇到运算符从栈中弹出两个数字计算，结果再压入栈。最终栈中只剩一个数字就是结果。

### 2.5 队列的实际应用

队列的"先进先出"特性使它适用于任务调度、广度优先搜索、消息传递等场景。

**应用1：任务调度**

```python
from collections import deque

task_queue = deque()

# 添加任务
for task in ["数据备份", "发送邮件", "清理缓存", "生成报表"]:
    task_queue.append(task)
    print(f"  添加任务: {task}")

print("  --- 执行任务 ---")
served = 0
while task_queue:
    current = task_queue.popleft()
    served += 1
    print(f"  [{served}] 执行: {current}")
    if task_queue:
        print(f"      下一个: {task_queue[0]}")

print(f"  共完成 {served} 个任务")
```

**应用2：广度优先搜索（BFS）**

BFS 是图遍历的基础算法，用队列实现：从起点出发，把邻居加入队列，每次从队首取节点访问。

```python
graph = {
    "A": ["B", "C"],
    "B": ["A", "D", "E"],
    "C": ["A", "F"],
    "D": ["B"],
    "E": ["B", "F"],
    "F": ["C", "E"],
}


def bfs(graph, start):
    """广度优先搜索"""
    visited = set()
    queue = deque([start])
    visited.add(start)
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return order


result = bfs(graph, "A")
print(f"  BFS 遍历顺序: {' → '.join(result)}")
```

运行结果：

```text
  BFS 遍历顺序: A → B → C → D → E → F
```

BFS 的核心是队列——从起点出发，把邻居加入队尾，从队首取节点。这保证了"同一层级的节点先被访问完，再访问下一层"。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

| 场景 | 推荐写法 | 不推荐写法 | 原因 |
|------|---------|-----------|------|
| 实现栈 | `lst.append()` + `lst.pop()` | `lst.insert(0,x)` + `lst.pop(0)` | 栈用末尾操作 O(1) |
| 实现队列 | `deque.append()` + `dq.popleft()` | `lst.append()` + `lst.pop(0)` | deque 头部 O(1) vs list 头部 O(n) |
| 头部频繁操作 | `deque.appendleft()` / `popleft()` | `lst.insert(0,x)` / `pop(0)` | deque O(1) vs list O(n) |
| 限制队列长度 | `deque(maxlen=n)` | 手动 `if len(lst)>n: lst.pop(0)` | deque 自动丢弃 |
| 随机访问 | `lst[i]` | `dq[i]` | list O(1) vs deque O(n) |
| 切片操作 | `lst[a:b]` | 先 `list(dq)[a:b]` | list 原生支持切片 |
| 旋转元素 | `dq.rotate(n)` | `lst = lst[-n:] + lst[:-n]` | rotate 原地操作 |
| 判断空栈/队列 | `if not stack:` | `if len(stack) == 0:` | 真值判断最 Pythonic |
| 安全出栈 | `if stack: stack.pop()` | `try/except` | 先检查更清晰 |

### 3.2 常见错误模式

**错误一：用 list.pop(0) 实现队列**

```python
# 不推荐：pop(0) 是 O(n)，大数据量时极慢
queue = []
for i in range(100000):
    queue.append(i)
while queue:
    queue.pop(0)  # 每次都要移动所有元素

# 推荐：用 deque.popleft()，O(1) 操作
from collections import deque
queue = deque()
for i in range(100000):
    queue.append(i)
while queue:
    queue.popleft()  # 高效
```

`pop(0)` 每次删除第一个元素后，后面所有元素要前移一位，10 万元素的循环总时间 O(n^2)。`popleft()` 是 O(1)，总时间 O(n)。

**错误二：混淆栈和队列的出队方向**

```python
# 错误理解：以为 pop() 是队列出队
queue = []
queue.append("A")
queue.append("B")
print(queue.pop())  # B ← 这是栈的出栈（LIFO），不是队列！

# 正确：队列用 pop(0) 或 deque.popleft()
print(queue.pop(0))  # A ← 这才是队列的出队（FIFO）
```

`pop()` 默认弹出末尾元素——这是栈的行为（后进先出）。队列需要从头部弹出，要用 `pop(0)` 或 `popleft()`。

**错误三：对空栈/队列弹出**

```python
stack = []
try:
    stack.pop()
except IndexError as e:
    print(f"空栈 pop → {e}")

# 安全做法
if stack:
    print(stack.pop())
else:
    print("栈为空")
```

运行结果：

```text
空栈 pop → pop from empty list
栈为空
```

对空列表 `pop()` 会抛出 `IndexError`。安全做法是先检查列表是否非空，或用 `try/except` 捕获。

**错误四：用 deque 做需要随机访问的场景**

```python
from collections import deque

# 不推荐：需要频繁随机访问时用 deque
dq = deque(range(100000))
# dq[50000] 是 O(n) 操作！deque 不是连续数组

# 推荐：需要随机访问时用 list
lst = list(range(100000))
# lst[50000] 是 O(1) 操作
```

`deque` 的索引访问 `dq[i]` 是 O(n) 操作——它需要从头或尾遍历到第 i 个位置。如果需要频繁随机访问，用 `list` 更高效。

### 3.3 方法速查表

| 操作 | list 写法 | deque 写法 | list 复杂度 | deque 复杂度 |
|------|----------|-----------|------------|-------------|
| 添加末尾 | `lst.append(x)` | `dq.append(x)` | O(1) | O(1) |
| 弹出末尾 | `lst.pop()` | `dq.pop()` | O(1) | O(1) |
| 添加头部 | `lst.insert(0, x)` | `dq.appendleft(x)` | O(n) | O(1) |
| 弹出头部 | `lst.pop(0)` | `dq.popleft()` | O(n) | O(1) |
| 查看末尾 | `lst[-1]` | `dq[-1]` | O(1) | O(1) |
| 查看头部 | `lst[0]` | `dq[0]` | O(1) | O(1) |
| 随机访问 | `lst[i]` | `dq[i]` | O(1) | O(n) |
| 切片 | `lst[a:b]` | 不支持 | O(k) | - |
| 长度 | `len(lst)` | `len(dq)` | O(1) | O(1) |
| 容量限制 | 手动管理 | `deque(maxlen=n)` | - | O(1) |
| 旋转 | 手动切片拼接 | `dq.rotate(n)` | O(n) | O(k) |

### 3.5 如何选择

| 场景 | 选择 | 原因 |
|------|------|------|
| 只做栈（末尾操作） | `list` 或 `deque` | 都是 O(1)，list 更直观 |
| 做队列（需头部操作） | `deque` | popleft O(1) vs pop(0) O(n) |
| 两端都要操作 | `deque` | appendleft/popleft 都是 O(1) |
| 需要随机访问 / 切片 | `list` | list[i] O(1)，支持切片 |
| 需要限制容量 | `deque(maxlen=n)` | 自动丢弃老元素 |
| 需要旋转元素 | `deque.rotate()` | 原地旋转，高效 |
| 中间频繁插入删除 | 都不行 | 考虑 `bisect` 或链表 |

简单规则：**只用末尾操作 → list 够了；需要操作头部 → 用 deque。**

## 4. 原理

### 4.1 list 与 deque 的底层结构差异

`list` 和 `deque` 的性能差异源于底层结构不同——`list` 是动态数组，`deque` 是链块。

```text
list 的内存结构（动态数组）：

  索引:    0     1     2     3     4
         ┌─────┬─────┬─────┬─────┬─────┐
  内存:  │  A  │  B  │  C  │  D  │  E  │  ← 连续存储
         └─────┴─────┴─────┴─────┴─────┘

  append(x) → 末尾空位写入 → O(1)
  pop()     → 末尾删除    → O(1)
  pop(0)    → 删除A，B~E全部前移 → O(n)  ← 性能瓶颈
  lst[i]    → 偏移量计算   → O(1)  ← 数组随机访问优势


deque 的内存结构（双向链块）：

  ┌──────┐     ┌──────┐     ┌──────┐
  │ 块1  │ ←→  │ 块2  │ ←→  │ 块3  │
  │[A,B,C]     │[D,E,F]     │[G,H,I]
  └──────┘     └──────┘     └──────┘
   ↑                           ↑
  popleft()                  append/pop()

  append(x)    → 末尾块写入   → O(1)
  pop()        → 末尾块删除   → O(1)
  appendleft(x) → 头部块写入  → O(1)  ← 不需要移动元素
  popleft()   → 头部块删除   → O(1)  ← 不需要移动元素
  dq[i]       → 遍历到第i个  → O(n)  ← 无法直接计算偏移
```

`list` 的连续数组结构使索引访问 `lst[i]` 可以直接通过内存偏移量计算，O(1) 就能取到。但 `pop(0)` 删除第一个元素后需要把后面所有元素前移——这是 O(n) 操作。

`deque` 的链块结构使两端操作不需要移动元素——`appendleft` 和 `popleft` 只需要修改头部指针，O(1) 完成。但索引访问 `dq[i]` 需要从头或尾遍历到第 i 个位置——这是 O(n) 操作。

### 4.2 为什么 list.pop(0) 是 O(n)

`list` 在 CPython 底层是一个 PyObject 指针数组。当 `pop(0)` 删除第一个元素时：

```text
list.pop(0) 的执行过程：

  原始列表: [A, B, C, D, E]
             0  1  2  3  4

  第1步: 取出 lst[0] = A（要返回的值）
  第2步: 把后面的所有指针前移一位:
         lst[0] ← lst[1]  (B 移到索引0)
         lst[1] ← lst[2]  (C 移到索引1)
         lst[2] ← lst[3]  (D 移到索引2)
         lst[3] ← lst[4]  (E 移到索引3)
  第3步: 长度减1: lst = [B, C, D, E]
  第4步: 返回 A

  移动次数: n-1 = O(n)
```

可以用代码验证 `pop(0)` 的时间与列表长度成正比：

```python
import time

for n in [10000, 50000, 100000]:
    lst = list(range(n))
    start = time.perf_counter()
    for _ in range(n):
        lst.pop(0)
    elapsed = time.perf_counter() - start
    print(f"  n={n:>6}, pop(0) x{n}: {elapsed:.4f} 秒")
```

运行结果：

```text
  n= 10000, pop(0) x10000: 0.0065 秒
  n= 50000, pop(0) x50000: 0.1711 秒    ← 5倍数据, 约26倍时间
  n=100000, pop(0) x100000: 0.6814 秒   ← 10倍数据, 约105倍时间
```

数据量增加 10 倍，时间增加约 105 倍——这符合 O(n^2) 的特征（每次 `pop(0)` 是 O(n)，循环 n 次总计 O(n^2)）。

### 4.3 deque 的 O(1) 头部操作原理

`deque` 底层是一个双向链块结构——多个固定大小的数组块通过前后指针连接。`popleft()` 只需要在头部块中移除一个元素，不需要移动其他块的内容：

```text
deque.popleft() 的执行过程：

  原始 deque:
    块1[A,B,C] ←→ 块2[D,E,F] ←→ 块3[G,H,I]
    ↑
    popleft() 从这里弹出

  第1步: 取出块1的第一个元素 A
  第2步: 块1的起始指针后移一位
         块1[B,C] ←→ 块2[D,E,F] ←→ 块3[G,H,I]
  第3步: 如果块1空了，释放块1，更新头指针
         块2[D,E,F] ←→ 块3[G,H,I]
  第4步: 返回 A

  移动次数: 0（只改指针，不移动元素）
  时间复杂度: O(1)
```

对比验证：

```python
from collections import deque
import time

for n in [10000, 50000, 100000]:
    dq = deque(range(n))
    start = time.perf_counter()
    for _ in range(n):
        dq.popleft()
    elapsed = time.perf_counter() - start
    print(f"  n={n:>6}, popleft() x{n}: {elapsed:.4f} 秒")
```

运行结果：

```text
  n= 10000, popleft() x10000: 0.0006 秒
  n= 50000, popleft() x50000: 0.0030 秒    ← 5倍数据, 约5倍时间
  n=100000, popleft() x100000: 0.0059 秒   ← 10倍数据, 约10倍时间
```

数据量增加 10 倍，时间也增加约 10 倍——这是 O(n) 的特征（每次 `popleft()` 是 O(1)，循环 n 次总计 O(n)）。

### 4.4 函数调用栈

Python 的函数调用也使用栈——每调用一个函数就创建一个栈帧（frame）压入调用栈，函数返回时弹出。这就是为什么递归过深会报 `RecursionError`——调用栈溢出了。

```python
def factorial(n):
    print(f"  调用 factorial({n})")
    if n <= 1:
        print(f"  返回 1")
        return 1
    result = n * factorial(n - 1)
    print(f"  返回 {n} * factorial({n-1}) = {result}")
    return result


print(f"factorial(5) = {factorial(5)}")
```

运行结果：

```text
  调用 factorial(5)
  调用 factorial(4)
  调用 factorial(3)
  调用 factorial(2)
  调用 factorial(1)
  返回 1
  返回 2 * factorial(1) = 2
  返回 3 * factorial(2) = 6
  返回 4 * factorial(3) = 24
  返回 5 * factorial(4) = 120
factorial(5) = 120
```

```text
函数调用栈的状态变化：

  factorial(5) 压入栈 →
  factorial(4) 压入栈 →
  factorial(3) 压入栈 →
  factorial(2) 压入栈 →
  factorial(1) 压入栈 →

  栈: [f(5), f(4), f(3), f(2), f(1)]
                                         ↑ 栈顶

  factorial(1) 返回弹栈 → 1
  factorial(2) 返回弹栈 → 2
  factorial(3) 返回弹栈 → 6
  factorial(4) 返回弹栈 → 24
  factorial(5) 返回弹栈 → 120

  栈空，递归结束
```

递归的本质就是栈——"递"（递进）是压栈，"归"（回归）是弹栈。理解这一点就能理解为什么递归可以等价地用循环+栈来改写。

## 5. 总结

本文围绕列表与栈和队列展开，系统介绍了以下内容：

- **用列表实现栈**：`append()` 入栈 + `pop()` 出栈，都是末尾 O(1) 操作；栈是后进先出（LIFO），适合浏览器后退、函数调用栈等场景
- **用列表实现队列**：`append()` 入队 + `pop(0)` 出队；队列是先进先出（FIFO），但 `pop(0)` 是 O(n) 操作，不适合大数据量
- **collections.deque 双端队列**：两端操作都是 O(1)，`appendleft()` / `popleft()` 高效替代 `insert(0)` / `pop(0)`；支持 `maxlen` 限制长度、`rotate()` 旋转
- **栈的实际应用**：括号匹配（左括号入栈、右括号匹配栈顶）、撤销/重做（双栈实现）、后缀表达式求值（数字入栈、运算符弹出计算）、函数调用栈
- **队列的实际应用**：任务调度（FIFO 处理任务）、广度优先搜索 BFS（队列保证按层遍历）、生产者-消费者模式（`maxlen` 限制容量）
- **最佳实践**：推荐 vs 不推荐写法对比、4 种常见错误模式（`pop(0)` 性能陷阱、栈/队列方向混淆、空栈弹出、deque 随机访问性能差）、方法速查表、list vs deque 性能对比（队列操作 deque 快 116 倍）、选择指南
