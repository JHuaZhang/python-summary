# Counter 计数字典

## 1. 介绍

### 1.1 什么是 Counter

`Counter` 是 Python 标准库 `collections` 模块提供的一个字典子类，专门用于**计数**——统计可迭代对象中各元素出现的次数。

普通字典的值可以是任意类型，而 `Counter` 的值语义上就是"这个键出现了几次"。正因为语义如此明确，`Counter` 在此基础上提供了一整套与计数相关的便捷方法，比如取出现次数最多的元素、按计数重复展开元素、多个 Counter 之间的数学运算等。

如果把普通字典比作一个"键值对存储器"，那 `Counter` 就是一个"自动帮你数数的字典"——你把一堆数据丢进去，它自动帮你统计好每个元素出现了几次，还附带排序、筛选、合并等计数场景常用的操作。

`Counter` 在 Python 知识体系中的定位：

```text
Python 内置类型
└── dict（字典）
    └── collections 模块
        ├── OrderedDict（有序字典）
        ├── defaultdict（默认值字典）
        └── Counter（计数字典）  ← 本篇主题
```

### 1.2 解决什么问题

在没有 `Counter` 之前，统计一个序列中各元素的出现次数，你需要手写一个循环：

```python
words = ["apple", "banana", "apple", "cherry", "banana", "apple"]
freq = {}
for word in words:
    if word in freq:
        freq[word] += 1
    else:
        freq[word] = 1
print(freq)
```

**运行结果**：

```text
{'apple': 3, 'banana': 2, 'cherry': 1}
```

这段代码虽然不长，但每次都写一遍很烦琐，而且如果还要做"取出现最多的前 3 个""把两个统计结果合并"这类操作，代码会更长。

使用 `Counter` 只需要一行：

```python
from collections import Counter

words = ["apple", "banana", "apple", "cherry", "banana", "apple"]
freq = Counter(words)
print(freq)
```

**运行结果**：

```text
Counter({'apple': 3, 'banana': 2, 'cherry': 1})
```

### 1.3 最简示例

`Counter` 的最简用法——统计字符串中每个字符出现的次数：

```python
from collections import Counter

# 统计每个字符出现了几次
result = Counter("hello")
print(result)
```

**运行结果**：

```text
Counter({'l': 2, 'h': 1, 'e': 1, 'o': 1})
```

`Counter` 对象的 `repr` 输出格式是 `Counter({...})`，看起来像一个字典，但按计数从高到低排列。

## 2. 核心内容

### 2.1 创建 Counter 的多种方式

`Counter` 的构造函数签名如下：

```text
Counter(iterable=None, /, **kwds)
```

它支持从可迭代对象、映射对象（如字典）或关键字参数创建，也可以不传参数创建一个空的 `Counter`。

#### 2.1.1 从列表创建

最常见的用法——统计一个列表中各元素的出现次数：

```python
from collections import Counter

fruits = ["apple", "banana", "apple", "cherry", "banana", "apple"]
fruit_counter = Counter(fruits)
print(fruit_counter)
```

**运行结果**：

```text
Counter({'apple': 3, 'banana': 2, 'cherry': 1})
```

`Counter` 会遍历列表中的每个元素，统计出现次数。输出结果按计数从高到低排列，计数相同的元素按首次出现的顺序排列。

#### 2.1.2 从字符串创建

字符串本身也是可迭代对象（逐字符迭代），因此可以直接传给 `Counter` 来做字符频率统计：

```python
from collections import Counter

char_counter = Counter("hello world")
print(char_counter)
```

**运行结果**：

```text
Counter({'l': 3, 'o': 2, 'h': 1, 'e': 1, ' ': 1, 'w': 1, 'r': 1, 'd': 1})
```

字符 `l` 出现 3 次最多，`o` 出现 2 次其次，其余各 1 次。注意空格 `' '` 也被统计了。

#### 2.1.3 从字典创建

如果你已经有一个 `{元素: 计数}` 的字典，可以直接传给 `Counter`：

```python
from collections import Counter

scores = {"Alice": 90, "Bob": 85, "Carol": 95}
score_counter = Counter(scores)
print(score_counter)
```

**运行结果**：

```text
Counter({'Carol': 95, 'Alice': 90, 'Bob': 85})
```

**关键点**：`Counter` 会根据值的大小重新排序。传入时字典是 `Alice` 在前，但 `Counter` 内部按值降序排列，`Carol` 的 95 最高的排在最前。

#### 2.1.4 从关键字参数创建

用 `key=value` 的方式快速创建，适合手动构造少量计数数据：

```python
from collections import Counter

manual_counter = Counter(a=3, b=2, c=1)
print(manual_counter)
```

**运行结果**：

```text
Counter({'a': 3, 'b': 2, 'c': 1})
```

#### 2.1.5 创建空 Counter 后逐步累加

`Counter` 也可以像普通字典一样先创建空对象，再逐步添加：

```python
from collections import Counter

empty = Counter()
for word in ["one", "two", "one", "three", "one"]:
    empty[word] += 1
print(empty)
```

**运行结果**：

```text
Counter({'one': 3, 'two': 1, 'three': 1})
```

**关键点**：这段代码之所以能正常运行，是因为 `Counter` 访问不存在的键时返回 `0` 而不是报 `KeyError`。第一次访问 `empty["one"]` 时，`"one"` 不存在，返回 `0`，加上 `1` 后赋值为 `1`，后续正常累加。

#### 2.1.6 计数可以是零或负数

与普通字典的值不同，`Counter` 的计数可以为零甚至负数——虽然从"计数"的语义上看不太常见，但在数学运算（如减法）时会出现：

```python
from collections import Counter

zero_counter = Counter(a=0, b=-1)
print(zero_counter)
```

**运行结果**：

```text
Counter({'a': 0, 'b': -1})
```

后续会讲到，`most_common`、`elements` 等方法会自动处理零和负数的情况。

### 2.2 访问计数

#### 2.2.1 方括号访问

`Counter` 是 `dict` 的子类，访问方式和普通字典一样——用方括号 `[]` 加键名：

```python
from collections import Counter

counter = Counter("abracadabra")
print(counter["a"])
print(counter["b"])
```

**运行结果**：

```text
5
2
```

#### 2.2.2 缺失键返回 0

这是 `Counter` 最实用的设计之一——访问不存在的键时，返回 `0` 而不是抛出 `KeyError`：

```python
from collections import Counter

counter = Counter("abracadabra")
print(counter["z"])
```

**运行结果**：

```text
0
```

`Counter` 重写了 `__missing__` 方法来实现这个行为。普通字典访问缺失键会报错：

```python
d = {"apple": 3}
# print(d["banana"])  # KeyError: 'banana'
```

**为什么返回 0 很合理**：从计数的语义来看，"不存在"和"出现了 0 次"是等价的。这个设计让你可以直接写 `counter[key] += 1` 而不用担心 `key` 是否存在，大幅简化了计数逻辑。

#### 2.2.3 get 方法

`Counter` 也继承了普通字典的 `get` 方法，行为与普通字典一致：

```python
from collections import Counter

counter = Counter(a=3, b=2)
print(counter.get("a"))
print(counter.get("c"))
print(counter.get("c", "不存在"))
```

**运行结果**：

```text
3
0
不存在
```

注意 `counter.get("c")` 返回 `None` 而不是 `0`（因为 `get` 方法不触发 `__missing__`），但 `counter.get("c", "不存在")` 传了默认值就用默认值。如果你需要 `0` 而非 `None`，直接用方括号访问即可。

#### 2.2.4 keys / values / items

这三个方法都继承自 `dict`，行为和普通字典一致：

```python
from collections import Counter

counter = Counter(a=3, b=2, c=1)
print("keys:", list(counter.keys()))
print("values:", list(counter.values()))
print("items:", list(counter.items()))
```

**运行结果**：

```text
keys: ['a', 'b', 'c']
values: [3, 2, 1]
items: [('a', 3), ('b', 2), ('c', 1)]
```

### 2.3 修改计数

#### 2.3.1 直接赋值

用方括号赋值会直接覆盖原有的计数：

```python
from collections import Counter

counter = Counter("abracadabra")
counter["a"] = 10
print(counter)
```

**运行结果**：

```text
Counter({'a': 10, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
```

#### 2.3.2 增量修改

用 `+=` 和 `-=` 做增量修改：

```python
from collections import Counter

counter = Counter("abracadabra")
counter["b"] += 1
counter["r"] -= 1
print(counter)
```

**运行结果**：

```text
Counter({'a': 5, 'b': 3, 'r': 1, 'c': 1, 'd': 1})
```

#### 2.3.3 update 方法——累加计数

`Counter` 的 `update` 方法与普通字典的 `update` 有一个关键区别：**普通字典是覆盖，Counter 是累加**。

```python
from collections import Counter

counter = Counter(a=2, b=1)
# 从可迭代对象累加
counter.update("aab")
print("update 后:", counter)

# 再从字典累加
counter.update({"a": 3, "c": 2})
print("再次 update 后:", counter)
```

**运行结果**：

```text
update 后: Counter({'a': 4, 'b': 2})
再次 update 后: Counter({'a': 7, 'b': 2, 'c': 2})
```

**关键点**：`update("aab")` 相当于统计 `"aab"` 中各字符的次数（a:2, b:1），然后累加到现有的 Counter 上。`a` 从 2 变成 4，`b` 从 1 变成 2。

#### 2.3.4 subtract 方法——减少计数

`subtract` 是 `update` 的逆操作，从当前计数中减去传入的计数：

```python
from collections import Counter

counter = Counter(a=5, b=3, c=2)

# 从可迭代对象减少
counter.subtract("aab")
print("subtract 后:", counter)

# 从字典减少
counter.subtract({"b": 2, "d": 1})
print("再次 subtract 后:", counter)
```

**运行结果**：

```text
subtract 后: Counter({'a': 3, 'b': 2, 'c': 2})
再次 subtract 后: Counter({'a': 3, 'c': 2, 'b': 0, 'd': -1})
```

**关键点**：`subtract` 不会删除计数变为零或负数的键（`b` 变为 0，`d` 变为 -1，它们仍然存在）。如果需要清除这些键，可以用数学运算的减法（`c1 - c2`），它会自动丢弃零和负数。

#### 2.3.5 del 删除键

用 `del` 可以完全删除一个键，让它从 `keys()` 中消失：

```python
from collections import Counter

counter = Counter(a=3, b=2, c=1)
del counter["c"]
print(counter)
print("c 的计数:", counter["c"])  # 返回 0
print("c 在 keys 中:", "c" in counter)  # 返回 False
```

**运行结果**：

```text
Counter({'a': 3, 'b': 2})
c 的计数: 0
c 在 keys 中: False
```

**关键点**：`del` 删除后，键不再存在于 `keys()` 中，但用方括号访问仍然返回 `0`（因为 `__missing__` 的机制）。这与"计数为 0 的键"不同——用 `Counter(a=0)` 创建的 `a` 存在于 `keys()` 中。

#### 2.3.6 clear 清空

```python
from collections import Counter

counter = Counter(a=3, b=2)
counter.clear()
print(counter)
```

**运行结果**：

```text
Counter()
```

### 2.4 most_common 方法

`most_common(n)` 是 `Counter` 最常用的方法之一，返回出现次数最多的 `n` 个元素。

#### 2.4.1 基本用法

```python
from collections import Counter

words = ["the", "quick", "brown", "fox", "the", "lazy", "dog", "the"]
word_counter = Counter(words)

print("Top 2:", word_counter.most_common(2))
print("Top 3:", word_counter.most_common(3))
```

**运行结果**：

```text
Top 2: [('the', 3), ('quick', 1)]
Top 3: [('the', 3), ('quick', 1), ('brown', 1)]
```

返回值是一个**列表**，每个元素是 `(键, 计数)` 元组，按计数从高到低排列。

#### 2.4.2 不传参数——返回全部排序

不传参数或传 `None`，返回所有元素按计数排序：

```python
from collections import Counter

counter = Counter(a=3, b=1, c=2)
print(counter.most_common())
```

**运行结果**：

```text
[('a', 3), ('c', 2), ('b', 1)]
```

#### 2.4.3 计数相同时的排序

当多个元素计数相同，`most_common` 会按它们在 Counter 中的存储顺序排列。Python 3.7+ 的 `Counter` 保留插入顺序（首次出现的顺序）：

```python
from collections import Counter

data = ["b", "a", "c", "b", "a", "c"]
c = Counter(data)
print(c.most_common())
```

**运行结果**：

```text
[('b', 2), ('a', 2), ('c', 2)]
```

三个元素计数都是 2，按首次出现顺序排列：`b` 最先出现在 `data` 中，所以排第一。

#### 2.4.4 取最高频元素的简写

`most_common(1)[0][0]` 可以直接拿到最高频元素：

```python
from collections import Counter

words = ["apple", "banana", "apple", "cherry", "apple"]
word_counter = Counter(words)

most_frequent = word_counter.most_common(1)[0][0]
print("最高频单词:", most_frequent)
```

**运行结果**：

```text
最高频单词: apple
```

#### 2.4.5 传 0 或负数

传 `0` 或负数时返回空列表：

```python
from collections import Counter

c = Counter(a=3, b=2)
print(c.most_common(0))   # 输出: []
print(c.most_common(-1))  # 输出: []
```

**运行结果**：

```text
[]
[]
```

#### 2.4.6 实际场景：词频统计

统计一段文本中的高频词，取 Top 5：

```python
from collections import Counter

sentence = """
Python is a great programming language Python is easy to learn
Python has a simple syntax Python is powerful Python is flexible
"""
word_list = sentence.lower().split()
freq = Counter(word_list)
print("Top 5 高频词:", freq.most_common(5))
```

**运行结果**：

```text
Top 5 高频词: [('python', 5), ('is', 4), ('a', 2), ('great', 1), ('programming', 1)]
```

#### 2.4.7 实际场景：DNA 碱基频率

统计 DNA 序列中各类碱基的出现频率：

```python
from collections import Counter

dna = "ATCGATCGATCGAAATTTCCCGGG"
base_freq = Counter(dna)
print("碱基频率:", base_freq.most_common())
```

**运行结果**：

```text
碱基频率: [('A', 7), ('C', 6), ('T', 5), ('G', 4)]
```

### 2.5 elements 方法

`elements()` 返回一个**迭代器**，按计数重复产生元素——计数为 3 的元素会出现 3 次。

#### 2.5.1 基本用法

```python
from collections import Counter

counter = Counter(a=3, b=2, c=1)
print(list(counter.elements()))
```

**运行结果**：

```text
['a', 'a', 'a', 'b', 'b', 'c']
```

元素按在 `Counter` 中的存储顺序连续重复，每个元素重复其计数次。

#### 2.5.2 返回的是迭代器

`elements()` 返回的不是列表，而是 `itertools.chain` 迭代器，内存效率高：

```python
from collections import Counter

counter = Counter(a=3, b=2)
e = counter.elements()
print(type(e))
```

**运行结果**：

```text
<class 'itertools.chain'>
```

如果你只需要遍历而不需要索引访问，可以直接用 `for` 循环，不必转成列表：

```python
from collections import Counter

for elem in Counter(a=2, b=3).elements():
    print(elem, end=" ")
```

**运行结果**：

```text
a a b b b
```

#### 2.5.3 自动跳过零和负数

`elements()` 自动跳过计数为零或负数的元素：

```python
from collections import Counter

counter = Counter(a=3, b=0, c=-1, d=2)
print(list(counter.elements()))
```

**运行结果**：

```text
['a', 'a', 'a', 'd', 'd']
```

`b` 计数为 0 和 `c` 计数为 -1 都被跳过了。

#### 2.5.4 实际场景：展开购物清单

每种商品要买的数量用 `Counter` 记录，用 `elements()` 展开成具体的商品列表：

```python
from collections import Counter

shopping = Counter({"milk": 2, "bread": 1, "eggs": 6, "apple": 3})
items = list(shopping.elements())
print("购物清单展开:", items)
```

**运行结果**：

```text
购物清单展开: ['milk', 'milk', 'bread', 'eggs', 'eggs', 'eggs', 'eggs', 'eggs', 'eggs', 'apple', 'apple', 'apple']
```

#### 2.5.5 配合 sorted 使用

`elements()` 的输出按存储顺序排列，如果你想按字母排序，可以配合 `sorted()`：

```python
from collections import Counter

counter = Counter("abracadabra")
print(sorted(counter.elements()))
```

**运行结果**：

```text
['a', 'a', 'a', 'a', 'a', 'b', 'b', 'c', 'd', 'r', 'r']
```

### 2.6 数学运算

`Counter` 支持五种数学运算：加法 `+`、减法 `-`、交集 `&`、并集 `|`、一元正号 `+` 和一元负号 `-`。

#### 2.6.1 加法（+）

两个 `Counter` 相加，相同键的计数相加，结果只保留计数为正的项：

```python
from collections import Counter

c1 = Counter(a=3, b=2, c=1)
c2 = Counter(a=1, b=3, d=4)
print("c1 + c2:", c1 + c2)
```

**运行结果**：

```text
c1 + c2: Counter({'b': 5, 'a': 4, 'd': 4, 'c': 1})
```

各键结果：`a: 3+1=4`，`b: 2+3=5`，`c: 1+0=1`，`d: 0+4=4`。

#### 2.6.2 减法（-）

两个 `Counter` 相减，相同键的计数相减，**丢弃结果为零或负数的项**：

```python
from collections import Counter

c3 = Counter(a=5, b=3, c=2)
c4 = Counter(a=2, b=3, d=1)
print("c3 - c4:", c3 - c4)
```

**运行结果**：

```text
c3 - c4: Counter({'a': 3, 'c': 2})
```

各键结果：`a: 5-2=3`，`b: 3-3=0`（被丢弃），`c: 2-0=2`，`d: 0-1=-1`（被丢弃）。

**关键点**：减法运算 `c3 - c4` 与 `subtract` 方法不同——`subtract` 会保留零和负数，而减法运算符会丢弃。

#### 2.6.3 交集（&）

交集运算 `&` 只保留两个 `Counter` 中都存在的键，计数取两者的**较小值**：

```python
from collections import Counter

c5 = Counter(a=4, b=2, c=1)
c6 = Counter(a=1, b=3, d=5)
print("c5 & c6:", c5 & c6)
```

**运行结果**：

```text
c5 & c6: Counter({'a': 1, 'b': 2})
```

`c` 只在 `c5` 中存在，`d` 只在 `c6` 中存在，都被丢弃。`a: min(4,1)=1`，`b: min(2,3)=2`。

#### 2.6.4 并集（|）

并集运算 `|` 合并所有键，计数取两者的**较大值**：

```python
from collections import Counter

c7 = Counter(a=4, b=2, c=1)
c8 = Counter(a=1, b=3, d=5)
print("c7 | c8:", c7 | c8)
```

**运行结果**：

```text
c7 | c8: Counter({'d': 5, 'a': 4, 'b': 3, 'c': 1})
```

`a: max(4,1)=4`，`b: max(2,3)=3`，`c: max(1,0)=1`，`d: max(0,5)=5`。

#### 2.6.5 一元运算（+ 和 -）

一元运算符作用于单个 `Counter`，用于筛选计数为正或为负的项：

```python
from collections import Counter

c9 = Counter(a=5, b=0, c=-2, d=3)
print("原始:", c9)
print("+c9 (正数项):", +c9)
print("-c9 (负数项):", -c9)
```

**运行结果**：

```text
原始: Counter({'a': 5, 'd': 3, 'b': 0, 'c': -2})
+c9 (正数项): Counter({'a': 5, 'd': 3})
-c9 (负数项): Counter({'c': 2})
```

- `+c9`：保留计数为正数的项（`a:5`，`d:3`），丢弃计数为 0 和负数的项。
- `-c9`：保留计数为负数的项，并将计数取绝对值变为正数（`c:2`）。注意原来 `c=-2`，结果变为 `c=2`。

#### 2.6.6 运算对比总结

| 运算 | 行为 | 丢弃零和负数 | 典型场景 |
|------|------|-------------|---------|
| `c1 + c2` | 计数相加 | 是 | 合并多个数据源的统计结果 |
| `c1 - c2` | 计数相减 | 是 | 查看两组数据的差异部分 |
| `c1 & c2` | 取计数较小值 | 是 | 两组数据共有的元素，各取最小出现次数 |
| `c1 \| c2` | 取计数较大值 | 是 | 合并两组数据，各取最大出现次数 |
| `+c` | 保留正数项 | 是 | 清除零和负数计数 |
| `-c` | 保留负数项（取绝对值） | 是 | 查看减少量，取绝对值 |
| `c.subtract(...)` | 计数相减 | 否（保留零和负数） | 在原对象上做减法，保留完整信息 |

#### 2.6.7 实际场景：多服务器日志合并

两台服务器的 HTTP 状态码统计，合并看总体趋势：

```python
from collections import Counter

server1 = Counter({200: 150, 404: 30, 500: 5})
server2 = Counter({200: 200, 404: 15, 500: 8})

total = server1 + server2
print("合并状态码统计:", total)
```

**运行结果**：

```text
合并状态码统计: Counter({200: 350, 404: 45, 500: 13})
```

### 2.7 Counter 与 dict 的关系

`Counter` 是 `dict` 的子类，拥有 `dict` 的所有方法，同时在此基础上扩展了计数相关的能力。

#### 2.7.1 类型关系

```python
from collections import Counter

c = Counter(a=3, b=2)
print("类型:", type(c))
print("是 dict 子类:", isinstance(c, dict))
```

**运行结果**：

```text
类型: <class 'collections.Counter'>
是 dict 子类: True
```

#### 2.7.2 缺失键行为对比

| 维度 | `dict` | `Counter` |
|------|--------|-----------|
| 访问不存在的键 | `KeyError` | 返回 `0` |
| 重写了 `__missing__` | 否 | 是 |

```python
from collections import Counter

# 普通字典
d = {"apple": 3}
# print(d["banana"])  # 抛出 KeyError

# Counter
c = Counter({"apple": 3})
print(c["banana"])  # 输出: 0，不报错
```

#### 2.7.3 update 行为对比

| 维度 | `dict.update()` | `Counter.update()` |
|------|----------------|-------------------|
| 行为 | 覆盖旧值 | 累加计数 |
| 传入已有键 | 新值替换旧值 | 新计数累加到旧计数上 |

```python
from collections import Counter

# 普通字典——覆盖
d = {"a": 1, "b": 2}
d.update({"a": 5, "c": 3})
print("dict update:", d)

# Counter——累加
c = Counter(a=1, b=2)
c.update({"a": 5, "c": 3})
print("Counter update:", c)
```

**运行结果**：

```text
dict update: {'a': 5, 'b': 2, 'c': 3}
Counter update: Counter({'a': 6, 'c': 3, 'b': 2})
```

`dict` 中 `a` 从 `1` 变为 `5`（覆盖），`Counter` 中 `a` 从 `1` 变为 `6`（`1+5`，累加）。

#### 2.7.4 Counter 独有的方法

| 方法/运算 | 说明 | `dict` 是否有 |
|----------|------|-------------|
| `most_common(n)` | 取计数最多的 n 个元素 | 无 |
| `elements()` | 按计数重复产生元素迭代器 | 无 |
| `subtract(iterable)` | 减少计数（保留零和负数） | 无 |
| `+` `&` `|` 运算 | 加法/交集/并集 | 无 |
| `+c` / `-c` 一元运算 | 筛选正数/负数项 | 无 |
| `total()` | 返回所有计数之和 | 无 |

#### 2.7.5 total 方法

`total()` 是 Python 3.10 引入的方法，返回所有计数的总和：

```python
from collections import Counter

c = Counter(a=3, b=2, c=1)
print("所有计数之和:", c.total())
```

**运行结果**：

```text
所有计数之和: 6
```

等价于 `sum(c.values())`，但更简洁直观。

如果你使用 Python 3.10 之前的版本，用 `sum(counter.values())` 替代即可。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

**统计元素出现次数——使用 Counter 而非手写循环**

推荐写法：

```python
from collections import Counter

data = ["apple", "banana", "apple", "cherry", "banana", "apple"]
freq = Counter(data)
print(freq)
```

**运行结果**：

```text
Counter({'apple': 3, 'banana': 2, 'cherry': 1})
```

不推荐写法：

```python
data = ["apple", "banana", "apple", "cherry", "banana", "apple"]
freq = {}
for item in data:
    if item in freq:
        freq[item] += 1
    else:
        freq[item] = 1
print(freq)
```

推荐写法更简洁、可读性更强，且 `Counter` 自带 `most_common`、`elements` 等方法，后续操作更方便。

**获取最高频元素——使用 most_common 而非手动排序**

推荐写法：

```python
from collections import Counter

data = ["a", "b", "a", "c", "a", "b"]
c = Counter(data)
top = c.most_common(1)
print(top)
```

**运行结果**：

```text
[('a', 3)]
```

不推荐写法：

```python
data = ["a", "b", "a", "c", "a", "b"]
freq = {}
for item in data:
    freq[item] = freq.get(item, 0) + 1
sorted_items = sorted(freq.items(), key=lambda x: x[1], reverse=True)
top = sorted_items[:1]
print(top)
```

**合并多个统计结果——使用加法运算而非手动循环**

推荐写法：

```python
from collections import Counter

batch1 = Counter(["a", "b", "a"])
batch2 = Counter(["a", "c", "b"])
combined = batch1 + batch2
print(combined)
```

**运行结果**：

```text
Counter({'a': 3, 'b': 2, 'c': 1})
```

不推荐写法：

```python
combined = {}
for source in [["a", "b", "a"], ["a", "c", "b"]]:
    for item in source:
        combined[item] = combined.get(item, 0) + 1
print(combined)
```

### 3.2 常见错误模式及修正

**错误一：把 Counter 当普通字典用，期望 update 是覆盖**

```python
from collections import Counter

c = Counter(a=3, b=2)
# 误以为这会把 a 设为 5
c.update({"a": 5})
print(c)  # a 变成了 8，不是 5
```

**运行结果**：

```text
Counter({'a': 8, 'b': 2})
```

修正——如果需要覆盖，直接赋值：

```python
c["a"] = 5
```

**错误二：用 subtract 后期望负数被删除**

```python
from collections import Counter

c = Counter(a=3, b=2)
c.subtract({"a": 5, "b": 2})
print(c)  # a=-2, b=0 仍然存在
```

**运行结果**：

```text
Counter({'a': -2, 'b': 0})
```

修正——如果需要丢弃零和负数，用减法运算符：

```python
result = Counter(a=3, b=2) - Counter(a=5, b=2)
print(result)  # 结果为空 Counter()
```

**运行结果**：

```text
Counter()
```

**错误三：在循环中频繁创建 Counter**

```python
from collections import Counter

# 不推荐：每次循环都创建新 Counter
for batch in data_batches:
    c = Counter(batch)  # 每次重新创建
    process(c)
```

推荐——复用同一个 Counter，用 update 累加：

```python
from collections import Counter

c = Counter()
for batch in data_batches:
    c.update(batch)  # 在原对象上累加
process(c)
```

### 3.3 可读性 / 性能 / 兼容性取舍

| 场景 | 推荐方式 | 原因 |
|------|---------|------|
| 需要统计元素出现次数 | `Counter(iterable)` | 一行代码完成统计，性能好 |
| 需要按计数排序 | `counter.most_common()` | 内部用堆优化，比手动排序快 |
| 需要合并多个统计 | `c1 + c2` | 运算符语义清晰，一行搞定 |
| 需要取共有的元素 | `c1 & c2` | 交集语义直观 |
| Python 3.10+ 需要总计数 | `counter.total()` | 3.10 引入的新方法，更简洁 |
| Python 3.9 及以下需要总计数 | `sum(counter.values())` | 兼容旧版本 |
| 只需要计数，不需要排序 | `Counter` 仍然推荐 | `most_common` 按需调用，不调不排序 |

**性能提示**：`most_common(n)` 在 `n` 远小于总元素数时，使用堆（`heapq`）来优化，时间复杂度为 `O(N log n)` 而非 `O(N log N)`。如果只是取前几个最高频元素，性能远好于全量排序。

## 4. 原理

### 4.1 Counter 的继承结构

`Counter` 继承自 `dict`，在 `dict` 的基础上重写了以下方法来实现计数语义：

```text
dict
 └── Counter (collections.Counter)
      ├── __missing__: 访问不存在的键返回 0
      ├── __repr__: 自定义输出格式为 Counter({...})
      ├── update: 改为累加而非覆盖
      ├── subtract: 新增方法，减少计数
      ├── most_common: 新增方法，取 Top N
      ├── elements: 新增方法，按计数展开
      ├── total: 新增方法（3.10+），返回总计数
      ├── __add__/__sub__/__and__/__or__: 数学运算
      ├── __pos__/__neg__: 一元运算
      └── __eq__/__ne__/__le__/__lt__/...: 比较运算
```

### 4.2 __missing__ 机制

`Counter` 的核心设计是重写了 `__missing__` 方法。当访问一个不存在的键时，Python 字典的 `__getitem__` 方法会先查找键，找不到则调用 `__missing__`（如果定义了的话）。

`Counter.__missing__` 的实现逻辑非常简单：

```python
def __missing__(self, key):
    return 0
```

这就是为什么 `counter["不存在的键"]` 返回 `0` 而不是 `KeyError`。你可以用以下代码验证这个机制：

```python
from collections import Counter

c = Counter(a=3)
# 直接调用 __missing__
print(c.__missing__("z"))  # 输出: 0
# 正常访问也会触发 __missing__
print(c["z"])  # 输出: 0
```

**运行结果**：

```text
0
0
```

### 4.3 most_common 的内部实现

`Counter` 的 `most_common` 方法内部使用 `heapq.nlargest` 来优化性能。当只需要取前 `n` 个元素时，不需要对全部元素排序，而是维护一个大小为 `n` 的堆，时间复杂度从全排序的 `O(N log N)` 降为 `O(N log n)`。

```python
from collections import Counter
import heapq

# 模拟 most_common 的核心逻辑
counter = Counter(a=5, b=3, c=8, d=1, e=6)

# most_common(3) 的内部逻辑类似:
items = list(counter.items())
top3 = heapq.nlargest(3, items, key=lambda x: x[1])
print(top3)

# 对比直接排序
sorted_all = sorted(items, key=lambda x: x[1], reverse=True)
print(sorted_all)
```

**运行结果**：

```text
[('c', 8), ('e', 6), ('a', 5)]
[('c', 8), ('e', 6), ('a', 5), ('b', 3), ('d', 1)]
```

当 `n` 小于元素总数时，`nlargest` 的效率显著高于全量排序后又取前 `n` 个。

### 4.4 数学运算的实现原理

`Counter` 的数学运算（`+`、`-`、`&`、`|`）每次都返回一个**新的 `Counter` 对象**，不会修改原对象。

```python
from collections import Counter

c1 = Counter(a=3, b=2)
c2 = Counter(a=1, c=4)

result = c1 + c2
print("c1:", c1)      # 原对象不变
print("c2:", c2)      # 原对象不变
print("result:", result)  # 新对象
```

**运行结果**：

```text
c1: Counter({'a': 3, 'b': 2})
c2: Counter({'c': 4, 'a': 1})
result: Counter({'a': 4, 'c': 4, 'b': 2})
```

这与 `update`/`subtract` 方法不同——后两者是在原对象上做**就地修改**（in-place），而运算符返回新对象。

| 操作类型 | 示例 | 是否修改原对象 | 返回值 |
|---------|------|-------------|--------|
| 运算符 | `c1 + c2` | 否 | 新 Counter |
| `update` | `c1.update(c2)` | 是 | None |
| `subtract` | `c1.subtract(c2)` | 是 | None |

### 4.5 elements 返回迭代器的设计

`elements()` 返回迭代器而非列表，这是一个有意的内存优化设计。当计数很大时（比如某元素出现 100 万次），生成列表会消耗大量内存，而迭代器按需产生元素，内存占用恒定。

```python
from collections import Counter

# 假设某元素计数很大
c = Counter(a=1_000_000, b=500_000)

# 迭代器方式——内存恒定
for elem in c.elements():
    if elem == "b":
        break  # 提前终止，不消耗全部内存

# 列表方式——占用约 150 万个字符串引用的内存
# items_list = list(c.elements())  # 不推荐
```

## 5. 总结

本文围绕 `Counter` 计数字典展开，主要介绍了以下内容：

- `Counter` 是 `collections` 模块提供的字典子类，专为统计元素出现次数而设计
- 支持从列表、字符串、字典、关键字参数等多种方式创建，也可创建空对象后逐步累加
- 访问不存在的键返回 `0` 而非 `KeyError`，这得益于重写的 `__missing__` 方法，使计数场景下的增量操作无需提前判断键是否存在
- `update` 方法是累加而非覆盖，`subtract` 方法减少计数但保留零和负数项
- `most_common(n)` 返回出现次数最多的 n 个元素，内部用堆优化，适合取 Top N 场景
- `elements()` 返回按计数重复产生元素的迭代器，自动跳过零和负数，内存效率高
- 支持五种数学运算：加法（累加）、减法（相减并丢弃零负）、交集（取较小值）、并集（取较大值）、一元正负号（筛选正负项），运算符返回新对象而非就地修改
- `Counter` 与普通 `dict` 的三大核心区别：缺失键返回 0、update 是累加、多了一套计数专用的方法和运算
- Python 3.10+ 新增 `total()` 方法返回所有计数之和，等价于 `sum(counter.values())`
- 推荐使用 `Counter` 替代手写计数循环，使用 `most_common` 替代手动排序，使用运算符替代手动合并统计结果
