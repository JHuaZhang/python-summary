# 集合的创建方式

> 本篇属于 Python 数据类型体系中"集合类型"的实操方法篇，聚焦「如何创建一个集合」这一核心问题，覆盖 `set` 和 `frozenset` 两大类型的所有创建途径——字面量、构造函数、推导式，以及空集合陷阱、混合类型、可哈希性等进阶话题。

## 1. 介绍

### 1.1 什么是集合

集合（Set）是 Python 内置的四大数据类型之一，与列表、元组、字典并列。它的两个核心特征是：

- **元素无序**：集合中的元素没有先后顺序，不能用索引访问。
- **元素唯一**：集合中的元素不会重复，相同值只保留一份（去重）。

这两个特征直接决定了集合的典型用途——去重和快速查找。当你有一批数据需要"去掉重复项"或者"判断某个值是否在里面"时，集合比列表高效得多。列表的 `in` 操作是 O(n) 线性查找，而集合的 `in` 操作基于哈希表，是 O(1) 常数时间查找——数据量越大，差距越明显。

Python 提供了两种集合类型：

| 类型 | 可变性 | 说明 |
|------|--------|------|
| `set` | 可变 | 创建后可以增删元素，最常用的集合类型 |
| `frozenset` | 不可变 | 创建后不可修改，可作为字典键或嵌套在其他集合中 |

一个最简单的集合创建示例：

```python
# 用花括号直接创建一个集合
fruits = {'apple', 'banana', 'cherry'}
print(fruits)
print(type(fruits))
```

运行结果：

```text
{'apple', 'banana', 'cherry'}
<class 'set'>
```

这就是一个可变集合。接下来你将看到，Python 提供了多种方式来创建集合，每一种都有自己的适用场景和注意事项。

---

## 2. 核心内容

### 2.1 使用花括号 {} 创建

最直观的创建方式就是用花括号 `{}` 把元素括起来，元素之间用逗号分隔。这种写法叫"字面量"创建，和列表的 `[]`、元组的 `()` 类似。

**基本语法**

```python
# 语法格式
# 集合名 = {元素1, 元素2, 元素3, ...}

# 创建水果集合
fruits = {'apple', 'banana', 'cherry'}
print("fruits =", fruits)

# 创建数字集合
numbers = {10, 20, 30, 40, 50}
print("numbers =", numbers)

# 创建字符串集合
letters = {'a', 'b', 'c', 'd'}
print("letters =", letters)
```

运行结果：

```text
fruits = {'apple', 'banana', 'cherry'}
numbers = {50, 20, 40, 10, 30}
letters = {'d', 'b', 'a', 'c'}
```

注意看输出——每次运行时，集合内元素的打印顺序可能不同。这是因为集合底层用的是哈希表，元素的存储位置由其哈希值决定，和写入顺序无关。

**自动去重**

花括号创建集合时，如果传入了重复的元素，集合只会保留一份：

```python
# 有重复元素的数据
scores = {85, 90, 85, 78, 90, 92, 78}
print("scores =", scores)  # 重复的 85、90、78 各只保留一份

# 字符串也去重
tags = {'python', 'java', 'python', 'go', 'java'}
print("tags =", tags)
```

运行结果：

```text
scores = {78, 85, 90, 92}
tags = {'java', 'go', 'python'}
```

**混合类型元素**

集合不要求所有元素类型一致，只要每个元素都是可哈希类型即可：

```python
# 整数、字符串、浮点数、布尔值混合
mixed = {42, 'hello', 3.14, True}
print("mixed =", mixed)
```

运行结果：

```text
mixed = {3.14, True, 42, 'hello'}
```

**特别注意：布尔值与整数的去重**

Python 中 `True == 1`，`False == 0`（布尔值是整数的子类）。当集合中同时存在 `True` 和 `1`（或 `False` 和 `0`）时，它们会被视为重复，只保留先出现的那一个：

```python
bool_and_int = {1, True, 0, False}
print("bool_and_int =", bool_and_int)  # 输出 {0, 1}，而非 {0, 1, True, False}
```

运行结果：

```text
bool_and_int = {0, 1}
```

这是因为哈希值相同：`hash(True) == hash(1)`，集合判定为"已存在"，后续的 `True` 和 `False` 被丢弃。先到先得——集合保留的是第一个出现的值（可能是 `1` 也可能是 `True`，取决于哈希碰撞后的冲突解决策略，从用户角度无需关心保留的是哪个，只需知道它们会被去重）。

**可哈希性要求**

花括号中的元素必须是**可哈希类型**（hashable）。通俗理解：不可变类型可哈希，可变类型不可哈希。

| 可哈希（可以放入集合） | 不可哈希（不能放入集合） |
|----------------------|------------------------|
| `int`、`float`、`complex` | `list` |
| `str` | `dict` |
| `tuple`（元组内的元素也需可哈希） | `set` |
| `frozenset` | `bytearray` |
| `bool` | 自定义可变对象 |

如果你尝试把列表放入集合，会直接报错：

```python
# 列表不可哈希，不能作为集合元素
try:
    invalid = {[1, 2], [3, 4]}
except TypeError as e:
    print(f"报错: {e}")
```

运行结果：

```text
报错: unhashable type: 'list'
```

但元组是可以的，因为元组是不可变的：

```python
# 元组作为集合元素
points = {(1, 2), (3, 4), (1, 2)}  # 重复的 (1,2) 被去重
print("points =", points)
```

运行结果：

```text
points = {(1, 2), (3, 4)}
```

### 2.2 使用 set() 函数创建

当数据已经存在于列表、元组、字符串等可迭代对象中时，用 `set()` 函数将它们转换为集合是最常用的方式。

**基本用法**

```python
# 从列表创建集合（最常见的去重场景）
letter_list = ['a', 'b', 'c', 'a', 'b']
letter_set = set(letter_list)
print("从列表创建:", letter_set)

# 从元组创建集合
number_tuple = (10, 20, 30, 10, 20)
number_set = set(number_tuple)
print("从元组创建:", number_set)
```

运行结果：

```text
从列表创建: {'b', 'c', 'a'}
从元组创建: {10, 20, 30}
```

`set()` 接受任何**可迭代对象**作为参数。可迭代对象是指能被 `for` 循环遍历的对象——列表、元组、字符串、字典、range、生成器等都是。

**从字符串创建**

字符串也是可迭代对象，`set()` 会把每个字符拆成独立的元素：

```python
text = "hello world"
char_set = set(text)
print("从字符串创建:", char_set)
```

运行结果：

```text
从字符串创建: {'d', 'o', 'h', ' ', 'l', 'w', 'r', 'e'}
```

注意空格也是一个元素——字符串中的每个字符（包括空格、标点）都会被拆分。这个特性可以用来统计一段文本中有哪些不同的字符。

**从 range 创建**

```python
range_set = set(range(5))
print("从 range(5) 创建:", range_set)
```

运行结果：

```text
从 range(5) 创建: {0, 1, 2, 3, 4}
```

**从字典创建**

字典也是可迭代对象，但 `set()` 默认取的是字典的**键**，而不是值或键值对：

```python
scores = {'Alice': 90, 'Bob': 85, 'Charlie': 78}

# 默认取键
keys_set = set(scores)
print("从字典创建（键）:", keys_set)

# 显式取值
values_set = set(scores.values())
print("从字典的值创建:", values_set)

# 显式取键值对（元组）
items_set = set(scores.items())
print("从字典的键值对创建:", items_set)
```

运行结果：

```text
从字典创建（键）: {'Alice', 'Charlie', 'Bob'}
从字典的值创建: {90, 85, 78}
从字典的键值对创建: {('Alice', 90), ('Charlie', 78), ('Bob', 85)}
```

这里第三个例子很有用——`scores.items()` 返回的是由 `(key, value)` 元组组成的可迭代对象，`set()` 把它们转换为由元组组成的集合。由于元组是可哈希的，可以作为集合元素。

**从生成器表达式创建**

```python
# 生成偶数的生成器表达式，转换为集合
gen = (x * 2 for x in range(5))
gen_set = set(gen)
print("从生成器创建:", gen_set)
```

运行结果：

```text
从生成器创建: {0, 2, 4, 6, 8}
```

生成器是"惰性求值"的——它不会一次性生成所有值，而是按需逐个产出。`set()` 会消费整个生成器，把所有产出的值收集进集合。

**从另一个集合创建（浅拷贝）**

```python
original = {1, 2, 3}
copy_set = set(original)
print("从集合创建副本:", copy_set)
print("是同一个对象吗?", original is copy_set)  # False
```

运行结果：

```text
从集合创建副本: {1, 2, 3}
是同一个对象吗? False
```

`set(已有的集合)` 会创建一个**新的集合对象**，内容相同但内存地址不同。这是一种浅拷贝方式。如果你需要修改其中一个而不影响另一个，用这种方式创建副本。

**set() 不传参数：创建空集合**

```python
empty = set()
print("空集合:", empty)
print("长度:", len(empty))
print("类型:", type(empty))
```

运行结果：

```text
空集合: set()
长度: 0
类型: <class 'set'>
```

`set()` 不传参数时返回一个空集合。这是创建空集合的**唯一正确方式**——上文提到过，`{}` 在 Python 中被字典占用了，所以空集合只能用 `set()` 创建。

### 2.3 创建空集合的陷阱

这是一个几乎所有 Python 初学者都会踩的坑：`{}` 创建的不是空集合，而是空字典。

**错误方式：{}**

```python
empty_braces = {}
print("type({}) =", type(empty_braces))  # dict，不是 set！
```

运行结果：

```text
type({}) = <class 'dict'>
```

原因很简单：在 Python 的语法设计中，`{}` 早就被字典占用了。字典的初始化用 `{}`，空字典也用 `{}`。当 Python 看到 `{}` 且其中没有任何内容时，它默认创建的是字典——因为字典比集合使用频率更高，且更早出现在语言设计中。

**正确方式：set()**

```python
empty_set = set()
print("type(set()) =", type(empty_set))  # set
```

运行结果：

```text
type(set()) = <class 'set'>
```

**对比汇总**

| 写法 | 实际类型 | 说明 |
|------|---------|------|
| `{}` | `dict` | 创建空字典 |
| `set()` | `set` | 创建空集合 |
| `{1, 2, 3}` | `set` | 有元素时花括号创建集合 |
| `{'a': 1}` | `dict` | 键值对格式创建字典 |
| `{1, 2, 3, 'a': 1}` | `TypeError` | 不能混用集合和字典语法 |

关键规则：花括号里**有元素但没有冒号** → 集合；花括号里**有冒号键值对** → 字典；**空的**花括号 → 字典。

**实际场景中的陷阱**

```python
# 想初始化一个空集合来收集标签
tags = set()   # 正确
tags.add('python')
tags.add('django')
tags.add('python')  # 重复自动忽略
print("收集的标签:", tags)
```

运行结果：

```text
收集的标签: {'python', 'django'}
```

如果你误用了 `{}` 来初始化，后面调用 `tags.add('python')` 就会报错，因为字典没有 `add` 方法——这是典型的"空集合陷阱"在实际编码中的表现。

### 2.4 集合推导式

集合推导式（Set Comprehension）是一种用简洁语法从可迭代对象创建集合的方式，语法格式为：

```text
{expression for item in iterable}
{expression for item in iterable if condition}
```

它和列表推导式 `[expression for ...]` 语法几乎完全一样，只是用花括号 `{}` 替代方括号 `[]`。区别在于结果是一个集合——自动去重且无序。

**基本用法**

```python
# 从 1~5 的平方创建集合
squares = {x ** 2 for x in range(1, 6)}
print("平方集合:", squares)
```

运行结果：

```text
平方集合: {1, 4, 9, 16, 25}
```

**带条件过滤**

```python
# 1~10 中偶数的平方
even_squares = {x ** 2 for x in range(1, 11) if x % 2 == 0}
print("偶数的平方集合:", even_squares)
```

运行结果：

```text
偶数的平方集合: {4, 16, 36, 64, 100}
```

`if x % 2 == 0` 过滤掉了奇数，只有偶数才参与平方计算并被加入集合。

**文本处理：提取唯一字符**

```python
text = "Hello World"
# 提取所有元音字母（忽略大小写后判断）
vowels = {char.lower() for char in text if char.lower() in 'aeiou'}
print("元音集合:", vowels)
```

运行结果：

```text
元音集合: {'e', 'o'}
```

这里体现了集合推导式的去重特性——"Hello World" 中有多个 'l' 和 'o'，但集合只保留一份。同时 `if` 条件过滤掉了非元音字符。

**提取单词首字母集合**

```python
words = ['apple', 'banana', 'apricot', 'blueberry', 'cherry']
first_letters = {word[0] for word in words}
print("单词首字母集合:", first_letters)
```

运行结果：

```text
单词首字母集合: {'b', 'a', 'c'}
```

5 个单词中 'apple' 和 'apricot' 都以 'a' 开头，'banana' 和 'blueberry' 都以 'b' 开头，但集合只保留了唯一的首字母 `{'a', 'b', 'c'}`。

**嵌套推导式：二维矩阵去重**

```python
matrix = [[1, 2, 3], [3, 4, 5], [5, 6, 1]]
# 展开二维列表并去重
unique_values = {val for row in matrix for val in row}
print("矩阵中的唯一值:", unique_values)
```

运行结果：

```text
矩阵中的唯一值: {1, 2, 3, 4, 5, 6}
```

这里的 `for row in matrix` 遍历每一行，`for val in row` 遍历行内的每个值——两个 `for` 的顺序对应了从外层到内层的展开。

**与列表推导式对比**

```python
# 列表推导式：保留重复
list_comp = [x % 3 for x in range(10)]
print("列表推导式:", list_comp)

# 集合推导式：自动去重
set_comp = {x % 3 for x in range(10)}
print("集合推导式:", set_comp)
```

运行结果：

```text
列表推导式: [0, 1, 2, 0, 1, 2, 0, 1, 2, 0]
集合推导式: {0, 1, 2}
```

这是两者的核心区别——列表保留所有结果（包括重复），集合自动去重。当你的需求是"提取一批数据中的唯一值"时，集合推导式比 `[...] + list(set(...))` 更直接。

**带函数调用的推导式**

```python
prices = ['$10', '$25', '$10', '$30', '$25']
# 去掉 $ 符号并转为整数，集合自动去重
unique_prices = {int(p.strip('$')) for p in prices}
print("去重后的价格:", unique_prices)
```

运行结果：

```text
去重后的价格: {25, 10, 30}
```

推导式的 `expression` 部分可以是任何合法的 Python 表达式，包括函数调用。这里对每个价格字符串做了 `strip('$')` 去掉美元符号，再 `int()` 转为整数，集合自动把重复的 10 和 25 去掉。

### 2.5 frozenset 的创建

`frozenset` 是 Python 内置的**不可变集合**类型。创建后不能添加或删除元素，因此它是可哈希的——可以作为字典的键、可以作为另一个集合的元素。

创建 `frozenset` 的唯一方式是使用 `frozenset()` 构造函数，不能用花括号语法。

**从列表创建**

```python
my_list = [3, 1, 4, 1, 5, 9, 2, 6]
fs = frozenset(my_list)
print("frozenset:", fs)
print("type:", type(fs))
```

运行结果：

```text
frozenset: frozenset({1, 2, 3, 4, 5, 6, 9})
type: <class 'frozenset'>
```

注意输出格式——`frozenset` 的打印结果带有 `frozenset(...)` 前缀，这是为了和普通 `set` 区分。元素同样会去重。

**从字符串创建**

```python
fs_str = frozenset('abracadabra')
print("从字符串创建:", fs_str)
```

运行结果：

```text
从字符串创建: frozenset({'d', 'a', 'r', 'b', 'c'})
```

**从 range 创建**

```python
fs_range = frozenset(range(5))
print("从 range 创建:", fs_range)
```

运行结果：

```text
从 range 创建: frozenset({0, 1, 2, 3, 4})
```

**从集合创建**

```python
normal_set = {10, 20, 30}
fs_from_set = frozenset(normal_set)
print("从集合创建:", fs_from_set)
```

运行结果：

```text
从集合创建: frozenset({10, 20, 30})
```

**与集合推导式配合**

可以直接把集合推导式的结果传给 `frozenset()`，一步创建只读集合：

```python
fs_comp = frozenset({x ** 2 for x in range(1, 6)})
print("推导式 + frozenset:", fs_comp)
```

运行结果：

```text
推导式 + frozenset: frozenset({1, 4, 9, 16, 25})
```

**创建空 frozenset**

```python
empty_fs = frozenset()
print("空 frozenset:", empty_fs)
print("长度:", len(empty_fs))
```

运行结果：

```text
空 frozenset: frozenset()
长度: 0
```

**读取操作不受限制**

`frozenset` 虽然不可修改，但所有读取操作和集合运算都正常支持：

```python
fs = frozenset({3, 1, 4, 1, 5, 9, 2, 6})

# 成员判断
print("9 在 fs 中吗?", 9 in fs)

# 长度
print("fs 的长度:", len(fs))

# 最值
print("fs 的最大值:", max(fs))
print("fs 的最小值:", min(fs))

# 遍历
for item in fs:
    print(f"  {item}")
```

运行结果：

```text
9 在 fs 中吗? True
fs 的长度: 7
fs 的最大值: 9
fs 的最小值: 1
  1
  2
  3
  4
  5
  6
  9
```

**修改操作会报错**

```python
fs = frozenset({1, 2, 3})

try:
    fs.add(100)
except AttributeError as e:
    print(f"add 报错: {e}")

try:
    fs.remove(2)
except AttributeError as e:
    print(f"remove 报错: {e}")
```

运行结果：

```text
add 报错: 'frozenset' object has no attribute 'add'
remove 报错: 'frozenset' object has no attribute 'remove'
```

`frozenset` 没有 `add`、`remove`、`discard`、`pop`、`clear` 等修改方法。这不是"运行时限制"——而是类型本身就缺少这些方法。

**frozenset 的独有价值：可哈希性**

正因为不可变，`frozenset` 是可哈希的，因此它可以做以下两件普通 `set` 做不到的事：

```python
# 1. frozenset 可以作为字典的键
fs_key = frozenset({'a', 'b', 'c'})
my_dict = {fs_key: 'value1'}
print("frozenset 作为字典键:", my_dict)

# 2. frozenset 可以嵌套在另一个集合中
inner = frozenset({1, 2})
outer = {inner, frozenset({3, 4})}
print("frozenset 嵌套在集合中:", outer)
```

运行结果：

```text
frozenset 作为字典键: {frozenset({'c', 'a', 'b'}): 'value1'}
frozenset 嵌套在集合中: {frozenset({3, 4}), frozenset({1, 2})}
```

如果你尝试把普通 `set` 放到字典键或另一个集合中，会得到 `TypeError: unhashable type: 'set'`。

**frozenset 支持集合运算**

```python
fs1 = frozenset({1, 2, 3, 4})
fs2 = frozenset({3, 4, 5, 6})

# 运算结果仍然是 frozenset
print("交集:", fs1 & fs2)
print("并集:", fs1 | fs2)
print("差集:", fs1 - fs2)
print("对称差集:", fs1 ^ fs2)
```

运行结果：

```text
交集: frozenset({3, 4})
并集: frozenset({1, 2, 3, 4, 5, 6})
差集: frozenset({1, 2})
对称差集: frozenset({1, 2, 5, 6})
```

普通 `set` 做运算返回 `set`，`frozenset` 做运算返回 `frozenset`——类型保持一致。

### 2.6 set 与 frozenset 的混合运算

`set` 和 `frozenset` 之间可以做集合运算，结果类型取决于左操作数：

```python
mutable = {1, 2, 3}
immutable = frozenset({3, 4, 5})

# set 运算 frozenset → 结果是 set
result1 = mutable & immutable
print("set & frozenset:", result1, type(result1))

# frozenset 运算 set → 结果是 frozenset
result2 = immutable | mutable
print("frozenset | set:", result2, type(result2))
```

运行结果：

```text
set & frozenset: {3} <class 'set'>
frozenset | set: frozenset({1, 2, 3, 4, 5}) <class 'frozenset'>
```

运算符左侧是 `set` 时返回 `set`，左侧是 `frozenset` 时返回 `frozenset`。这在使用时可以根据需求选择——如果你希望结果可变，让 `set` 在左边；如果想保持不可变，让 `frozenset` 在左边。

### 2.7 利用 set 进行快速去重和查找

了解了多种创建方式之后，来看看集合在实际场景中怎么用。集合的两个杀手级优势——自动去重和 O(1) 查找——在以下场景中尤为突出。

**场景一：列表去重**

```python
raw_data = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
unique_data = list(set(raw_data))
print("原始数据:", raw_data)
print("去重后（无序）:", unique_data)
```

运行结果：

```text
原始数据: [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
去重后（无序）: [1, 2, 3, 4, 5, 6, 9]
```

`list(set(...))` 是最经典的去重一行代码。缺点是去重后顺序会丢失——如果需要保持原始出现顺序，可以用以下方式：

```python
raw_tags = ['python', 'java', 'python', 'go', 'java', 'rust', 'go']
unique_tags = list(dict.fromkeys(raw_tags))
print("去重后（保持顺序）:", unique_tags)
```

运行结果：

```text
去重后（保持顺序）: ['python', 'java', 'go', 'rust']
```

`dict.fromkeys()` 利用了字典键的唯一性且保留了插入顺序（Python 3.7+ 字典有序）。

**场景二：找出两组数据的差异**

```python
team_a_skills = {'Python', 'Django', 'PostgreSQL', 'Docker'}
team_b_skills = {'Python', 'Flask', 'MySQL', 'Docker', 'Kubernetes'}

# 共同技能（交集）
common = team_a_skills & team_b_skills
# 所有技能（并集）
all_skills = team_a_skills | team_b_skills
# A 有但 B 没有的（差集）
only_a = team_a_skills - team_b_skills
# B 有但 A 没有的（差集）
only_b = team_b_skills - team_a_skills

print("共同技能:", common)
print("A 独有:", only_a)
print("B 独有:", only_b)
print("所有技能:", all_skills)
```

运行结果：

```text
共同技能: {'Python', 'Docker'}
A 独有: {'Django', 'PostgreSQL'}
B 独有: {'Flask', 'MySQL', 'Kubernetes'}
所有技能: {'Flask', 'Python', 'Docker', 'Django', 'PostgreSQL', 'Kubernetes', 'MySQL'}
```

用列表实现同样的逻辑需要嵌套循环，时间复杂度是 O(n*m)；而集合的交集、并集、差集运算基于哈希表，时间复杂度是 O(n+m)。

**场景三：日志中提取唯一 IP**

```python
log_lines = [
    "192.168.1.1 - GET /home",
    "10.0.0.5 - POST /login",
    "192.168.1.1 - GET /about",
    "172.16.0.3 - GET /home",
    "10.0.0.5 - GET /dashboard",
]

# 用集合推导式提取唯一 IP
ip_addresses = {line.split(' - ')[0] for line in log_lines}
print("唯一 IP 地址:", ip_addresses)
print("总访问数:", len(log_lines))
print("唯一访客数:", len(ip_addresses))
```

运行结果：

```text
唯一 IP 地址: {'172.16.0.3', '192.168.1.1', '10.0.0.5'}
总访问数: 5
唯一访客数: 3
```

集合推导式 `{line.split(' - ')[0] for line in log_lines}` 一步完成了"提取 + 去重"，非常简洁。

**场景四：白名单过滤（利用 O(1) 查找）**

```python
# 使用 frozenset 作为白名单——不可变，防止意外修改
whitelist = frozenset({'admin@company.com', 'user1@company.com', 'user2@company.com'})

requests_emails = [
    'admin@company.com',
    'hacker@evil.com',
    'user1@company.com',
    'spam@spam.com',
    'user2@company.com',
]

for email in requests_emails:
    status = "通过" if email in whitelist else "拒绝"
    print(f"  {email:30s} -> {status}")
```

运行结果：

```text
  admin@company.com              -> 通过
  hacker@evil.com               -> 拒绝
  user1@company.com             -> 通过
  spam@spam.com                  -> 拒绝
  user2@company.com             -> 通过
```

这里用 `frozenset` 而不是 `set` 作为白名单是刻意的——白名单应该是只读的，用 `frozenset` 可以防止代码中意外调用 `add()` 或 `remove()` 修改白名单。即使有人误写了修改代码，也会在运行时抛出 `AttributeError`。

查找操作 `email in whitelist` 的复杂度是 O(1)，无论白名单有 3 个还是 3 万个邮箱，判断速度几乎一样快。如果用列表实现白名单，查找复杂度是 O(n)，数据量大时性能差距非常大。

**场景五：多集合运算——统计多场活动参与情况**

```python
event_a = {'Alice', 'Bob', 'Charlie', 'David'}
event_b = {'Bob', 'Charlie', 'Eve', 'Frank'}
event_c = {'Alice', 'Charlie', 'Eve', 'Grace'}

# 三场都参加的人（三次交集运算）
all_three = event_a & event_b & event_c
# 至少参加一场的人（三次并集运算）
any_event = event_a | event_b | event_c
# 只参加第一场的人
only_a = event_a - event_b - event_c

print("参加全部三场:", all_three)
print("至少参加一场:", any_event)
print("只参加第一场:", only_a)
```

运行结果：

```text
参加全部三场: {'Charlie'}
至少参加一场: {'David', 'Grace', 'Eve', 'Alice', 'Frank', 'Bob', 'Charlie'}
只参加第一场: {'David'}
```

集合运算符可以链式调用——`event_a & event_b & event_c` 等价于 `event_a.__and__(event_b).__and__(event_c)`，从左到右逐步运算。差集 `event_a - event_b - event_c` 表示"从 A 中先去掉 B 的元素，再去掉 C 的元素"，结果就是"只参加第一场的人"。

## 3. 最佳实践

### 3.1 创建方式选择指南

不同的创建方式适用于不同场景，以下是推荐与不推荐的对比：

| 场景 | 推荐写法 | 不推荐写法 | 原因 |
|------|---------|-----------|------|
| 已知少量元素，直接写字面量 | `{'a', 'b', 'c'}` | `set(['a', 'b', 'c'])` | 字面量更简洁直观 |
| 从已有列表去重 | `set(my_list)` | `for x in my_list: s.add(x)` | 构造函数一行搞定 |
| 创建空集合 | `set()` | `{}` | `{}` 创建的是空字典 |
| 需要保持顺序的去重 | `list(dict.fromkeys(lst))` | `list(set(lst))` | `set` 不保持顺序 |
| 需要集合运算的结果不可变 | `frozenset(s1 & s2)` | `s1 & s2`（返回 set） | 防止后续意外修改 |
| 大量数据去重且需要只读 | `frozenset(big_list)` | `set(big_list)` | frozenset 可作为字典键 |
| 从复杂表达式创建 | `{expr for x in iter}` | `s = set(); for ...: s.add(expr)` | 推导式更简洁 |

### 3.2 推荐写法 vs 不推荐写法

**推荐：用 set() 做批量去重**

```python
# 推荐：一行完成
raw = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
unique = list(set(raw))
```

```python
# 不推荐：手动循环判断
raw = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
unique = []
for x in raw:
    if x not in unique:
        unique.append(x)
# 功能一样，但 O(n^2) 复杂度，数据量大时极慢
```

**推荐：用集合推导式一步完成提取+去重**

```python
# 推荐：一步到位
words = ['apple', 'banana', 'apricot', 'blueberry', 'cherry']
first_letters = {word[0] for word in words}
```

```python
# 不推荐：先建列表再转集合
first_letters_list = []
for word in words:
    first_letters_list.append(word[0])
first_letters = set(first_letters_list)
# 多了两步，可读性也差
```

**推荐：用 frozenset 做常量集合**

```python
# 推荐：白名单用 frozenset，明确语义上不可变
ALLOWED_EXTENSIONS = frozenset({'.jpg', '.png', '.gif', '.webp'})

def is_allowed(filename):
    return filename.endswith(tuple(ALLOWED_EXTENSIONS))
```

```python
# 不推荐：白名单用 set，可能被意外修改
ALLOWED_EXTENSIONS = {'.jpg', '.png', '.gif', '.webp'}

# 某处代码不小心调用了
ALLOWED_EXTENSIONS.add('.exe')  # 安全漏洞！
```

**推荐：用 set 做成员判断而非列表**

```python
# 推荐：集合判断 O(1)
valid_ids = set(range(1, 100001))
for item in data:
    if item.id in valid_ids:  # O(1) 查找
        process(item)
```

```python
# 不推荐：列表判断 O(n)
valid_ids = list(range(1, 100001))
for item in data:
    if item.id in valid_ids:  # 每次查找 O(n)，总复杂度 O(n*m)
        process(item)
```

### 3.3 常见错误模式

**错误一：用 {} 创建空集合**

```python
# 错误
empty_set = {}              # 实际是 dict
empty_set.add(1)             # AttributeError: 'dict' object has no attribute 'add'

# 正确
empty_set = set()
empty_set.add(1)             # 正常工作
```

**错误二：尝试放入可变类型**

```python
# 错误
nested = {[1, 2], [3, 4]}   # TypeError: unhashable type: 'list'

# 正确：用元组替代列表
nested = {(1, 2), (3, 4)}   # 元组不可变，可以哈希
```

**错误三：误以为集合有序**

```python
# 错误：依赖集合的遍历顺序
s = {3, 1, 2}
for i, item in enumerate(s):
    print(i, item)           # 顺序不保证！

# 正确：需要有序时用列表
ordered = [3, 1, 2]
for i, item in enumerate(ordered):
    print(i, item)           # 顺序固定
```

**错误四：对 frozenset 调用修改方法**

```python
# 错误
fs = frozenset({1, 2, 3})
fs.add(4)                    # AttributeError

# 正确：如需修改，转回 set
s = set(fs)
s.add(4)                     # 正常
```

## 4. 原理

### 4.1 集合底层：哈希表

Python 的 `set` 底层是一个哈希表（Hash Table）。理解哈希表的工作原理，可以帮你解释集合的几个关键行为：

**为什么查找是 O(1)**

当你执行 `x in my_set` 时，Python 的过程是：

```text
1. 计算 x 的哈希值：hash_value = hash(x)
2. 用哈希值定位桶位置：bucket_index = hash_value % table_size
3. 检查那个桶里是否已存放 x
4. 如果哈希冲突，用开放寻址法向后探测
```

第 1~3 步是常数时间操作，第 4 步在哈希分布均匀时探测次数极少，平均下来查找时间是 O(1)。相比之下，列表的 `x in my_list` 需要从头到尾逐个比较，最坏情况 O(n)。

**为什么元素必须可哈希**

哈希表依赖哈希值定位存储位置。如果元素可变（比如列表），修改后哈希值会变，元素在哈希表中的"地址"就失效了——你再也找不到这个元素了。所以集合要求元素是**不可变类型**，确保哈希值终生不变。

```python
# 验证哈希值
print(hash(42))          # 整数可哈希
print(hash("hello"))     # 字符串可哈希
print(hash((1, 2)))     # 元组可哈希

# 以下会报错
try:
    hash([1, 2])
except TypeError as e:
    print(f"hash([1,2]) 报错: {e}")
```

运行结果：

```text
42
-7090216201728385294
3713081631934410656
hash([1,2]) 报错: unhashable type: 'list'
```

**为什么集合是无序的**

哈希表中的元素存储位置由哈希值决定，不是由放入顺序决定。当你插入 `3, 1, 2` 时：

```text
插入 3 → hash(3) % 8 = 3 → 存到桶[3]
插入 1 → hash(1) % 8 = 1 → 存到桶[1]
插入 2 → hash(2) % 8 = 2 → 存到桶[2]
```

遍历时是按桶的位置顺序 0→7 扫描的，所以打印顺序是 `1, 2, 3` 而不是 `3, 1, 2`。不同哈希表大小会产生不同的存储布局，所以集合元素的遍历顺序是**非确定的**——在不同 Python 版本、不同数据规模下可能不同。

### 4.2 frozenset 为什么可哈希

`frozenset` 和 `set` 的区别在于可变性。可变对象的哈希值会在内容变化后改变（理论上不可靠），而 `frozenset` 创建后内容永不变化——哈希值终生不变，因此可以安全地用作字典键或集合元素。

```python
# frozenset 可以哈希
fs = frozenset({1, 2, 3})
print(hash(fs))  # 有哈希值

# set 不可哈希
s = {1, 2, 3}
try:
    hash(s)
except TypeError as e:
    print(f"hash(set) 报错: {e}")
```

运行结果：

```text
-2723754012243316531
hash(set) 报错: unhashable type: 'set'
```

### 4.3 True/False 与 1/0 的哈希冲突

你可能在写 `{1, True, 0, False}` 时发现它只保留了 `{0, 1}` 这个现象。根因是 `bool` 是 `int` 的子类，`True` 的整数值就是 1，`False` 就是 0。它们的哈希值完全相同：

```python
print(hash(True) == hash(1))    # True
print(hash(False) == hash(0))   # True
print(True == 1)                # True
print(False == 0)               # True
```

运行结果：

```text
True
True
True
True
```

集合判定元素是否重复的逻辑是"哈希值相同**且**值相等"。`True` 和 `1` 两个条件都满足，所以会被去重为同一个元素。

## 5. 总结

本文围绕 Python 集合的创建方式展开，主要介绍了以下内容：

- 使用花括号 `{}` 直接创建集合——适合少量已知元素，需注意花括号中只能放可哈希类型
- 使用 `set()` 构造函数从可迭代对象（列表、元组、字符串、字典、range、生成器）创建集合——最灵活的创建方式
- 创建空集合必须用 `set()` 而非 `{}`——`{}` 创建的是空字典，这是初学者最常踩的坑
- 集合推导式 `{expression for item in iterable}`——用简洁语法一步完成"计算 + 过滤 + 去重"
- `frozenset()` 创建不可变集合——创建后不可修改，但可哈希，可作为字典键或嵌套在其他集合中
- `set` 与 `frozenset` 的混合运算——运算结果类型跟随左操作数
- 利用 set 做批量去重、差异比较、日志分析、白名单过滤、多集合交并差——集合运算的时间复杂度远优于列表
- 底层哈希表原理——理解哈希表可以解释集合的无序性、O(1) 查找、可哈希性要求和 True/1 去重现象
