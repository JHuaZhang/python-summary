# frozenset 不可变集合

## 1. 介绍

### 1.1 什么是 frozenset

`frozenset` 是 Python 内置的一种集合类型，它是 `set` 的**不可变版本**。普通 `set` 创建后还可以增删元素，而 `frozenset` 一旦创建就**不可修改**——没有 `add`、`remove`、`discard`、`pop`、`clear`、`update` 等任何修改方法。

`frozenset` 和 `set` 的关系，就像 `tuple` 和 `list` 的关系：

| 可变类型 | 不可变类型 | 共同点 |
|---------|-----------|-------|
| `list` | `tuple` | 有序序列 |
| `set` | `frozenset` | 无序集合 |

`frozenset` 保留了 `set` 所有的**只读能力**：成员判断、集合运算（并集、交集、差集、对称差集）、子集/超集判断。唯一的区别是创建之后不能修改内容。

### 1.2 为什么需要 frozenset

你可能会问：既然已经有 `set` 了，为什么还要搞一个 `frozenset`？

核心原因只有一个：**`frozenset` 是可哈希的（hashable），而 `set` 不是**。

这意味着：

- `frozenset` 可以做**字典的键**——`set` 不行
- `frozenset` 可以做**集合的元素**——`set` 不行

```python
# frozenset 可以做字典键
d = {frozenset([1, 2]): "数学组合"}

# frozenset 可以做集合元素（实现嵌套集合）
s = {frozenset([1, 2]), frozenset([3, 4])}

# set 不行
d = {{1, 2}: "value"}  # TypeError: unhashable type: 'set'
s = {{1, 2}, {3, 4}}   # TypeError: unhashable type: 'set'
```

当你需要"一组集合的集合"或"以集合为键的字典"时，`frozenset` 是唯一的内置选择。

### 1.3 最简示例

```python
# 创建一个 frozenset
fs = frozenset([1, 2, 3, 4, 5])
print(fs)        # frozenset({1, 2, 3, 4, 5})
print(type(fs))  # <class 'frozenset'>

# 成员判断——和 set 完全一样
print(3 in fs)   # True
print(10 in fs)  # False

# 集合运算——返回新的 frozenset
fs2 = frozenset([4, 5, 6, 7])
print(fs | fs2)  # frozenset({1, 2, 3, 4, 5, 6, 7})  并集
print(fs & fs2)  # frozenset({4, 5})                  交集

# 尝试修改——没有这些方法
# fs.add(6)        # AttributeError: 'frozenset' object has no attribute 'add'
# fs.remove(1)     # AttributeError: 'frozenset' object has no attribute 'remove'
```

### 1.4 在 Python 集合知识体系中的定位

```text
Python 集合类型
├── set（可变集合）
│   ├── 增删改：add / remove / discard / pop / clear / update
│   ├── 查询：in / len / issubset / issuperset / isdisjoint
│   ├── 运算：| & - ^
│   └── 不可哈希 → 不能做字典键、不能嵌套在集合中
│
└── frozenset（不可变集合）
    ├── 无增删改方法
    ├── 查询：in / len / issubset / issuperset / isdisjoint（与 set 相同）
    ├── 运算：| & - ^（返回新 frozenset）
    └── 可哈希 → 可以做字典键、可以嵌套在集合中
```

`frozenset` 属于集合知识的**进阶使用**层面——当你掌握了 `set` 的基本操作后，`frozenset` 解决的是"需要不可变集合"和"需要集合做键/嵌套"的场景。

## 2. 核心内容

### 2.1 frozenset 的创建方式

`frozenset` 没有字面量语法（`set` 有 `{1, 2, 3}` 字面量），只能通过构造函数 `frozenset()` 创建。

#### 2.1.1 从可迭代对象创建

最常见的创建方式：传入任意可迭代对象（列表、元组、字符串、集合等），`frozenset` 会提取其中的元素并去重。

```python
# 从列表创建
fs1 = frozenset([1, 2, 3, 4, 5])
print(fs1)  # frozenset({1, 2, 3, 4, 5})

# 从元组创建
fs2 = frozenset((10, 20, 30))
print(fs2)  # frozenset({10, 20, 30})

# 从字符串创建——每个字符变成一个元素
fs3 = frozenset("hello")
print(fs3)  # frozenset({'h', 'e', 'l', 'o'})  注意去重

# 从集合创建
s = {1, 2, 3}
fs4 = frozenset(s)
print(fs4)  # frozenset({1, 2, 3})

# 从另一个 frozenset 创建
fs5 = frozenset(fs1)
print(fs5)  # frozenset({1, 2, 3, 4, 5})
```

**运行结果**：

```text
frozenset({1, 2, 3, 4, 5})
frozenset({10, 20, 30})
frozenset({'h', 'e', 'l', 'o'})
frozenset({1, 2, 3})
frozenset({1, 2, 3, 4, 5})
```

**关键点**：`frozenset` 的构造函数接收的是**可迭代对象**，不是单个元素。传入非可迭代对象会报错。

```python
# 传入整数会报错——整数不可迭代
try:
    frozenset(42)
except TypeError as e:
    print(e)  # 'int' object is not iterable
```

#### 2.1.2 创建空 frozenset

```python
fs_empty = frozenset()
print(fs_empty)       # frozenset()
print(len(fs_empty))  # 0
print(bool(fs_empty)) # False（空 frozenset 为假值）
```

注意：空 `frozenset` 的 `bool()` 返回 `False`，这在条件判断中很有用。

#### 2.1.3 使用集合推导式创建

集合推导式 `{表达式 for 变量 in 可迭代对象}` 产生的是 `set`，给它套上 `frozenset()` 就得到了 `frozenset`。

```python
# 集合推导式 + frozenset
fs = frozenset({x * 2 for x in range(5)})
print(fs)  # frozenset({0, 2, 4, 6, 8})
print(type(fs))  # <class 'frozenset'>
```

#### 2.1.4 去重特性

`frozenset` 继承了 `set` 的去重能力——传入的重复元素只会保留一个。

```python
fs = frozenset([1, 1, 2, 2, 3, 3])
print(fs)  # frozenset({1, 2, 3})
print(len(fs))  # 3
```

### 2.2 frozenset 的不可变性

不可变性是 `frozenset` 和 `set` 的**核心区别**。`frozenset` 创建之后，不能添加、删除、修改任何元素。

#### 2.2.1 没有修改方法

```python
fs = frozenset([1, 2, 3, 4, 5])

# 以下方法全部不存在
# fs.add(6)           # AttributeError
# fs.remove(1)        # AttributeError
# fs.discard(1)        # AttributeError
# fs.pop()             # AttributeError
# fs.clear()           # AttributeError
# fs.update([6, 7])    # AttributeError
```

用代码验证每个修改操作都会报 `AttributeError`：

```python
fs = frozenset([1, 2, 3, 4, 5])

operations = [
    ("add(6)", lambda: fs.add(6)),
    ("remove(1)", lambda: fs.remove(1)),
    ("discard(1)", lambda: fs.discard(1)),
    ("pop()", lambda: fs.pop()),
    ("clear()", lambda: fs.clear()),
    ("update([6,7])", lambda: fs.update([6, 7])),
]

for name, op in operations:
    try:
        op()
    except AttributeError as e:
        print(f"{name} → AttributeError: {e}")
```

**运行结果**：

```text
add(6) → AttributeError: 'frozenset' object has no attribute 'add'
remove(1) → AttributeError: 'frozenset' object has no attribute 'remove'
discard(1) → AttributeError: 'frozenset' object has no attribute 'discard'
pop() → AttributeError: 'frozenset' object has no attribute 'pop'
clear() → AttributeError: 'frozenset' object has no attribute 'clear'
update([6,7]) → AttributeError: 'frozenset' object has no attribute 'update'
```

#### 2.2.2 原地运算符也会报错

`set` 支持原地运算符 `|=`、`&=`、`-=`、`^=`（会修改原集合），但 `frozenset` 不支持这些原地运算符：

```python
fs = frozenset([1, 2, 3])

# set 支持 |= 原地并集
# s = {1, 2, 3}
# s |= {4, 5}  # s 变成 {1, 2, 3, 4, 5}

# frozenset 不支持
try:
    fs |= {4, 5}
except TypeError as e:
    print(f"fs |= {{4, 5}} → TypeError: {e}")
    # 输出: 'frozenset' 类型不支持就地更新
```

#### 2.2.3 frozenset 有哪些方法

对比 `set` 和 `frozenset` 的方法列表，`frozenset` 只保留了只读方法：

| 方法类别 | set 的方法 | frozenset 的方法 |
|---------|-----------|-----------------|
| 添加 | `add` | 无 |
| 删除 | `remove`, `discard`, `pop`, `clear` | 无 |
| 批量更新 | `update`, `intersection_update`, `difference_update`, `symmetric_difference_update` | 无 |
| 并集 | `union`, `\|` | `union`, `\|` |
| 交集 | `intersection`, `&` | `intersection`, `&` |
| 差集 | `difference`, `-` | `difference`, `-` |
| 对称差集 | `symmetric_difference`, `^` | `symmetric_difference`, `^` |
| 子集判断 | `issubset`, `<=` | `issubset`, `<=` |
| 超集判断 | `issuperset`, `>=` | `issuperset`, `>=` |
| 相交判断 | `isdisjoint` | `isdisjoint` |
| 拷贝 | `copy` | `copy` |

用代码列出 `frozenset` 的全部公开方法：

```python
fs = frozenset([1, 2, 3])
methods = [m for m in dir(frozenset) if not m.startswith('_')]
print(methods)
# ['copy', 'difference', 'intersection', 'isdisjoint', 'issubset', 'issuperset', 'symmetric_difference', 'union']
```

再列出 `set` 有而 `frozenset` 没有的方法（都是修改类）：

```python
set_only = set(dir(set)) - set(dir(frozenset))
set_only = {m for m in set_only if not m.startswith('_')}
print(sorted(set_only))
# ['add', 'clear', 'difference_update', 'discard', 'intersection_update',
#  'pop', 'remove', 'symmetric_difference_update', 'update']
```

#### 2.2.4 不可变 ≠ 变量名不能重新绑定

`frozenset` 的不可变性是指**对象本身的内容不可变**，而不是变量名不能重新指向新对象：

```python
fs = frozenset([1, 2, 3])
print(f"原对象: {fs}, id={id(fs)}")

# 这不是"修改"，而是重新绑定——变量名指向了一个新对象
fs = frozenset([4, 5, 6])
print(f"新对象: {fs}, id={id(fs)}")
# 两个 id 不同，说明是两个不同的对象
```

**运行结果**：

```text
原对象: frozenset({1, 2, 3}), id=4384954560
新对象: frozenset({4, 5, 6}), id=4384955456
```

这和 `tuple` 的行为完全一致：你不能再给 `tuple` 追加元素，但你可以让变量名重新指向另一个 `tuple`。

### 2.3 frozenset 与 set 的对比

理解 `frozenset` 最好的方式是和 `set` 做全面对比。

#### 2.3.1 全面对比表

| 维度 | set | frozenset |
|------|-----|-----------|
| 可变性 | 可变（可增删改） | 不可变（无修改方法） |
| 字面量语法 | `{1, 2, 3}` | 无，只能用 `frozenset()` |
| 可哈希性 | 不可哈希 | 可哈希 |
| 做字典键 | 不可以 | 可以 |
| 做集合元素 | 不可以 | 可以 |
| 成员判断 `in` | 支持 | 支持 |
| `len()` | 支持 | 支持 |
| 集合运算 `\| & - ^` | 支持，返回 set | 支持，返回 frozenset |
| 原地运算 `\|= &= -= ^=` | 支持 | 不支持 |
| 集合运算方法 | 支持 | 支持 |
| 子集/超集判断 | 支持 | 支持 |
| 元素要求 | 可哈希对象 | 可哈希对象 |
| 去重 | 是 | 是 |
| 无序 | 是 | 是 |

#### 2.3.2 运算结果的类型规则

`frozenset` 和 `set` 混合运算时，**结果类型跟随左侧操作数**：

```python
fs = frozenset([1, 2, 3])
s = {3, 4, 5}

# frozenset 在左 → 返回 frozenset
result1 = fs | s
print(type(result1).__name__)  # frozenset

# set 在左 → 返回 set
result2 = s | fs
print(type(result2).__name__)  # set

# 方法调用的结果类型取决于调用者
result3 = fs.union(s)
print(type(result3).__name__)  # frozenset

result4 = s.union(fs)
print(type(result4).__name__)  # set
```

这个规则在所有集合运算中都成立：`|`、`&`、`-`、`^` 以及对应的 `.union()`、`.intersection()`、`.difference()`、`.symmetric_difference()` 方法。

#### 2.3.3 查询能力完全一致

在"只读"层面，`frozenset` 和 `set` 的表现完全相同：

```python
s = {1, 2, 3, 4, 5}
fs = frozenset([1, 2, 3, 4, 5])

# 成员判断
print(3 in s)    # True
print(3 in fs)   # True

# 长度
print(len(s))    # 5
print(len(fs))   # 5

# 子集判断
print(s.issubset({1, 2, 3, 4, 5, 6}))     # True
print(fs.issubset({1, 2, 3, 4, 5, 6}))    # True

# 并集
print(s.union({6, 7}))     # {1, 2, 3, 4, 5, 6, 7}
print(fs.union({6, 7}))    # frozenset({1, 2, 3, 4, 5, 6, 7})
```

**关键点**：查询结果值相同，但 `union` 等运算返回的类型不同——`set` 的运算返回 `set`，`frozenset` 的运算返回 `frozenset`。

### 2.4 frozenset 的可哈希性

可哈希性是 `frozenset` 存在的核心意义。正因为可哈希，`frozenset` 可以做字典键和集合元素。

#### 2.4.1 什么是可哈希

一个对象可哈希，意味着它实现了 `__hash__()` 方法，能计算出一个固定不变的哈希值。Python 的字典和集合用哈希值来做快速查找。

不可变对象通常是可哈希的：`int`、`float`、`str`、`tuple`（元素都不可变时）、`frozenset`。
可变对象通常不可哈希：`list`、`dict`、`set`。

```python
# frozenset 可以计算哈希值
print(hash(frozenset([1, 2, 3])))  # 返回一个整数，如 -272375401224217160

# set 不行
try:
    hash({1, 2, 3})
except TypeError as e:
    print(e)  # unhashable type: 'set'
```

#### 2.4.2 frozenset 的哈希值规则

`frozenset` 的哈希值是基于其元素的哈希值计算的，与元素顺序无关：

```python
# 相同元素的 frozenset，哈希值相同
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([3, 2, 1])  # 顺序不同
print(hash(fs1) == hash(fs2))  # True

# 不同元素，哈希值不同
fs3 = frozenset([1, 2, 4])
print(hash(fs1) == hash(fs3))  # False
```

这保证了无论创建时元素顺序如何，只要包含的元素相同，`frozenset` 就被认为是相等的，可以做同一个字典键。

#### 2.4.3 frozenset 做字典键

这是 `frozenset` 最典型的使用场景。

**场景：统计选课组合的人数**

每个学生选了一组课程，你想统计每种课程组合有多少人选。

```python
# 用 frozenset 表示课程组合（因为课程组合是一组无序的课程名）
combo1 = frozenset({"数学", "物理", "化学"})
combo2 = frozenset({"数学", "物理"})
combo3 = frozenset({"语文", "历史"})

# frozenset 做字典键——课程组合 → 选课人数
enrollment = {
    combo1: 45,
    combo2: 78,
    combo3: 32,
}

# 查找——即使顺序不同也能找到
lookup = frozenset({"物理", "数学", "化学"})
print(enrollment[lookup])  # 45
```

如果用 `set` 做键：

```python
# set 不能做字典键
try:
    d = {{1, 2}: "value"}
except TypeError as e:
    print(e)  # unhashable type: 'set'
```

**场景：缓存函数参数组合**

当函数接收一组参数，你想用参数组合做缓存键：

```python
cache = {}

def compute_avg(*values):
    key = frozenset(values)  # 参数组合转为 frozenset 做缓存键
    if key in cache:
        print(f"  命中缓存: {set(key)}")
        return cache[key]
    result = sum(values) / len(values)
    cache[key] = result
    print(f"  计算并缓存: {set(key)} → {result}")
    return result

compute_avg(10, 20, 30)   # 计算并缓存: {10, 20, 30} → 20.0
compute_avg(10, 20, 30)   # 命中缓存: {10, 20, 30}
compute_avg(30, 10, 20)   # 命中缓存: {10, 20, 30}（顺序不同也命中）
```

#### 2.4.4 frozenset 做集合元素

`frozenset` 可以放在 `set` 里面，实现"集合的集合"（嵌套集合）。`set` 本身不能嵌套。

**set 不能嵌套：**

```python
# 想把多个子集合放进一个大集合
try:
    s = {{1, 2}, {3, 4}}
except TypeError as e:
    print(e)  # unhashable type: 'set'
```

**frozenset 可以嵌套：**

```python
# 用 frozenset 实现嵌套集合
nested = {frozenset([1, 2]), frozenset([3, 4]), frozenset([5, 6])}
print(nested)
# {frozenset({1, 2}), frozenset({3, 4}), frozenset({5, 6})}

# 遍历每个子集合
for item in nested:
    print(f"  子集合: {set(item)}")
```

**场景：图论中的边集合**

图的边可以用 `frozenset` 表示（无向边的两个端点顺序无关）：

```python
# 无向图的边——每条边是一对节点，顺序无关
edges = {
    frozenset(["A", "B"]),
    frozenset(["B", "C"]),
    frozenset(["A", "C"]),
    frozenset(["C", "D"]),
}

print(f"图有 {len(edges)} 条边")

# 查询某条边是否存在——方向无关
print(frozenset(["A", "B"]) in edges)  # True
print(frozenset(["B", "A"]) in edges)  # True（顺序不同也能找到）
```

**场景：权限组去重**

```python
# 每个权限组是一组权限，用 frozenset 表示可以自动去重
admin = frozenset(["read", "write", "delete", "admin"])
editor = frozenset(["read", "write"])
viewer = frozenset(["read"])

groups = {admin, editor, viewer}
print(f"共 {len(groups)} 个权限组")

# 添加重复权限组——自动去重
groups.add(frozenset(["read", "write"]))  # 和 editor 相同
print(f"添加重复组后仍有 {len(groups)} 个权限组")  # 3
```

### 2.5 frozenset 的集合运算

`frozenset` 支持和 `set` 完全一样的集合运算，区别仅在于返回类型是 `frozenset`。

#### 2.5.1 四大基本运算

```python
fs1 = frozenset([1, 2, 3, 4, 5])
fs2 = frozenset([4, 5, 6, 7, 8])

# 并集——运算符和方法两种写法
union1 = fs1 | fs2
union2 = fs1.union(fs2)
print(f"并集: {union1}")
# frozenset({1, 2, 3, 4, 5, 6, 7, 8})

# 交集
inter1 = fs1 & fs2
inter2 = fs1.intersection(fs2)
print(f"交集: {inter1}")
# frozenset({4, 5})

# 差集
diff1 = fs1 - fs2
diff2 = fs1.difference(fs2)
print(f"差集: {diff1}")
# frozenset({1, 2, 3})

# 对称差集
symdiff1 = fs1 ^ fs2
symdiff2 = fs1.symmetric_difference(fs2)
print(f"对称差集: {symdiff1}")
# frozenset({1, 2, 3, 6, 7, 8})
```

**关键点**：`union` 方法可以接受任意可迭代对象（不仅限于集合），而运算符 `|` 只接受集合类型：

```python
# union 方法接受列表
result = fs1.union([9, 10])
print(result)  # frozenset({1, 2, 3, 4, 5, 9, 10})

# 运算符 | 不接受列表
# fs1 | [9, 10]  # TypeError: unsupported operand type(s) for |: 'frozenset' and 'list'
```

#### 2.5.2 关系判断

```python
fs = frozenset([1, 2, 3, 4, 5])
sub = frozenset([1, 2])

# 子集判断
print(sub <= fs)         # True（sub 是 fs 的子集）
print(sub.issubset(fs)) # True

# 超集判断
print(fs >= sub)              # True（fs 是 sub 的超集）
print(fs.issuperset(sub))    # True

# 真子集/真超集（不含等于）
print(sub < fs)  # True（sub 是 fs 的真子集）
print(fs > sub)  # True（fs 是 sub 的真超集）

# 不相交判断
print(fs.isdisjoint(frozenset([10, 11])))  # True（没有共同元素）
print(fs.isdisjoint(frozenset([5, 6])))     # False（有共同元素 5）
```

#### 2.5.3 运算结果类型

所有集合运算的结果都是 `frozenset`：

```python
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([3, 4, 5])

operations = {
    "|": fs1 | fs2,
    "&": fs1 & fs2,
    "-": fs1 - fs2,
    "^": fs1 ^ fs2,
}

for op, result in operations.items():
    print(f"{op} → {type(result).__name__}: {result}")
```

**运行结果**：

```text
| → frozenset: frozenset({1, 2, 3, 4, 5})
& → frozenset: frozenset({3})
- → frozenset: frozenset({1, 2})
^ → frozenset: frozenset({1, 2, 4, 5})
```

### 2.6 frozenset 的只读方法速览

`frozenset` 全部公开方法只有 8 个，全部是只读的：

| 方法 | 运算符 | 作用 | 返回值 |
|------|--------|------|--------|
| `union(other)` | `\|` | 并集 | 新 frozenset |
| `intersection(other)` | `&` | 交集 | 新 frozenset |
| `difference(other)` | `-` | 差集 | 新 frozenset |
| `symmetric_difference(other)` | `^` | 对称差集 | 新 frozenset |
| `issubset(other)` | `<=` | 是否子集 | bool |
| `issuperset(other)` | `>=` | 是否超集 | bool |
| `isdisjoint(other)` | | 是否不相交 | bool |
| `copy()` | | 浅拷贝 | 新 frozenset |

加上内置操作 `in`、`len()`、`==`、`!=`、`<`、`>`、`<=`、`>=`，这就是 `frozenset` 的全部能力。

```python
fs = frozenset([1, 2, 3, 4, 5])
other = frozenset([4, 5, 6, 7])

# 全部方法演示
print(f"union:              {fs.union(other)}")
print(f"intersection:       {fs.intersection(other)}")
print(f"difference:         {fs.difference(other)}")
print(f"symmetric_diff:     {fs.symmetric_difference(other)}")
sub = frozenset([1, 2])
print(f"issubset({set(sub)}): {sub.issubset(fs)}")
print(f"issuperset({set(sub)}): {fs.issuperset(sub)}")
print(f"isdisjoint([10]):   {fs.isdisjoint(frozenset([10]))}")
print(f"copy: {fs.copy()}, is same: {fs.copy() is fs}, is equal: {fs.copy() == fs}")
```

**运行结果**：

```text
union:              frozenset({1, 2, 3, 4, 5, 6, 7})
intersection:       frozenset({4, 5})
difference:         frozenset({1, 2, 3})
symmetric_diff:     frozenset({1, 2, 3, 6, 7})
issubset({1, 2}): True
issuperset({1, 2}): True
isdisjoint([10]):   True
copy: frozenset({1, 2, 3, 4, 5}), is same: True, is equal: True
```

注意：`fs.copy() is fs` 返回 `True`——因为 `frozenset` 是不可变对象，Python 对 `copy()` 做了优化，直接返回自身（拷贝不可变对象没有意义）。这与 `set` 的 `copy()` 不同（`set.copy()` 返回新对象）。

## 3. 最佳实践

### 3.1 什么时候用 frozenset，什么时候用 set

**选 set 的场景**（需要修改）：
- 逐步添加元素的收集场景：先创建空集合，逐步 `add`
- 逐步过滤元素的场景：用 `remove` 或 `discard` 删除
- 需要去重但后续会动态变化的场景

**选 frozenset 的场景**（需要不可变或可哈希）：
- 集合内容创建后不再修改，且需要做字典键
- 集合内容创建后不再修改，且需要嵌套在其他集合中
- 函数参数中传递"一组不可变的值"（如配置项）
- 需要不可变集合做函数默认参数（避免可变默认参数陷阱）

```python
# 推荐：需要不可变集合时用 frozenset
GOOD_CONFIG = frozenset({"debug", "verbose", "trace"})

# 不推荐：用 set 做需要不可变的配置
# config = {"debug", "verbose"}  # 可能被意外修改

# 推荐：用 frozenset 做函数默认参数
def process(data, tags=frozenset()):
    # frozenset 不可变，不会在函数调用间累积状态
    return data | tags if isinstance(data, set) else data

# 不推荐：用 set 做函数默认参数
# def process(data, tags=set()):  # 可变默认参数是经典陷阱
#     tags.add("default")
#     return data | tags
```

### 3.2 frozenset 与 tuple 的选择

`frozenset` 和 `tuple` 都是不可变的，但用途不同：

| 维度 | frozenset | tuple |
|------|-----------|-------|
| 有序性 | 无序 | 有序 |
| 去重 | 自动去重 | 不去重 |
| 成员判断 | O(1) | O(n) |
| 索引访问 | 不支持 | 支持 |
| 做字典键 | 可以 | 可以（元素都不可变时） |

```python
# 推荐 frozenset：需要去重 + 快速成员判断 + 顺序无关
tags = frozenset(["python", "web", "api"])
print("python" in tags)  # O(1)，快速

# 推荐 tuple：需要有序 + 允许重复 + 索引访问
coordinates = (3.14, 2.71, 1.41)
print(coordinates[0])  # 3.14，索引访问
```

### 3.3 推荐 vs 不推荐写法对比

| 场景 | 推荐 | 不推荐 | 原因 |
|------|------|--------|------|
| 不可变配置集合 | `frozenset([...])` | `set([...])` | set 可被意外修改 |
| 函数默认参数 | `def f(x, s=frozenset())` | `def f(x, s=set())` | 可变默认参数陷阱 |
| 嵌套集合 | `{frozenset([1,2]), frozenset([3,4])}` | `{{1,2}, {3,4}}` | set 不可哈希 |
| 集合做字典键 | `{frozenset([1,2]): "val"}` | `{{1,2}: "val"}` | set 不可哈希 |
| 临时去重只需读 | `frozenset(data)` 后用 | `set(data)` 后修改 | 不需要修改时 frozenset 更安全 |
| 需要逐步增删 | `set([...])` | `frozenset([...])` | frozenset 不能增删 |

### 3.4 避免不必要的 frozenset

不要为了"不可变"而滥用 `frozenset`。如果你的代码中从来不会修改某个 `set`，用它就够了——`frozenset` 的价值在于"你需要它的可哈希性"或"你想从类型层面防止意外修改"。

```python
# 不推荐：纯粹为了可读性而用 frozenset，但用不到可哈希性
def get_constants():
    return frozenset([3.14, 2.71, 1.41])  # 如果只是返回常数集合，用 tuple 更合适

# 推荐：需要可哈希或嵌套时才用 frozenset
def get_tag_set():
    return frozenset(["python", "web", "api"])  # 如果后面要用做字典键
```

## 4. 原理

### 4.1 frozenset 为什么可哈希

`frozenset` 可哈希的根源在于它**不可变**。哈希表的查找依赖哈希值定位桶位置——如果对象的内容可以变，哈希值就会变化，之前存入字典/集合的元素就"找不到"了。

`set` 可变，所以 Python 禁止它可哈希（不提供 `__hash__` 方法），从根源上避免"元素入集合后修改导致丢失"的问题。

`frozenset` 不可变，内容永远不会变，哈希值也不会变，所以可以安全地做字典键和集合元素。

```python
# frozenset 实现了 __hash__ 方法
print(frozenset.__hash__)  # <slot wrapper '__hash__' of 'frozenset' objects>

# set 没有 __hash__ 方法（设为 None）
print(set.__hash__)  # None
```

### 4.2 frozenset 的哈希值计算

`frozenset` 的哈希值不是简单地把元素的哈希值加起来。CPython 的实现考虑了集合的无序特性——确保无论元素排列顺序如何，只要元素集合相同，哈希值就相同。

核心算法（简化描述）：

1. 对每个元素计算哈希值
2. 对每个元素的哈希值做位变换后累加
3. 最终累加值再做一次位变换

这保证了 `{1, 2, 3}` 和 `{3, 2, 1}` 的哈希值完全一致：

```python
# 验证哈希值与顺序无关
fs1 = frozenset([1, 2, 3])
fs2 = frozenset([3, 2, 1])
fs3 = frozenset([2, 1, 3])

print(hash(fs1) == hash(fs2))  # True
print(hash(fs1) == hash(fs3))  # True
print(f"三个哈希值: {hash(fs1)}, {hash(fs2)}, {hash(fs3)}")
```

### 4.3 copy() 返回自身的优化

`fs.copy() is fs` 返回 `True`。这是因为 `frozenset` 不可变，拷贝一个不可变对象没有实际意义——既然内容不会变，多个变量引用同一个对象也不会出问题。

```python
fs = frozenset([1, 2, 3])
fs_copy = fs.copy()
print(fs is fs_copy)  # True——同一个对象

# 对比 set
s = {1, 2, 3}
s_copy = s.copy()
print(s is s_copy)  # False——不同对象，因为 set 可变需要独立拷贝
```

这是 CPython 的内部优化，与 `str` 的行为一致：

```python
# 不可变字符串也有类似优化
s1 = "hello"
s2 = "hello"
print(s1 is s2)  # True（字符串驻留）
```

## 5. 总结

本文围绕 `frozenset` 不可变集合展开，主要介绍了以下内容：

- `frozenset` 是 `set` 的不可变版本，创建后不能增删改，保留了 `set` 的全部只读能力和集合运算
- `frozenset` 的核心价值是**可哈希**——可以做字典键、可以嵌套在集合中，这是 `set` 做不到的
- 创建方式：只能通过 `frozenset()` 构造函数，从任意可迭代对象创建，没有字面量语法
- 不可变性体现在没有 `add`/`remove`/`discard`/`pop`/`clear`/`update` 等修改方法，也不支持 `|=` 等原地运算符
- `frozenset` 与 `set` 的运算结果类型遵循"左操作数决定"规则——frozenset 运算返回 frozenset，set 运算返回 set
- `frozenset` 全部公开方法只有 8 个（`union`/`intersection`/`difference`/`symmetric_difference`/`issubset`/`issuperset`/`isdisjoint`/`copy`），全部只读
- 典型使用场景：不可变配置集合、嵌套集合、集合做字典键、函数默认参数
- `frozenset` 可哈希的根源是不可变性——内容不变则哈希值不变，可以安全做字典键和集合元素
- 哈希值计算与元素顺序无关，确保元素相同的 frozenset 哈希值一致
- `copy()` 方法因不可变优化直接返回自身，与 `set` 的 `copy()` 行为不同
