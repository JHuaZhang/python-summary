# 字典概述与基本概念

## 1. 介绍

### 1.1 什么是字典

字典（`dict`）是 Python 中最强大的**映射类型**——它不是像列表那样用"位置编号"找数据，而是用一个"标签"（键）来快速找到对应的数据（值）。就像现实生活中查字典：你知道了"单词"（键），就能直接翻到对应的"释义"（值），而不需要从第一页逐页扫描。

```python
# 字典用花括号 {} 创建，键和值之间用冒号 : 分隔
student = {
    "name": "张三",
    "age": 20,
    "major": "计算机科学",
    "score": 90.5,
}

# 通过"键"直接取出"值"——不需要知道位置编号
print(student["name"])    # 张三
print(student["score"])   # 90.5
print(type(student))      # <class 'dict'>
```

字典和列表的根本区别在于**访问方式**：列表用整数索引 `lst[0]`，字典用任意不可变对象作为键 `d["name"]`。这看似只是换了种写法，但背后是完全不同的数据结构——列表是"连续内存 + 偏移量访问"，字典是"哈希表 + 键定位"，这让字典在查找时可以达到 O(1) 的时间复杂度。

```python
# 列表：按位置存取
shopping = ["apple", "banana", "cherry"]
print(shopping[1])        # banana（必须记住"第1个"是 banana）

# 字典：按名字存取
prices = {"apple": 3.5, "banana": 2.8, "cherry": 8.0}
print(prices["banana"])   # 2.8（直接用名字"banana"取价格）
```

理解字典，核心在于理解三件事：**键值对结构**（数据怎么存）、**哈希查找机制**（数据怎么找）、**键的可哈希要求**（哪些对象能做键）。这三点是本篇的重点。

### 1.2 字典的基本特性

字典有五条核心特性，与列表和元组都有显著差异：

```python
d = {"name": "张三", "age": 25, "city": "北京"}

# 特性一：键值映射——通过键找值
print(d["name"])          # 张三

# 特性二：键唯一——同一个键只能存在一个
d2 = {"a": 1, "a": 99}    # 字面量中重复键，后者覆盖前者
print(d2)                 # {'a': 99}

# 特性三：可变——可以增删改
d["score"] = 95            # 增加新键值对
d["age"] = 26              # 修改已有键的值
del d["city"]              # 删除键值对
print(d)                   # {'name': '张三', 'age': 26, 'score': 95}

# 特性四：键必须可哈希——不可变类型才能做键
valid = {"str": 1, 42: 2, (1, 2): 3}     # OK：str、int、tuple 都不可变
# invalid = {[1, 2]: "x"}                # TypeError: list 不可哈希

# 特性五：有序（Python 3.7+）——保持插入顺序
d3 = {"c": 3, "a": 1, "b": 2}
print(list(d3.keys()))    # ['c', 'a', 'b']（保持插入顺序）
```

| 特性 | 说明 | 与列表对比 | 与元组对比 |
|------|------|-----------|-----------|
| 键值映射 | 数据以"键→值"形式存储 | 列表是"位置→值" | 元组是"位置→值" |
| 键唯一 | 同一个键只能存在一个值 | 列表允许重复 | 元组允许重复 |
| 可变 | 可以增删改键值对 | 可变 | 不可变 |
| 键需可哈希 | 键必须是不可变类型 | N/A | N/A |
| 有序 | 保持插入顺序（3.7+） | 有序 | 有序 |

### 1.3 字典与列表的对比

字典和列表是 Python 中最常用的两种容器，但它们适用完全不同的场景：

```python
# 场景对比：存储学生信息

# 用列表存——必须记住"第0个是姓名，第1个是年龄..."
student_list = ["张三", 20, "计算机科学", 90.5]
print(student_list[0])    # 张三（0 是什么？读代码的人需要猜）

# 用字典存——键名自带语义
student_dict = {"name": "张三", "age": 20, "major": "计算机科学", "score": 90.5}
print(student_dict["name"])   # 张三（键名 "name" 自带语义）
```

**核心差异**：

| 维度 | list | dict |
|------|------|------|
| 访问方式 | 整数索引 `lst[0]` | 键访问 `d["name"]` |
| 查找时间复杂度 | O(n)（线性扫描） | O(1)（哈希查找） |
| 键类型 | 无键，只有位置 | 任意不可变类型 |
| 值是否可重复 | 允许 | 键不可重复，值可重复 |
| 有序性 | 有序 | 有序（3.7+保证插入顺序） |
| 内存占用 | 较小 | 较大（哈希表开销） |
| 典型用途 | 有序集合、队列、栈 | 映射、缓存、配置 |

```python
# 查找效率对比
import time

# 构造 10 万元素
big_list = [f"item_{i}" for i in range(100000)]
big_dict = {f"item_{i}": i for i in range(100000)}
target = "item_99999"

# 列表查找：O(n)
start = time.perf_counter()
for _ in range(1000):
    _ = target in big_list
list_time = time.perf_counter() - start

# 字典查找：O(1)
start = time.perf_counter()
for _ in range(1000):
    _ = target in big_dict
dict_time = time.perf_counter() - start

print(f"列表查找 1000 次: {list_time:.4f} 秒")
print(f"字典查找 1000 次: {dict_time:.4f} 秒")
# 字典快了上千倍
```

### 1.4 字典在 Python 中的地位和常见用途

字典是 Python 中使用频率极高的数据结构。Python 的很多机制底层就依赖字典——比如对象的属性表 `obj.__dict__`、函数的参数表、模块的命名空间等，都是字典实现的。

```python
# 1. 配置管理（配置项 → 配置值）
db_config = {
    "host": "localhost",
    "port": 5432,
    "database": "myapp",
    "user": "admin",
}
print(f"连接: {db_config['host']}:{db_config['port']}")

# 2. 词频统计（单词 → 出现次数）
text = "apple banana apple cherry banana apple"
word_count = {}
for word in text.split():
    if word in word_count:
        word_count[word] += 1
    else:
        word_count[word] = 1
print(word_count)   # {'apple': 3, 'banana': 2, 'cherry': 1}

# 3. 用户映射（用户名 → 用户信息）
users = {
    "zhangsan": {"name": "张三", "role": "admin"},
    "lisi": {"name": "李四", "role": "user"},
}
print(users["zhangsan"]["name"])   # 张三

# 4. 缓存（参数 → 计算结果）
_fib_cache = {}
def fib(n):
    if n in _fib_cache:
        return _fib_cache[n]
    if n <= 1:
        result = n
    else:
        result = fib(n - 1) + fib(n - 2)
    _fib_cache[n] = result
    return result

print(fib(10))   # 55（带缓存的斐波那契，避免重复计算）

# 5. HTTP 状态码映射
status_codes = {200: "OK", 404: "Not Found", 500: "Internal Server Error"}
print(status_codes[404])   # Not Found

# 6. 分组归类
students = [("张三", "计算机"), ("李四", "数学"), ("王五", "计算机")]
groups = {}
for name, major in students:
    groups.setdefault(major, []).append(name)
print(groups)   # {'计算机': ['张三', '王五'], '数学': ['李四']}
```

每当数据有"标签 → 内容"的映射关系时，字典就是比列表更好的选择——查找快、语义清晰、增删方便。

## 2. 核心内容

### 2.1 字典的基本操作速览

先一览字典最常用的操作，建立全局认识：

```python
# ========== 创建 ==========
d1 = {"a": 1, "b": 2}               # 字面量（最常用）
d2 = dict(name="张三", age=20)        # dict() 关键字参数
d3 = dict([("a", 1), ("b", 2)])      # dict() 从键值对列表
d4 = {k: v**2 for k, v in {"x": 1, "y": 2}.items()}  # 字典推导式
d5 = {}                              # 空字典

# ========== 访问 ==========
d = {"name": "张三", "age": 20, "score": 90.5}
print(d["name"])                    # 张三（通过键取值）
print(len(d))                       # 3（键值对数量）

# ========== 增删改 ==========
d["major"] = "CS"                   # 增加：赋值新键
d["age"] = 21                       # 修改：赋值已有键
del d["score"]                      # 删除：del 关键字
print(d)                            # {'name': '张三', 'age': 21, 'major': 'CS'}

# ========== 查询 ==========
print("name" in d)                  # True（in 检查键是否存在）
print("score" in d)                 # False
print(d.get("age"))                 # 21（get 安全访问）
print(d.get("height", "未知"))       # 未知（get 带默认值）

# ========== 遍历 ==========
for key in d:                       # 遍历键
    print(key)
for value in d.values():            # 遍历值
    print(value)
for key, value in d.items():        # 遍历键值对
    print(f"{key}: {value}")
```

**字典操作时间复杂度速览**：

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `d[key]` 访问 | O(1) | 哈希查找 |
| `d[key] = value` 赋值 | O(1) | 哈希定位 + 写入 |
| `key in d` | O(1) | 哈希查找 |
| `del d[key]` | O(1) | 哈希定位 + 删除 |
| `d.get(key)` | O(1) | 哈希查找 |
| `len(d)` | O(1) | 直接读取 ob_size |
| `d.keys()` / `d.values()` / `d.items()` | O(1) | 返回视图对象 |
| `for k in d` 遍历 | O(n) | 逐个访问 |
| `d.update(other)` | O(len(other)) | 逐个合并 |

### 2.2 字典的创建方式详解

字典有多种创建方式，各有适用场景。

**字面量创建（最常用）**

用花括号 `{}` 把键值对括起来，键和值之间用冒号 `:` 分隔：

```python
# 标准创建
person = {"name": "张三", "age": 25}
prices = {"apple": 3.5, "banana": 2.8, "cherry": 8.0}

# 空字典
empty = {}

# 嵌套字典
school = {
    "name": "清华大学",
    "address": "北京",
    "departments": {
        "cs": "计算机学院",
        "math": "数学系",
    }
}
print(school["departments"]["cs"])   # 计算机学院
```

**dict() 构造函数**

`dict()` 有两种传参方式：

```python
# 方式一：关键字参数（键名必须是合法的 Python 标识符）
d1 = dict(name="张三", age=20, score=90.5)
print(d1)   # {'name': '张三', 'age': 20, 'score': 90.5}

# 方式二：从键值对列表/元组创建
pairs = [("a", 1), ("b", 2), ("c", 3)]
d2 = dict(pairs)
print(d2)   # {'a': 1, 'b': 2, 'c': 3}

# 从 zip 对象创建
keys = ["name", "age", "city"]
values = ["李四", 30, "上海"]
d3 = dict(zip(keys, values))
print(d3)   # {'name': '李四', 'age': 30, 'city': '上海'}
```

关键字参数方式的限制：键名必须是合法的 Python 标识符（不能含空格、不能以数字开头等），所以 `"my name"` 这样的键只能用字面量方式。

**字典推导式**

```python
# 基本推导式：从列表创建字典
squares = {x: x**2 for x in range(5)}
print(squares)   # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 带条件过滤
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}
print(even_squares)   # {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}

# 从另一个字典转换
prices = {"apple": 3.5, "banana": 2.8, "cherry": 8.0}
discounted = {k: round(v * 0.8, 2) for k, v in prices.items()}
print(discounted)   # {'apple': 2.8, 'banana': 2.24, 'cherry': 6.4}
```

**fromkeys() 方法**

`dict.fromkeys()` 用于批量创建键相同的字典，所有键共享同一个默认值：

```python
# 所有键初始化为 None
d = dict.fromkeys(["a", "b", "c"])
print(d)   # {'a': None, 'b': None, 'c': None}

# 指定默认值
d = dict.fromkeys(["a", "b", "c"], 0)
print(d)   # {'a': 0, 'b': 0, 'c': 0}

# 注意：可变默认值的陷阱
d = dict.fromkeys(["a", "b", "c"], [])
d["a"].append(1)
print(d)   # {'a': [1], 'b': [1], 'c': [1]}  ← 三个键共享同一个 list！
```

### 2.3 字典的键值对结构：键与值

字典的核心数据单元是"键值对"。理解键和值的各自规则，是正确使用字典的前提。

**键（key）的规则**

```python
# 规则一：键必须唯一——重复的键，后者覆盖前者
d = {"a": 1, "b": 2, "a": 99}
print(d)   # {'a': 99, 'b': 2}

# 规则二：键必须可哈希——不可变类型才能做键
valid_keys = {
    "string": "字符串键",
    42: "整数键",
    3.14: "浮点键",
    (0, 0): "元组键",        # tuple 不可变，可哈希 → OK
    True: "布尔键",
    frozenset([1, 2]): "frozenset 键",
}
print(valid_keys)

# 可变类型不能做键
try:
    d = {[1, 2]: "value"}
except TypeError as e:
    print(f"列表做键: {e}")   # unhashable type: 'list'

try:
    d = {{'a': 1}: "value"}
except TypeError as e:
    print(f"字典做键: {e}")   # unhashable type: 'dict'
```

**值（value）的规则**

```python
# 值没有类型限制，可以是任何对象
d = {
    "name": "张三",              # 字符串
    "age": 25,                   # 整数
    "active": True,              # 布尔
    "scores": [85, 92, 78],      # 列表
    "info": {"city": "北京"},    # 嵌套字典
    "callback": lambda x: x*2,  # 函数
}

# 值可以重复——不同的键可以指向相同的值
d2 = {"a": [1, 2], "b": [1, 2]}
print(d2)   # {'a': [1, 2], 'b': [1, 2]}
```

**键唯一的实际影响**

```python
# 场景：用字典更新数据，重复键自动覆盖
defaults = {"host": "localhost", "port": 80, "debug": False}
user_config = {"port": 8080, "debug": True}
defaults.update(user_config)      # 重复键被覆盖
print(defaults)
# {'host': 'localhost', 'port': 8080, 'debug': True}
```

### 2.4 字典的访问方式：通过键取值

字典最核心的操作就是通过键访问值。Python 提供了多种访问方式，各有适用场景。

**直接索引访问：`d[key]`**

```python
d = {"name": "张三", "age": 20, "major": "计算机科学"}

# 通过键直接取值——O(1)
print(d["name"])    # 张三
print(d["age"])     # 20

# 键不存在时报 KeyError
try:
    print(d["height"])
except KeyError as e:
    print(f"KeyError: {e}")   # KeyError: 'height'
```

`d[key]` 方式的特点：速度快，但键不存在时直接抛出 `KeyError`。如果你确定键一定存在，用这种方式最简洁。

**安全访问：`d.get(key, default)`**

```python
d = {"name": "张三", "age": 20}

# 键存在 → 返回值
print(d.get("name"))           # 张三
# 键不存在 → 返回 None（默认）
print(d.get("height"))         # None
# 键不存在 → 返回指定的默认值
print(d.get("height", "未知"))  # 未知

# get 不会修改字典
print(d)   # {'name': '张三', 'age': 20}  ← 没有添加 "height"
```

`get` 方式的特点：键不存在时返回默认值（不传则返回 `None`），不报错。当你不确定键是否存在时，用 `get` 更安全。

**参数和返回值**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `key` | 任意可哈希类型 | 无（必传） | 要查找的键 |
| `default` | 任意 | `None` | 键不存在时返回的值 |

| 返回值 | 说明 |
|--------|------|
| `value` | 键存在时返回对应的值 |
| `default` 或 `None` | 键不存在时返回默认值 |

**遍历访问**

```python
d = {"name": "张三", "age": 20, "score": 90.5}

# 遍历键
for key in d:
    print(key)
# name / age / score

# 遍历值
for value in d.values():
    print(value)
# 张三 / 20 / 90.5

# 遍历键值对
for key, value in d.items():
    print(f"{key}: {value}")
# name: 张三 / age: 20 / score: 90.5
```

**三种访问方式对比**：

| 方式 | 键不存在时 | 适用场景 |
|------|-----------|---------|
| `d[key]` | 抛出 `KeyError` | 确定键一定存在 |
| `d.get(key)` | 返回 `None` | 不确定键是否存在 |
| `d.get(key, default)` | 返回 `default` | 不确定键存在，且需要自定义默认值 |

### 2.5 字典的可变性：增删改操作

字典是可变容器——可以动态增加、删除、修改键值对，操作是**就地修改**，`id` 不变。

**增加键值对**

```python
d = {"a": 1, "b": 2}

# 方式一：直接赋值新键
d["c"] = 3
print(d)   # {'a': 1, 'b': 2, 'c': 3}

# 方式二：update() 批量添加
d.update({"d": 4, "e": 5})
print(d)   # {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5}

# 方式三：setdefault()——键不存在时才添加
d.setdefault("f", 6)
d.setdefault("a", 99)    # "a" 已存在，不做任何操作
print(d)   # {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6}
```

**修改键值对**

```python
d = {"name": "张三", "age": 20}

# 直接赋值已有键 → 修改值
d["age"] = 21
print(d)   # {'name': '张三', 'age': 21}

# update() 也可以修改
d.update({"name": "李四", "city": "上海"})
print(d)   # {'name': '李四', 'age': 21, 'city': '上海'}
```

**删除键值对**

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4}

# 方式一：del 关键字
del d["a"]
print(d)   # {'b': 2, 'c': 3, 'd': 4}

# 方式二：pop()——删除并返回被删的值
removed = d.pop("b")
print(f"删除了: {removed}")   # 删除了: 2
print(d)                      # {'c': 3, 'd': 4}

# pop() 键不存在时可以指定默认值
result = d.pop("z", "不存在")
print(result)   # 不存在

# 方式三：popitem()——删除并返回最后一个键值对（LIFO 顺序）
last = d.popitem()
print(f"弹出: {last}")   # 弹出: ('d', 4)
print(d)                  # {'c': 3}

# 方式四：clear()——清空字典
d.clear()
print(d)   # {}
```

**就地修改的 id 验证**

```python
d = {"a": 1, "b": 2}
print(id(d))        # 地址 A
d["c"] = 3          # 增
d["a"] = 99         # 改
del d["b"]          # 删
print(id(d))        # 地址 A（同一个对象，id 不变）
print(d)            # {'a': 99, 'c': 3}
```

### 2.6 字典的有序性

从 Python 3.7 开始，字典**保证插入顺序**——先插入的键值对在前，后插入的在后。这意味着字典的行为更接近一个"有序映射"。

```python
# 插入顺序就是遍历顺序
d = {}
d["banana"] = 2
d["apple"] = 1
d["cherry"] = 3
print(list(d.keys()))   # ['banana', 'apple', 'cherry']

# 字面量创建时也保持书写顺序
d2 = {"c": 3, "a": 1, "b": 2}
print(list(d2.keys()))   # ['c', 'a', 'b']

# 遍历时也保持顺序
for key in d2:
    print(key, d2[key])
# c 3 / a 1 / b 2
```

**有序性的实际影响**：

```python
# 删除再添加相同的键 → 该键移到末尾
d = {"a": 1, "b": 2, "c": 3}
print(list(d.keys()))   # ['a', 'b', 'c']

del d["a"]
d["a"] = 99             # 重新添加 "a" → 移到最后
print(list(d.keys()))   # ['b', 'c', 'a']

# 修改已有键的值 → 顺序不变
d["b"] = 200
print(list(d.keys()))   # ['b', 'c', 'a']  ← "b" 的位置没变
```

**注意**：Python 3.7 之前（3.6 是 CPython 实现细节，3.7 才作为语言保证），字典不保证插入顺序。如果你需要兼容旧版本，可以使用 `collections.OrderedDict`。

### 2.7 字典的成员判断：in 操作符

`in` 操作符用于检查一个键是否存在于字典中，时间复杂度 O(1)。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# in 检查键
print("name" in d)          # True
print("height" in d)        # False
print("name" not in d)      # False

# 重点：in 只检查键，不检查值
print("张三" in d)           # False（"张三" 是值，不是键）
print("张三" in d.values())  # True（在 values() 中查找）

# in vs get 的典型搭配
key = "score"
if key in d:
    print(f"{key} = {d[key]}")
else:
    print(f"{key} 不存在")

# 等价的更简洁写法
value = d.get(key, "不存在")
print(f"{key} = {value}")
```

**in 的时间复杂度对比**：

| 容器 | `x in container` | 原因 |
|------|-------------------|------|
| `dict` | O(1) | 哈希查找 |
| `set` | O(1) | 哈希查找 |
| `list` | O(n) | 线性扫描 |
| `tuple` | O(n) | 线性扫描 |

```python
# 性能对比：在 10 万元素中查找
import time
big_dict = {str(i): i for i in range(100000)}
big_list = [str(i) for i in range(100000)]
target = "99999"

# 字典 O(1)
start = time.perf_counter()
for _ in range(10000):
    _ = target in big_dict
dict_time = time.perf_counter() - start

# 列表 O(n)
start = time.perf_counter()
for _ in range(10000):
    _ = target in big_list
list_time = time.perf_counter() - start

print(f"字典: {dict_time:.4f} 秒")
print(f"列表: {list_time:.4f} 秒")
print(f"字典快了约 {list_time / max(dict_time, 1e-10):.0f} 倍")
```

### 2.8 字典的视图对象：keys()、values()、items()

`dict.keys()`、`dict.values()`、`dict.items()` 返回的不是列表，而是**视图对象**（view object）。视图对象是字典的"实时投影"——字典变化时，视图自动更新。

```python
d = {"a": 1, "b": 2, "c": 3}

# 三个视图对象
keys = d.keys()
values = d.values()
items = d.items()

print(type(keys))     # <class 'dict_keys'>
print(type(values))   # <class 'dict_values'>
print(type(items))    # <class 'dict_items'>

# 视图是实时投影——字典变化时视图同步更新
d["d"] = 4
print(list(keys))     # ['a', 'b', 'c', 'd']  ← 自动包含新键
print(list(values))   # [1, 2, 3, 4]
print(list(items))    # [('a', 1), ('b', 2), ('c', 3), ('d', 4)]
```

**视图对象的特性**：

```python
d = {"a": 1, "b": 2, "c": 3}

# 1. 可迭代——可以直接 for 遍历
for key in d.keys():
    print(key)

# 2. 支持 in 判断
print("a" in d.keys())      # True
print(1 in d.values())       # True
print(("a", 1) in d.items()) # True

# 3. 不支持索引访问（不是列表！）
# list(d.keys())[0]   # 可以先转 list 再索引
keys_list = list(d.keys())
print(keys_list[0])   # 'a'

# 4. 视图对象不能直接修改
# d.keys().append("e")   # AttributeError！
d["e"] = 5               # 只能通过修改字典来改变视图
```

**三个视图的对比**：

| 方法 | 返回类型 | 内容 | 用途 |
|------|---------|------|------|
| `d.keys()` | `dict_keys` | 所有键 | 检查键是否存在、遍历键 |
| `d.values()` | `dict_values` | 所有值 | 遍历值、检查值是否存在 |
| `d.items()` | `dict_items` | 所有键值对元组 | 遍历键值对、交集/并集运算 |

`dict_keys` 和 `dict_items` 支持集合运算（因为键是唯一的），`dict_values` 不支持（值可能重复）：

```python
d1 = {"a": 1, "b": 2, "c": 3}
d2 = {"b": 20, "c": 30, "d": 40}

# keys() 支持集合运算
print(d1.keys() & d2.keys())   # {'b', 'c'}（交集）
print(d1.keys() | d2.keys())   # {'a', 'b', 'c', 'd'}（并集）
print(d1.keys() - d2.keys())   # {'a'}（差集）

# items() 也支持集合运算
print(d1.items() & d2.items()) # set()（值不同，没有共同项）

# values() 不支持集合运算
# d1.values() & d2.values()  # TypeError: unsupported operand type
```

### 2.9 字典的键要求：可哈希性

字典之所以能做到 O(1) 查找，是因为底层用了**哈希表**。哈希表要求键必须是**可哈希的**——即键必须满足两个条件：能计算出哈希值，且哈希值生命周期内不变。

**什么是可哈希**

```python
# 可哈希对象：有固定的 __hash__ 方法，hash() 能返回固定整数
print(hash("hello"))       # 一个整数，如 -2599133897403531917
print(hash(42))            # 42
print(hash((1, 2, 3)))     # 一个整数

# 不可哈希对象：hash() 直接报错
try:
    hash([1, 2, 3])
except TypeError as e:
    print(f"hash([1,2,3]) → {e}")   # unhashable type: 'list'

try:
    hash({"a": 1})
except TypeError as e:
    print(f"hash(d) → {e}")           # unhashable type: 'dict'
```

**可哈希性规则**：

| 类型 | 可哈希 | 原因 |
|------|--------|------|
| `int` / `float` / `bool` | 是 | 不可变 |
| `str` | 是 | 不可变 |
| `tuple`（元素全可哈希） | 是 | 不可变 |
| `frozenset` | 是 | 不可变集合 |
| `None` | 是 | 不可变 |
| `list` | **否** | 可变 |
| `dict` | **否** | 可变 |
| `set` | **否** | 可变 |
| `tuple`（含可变元素） | **否** | 内含可变对象 |

```python
# 验证各种键类型

# 不可变类型做键 → OK
d = {
    "string": "字符串",
    42: "整数",
    3.14: "浮点数",
    (0, 0): "元组坐标",
    True: "布尔",
    None: "空值",
}
print(d[(0, 0)])   # 元组坐标

# 含可变元素的元组也不能做键
try:
    d = {(1, [2, 3]): "含列表的元组"}
except TypeError as e:
    print(f"含列表的元组做键 → {e}")   # unhashable type: 'list'
```

**为什么可变对象不能做键**

```python
# 假设 list 能做键（实际不行，这里假设理解）
# 如果允许 list 做键：
bad_dict = {[1, 2]: "a"}
bad_dict[[1, 2]].append(3)   # 修改了列表 → [1, 2, 3]
# 现在查找 [1, 2, 3] → hash 不一样了 → 找不到原来的值
# 原来的键 [1, 2]（已变成 [1,2,3]）→ 也找不到了
# 哈希表彻底混乱

# 所以 Python 规定：可变对象不可哈希，不能做键
```

### 2.10 字典的嵌套与深层访问

字典的值可以是任何对象，包括另一个字典（或列表），形成嵌套结构。访问嵌套数据时需要逐层深入。

```python
# 嵌套字典：公司 → 部门 → 员工
company = {
    "name": "TechCorp",
    "departments": {
        "engineering": {
            "head": "张三",
            "members": ["李四", "王五", "赵六"],
            "budget": 1000000,
        },
        "sales": {
            "head": "钱七",
            "members": ["孙八", "周九"],
            "budget": 500000,
        }
    }
}

# 逐层访问
print(company["name"])                          # TechCorp
print(company["departments"]["engineering"]["head"])  # 张三
print(company["departments"]["sales"]["members"][0])  # 孙八
```

**嵌套字典的修改**

```python
# 直接逐层赋值修改
company["departments"]["engineering"]["budget"] = 1200000
print(company["departments"]["engineering"]["budget"])   # 1200000

# 在嵌套列表中追加元素
company["departments"]["engineering"]["members"].append("吴十")
print(company["departments"]["engineering"]["members"])
# ['李四', '王五', '赵六', '吴十']
```

### 2.11 字典与列表的内存对比

字典的哈希表结构比列表的数组结构开销更大——需要存储哈希值、键、值三部分信息，还需要维护空闲槽位。

```python
import sys

# 空容器对比
print(f"空字典 {{}}: {sys.getsizeof(dict())} 字节")    # 64 字节
print(f"空列表 []: {sys.getsizeof([])} 字节")           # 56 字节

# 小规模数据对比
small_dict = {"a": 1, "b": 2, "c": 3}
small_list = ["a", 1, "b", 2, "c", 3]
print(f"3键值对字典: {sys.getsizeof(small_dict)} 字节")  # 184 字节
print(f"6元素列表:   {sys.getsizeof(small_list)} 字节")   # 104 字节
```

字典内存更大的原因：

| 维度 | dict | list |
|------|------|------|
| 存储内容 | 哈希值 + 键 + 值 | 值 |
| 空闲槽位 | 有（哈希表过度分配） | 有（预分配，但较少） |
| 哈希计算 | 需要存储 hash 值 | 不需要 |
| 碰撞处理 | 需要额外的探测机制 | 不需要 |

字典用空间换时间——多占一些内存，换来 O(1) 的查找速度。

## 3. 最佳实践

### 3.1 什么时候用字典，什么时候用列表

| 场景 | 推荐 | 原因 |
|------|------|------|
| 数据有"标签→值"的映射关系 | 字典 | 键值对结构天然适合 |
| 需要按名字快速查找 | 字典 | O(1) 查找 |
| 配置项 / 属性表 | 字典 | 键名自带语义 |
| 需要去重（用键） | 字典 | 键唯一 |
| 有序的同类元素集合 | 列表 | 索引访问更直观 |
| 需要排序 | 列表 | 列表支持 sort |
| 数据流式到来 | 列表 | append 灵活 |
| 需要栈/队列操作 | 列表 | append/pop 高效 |

```python
# 好：映射关系用字典
student = {"name": "张三", "age": 20, "score": 90.5}
print(student["name"])   # 语义清晰

# 坏：用列表存映射关系，必须记住位置编号
student_list = ["张三", 20, 90.5]
print(student_list[0])   # 0 是什么？读代码的人需要猜

# 好：有序同类集合用列表
fruits = ["apple", "banana", "cherry"]   # 有序、同类

# 坏：用字典存有序同类集合（键无意义）
fruits_dict = {0: "apple", 1: "banana", 2: "cherry"}  # 键名毫无意义
```

### 3.2 用 get 取代直接索引访问（键可能不存在时）

```python
d = {"name": "张三", "age": 20}

# 不推荐：直接索引访问 + 手动检查
if "score" in d:
    score = d["score"]
else:
    score = 0
print(score)

# 推荐：get 一步到位
score = d.get("score", 0)
print(score)

# 不推荐：直接索引，可能报错
# score = d["score"]   # KeyError！

# 推荐：确定键存在时才用直接索引
name = d["name"]   # 确定 "name" 一定在，直接索引更快
```

### 3.3 不要用可变对象做 fromkeys 的默认值

```python
# 不推荐：所有键共享同一个 list
d = dict.fromkeys(["a", "b", "c"], [])
d["a"].append(1)
print(d)   # {'a': [1], 'b': [1], 'c': [1]}  ← 三个键共享同一个 list！

# 推荐：用推导式各自创建独立 list
d = {k: [] for k in ["a", "b", "c"]}
d["a"].append(1)
print(d)   # {'a': [1], 'b': [], 'c': []}  ← 各自独立
```

原因：`fromkeys` 的默认值只在创建时传入一次，所有键引用同一个对象。修改其中一个，其他跟着变。

### 3.4 用 setdefault 处理"键不存在时初始化"

```python
# 场景：按专业分组学生

# 不推荐：手动判断
students = [("张三", "CS"), ("李四", "Math"), ("王五", "CS")]
groups = {}
for name, major in students:
    if major not in groups:
        groups[major] = []
    groups[major].append(name)
print(groups)

# 推荐：用 setdefault
groups = {}
for name, major in students:
    groups.setdefault(major, []).append(name)
print(groups)
# {'CS': ['张三', '王五'], 'Math': ['李四']}
```

`setdefault(key, default)` 的行为：如果键存在，返回已有值；如果不存在，设置 `d[key] = default` 并返回 `default`。一步完成"检查 + 初始化"。

### 3.5 遍历字典时的安全修改

```python
# 不推荐：遍历时修改字典大小 → RuntimeError
d = {"a": 1, "b": 2, "c": 3}
# for key in d:
#     if d[key] < 2:
#         del d[key]   # RuntimeError: dictionary changed size during iteration

# 推荐：先记录要删除的键，遍历后再删
to_delete = [key for key, value in d.items() if value < 2]
for key in to_delete:
    del d[key]
print(d)   # {'b': 2, 'c': 3}

# 推荐：用推导式创建新字典（不变通则变）
d = {"a": 1, "b": 2, "c": 3}
d = {k: v for k, v in d.items() if v >= 2}
print(d)   # {'b': 2, 'c': 3}
```

## 4. 原理

### 4.1 字典的底层结构：哈希表

Python 字典底层是一个**哈希表**（Hash Table）——一种用"键的哈希值"直接计算存储位置的数据结构。

```text
字典 d = {"name": "张三", "age": 20, "score": 90.5}

哈希表结构（简化示意）：

索引槽位      哈希值        键          值
┌─────────┬──────────┬───────────┬───────────┐
│    0    │   ...    │   ...     │   ...     │  (空槽)
│    1    │  hash_1  │  "name"   │  "张三"    │  ← 存储位置 = hash("name") % 表大小
│    2    │   ...    │   ...     │   ...     │  (空槽)
│    3    │  hash_2  │  "age"    │   20      │  ← 存储位置 = hash("age") % 表大小
│    4    │  hash_3  │  "score"  │  90.5     │  ← 存储位置 = hash("score") % 表大小
│   ...   │   ...    │   ...     │   ...     │
└─────────┴──────────┴───────────┴───────────┘

查找过程：d["name"]
  1. 计算 hash("name") → 得到一个大整数
  2. hash % 表大小 → 得到索引位置 1
  3. 直接访问索引 1 → 拿到值 "张三"
  整个过程 O(1)
```

**为什么 O(1)？**

因为哈希函数把"键"直接映射到"数组索引"——不需要从头扫描，而是一次定位。

### 4.2 哈希冲突与开放寻址法

不同的键可能算出同一个哈希值（或取模后落到同一个槽位），这叫**哈希冲突**。Python 用**开放寻址法**（Open Addressing）处理冲突——冲突时往后找下一个空槽。

```text
冲突场景：

假设 hash("name") % 8 = 1
假设 hash("id")   % 8 = 1  ← 冲突！

槽位 1: "name" → "张三"   (已占用)
槽位 2: "id"   → 1001    (冲突，往后找一个空槽)

查找 "id" 时：
  1. hash("id") % 8 = 1
  2. 槽位 1 存的是 "name" ≠ "id" → 冲突
  3. 往后探查槽位 2 → 存的是 "id" → 命中
```

Python 3.6+ 使用了一种改进的哈希表实现——**紧凑哈希表**（Compact Dict），把键值对的存储和索引数组分离，既节省内存又保证有序性。

```python
# 验证哈希冲突的存在
# 字符串 "a" 和某个数可能产生相同的哈希值取模
# 但 Python 内部自动处理冲突，用户无需关心
d = {}
for i in range(1000):
    d[f"key_{i}"] = i    # 即使有冲突，字典也能正确存取
print(len(d))   # 1000（全部正确存储）
```

### 4.3 字典的动态扩容

哈希表不能装得太满——装填因子（已用槽数 / 总槽数）超过约 2/3 时，查找效率会下降。Python 字典在装填因子超过阈值时自动扩容。

```python
import sys

# 观察字典扩容时的内存变化
d = {}
sizes = []
for i in range(20):
    d[i] = i
    sizes.append(sys.getsizeof(d))

print("字典增长时的内存变化（字节）:")
for i, size in enumerate(sizes):
    print(f"  len={i+1:2d}: {size} 字节")
```

运行结果示例：

```text
len= 1: 184 字节
len= 2: 184 字节
...
len= 6: 184 字节    ← 同一段大小内
len= 7: 368 字节    ← 扩容！大小翻倍
...
len=12: 368 字节
len=13: 368 字节
...
```

扩容的步骤：
1. 分配新的更大的哈希表（通常是当前大小的 2 倍以上）
2. 把所有键值对重新哈希，放入新表
3. 释放旧表

扩容是 O(n) 操作，但因为是分摊的（amortized），平均下来每次插入仍然是 O(1)。

### 4.4 字典有序性的实现：紧凑哈希表

Python 3.6 引入了紧凑哈希表，3.7 正式将"插入有序"作为语言保证。实现思路是把"索引数组"和"键值对数组"分离：

```text
紧凑哈希表结构：

字典 d = {"c": 3, "a": 1, "b": 2}（按插入顺序）

1. 索引数组（紧凑，含空槽）
   ┌────┬────┬────┬────┬────┬────┬────┬────┐
   │ 0  │ 1  │ -1 │ 2  │ -1 │ -1 │ -1 │ -1 │   (-1 表示空槽)
   └────┴────┴────┴────┴────┴────┴────┴────┘
     ↓    ↓         ↓
     指向  指向      指向

2. 键值对数组（紧凑排列，无空隙，按插入顺序）
   ┌───┬─────┬───┬───┬─────┬───┬───┬─────┬───┐
   │ 0 │ "c" │ 3 │ 1 │ "a" │ 1 │ 2 │ "b" │ 2 │
   └───┴─────┴───┴───┴─────┴───┴───┴─────┴───┘
     索引  键   值     键   值     键   值
     (插入顺序：c → a → b)

查找 "a":
  1. hash("a") % 索引数组大小 → 得到索引位置
  2. 索引数组中该位置的值 → 1（指向键值对数组的第 1 组）
  3. 键值对数组第 1 组 → ("a", 1) → 返回 1

遍历时：
  直接按键值对数组的紧凑顺序遍历 → 自然就是插入顺序
```

这种设计的好处：
- **内存更省**：索引数组只需要整数（可以很小），键值对数组无空隙
- **有序保证**：键值对数组按插入顺序排列，遍历天然有序
- **查找仍 O(1)**：索引数组负责快速定位，不影响查找效率

### 4.5 PyDictObject 结构详解

CPython 中字典由 `PyDictObject` 结构体实现。核心是两个数组——一个稀疏的索引数组和一个紧凑的键值对数组。

```c
// 简化的 PyDictObject 结构（Python 3.6+ 紧凑实现）
typedef struct {
    PyObject_HEAD
    Py_ssize_t ma_used;        // 已使用的键值对数量（len() 返回此值）
    uint64_t ma_version_tag;   // 版本标签（用于优化）
    PyDictKeysObject *ma_keys; // 指向键结构（包含索引数组和键数组）
    PyObject **ma_values;      // 指向值数组（分离存储时使用）
} PyDictObject;
```

与列表的结构对比：

| 字段 | PyDictObject | PyListObject |
|------|-------------|--------------|
| 元素数量 | `ma_used` | `ob_size` |
| 数据指针 | `ma_keys` + `ma_values` | `ob_item` |
| 扩容方式 | 重建哈希表 | `list_resize` |
| 存储内容 | 哈希 + 键 + 值 | 值（指针数组） |
| 有序性 | 插入顺序（紧凑表保证） | 数组顺序 |

字典结构更复杂，但换来了 O(1) 查找和语义清晰的键值映射。

### 4.6 空字典的优化

与空元组类似，空字典在 CPython 中也有特殊优化——虽然不像空元组那样是全局单例，但空字典的创建开销已经很小：

```python
# 空字典不是单例（不同对象）
a = {}
b = {}
print(a is b)   # False（不同对象）

# 但空字典占用内存已经优化
import sys
print(f"空字典: {sys.getsizeof({})} 字节")   # 64 字节
print(f"空列表: {sys.getsizeof([])} 字节")   # 56 字节
```

## 5. 总结

本文围绕"字典概述与基本概念"展开，核心内容如下：

- **字典定义**：Python 中最核心的映射类型，通过"键→值"的方式存储数据。与列表的"位置→值"不同，字典用任意不可变对象作为键，通过哈希表实现 O(1) 查找。

- **基本特性**：键值映射（通过键找值）、键唯一（同键取最后值）、可变（增删改就地修改）、键需可哈希（不可变类型才能做键）、有序（3.7+ 保证插入顺序）。

- **创建方式**：字面量 `{}`（最常用）、`dict()` 关键字参数、`dict()` 从键值对列表、字典推导式、`fromkeys()` 批量创建。

- **访问方式**：`d[key]` 直接访问（键不存在报 `KeyError`）、`d.get(key, default)` 安全访问（键不存在返回默认值）、遍历 `keys()` / `values()` / `items()` 视图对象。

- **可变性**：可增删改，就地修改 id 不变。增加用 `d[new_key] = value` 或 `update()`，删除用 `del` / `pop()` / `popitem()` / `clear()`。遍历时不能修改字典大小，需先记录后修改。

- **键的要求**：键必须可哈希——`int`、`str`、`tuple`（全不可变元素）等不可变类型可以做键，`list`、`dict`、`set` 等可变类型不能做键。可哈希意味着 `hash()` 能返回固定整数。

- **视图对象**：`keys()` / `values()` / `items()` 返回视图而非列表，是字典的实时投影，字典变化时视图同步更新。`dict_keys` 和 `dict_items` 支持集合运算。

- **底层原理**：字典基于哈希表，Python 3.6+ 使用紧凑哈希表（索引数组 + 键值对数组分离），在保证 O(1) 查找的同时实现插入有序且节省内存。装填因子超阈值时自动扩容（O(n) 分摊到 O(1)）。

- **最佳实践**：映射关系用字典、有序同类集合用列表；不确定键是否存在时用 `get`；`fromkeys` 不用可变默认值；分组归类用 `setdefault`；遍历时不可修改字典大小。
