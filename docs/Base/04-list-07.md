# insert、pop 与 remove 方法

## 1. 介绍

`insert`、`pop` 和 `remove` 是 Python 列表用于在任意位置插入和删除元素的三种核心方法。`append` 和 `extend` 只能在列表末尾追加，而 `insert` 可以在指定位置插入、`pop` 可以按索引弹出并返回值、`remove` 可以按值删除。再加上 `del` 语句和 `clear` 方法，构成了 Python 列表完整的增删操作体系。

理解这三个方法的核心在于搞清楚它们的**定位方式**——`insert` 和 `pop` 用索引定位，`remove` 用值定位；以及**返回值差异**——`pop` 返回被删除的元素，`insert` 和 `remove` 返回 `None`。此外，`insert(0, x)` 和 `pop(0)` 的时间复杂度是 O(n)，在头部频繁操作会导致性能问题，这也是实际开发中需要特别注意的。

**最简示例**

用 `insert` 在指定位置插入、用 `pop` 弹出末尾元素、用 `remove` 按值删除：

```python
# insert：在索引1处插入 2
lst = [1, 3, 4]
lst.insert(1, 2)
print(lst)

# pop：弹出末尾元素
stack = [1, 2, 3]
top = stack.pop()
print(f"弹出: {top}, 剩余: {stack}")

# remove：按值删除第一个匹配
fruits = ["apple", "banana", "cherry"]
fruits.remove("banana")
print(fruits)
```

运行结果：

```text
[1, 2, 3, 4]
弹出: 3, 剩余: [1, 2]
['apple', 'cherry']
```

## 2. 核心内容

列表的插入与删除方法可以分为以下几种：

| 方法 | 定位方式 | 功能 | 返回值 | 时间复杂度 |
|------|---------|------|--------|-----------|
| `insert(i, x)` | 索引 | 在索引 i 处插入 x | `None` | O(n) |
| `pop(i=-1)` | 索引 | 弹出索引 i 的元素 | 被弹出的元素 | O(1) 末尾 / O(n) 中间 |
| `remove(x)` | 值 | 删除第一个等于 x 的元素 | `None` | O(n) |
| `del lst[i]` | 索引 | 删除索引 i 的元素 | 无 | O(n) |
| `del lst[i:j]` | 切片 | 删除切片范围的元素 | 无 | O(n) |
| `clear()` | - | 清空整个列表 | `None` | O(n) |

下面逐一详细讲解。

### 2.1 insert 方法

`insert` 在指定索引位置插入一个元素，原位置及之后的元素向后移动。语法如下：

```python
列表.insert(索引, 对象)
```

第一个参数是索引位置，第二个参数是要插入的对象。列表长度增加 1。

**基本用法**

```python
lst = [1, 3, 4]
lst.insert(1, 2)  # 在索引1处插入 2
print(lst)
```

运行结果：

```text
[1, 2, 3, 4]
```

原来索引 1 处的元素 `3` 和索引 2 处的元素 `4` 都向后移动了一位，`2` 被插入到索引 1 的位置。

**在开头插入**

```python
lst2 = [2, 3, 4]
lst2.insert(0, 1)
print(lst2)
```

运行结果：

```text
[1, 2, 3, 4]
```

`insert(0, 1)` 把 `1` 插入到列表开头，所有原有元素都向后移动一位。

**在末尾插入（等价于 append）**

```python
lst3 = [1, 2, 3]
lst3.insert(len(lst3), 4)
print(lst3)
```

运行结果：

```text
[1, 2, 3, 4]
```

`insert(len(lst), x)` 等价于 `lst.append(x)`，但 `append` 更直观、更高效（O(1) vs O(1)，但 `append` 的常数因子更小）。

**索引越界处理——自动调整到边界**

```python
lst4 = [1, 2, 3]
lst4.insert(100, 4)  # 索引超出范围，等同于 append
print(f"insert(100, 4): {lst4}")

lst5 = [1, 2, 3]
lst5.insert(-100, 0)  # 负索引超出范围，等同于 insert(0, 0)
print(f"insert(-100, 0): {lst5}")
```

运行结果：

```text
insert(100, 4): [1, 2, 3, 4]
insert(-100, 0): [0, 1, 2, 3]
```

`insert` 不论索引多大（或多小），都不会报错——超出正索引范围时等同 `append`，超出负索引范围时等同 `insert(0, x)`。这是 `insert` 和 `pop` 的一个重要区别：`pop` 索引越界会报 `IndexError`，而 `insert` 不会。

**负索引插入**

```python
lst6 = [1, 2, 3, 5]
lst6.insert(-1, 4)  # 在倒数第1个位置前插入
print(lst6)
```

运行结果：

```text
[1, 2, 3, 4, 5]
```

`insert(-1, 4)` 在倒数第 1 个元素（索引 -1，即 `5`）的前面插入 `4`。注意：`insert(-1, x)` 不是在末尾追加，而是在最后一个元素前面插入。

**insert 返回 None**

```python
lst7 = [1, 2, 3]
result = lst7.insert(0, 0)
print(f"返回值: {result}")
print(f"列表: {lst7}")
```

运行结果：

```text
返回值: None
列表: [0, 1, 2, 3]
```

和 `append`、`extend` 一样，`insert` 是原地修改方法，返回 `None`。

**实际场景：按优先级插入任务**

```python
tasks = []
tasks.insert(0, "低优先级任务")
tasks.insert(0, "高优先级任务")  # 插入到队首
print(f"任务队列: {tasks}")
```

运行结果：

```text
任务队列: ['高优先级任务', '低优先级任务']
```

利用 `insert(0, x)` 可以实现"后来居上"的优先队列——新消息总是插到队列开头，最先被处理。

### 2.2 pop 方法

`pop` 弹出（删除并返回）指定索引位置的元素。语法如下：

```python
列表.pop(index=-1)
```

默认弹出末尾元素（索引 -1）。可以传入索引参数弹出任意位置的元素。与 `remove` 和 `del` 不同，`pop` **返回被删除的值**——这是 `pop` 最重要的特征。

**默认弹出末尾元素**

```python
stack = [1, 2, 3, 4, 5]
top = stack.pop()
print(f"弹出: {top}")
print(f"剩余: {stack}")
```

运行结果：

```text
弹出: 5
剩余: [1, 2, 3, 4]
```

`pop()` 不传参数时弹出末尾元素，时间复杂度为 O(1)。

**弹出指定索引元素**

```python
lst = ["apple", "banana", "cherry", "date"]
removed = lst.pop(1)
print(f"弹出索引1: {removed}")
print(f"剩余: {lst}")
```

运行结果：

```text
弹出索引1: banana
剩余: ['apple', 'cherry', 'date']
```

`pop(1)` 弹出索引 1 的元素 `"banana"`，之后的元素向前移动。弹出中间元素的时间复杂度为 O(n)。

**负索引弹出**

```python
lst2 = [10, 20, 30, 40, 50]
last = lst2.pop(-1)
second_last = lst2.pop(-1)
print(f"弹出倒数第1: {last}")
print(f"弹出倒数第2: {second_last}")
print(f"剩余: {lst2}")
```

运行结果：

```text
弹出倒数第1: 50
弹出倒数第2: 40
剩余: [10, 20, 30]
```

`pop(-1)` 弹出最后一个，`pop(-1)` 再弹出新的最后一个（原来的倒数第二个）。

**pop 返回被弹出的值——区别于 remove 和 del**

```python
queue = ["task_a", "task_b", "task_c"]
while queue:
    task = queue.pop(0)  # 从队首弹出
    print(f"处理: {task}, 剩余: {queue}")
```

运行结果：

```text
处理: task_a, 剩余: ['task_b', 'task_c']
处理: task_b, 剩余: ['task_c']
处理: task_c, 剩余: []
```

`pop(0)` 从队首弹出一个元素并返回它。这个模式常用于实现队列（先进先出）。但注意 `pop(0)` 的时间复杂度是 O(n)，因为需要移动所有剩余元素。

**空列表 pop 报错**

```python
empty = []
try:
    empty.pop()
except IndexError as e:
    print(f"空列表 pop() → IndexError: {e}")
```

运行结果：

```text
空列表 pop() → IndexError: pop from empty list
```

对空列表调用 `pop()` 会抛出 `IndexError`，错误信息是 `"pop from empty list"`。

**索引越界报错**

```python
lst3 = [1, 2, 3]
try:
    lst3.pop(10)
except IndexError as e:
    print(f"pop(10) → IndexError: {e}")
```

运行结果：

```text
pop(10) → IndexError: pop index out of range
```

`pop(10)` 索引超出列表长度时抛出 `IndexError`，错误信息是 `"pop index out of range"`。

**实际场景：实现栈（后进先出）**

```python
stack2 = []
for i in range(1, 4):
    stack2.append(f"操作{i}")
    print(f"入栈: {stack2}")

print("---")
while stack2:
    item = stack2.pop()
    print(f"出栈: {item}, 剩余: {stack2}")
```

运行结果：

```text
入栈: ['操作1']
入栈: ['操作1', '操作2']
入栈: ['操作1', '操作2', '操作3']
---
出栈: 操作3, 剩余: ['操作1', '操作2']
出栈: 操作2, 剩余: ['操作1']
出栈: 操作1, 剩余: []
```

`append` + `pop()` 是实现栈的标准模式——`append` 入栈，`pop()` 出栈，都是末尾操作，O(1) 时间复杂度。

### 2.3 remove 方法

`remove` 按值删除列表中**第一个**匹配的元素。语法如下：

```python
列表.remove(值)
```

参数是要删除的值（不是索引）。`remove` 从左到右搜索第一个等于该值的元素，找到后删除它。列表长度减 1。

**基本用法**

```python
fruits = ["apple", "banana", "cherry", "banana"]
fruits.remove("banana")  # 只删除第一个匹配的
print(fruits)
```

运行结果：

```text
['apple', 'cherry', 'banana']
```

列表中有两个 `"banana"`，`remove` 只删除第一个（索引 1），第二个（现在的索引 2）保留不变。

**remove 只删第一个匹配**

```python
nums = [1, 2, 3, 2, 4, 2]
nums.remove(2)
print(nums)
```

运行结果：

```text
[1, 3, 2, 4, 2]
```

三个 `2` 只有第一个被删除，后两个保留。

**删除所有匹配项（需要循环）**

```python
nums2 = [1, 2, 3, 2, 4, 2]
while 2 in nums2:
    nums2.remove(2)
print(f"删除所有2: {nums2}")
```

运行结果：

```text
删除所有2: [1, 3, 4]
```

`remove` 只删一个，要删除所有匹配项需要配合 `while` 循环。但这种方法的时间复杂度是 O(n^2)，因为每次 `remove` 都要线性搜索 + 移动元素。对于大批量删除，推荐用列表推导式过滤：

```python
filtered = [x for x in nums2 if x != 2]
```

**元素不存在报错**

```python
lst = [1, 2, 3]
try:
    lst.remove(5)
except ValueError as e:
    print(f"remove(5) → ValueError: {e}")
```

运行结果：

```text
remove(5) → ValueError: list.remove(x): x not in list
```

如果值不存在于列表中，`remove` 抛出 `ValueError`，错误信息是 `"list.remove(x): x not in list"`。这与 `pop` 的越界报错（`IndexError`）不同——`pop` 是索引问题，`remove` 是值问题。

**remove 返回 None**

```python
lst2 = ["a", "b", "c"]
result = lst2.remove("b")
print(f"返回值: {result}")
print(f"列表: {lst2}")
```

运行结果：

```text
返回值: None
列表: ['a', 'c']
```

`remove` 返回 `None`，不返回被删除的值——这是它与 `pop` 的一个关键区别。如果你既需要删除元素又需要获取它的值，用 `pop`；如果你只知道值不需要返回值，用 `remove`。

**remove 与 in 搭配（安全删除）**

```python
data = [10, 20, 30]
target = 25
if target in data:
    data.remove(target)
else:
    print(f"{target} 不在列表中，无需删除")

target2 = 20
if target2 in data:
    data.remove(target2)
    print(f"已删除 {target2}，剩余: {data}")
```

运行结果：

```text
25 不在列表中，无需删除
已删除 20，剩余: [10, 30]
```

为避免 `ValueError`，可以先检查 `值 in 列表` 再调用 `remove`。或者用 `try/except` 捕获异常。

**实际场景：清理无效数据**

```python
records = ["ok", "error", "ok", "error", "ok", "timeout"]
# 删除第一个 "error"
records.remove("error")
print(f"删除第一个error: {records}")
# 删除所有 "error"
while "error" in records:
    records.remove("error")
print(f"删除所有error: {records}")
```

运行结果：

```text
删除第一个error: ['ok', 'ok', 'error', 'ok', 'timeout']
删除所有error: ['ok', 'ok', 'ok', 'timeout']
```

### 2.4 del 语句与 clear 方法

除了 `insert`、`pop`、`remove`，Python 还提供了 `del` 语句和 `clear` 方法来删除列表元素。

#### 2.4.1 del 语句

`del` 是 Python 关键字（不是方法），用于删除指定索引或切片范围的元素。

**del 删除单个元素**

```python
lst = [10, 20, 30, 40, 50]
del lst[2]  # 删除索引2的元素
print(f"del lst[2]: {lst}")
```

运行结果：

```text
del lst[2]: [10, 20, 40, 50]
```

`del lst[2]` 删除索引 2 的元素 `30`，之后的元素前移。

**del 切片删除——批量删除**

```python
lst2 = [10, 20, 30, 40, 50, 60, 70]
del lst2[1:4]  # 删除索引1~3的元素
print(f"del lst2[1:4]: {lst2}")
```

运行结果：

```text
del lst2[1:4]: [10, 50, 60, 70]
```

`del lst2[1:4]` 一次性删除索引 1~3 的元素（`20`、`30`、`40`）。这是 `del` 相比 `pop` 和 `remove` 的独特优势——支持切片批量删除。

**del 负索引删除**

```python
lst3 = [1, 2, 3, 4, 5]
del lst3[-1]  # 删除最后一个
print(f"del lst3[-1]: {lst3}")
```

运行结果：

```text
del lst3[-1]: [1, 2, 3, 4]
```

**del 删除整个变量**

```python
lst4 = [1, 2, 3]
del lst4
try:
    print(lst4)
except NameError as e:
    print(f"del 后变量不存在: {e}")
```

运行结果：

```text
del 后变量不存在: name 'lst4' is not defined
```

`del lst4` 删除变量本身，之后引用 `lst4` 会得到 `NameError`。这和删除列表元素不同——它删除的是变量绑定，不是列表中的元素。

**del 索引越界报错**

```python
lst5 = [1, 2, 3]
try:
    del lst5[10]
except IndexError as e:
    print(f"del lst5[10] → IndexError: {e}")
```

运行结果：

```text
del lst5[10] → IndexError: list assignment index out of range
```

`del` 索引越界时抛出 `IndexError`，错误信息是 `"list assignment index out of range"`。

#### 2.4.2 clear 方法

`clear` 清空列表的所有元素，使其变为空列表。语法如下：

```python
列表.clear()
```

**clear 清空列表**

```python
lst6 = [1, 2, 3, 4, 5]
lst6.clear()
print(f"clear后: {lst6}")
print(f"类型: {type(lst6).__name__}")
```

运行结果：

```text
clear后: []
类型: list
```

`clear` 后列表变为空列表 `[]`，但仍然是 `list` 类型——它清空内容，不删除变量。

**clear vs 赋空列表的区别**

```python
# clear 原地清空，id 不变，引用也看到变化
original = [1, 2, 3]
ref = original
original.clear()
print(f"clear后 original: {original}")
print(f"ref 也变了: {ref}")

# 赋空列表创建新对象，原列表和引用不变
original2 = [1, 2, 3]
ref2 = original2
original2 = []
print(f"赋空后 original2: {original2}")
print(f"ref2 不变: {ref2}")
```

运行结果：

```text
clear后 original: []
ref 也变了: []
赋空后 original2: []
ref2 不变: [1, 2, 3]
```

这是 `clear` 和 `original = []` 的关键区别：

```text
original.clear() → 原地修改，id 不变，所有引用都看到空列表
original = []    → 创建新的空列表对象，id 变了，其他引用仍指向旧列表
```

如果多个变量指向同一个列表，`clear` 会让所有引用都看到空列表，而赋空列表只会影响当前变量。

### 2.5 pop 与 remove 的核心区别

`pop` 和 `remove` 都是删除元素的方法，但定位方式和行为截然不同：

| 维度 | `pop(index)` | `remove(value)` |
|------|------------|----------------|
| 定位方式 | 按索引 | 按值 |
| 返回值 | 返回被删除的元素 | `None` |
| 越界报错 | `IndexError` | `ValueError` |
| 删除范围 | 指定索引的一个元素 | 第一个匹配值的元素 |
| 默认行为 | `pop()` 默认弹出末尾 | 无默认，必须传值 |

**典型用法对比**

```python
# pop：知道位置，需要获取被删除的值
lst = [10, 20, 30, 40]
value = lst.pop(2)  # 弹出索引2，获取值
print(f"pop 得到了: {value}")

# remove：知道值，不需要返回值
lst2 = [10, 20, 30, 40]
lst2.remove(20)  # 删除值20
print(f"remove 后: {lst2}")
```

运行结果：

```text
pop 得到了: 30
remove 后: [10, 30, 40]
```

简单规则：知道位置用 `pop`，知道值用 `remove`；需要返回值用 `pop`，不需要返回值用 `remove` 或 `del`。

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

| 场景 | 推荐写法 | 不推荐写法 | 原因 |
|------|---------|-----------|------|
| 删除末尾并取值 | `lst.pop()` | `val = lst[-1]; del lst[-1]` | pop 一步到位 |
| 删除指定值 | `lst.remove(x)` | 循环找到索引再 pop | remove 语义更明确 |
| 删除所有匹配值 | `[x for x in lst if x != target]` | `while target in lst: lst.remove(target)` | 推导式 O(n) vs while O(n^2) |
| 清空列表 | `lst.clear()` | `lst = []` 或 `del lst[:]` | clear 语义明确，原地修改 |
| 删除切片 | `del lst[1:4]` | 逐个 pop | 切片删除一步到位 |
| 头部插入 | `collections.deque` + `appendleft` | `lst.insert(0, x)` 循环 | insert(0) 是 O(n) |
| 安全删除 | `if x in lst: lst.remove(x)` | `lst.remove(x)` 直接调用 | 避免 ValueError |

### 3.2 常见错误模式

**错误一：遍历列表时删除元素——经典陷阱**

```python
# 错误：边遍历边 remove，会跳过元素
nums = [1, 2, 2, 3, 2, 4]
# for x in nums:
#     if x == 2:
#         nums.remove(x)  # 会漏删！
# 结果: [1, 2, 3, 2, 4] 只删了一个2，漏了两个

# 正确方式1：while + in
nums1 = [1, 2, 2, 3, 2, 4]
while 2 in nums1:
    nums1.remove(2)
print(f"while+remove: {nums1}")

# 正确方式2：新建列表过滤
nums2 = [1, 2, 2, 3, 2, 4]
filtered = [x for x in nums2 if x != 2]
print(f"推导式过滤: {filtered}")

# 正确方式3：倒序遍历后删除
nums3 = [1, 2, 2, 3, 2, 4]
for i in range(len(nums3) - 1, -1, -1):
    if nums3[i] == 2:
        del nums3[i]
print(f"倒序del: {nums3}")
```

运行结果：

```text
while+remove: [1, 3, 4]
推导式过滤: [1, 3, 4]
倒序del: [1, 3, 4]
```

遍历时 `remove` 的问题在于：`remove` 删除元素后列表变短了，循环的索引会跳过下一个元素。解决方法有三种：

1. `while + in`：安全但 O(n^2)
2. 列表推导式过滤：简洁高效 O(n)
3. 倒序遍历 + `del`：可原地修改且不跳元素

**错误二：pop 空列表**

```python
empty = []
try:
    empty.pop()
except IndexError as e:
    print(f"pop() → IndexError: {e}")

# 安全做法：先检查长度
data = []
if data:
    item = data.pop()
else:
    print("列表为空，不能 pop")
```

运行结果：

```text
pop() → IndexError: pop from empty list
列表为空，不能 pop
```

对空列表 `pop` 会抛出 `IndexError`。安全做法是在 `pop` 前检查列表是否非空，或者用 `try/except` 捕获异常。

**错误三：remove 不存在的值**

```python
lst = [1, 2, 3]
try:
    lst.remove(5)
except ValueError as e:
    print(f"remove(5) → ValueError: {e}")

# 安全做法：先检查 in
if 5 in lst:
    lst.remove(5)
else:
    print("5 不在列表中")
```

运行结果：

```text
remove(5) → ValueError: list.remove(x): x not in list
5 不在列表中
```

`remove` 不存在的值会抛出 `ValueError`。安全做法是先检查 `值 in 列表`，或用 `try/except` 捕获。

**错误四：在头部频繁 insert**

```python
import time

# 在开头 insert：O(n) 每次都要移动所有元素
start = time.perf_counter()
lst_head = []
for i in range(50000):
    lst_head.insert(0, i)
time_head = time.perf_counter() - start

# 在末尾 append：O(1) 均摊
start = time.perf_counter()
lst_tail = []
for i in range(50000):
    lst_tail.append(i)
time_tail = time.perf_counter() - start

print(f"头部insert: {time_head:.4f} 秒")
print(f"尾部append: {time_tail:.4f} 秒")
print(f"速度比: {time_head / time_tail:.1f}x")
```

运行结果：

```text
头部insert: 0.4854 秒
尾部append: 0.0019 秒
速度比: 250.5x
```

`insert(0, x)` 每次都要把所有现有元素后移一位，循环 N 次的总时间复杂度是 O(n^2)。而 `append` 是 O(1) 均摊。在头部频繁插入时，应该改用 `collections.deque`（双端队列），它的 `appendleft` 和 `popleft` 都是 O(1)。

**错误五：在头部频繁 pop(0)**

```python
queue = list(range(50000))

start = time.perf_counter()
while queue:
    queue.pop(0)  # O(n) 每次都要移动所有元素
time_pop0 = time.perf_counter() - start

queue2 = list(range(50000))
start = time.perf_counter()
while queue2:
    queue2.pop()  # O(1) 末尾弹出
time_pop = time.perf_counter() - start

print(f"pop(0):    {time_pop0:.4f} 秒")
print(f"pop():     {time_pop:.4f} 秒")
print(f"速度比: {time_pop0 / time_pop:.1f}x")
```

运行结果：

```text
pop(0):    0.1881 秒
pop():     0.0012 秒
速度比: 156.9x
```

`pop(0)` 每次都要把所有剩余元素前移一位，循环 N 次的总时间复杂度是 O(n^2)。如果需要频繁从头部弹出，同样建议用 `collections.deque`。

### 3.3 方法速查表

| 方法 | 语法 | 定位方式 | 返回值 | 越界/不存在 | 时间复杂度 |
|------|------|---------|--------|-----------|-----------|
| `insert(i, x)` | `lst.insert(i, x)` | 索引 | `None` | 自动调整到边界 | O(n) |
| `pop(i)` | `lst.pop(i=-1)` | 索引 | 被删除的元素 | `IndexError` | O(1) 末尾 / O(n) 中间 |
| `remove(x)` | `lst.remove(x)` | 值 | `None` | `ValueError` | O(n) |
| `del lst[i]` | `del lst[i]` | 索引 | 无返回值 | `IndexError` | O(n) |
| `del lst[i:j]` | `del lst[i:j]` | 切片 | 无返回值 | - | O(n) |
| `clear()` | `lst.clear()` | - | `None` | - | O(n) |

### 3.4 实际应用场景

**栈（后进先出 LIFO）**

```python
stack = []
for item in ["页面A", "页面B", "页面C"]:
    stack.append(item)
    print(f"  入栈: {item} → {stack}")

print("  ---")
while stack:
    current = stack.pop()
    print(f"  出栈: {current} → {stack}")
```

运行结果：

```text
  入栈: 页面A → ['页面A']
  入栈: 页面B → ['页面A', '页面B']
  入栈: 页面C → ['页面A', '页面B', '页面C']
  ---
  出栈: 页面C → ['页面A', '页面B']
  出栈: 页面B → ['页面A']
  出栈: 页面A → []
```

栈是最自然使用 `append` + `pop()` 的场景。所有操作在列表尾部完成，时间复杂度均为 O(1)。

**队列（先进先出 FIFO）**

```python
queue = []
for task in ["任务1", "任务2", "任务3"]:
    queue.append(task)
    print(f"  入队: {task} → {queue}")

print("  ---")
while queue:
    current = queue.pop(0)
    print(f"  出队: {current} → {queue}")
```

运行结果：

```text
  入队: 任务1 → ['任务1']
  入队: 任务2 → ['任务1', '任务2']
  入队: 任务3 → ['任务1', '任务2', '任务3']
  ---
  出队: 任务1 → ['任务2', '任务3']
  出队: 任务2 → ['任务3']
  出队: 任务3 → []
```

队列用 `append` 入队、`pop(0)` 出队。功能正确但 `pop(0)` 是 O(n)，大数据量时应改用 `collections.deque`。

**优先级队列（用 insert 按优先级插入）**

```python
pq = []

def add_task(priority, name):
    """按优先级插入（数字越小优先级越高）"""
    inserted = False
    for i, (p, n) in enumerate(pq):
        if priority < p:
            pq.insert(i, (priority, name))
            inserted = True
            break
    if not inserted:
        pq.append((priority, name))

add_task(3, "普通任务")
add_task(1, "紧急任务")
add_task(2, "高优任务")
add_task(1, "另一个紧急任务")

print("  优先级队列内容:")
for p, n in pq:
    print(f"    优先级{p}: {n}")

print("  ---")
while pq:
    priority, name = pq.pop(0)
    print(f"  执行: 优先级{priority} - {name}")
```

运行结果：

```text
  优先级队列内容:
    优先级1: 紧急任务
    优先级1: 另一个紧急任务
    优先级2: 高优任务
    优先级3: 普通任务
  ---
  执行: 优先级1 - 紧急任务
  执行: 优先级1 - 另一个紧急任务
  执行: 优先级2 - 高优任务
  执行: 优先级3 - 普通任务
```

利用 `insert` 可以实现优先级队列——找到合适的位置后插入，保持列表按优先级排序。

**撤销/重做（双栈实现）**

```python
undo_stack = []
redo_stack = []

def execute(action):
    undo_stack.append(action)
    redo_stack.clear()  # 新操作清空 redo
    print(f"  执行: {action}")

def undo():
    if undo_stack:
        action = undo_stack.pop()
        redo_stack.append(action)
        print(f"  撤销: {action}")
    else:
        print("  无可撤销操作")

def redo():
    if redo_stack:
        action = redo_stack.pop()
        undo_stack.append(action)
        print(f"  重做: {action}")
    else:
        print("  无可重做操作")

execute("输入A")
execute("输入B")
execute("删除C")

undo()
undo()
redo()
redo()
redo()
```

运行结果：

```text
  执行: 输入A
  执行: 输入B
  执行: 删除C
  撤销: 删除C
  撤销: 输入B
  重做: 输入B
  重做: 删除C
  无可重做操作
```

撤销/重做是双栈的经典应用。`undo_stack` 记录已执行的操作，`redo_stack` 记录被撤销的操作。执行新操作时清空 `redo_stack`（用 `clear()`），撤销时从 `undo_stack` 弹出到 `redo_stack`，重做时反向操作。

## 4. 原理

### 4.1 列表底层结构与时间复杂度

Python 列表在底层是一个动态数组——它在连续的内存区域中存储元素的指针。这个结构决定了不同操作的时间复杂度差异：

```text
列表 [10, 20, 30, 40, 50] 的内存布局：

  索引:    0     1     2     3     4
         ┌─────┬─────┬─────┬─────┬─────┐
  数组:  │ ptr │ ptr │ ptr │ ptr │ ptr │
         └──┬──┴──┬──┴──┬──┴──┬──┴──┬──┘
            ↓     ↓     ↓     ↓     ↓
           10    20    30    40    50

append(60) → 末尾追加，O(1):
  索引:    0     1     2     3     4     5
         ┌─────┬─────┬─────┬─────┬─────┬─────┐
  数组:  │ ptr │ ptr │ ptr │ ptr │ ptr │ ptr │  ← 末尾空位直接写入
         └─────┴─────┴─────┴─────┴─────┴─────┘
           10    20    30    40    50    60

insert(1, 15) → 中间插入，O(n):
  索引:    0     1     2     3     4     5
         ┌─────┬─────┬─────┬─────┬─────┬─────┐
  数组:  │ ptr │ ptr │ ptr │ ptr │ ptr │ ptr │
         └─────┴──┬──┴──┬──┴──┬──┴──┬──┴──┬──┘
           10    15    20    30    40    50
                 ↑
           原有元素 20~50 全部后移一位

pop() → 末尾弹出，O(1):
  索引:    0     1     2     3     4
         ┌─────┬─────┬─────┬─────┬─────┐
  数组:  │ ptr │ ptr │ ptr │ ptr │     │  ← 末尾元素直接移除
         └─────┴─────┴─────┴─────┴─────┘
           10    20    30    40

pop(0) → 头部弹出，O(n):
  索引:    0     1     2     3
         ┌─────┬─────┬─────┬─────┐
  数组:  │ ptr │ ptr │ ptr │     │  ← 所有元素前移一位
         └─────┴─────┴─────┴─────┘
           20    30    40
```

因为列表在内存中是连续的数组结构：

- **末尾操作**（`append`、`pop()`）只需要在末尾写入或移除一个指针，O(1)
- **中间操作**（`insert(i, x)`、`pop(i)`）需要移动 `i` 之后的所有元素，最坏 O(n)
- **头部操作**（`insert(0, x)`、`pop(0)`）需要移动全部元素，O(n)
- **按值操作**（`remove(x)`）需要先线性搜索找到元素，再移动后续元素，O(n)

### 4.2 insert 与 append 的性能差异

`insert` 比 `append` 慢的原因在于元素的移动开销：

```python
import time

N = 50000

# insert(0, x) 头部插入：每次都要移动所有现有元素
start = time.perf_counter()
lst_head = []
for i in range(N):
    lst_head.insert(0, i)
time_head = time.perf_counter() - start

# append(x) 末尾追加：不需要移动元素
start = time.perf_counter()
lst_tail = []
for i in range(N):
    lst_tail.append(i)
time_tail = time.perf_counter() - start

print(f"头部insert: {time_head:.4f} 秒")
print(f"尾部append: {time_tail:.4f} 秒")
print(f"速度比: {time_head / time_tail:.1f}x")
```

运行结果：

```text
头部insert: 0.4854 秒
尾部append: 0.0019 秒
速度比: 250.5x
```

头部 `insert` 比尾部 `append` 慢 250 倍。这是因为：

- `insert(0, x)` 第 1 次移动 0 个元素，第 2 次移动 1 个，... 第 N 次移动 N-1 个，总共移动 N*(N-1)/2 次，时间复杂度 O(n^2)
- `append(x)` 每次只在末尾写入，均摊 O(1)

在需要频繁头部插入/删除的场景，应使用 `collections.deque`：

```python
from collections import deque

# deque 的 appendleft/popleft 都是 O(1)
dq = deque()
for i in range(50000):
    dq.appendleft(i)  # O(1)，不需要移动元素

print(f"deque 长度: {len(dq)}")
```

### 4.3 遍历时删除元素的问题

遍历列表同时删除元素是 Python 中的经典陷阱。问题根源在于 `for` 循环使用迭代器遍历，而迭代器内部维护了一个索引计数器：

```text
列表: [1, 2, 2, 3, 2, 4]

迭代器状态: index=0, 值=1 → 不是2，继续
迭代器状态: index=1, 值=2 → 是2，remove(2)，列表变为 [1, 2, 3, 2, 4]
迭代器状态: index=2, 值=3 → 跳过了第二个2！
迭代器状态: index=3, 值=2 → 是2，remove(2)，列表变为 [1, 2, 3, 4]
迭代器状态: index=4 → 越出范围（列表已缩短），循环结束

结果: [1, 2, 3, 4] — 本应删除所有2，但漏了一个
```

当 `remove` 删除元素后，列表缩短了，迭代器的索引自动前移，导致跳过下一个元素。解决方法：

```text
方法1: while + in（安全但 O(n^2)）
  while 2 in nums:
      nums.remove(2)

方法2: 列表推导式过滤（推荐，O(n)）
  filtered = [x for x in nums if x != 2]

方法3: 倒序遍历 + del（原地修改，不跳元素）
  for i in range(len(nums) - 1, -1, -1):
      if nums[i] == 2:
          del nums[i]
```

方法 2 是推荐的写法——创建新列表而非修改原列表，时间复杂度 O(n)。

## 5. 总结

本文围绕 `insert`、`pop`、`remove` 三个列表方法展开，系统介绍了以下内容：

- **insert 方法**：在指定索引位置插入元素，原位置及之后的元素后移，返回 `None`，时间复杂度 O(n)；索引越界时不报错而是自动调整到边界
- **pop 方法**：弹出（删除并返回）指定索引的元素，默认弹出末尾（-1），返回被弹出的值，末尾操作 O(1)、中间操作 O(n)；索引越界抛出 `IndexError`，空列表 pop 报错
- **remove 方法**：按值删除第一个匹配的元素，返回 `None`；值不存在抛出 `ValueError`；只删第一个匹配，删除所有需要循环
- **del 语句**：按索引删除单个元素或按切片批量删除元素，无返回值，索引越界抛出 `IndexError`；还能删除整个变量
- **clear 方法**：清空列表所有元素，原地修改返回 `None`，与赋空列表 `lst = []` 的区别在于 clear 原地修改影响所有引用
- **pop vs remove 核心区别**：pop 按索引定位且返回被删值，remove 按值定位且返回 None
- **最佳实践**：推荐 vs 不推荐写法对比、5 种常见错误模式（遍历时删除、pop 空列表、remove 不存在的值、头部 insert 性能、头部 pop(0) 性能）、方法速查表、实际应用场景（栈/队列/优先级队列/撤销重做）
- **原理**：列表底层动态数组结构与时间复杂度（末尾操作 O(1) vs 中间/头部操作 O(n)）、insert 与 append 性能差异 250 倍（O(n^2) vs O(n)）、遍历时删除元素的迭代器陷阱与三种解决方案
