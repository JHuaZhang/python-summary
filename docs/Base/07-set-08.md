# 集合的交集操作

## 1. 介绍

### 1.1 什么是集合交集

交集（Intersection）是集合论中最基本的运算之一。给定两个集合 A 和 B，它们的交集 A∩B 包含所有同时属于 A 和 B 的元素——即两个集合的"公共部分"。在 Python 中，集合交集操作通过 `intersection()` 方法、`&` 运算符和 `intersection_update()` 方法三种方式实现。

交集操作解决的核心问题是：**从多个数据来源中找出共同拥有的元素**。这在处理权限交集、用户重叠分析、多条件筛选等场景中非常实用——你不需要手动编写循环比对逻辑，集合的哈希查找机制天然帮你高效完成了这一步。

Python 交集操作的三种方式各有定位：

- **`intersection()` 方法**：返回新集合，原集合不变，接受任意可迭代对象作为参数
- **`&` 运算符**：返回新集合，原集合不变，两侧必须是集合类型
- **`intersection_update()` 方法 / `&=` 运算符**：原地修改当前集合，不产生新集合

### 1.2 最简示例

```python
# 两个集合
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# intersection() 方法：返回新集合
print(a.intersection(b))  # 输出：{3, 4}

# & 运算符：等价写法
print(a & b)              # 输出：{3, 4}

# intersection_update() 方法：原地修改
c = {1, 2, 3, 4}
c.intersection_update({3, 4, 5, 6})
print(c)                  # 输出：{3, 4}
```

三种方式的直观区别可以用下图表示：

```text
  intersection() / & 运算符          intersection_update() / &= 运算符
  ┌──────────────────────┐          ┌──────────────────────┐
  │  A.intersection(B)   │          │  A.intersection_      │
  │                      │          │  update(B)            │
  │  A = {1,2,3,4}       │          │                      │
  │  B = {3,4,5,6}       │          │  A = {1,2,3,4}       │
  │                      │          │  B = {3,4,5,6}       │
  │  结果 = {3,4}        │          │                      │
  │  (新集合)            │          │  A 变成 {3,4}        │
  │  A 不变              │          │  (原集合被修改)      │
  │  B 不变              │          │  返回 None           │
  └──────────────────────┘          └──────────────────────┘
```

### 1.3 交集的数学关系

交集的元素数量与交集、并集之间有一个重要的恒等关系——容斥原理：

```text
|A ∩ B| = |A| + |B| - |A ∪ B|
```

即：交集的元素数 = A 的元素数 + B 的元素数 - 并集的元素数。也可以从另一个角度理解：并集的元素数 = A 的元素数 + B 的元素数 - 交集的元素数（因为共有的元素被 A 和 B 各算了一次，但并集中只保留一份，所以要减去重复计算的交集部分）。

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(len(a))              # 输出：4
print(len(b))              # 输出：4
print(len(a & b))          # 输出：2（交集：{3, 4}）
print(len(a | b))          # 输出：6（并集）
# 验证容斥原理：4 + 4 - 6 = 2
# 即 |A ∩ B| = |A| + |B| - |A ∪ B| = 4 + 4 - 6 = 2
```

交集运算满足以下数学性质：

- **交换律**：A ∩ B = B ∩ A
- **结合律**：(A ∩ B) ∩ C = A ∩ (B ∩ C)
- **幂等律**：A ∩ A = A（自己和自己求交集等于自身）
- **空集吸收律**：A ∩ ∅ = ∅（任何集合与空集的交集都是空集）

```python
a = {1, 2, 3}
b = {2, 3, 4}
c = {3, 4, 5}

# 交换律
print(a & b == b & a)          # 输出：True

# 结合律
print((a & b) & c == a & (b & c))  # 输出：True

# 幂等律
print(a & a == a)              # 输出：True

# 空集吸收律
print(a & set() == set())      # 输出：True
```

## 2. 核心内容

### 2.1 intersection() 方法

`intersection()` 是集合对象的方法，返回一个包含当前集合和参数集合中共同元素的新集合。它是交集操作最基础、最灵活的方式。

**方法签名**：

```text
set.intersection(*others)
```

- `*others`：接受一个或多个可迭代对象（集合、列表、元组、字典、生成器等都可以），用逗号分隔
- 返回值：一个新的 `set` 对象，包含所有参数中共有的元素
- 原集合不会被修改

**基本用法**：

```python
# 场景：两个团队共有的成员，用于排期协调
team_alpha = {"张三", "李四", "王五", "赵六"}
team_beta = {"王五", "赵六", "钱七", "孙八"}

common_members = team_alpha.intersection(team_beta)
print(common_members)
```

**运行结果**：

```text
{'王五', '赵六'}
```

"王五"和"赵六"在两个团队都有，所以它们出现在交集中。"张三"只在 team_alpha 中，"钱七"只在 team_beta 中，所以不在交集中。

**intersection() 不修改原集合**：

```python
print(team_alpha)  # 输出：{'张三', '李四', '王五', '赵六'}  ← 不变
print(team_beta)   # 输出：{'王五', '赵六', '钱七', '孙八'}  ← 不变
```

**运行结果**：

```text
{'张三', '李四', '王五', '赵六'}
{'王五', '赵六', '钱七', '孙八'}
```

**关键点**：

- `intersection()` 返回的新集合与原集合是不同的对象——修改新集合不会影响原集合
- 如果参数是空集，结果必为空集——任何集合与空集的交集都是空集
- `intersection()` 返回的集合类型与调用者一致：`set` 调用返回 `set`，`frozenset` 调用返回 `frozenset`

### 2.2 & 运算符

`&` 运算符是 `intersection()` 方法的运算符写法，功能等价但写法更简洁。在数学表达中，`A & B` 对应 `A ∩ B`，非常直观。

**基本用法**：

```python
# 场景：找出同时具备两种技能的员工
python_devs = {"张三", "李四", "王五", "赵六"}
sql_devs = {"王五", "赵六", "钱七", "孙八"}

both_skills = python_devs & sql_devs
print(both_skills)
```

**运行结果**：

```text
{'王五', '赵六'}
```

**`&` 运算符与 `intersection()` 方法结果完全一致**：

```python
op_result = python_devs & sql_devs
method_result = python_devs.intersection(sql_devs)
print(op_result == method_result)  # 输出：True
```

**`&` 运算符不修改原集合**：

```python
python_devs.add("周九")
print(python_devs)  # 输出：{'张三', '李四', '王五', '赵六', '周九'}
print(both_skills)  # 输出：{'王五', '赵六'}  ← 交集结果不受影响
```

**关键点**：

- `&` 运算符两侧必须都是集合类型（`set` 或 `frozenset`），传入列表、元组等会报 `TypeError`
- 结果是一个新集合，原集合不受影响
- `&` 在集合上下文中是交集运算符，不是位运算符——Python 根据操作数类型自动选择对应行为

### 2.3 多集合交集

实际开发中经常需要对三个以上的集合求交集。`intersection()` 方法和 `&` 运算符都支持多集合交集，但语法略有不同。

#### 2.3.1 intersection() 多参数

`intersection()` 方法接受 `*others` 可变参数，可以一次传入多个集合：

```python
# 场景：三个系统都记录了用户行为，找出在所有系统中都活跃的用户
system_a = {"user_001", "user_002", "user_003", "user_004"}
system_b = {"user_002", "user_003", "user_005"}
system_c = {"user_001", "user_003", "user_006"}

common_in_all = system_a.intersection(system_b, system_c)
print(common_in_all)
```

**运行结果**：

```text
{'user_003'}
```

`intersection()` 传多个参数等价于依次求交集：`A.intersection(B, C)` = `A & B & C`，满足结合律。

#### 2.3.2 & 运算符链式调用

`&` 运算符通过链式调用来对多个集合求交集，每一步返回新集合再继续运算：

```python
common_in_all = system_a & system_b & system_c
print(common_in_all)
```

**运行结果**：

```text
{'user_003'}
```

两种方式结果一致：

```python
print(system_a.intersection(system_b, system_c) == \
      system_a & system_b & system_c)  # 输出：True
```

逐步求交集的过程：

```python
ab = system_a & system_b
abc = ab & system_c
print("A & B =", ab)    # 输出：{'user_002', 'user_003'}
print("A & B & C =", abc)  # 输出：{'user_003'}
```

#### 2.3.3 使用解包对大量集合求交集

当集合数量不确定时，可以用 `*` 解包配合 `intersection()` 一次求交集：

```python
# 场景：从多个数据源中找出都出现的活跃用户
many_systems = [
    {"user_003", "user_007"},
    {"user_003", "user_008"},
    {"user_003", "user_009"},
    {"user_003", "user_010"},
]

# 用第一个集合调用 intersection()，其余通过 * 解包传入
all_common = system_a.intersection(*many_systems)
print(all_common)  # 输出：{'user_003'}
```

**运行结果**：

```text
{'user_003'}
```

这里 `*many_systems` 将列表中的每个集合解包为独立参数，等价于 `system_a.intersection({"user_003", "user_007"}, {"user_003", "user_008"}, ...)`。

**关键点**：

- `intersection()` 一次接受多个参数，代码更简洁
- `&` 运算符需要链式调用，每步创建中间集合（略多一步开销）
- 大量集合求交集时，`A.intersection(*sets)` 是最简洁高效的写法
- 空集参与多集合交集时，结果必为空集——因为任何集合与空集的交集都是空集

### 2.4 intersection_update() 方法

`intersection_update()` 方法将当前集合更新为当前集合与参数集合的交集，**原地修改**当前集合，不返回新集合。

**方法签名**：

```text
set.intersection_update(*others)
```

- `*others`：接受一个或多个可迭代对象
- 返回值：`None`（注意不是新集合！）
- 原集合被直接修改

**基本用法**：

```python
# 场景：从白名单中筛出同时也在黑名单中的 IP（这些 IP 需要人工审核）
whitelist = {"192.168.1.1", "192.168.1.2", "192.168.1.3", "192.168.1.4"}
blacklist = {"192.168.1.2", "192.168.1.3", "192.168.1.5"}

whitelist.intersection_update(blacklist)
print(whitelist)
```

**运行结果**：

```text
{'192.168.1.2', '192.168.1.3'}
```

`whitelist` 现在变成了交集结果，原始的白名单数据已丢失——这是 `intersection_update()` 的核心特性：**原地修改**。

**intersection_update() 返回 None**：

```python
test_set = {1, 2, 3}
result = test_set.intersection_update({2, 3, 4})
print(result)       # 输出：None
print(test_set)     # 输出：{2, 3}  ← 集合已被修改
```

**运行结果**：

```text
None
{2, 3}
```

**intersection_update() 接受多个参数**：

```python
data_a = {"x", "y", "z", "w"}
data_b = {"x", "y", "a"}
data_c = {"x", "b", "c"}
data_a.intersection_update(data_b, data_c)
print(data_a)  # 输出：{'x'}
```

**运行结果**：

```text
{'x'}
```

三个集合中只有 "x" 是共有的，所以 `data_a` 被更新为 `{'x'}`。

**关键点**：

- `intersection_update()` 返回 `None`，不能用于链式调用——`A.intersection_update(B).intersection_update(C)` 会报错
- `intersection_update()` 接受任意可迭代对象，不限于集合——列表、元组、字典（取 key）、生成器都可以
- `intersection_update()` 是原地修改操作，如果其他变量引用了同一个集合对象，它们看到的也会是修改后的内容

### 2.5 &= 复合赋值运算符

`&=` 是 `intersection_update()` 的运算符写法，功能等价：将当前集合更新为当前集合与右侧集合的交集，原地修改左侧集合。

**基本用法**：

```python
# 场景：逐步收窄候选用户范围
candidates = {"user_001", "user_002", "user_003", "user_004", "user_005"}

# 第一轮筛选：活跃用户
active = {"user_001", "user_003", "user_005", "user_006"}
candidates &= active
print(candidates)  # 输出：{'user_001', 'user_003', 'user_005'}

# 第二轮筛选：已付费用户
paid = {"user_001", "user_003", "user_007"}
candidates &= paid
print(candidates)  # 输出：{'user_001', 'user_003'}
```

**运行结果**：

```text
{'user_001', 'user_003', 'user_005'}
{'user_001', 'user_003'}
```

**`&=` 与 `intersection_update()` 的等价性**：

```python
s1 = {1, 2, 3, 4}
s2 = {1, 2, 3, 4}

s1 &= {3, 4, 5}
s2.intersection_update({3, 4, 5})

print(s1)          # 输出：{3, 4}
print(s2)          # 输出：{3, 4}
print(s1 == s2)    # 输出：True
```

**`&=` 只接受集合类型**：

```python
s = {1, 2, 3}

# 集合 → 正常
s &= {4, 5}

# 列表不行
# s &= [6, 7]  # 报错：TypeError: unsupported operand type(s) for &=: 'set' and 'list'
```

**运行结果**：

```text
TypeError: unsupported operand type(s) for &=: 'set' and 'list'
```

这是 `&=` 和 `intersection_update()` 的一个重要区别：`&=` 只接受集合类型，而 `intersection_update()` 接受任意可迭代对象。

**frozenset 不支持 `&=`**：

```python
fs = frozenset({1, 2, 3})
# fs &= {3, 4}  # 报错：TypeError
```

`frozenset` 是不可变集合，不支持任何原地修改操作。

**关键点**：

- `&=` 是原地修改，不产生新集合——通过 `id()` 可以验证对象身份不变
- `&=` 右侧必须是集合类型，灵活性不如 `intersection_update()` 方法
- 适合在需要逐步收窄范围的筛选场景中使用，链式风格简洁直观

### 2.6 与非集合类型求交集

`intersection()` 和 `intersection_update()` 方法接受任意可迭代对象作为参数，而 `&` 和 `&=` 运算符只接受集合类型。这是方法与运算符之间最重要的使用差异。

**intersection() 接受各种可迭代对象**：

```python
online_users = {"user_001", "user_002", "user_003", "user_004"}

# 列表
print(online_users.intersection(["user_002", "user_004", "user_006"]))
# 输出：{'user_002', 'user_004'}

# 元组
print(online_users.intersection(("user_003", "user_005")))
# 输出：{'user_003'}

# 字符串（每个字符作为元素）
print({"a", "b", "c", "d"}.intersection("bcde"))
# 输出：{'b', 'c'}

# 字典（key 被加入运算，value 被忽略）
print({"name", "age", "city"}.intersection({"name": "张三", "age": 25, "phone": "123"}))
# 输出：{'name', 'age'}

# 生成器
print({1, 2, 3, 4, 5}.intersection(x * 2 for x in range(1, 6)))
# 生成器产生 2,4,6,8,10 → 交集 {2, 4}
```

**& 运算符只接受集合类型**：

```python
a = {1, 2, 3}

# 集合 → 正常
print(a & {3, 4})       # 输出：{3}

# 列表 → 报错
# a & [3, 4]  # TypeError: unsupported operand type(s) for &: 'set' and 'list'

# 元组 → 报错
# a & (3, 4)  # TypeError: unsupported operand type(s) for &: 'set' and 'tuple'
```

**混合类型多参数求交集**：`intersection()` 可以同时传入不同类型的参数：

```python
numbers = {1, 2, 3, 4, 5}
mixed = numbers.intersection([3, 4, 5], (5, 6, 7))
print(mixed)  # 输出：{5}
```

**frozenset 的交集操作**：`frozenset` 支持 `intersection()` 和 `&`，返回新的 `frozenset`：

```python
fs = frozenset({1, 2, 3, 4})

# intersection() 返回 frozenset
result_method = fs.intersection({3, 4, 5})
print(type(result_method).__name__)  # 输出：frozenset

# & 运算符也返回 frozenset
result_op = fs & {3, 4, 5}
print(type(result_op).__name__)      # 输出：frozenset

# 但不支持 intersection_update()（不可变）
# fs.intersection_update({4, 5})  # AttributeError
```

**intersection_update() 也接受任意可迭代对象**：

```python
s = {1, 2, 3, 4, 5}
s.intersection_update([3, 4, 6])
print(s)  # 输出：{3, 4}
```

**关键点**：

- 需要与非集合类型（列表、元组等）求交集时，必须使用 `intersection()` 或 `intersection_update()` 方法
- `&` 和 `&=` 运算符两侧必须是 `set` 或 `frozenset`
- `frozenset` 调用 `intersection()` 返回 `frozenset`，`set` 调用 `intersection()` 返回 `set`

### 2.7 API 速查表

| 方式 | 语法 | 返回值 | 是否修改原集合 | 参数类型要求 | 等价关系 |
|------|------|--------|--------------|-------------|---------|
| `intersection()` | `A.intersection(B, C, ...)` | 新集合 | 否 | 任意可迭代对象 | — |
| `&` 运算符 | `A & B` | 新集合 | 否 | 必须是集合 | `A.intersection(B)` |
| `intersection_update()` | `A.intersection_update(B, C, ...)` | `None` | 是 | 任意可迭代对象 | — |
| `&=` 运算符 | `A &= B` | `None` | 是 | 必须是集合 | `A.intersection_update(B)` |

## 3. 最佳实践

### 3.1 推荐 vs 不推荐写法对比

**推荐：用 `intersection()` 与非集合类型求交集**

```python
# 推荐：intersection() 直接接受列表和元组
db_ids = {101, 102, 103}
cache_ids = [103, 104]
api_ids = (103, 105)

common = db_ids.intersection(cache_ids, api_ids)  # 简洁直观

# 不推荐：手动转集合再用运算符
common = db_ids & set(cache_ids) & set(api_ids)  # 冗余转换
```

**推荐：需要保留原集合时用 `intersection()` 或 `&`**

```python
# 推荐：用 intersection() 产生新集合，原集合不动
original = {1, 2, 3, 4}
common = original.intersection({3, 4, 5})
# original 仍然是 {1, 2, 3, 4}

# 不推荐：用 intersection_update() 后丢失原始数据
original = {1, 2, 3, 4}
original.intersection_update({3, 4, 5})
# original 变成了 {3, 4}，原始数据丢失
```

**推荐：逐步收窄范围时用 `&=` 链式风格**

```python
# 推荐：&= 链式逐步收窄，代码清晰
pool = {1, 2, 3, 4, 5, 6, 7, 8}
pool &= {2, 4, 6, 8}    # 保留偶数
pool &= {4, 6, 8}       # 保留大于2的偶数
pool &= {4, 8}          # 进一步收窄

# 不推荐：用 intersection() 反复创建新对象赋值
pool = {1, 2, 3, 4, 5, 6, 7, 8}
pool = pool.intersection({2, 4, 6, 8})
pool = pool.intersection({4, 6, 8})
pool = pool.intersection({4, 8})
```

**推荐：大量集合求交集时用 `A.intersection(*sets)`**

```python
# 推荐：解包方式一次求交集
many_sets = [{"a", "x"}, {"b", "x"}, {"c", "x"}]
merged = set().intersection(*many_sets)  # 一次调用

# 不推荐：循环逐个求交集
merged = many_sets[0]
for s in many_sets[1:]:
    merged = merged & s  # 多次操作
```

### 3.2 常见错误模式

**错误一：误以为 intersection_update() 返回新集合**

```python
# 错误：intersection_update() 返回 None，不能赋值
result = {1, 2, 3}.intersection_update({2, 3})
print(result)  # 输出：None

# 修正：直接操作原集合，或用 intersection()
s = {1, 2, 3}
s.intersection_update({2, 3})  # 原地修改
print(s)  # 输出：{2, 3}

# 或者用 intersection() 获取新集合
result = {1, 2, 3}.intersection({2, 3})
print(result)  # 输出：{2, 3}
```

**错误二：对 & 运算符使用非集合类型**

```python
a = {1, 2, 3}

# 错误：& 运算符不接受列表
# a & [3, 4]  # TypeError: unsupported operand type(s) for &: 'set' and 'list'

# 修正：用 intersection() 方法，或先转换为集合
result = a.intersection([3, 4])     # 方法：直接传列表
result = a & set([3, 4])            # 运算符：先转换
```

**错误三：intersection_update() 链式调用**

```python
# 错误：intersection_update() 返回 None，不能链式
# {1, 2, 3}.intersection_update({2}).intersection_update({2})  # AttributeError

# 修正：分步调用，或用 intersection() 链式
s = {1, 2, 3}
s.intersection_update({2, 3})
s.intersection_update({2})
print(s)  # 输出：{2}

# 或者用 intersection() 链式（产生新集合）
result = {1, 2, 3}.intersection({2, 3}).intersection({2})
print(result)  # 输出：{2}
```

**错误四：混淆 &= 和 &**

```python
s = {1, 2, 3}

# & 不修改原集合（产生新集合）
result = s & {3, 4}
print(s)        # 输出：{1, 2, 3}  ← 原集合不变
print(result)   # 输出：{3}

# &= 原地修改（不产生新集合）
s &= {3, 4}
print(s)        # 输出：{3}  ← 原集合被修改
```

### 3.3 性能取舍建议

| 场景 | 推荐方式 | 原因 |
|------|---------|------|
| 两个集合简单求交集 | `A & B` | 写法简洁，运算符效率略高 |
| 与非集合可迭代对象求交集 | `A.intersection(list_data)` | 避免手动转换 |
| 大量集合一次求交集 | `A.intersection(*sets)` | 一次调用，避免中间集合 |
| 逐步收窄范围 | `A &= B` | 原地修改，不创建新对象 |
| 需要保留原集合 | `A.intersection(B)` / `A & B` | 返回新集合，原集不变 |
| 不确定是否需要保留 | `A.intersection(B)` | 更安全，避免副作用 |

## 4. 原理：intersection() 与 intersection_update() 的底层差异

### 4.1 新集合 vs 原地修改

`intersection()` 和 `intersection_update()` 在底层的核心区别在于：`intersection()` 分配新内存创建新集合，`intersection_update()` 在已有集合的内存上直接操作。

```text
  A.intersection(B)                  A.intersection_update(B)
  ┌─────────────────────┐           ┌──────────────────────────┐
  │  1. 分配新内存       │           │  1. 不分配新内存          │
  │  2. 遍历 A 的元素    │           │  2. 遍历 A 的元素         │
  │     如果在 B 中，    │           │     如果不在 B 中，       │
  │     添加到新集合     │           │     从 A 中删除           │
  │  3. 返回新集合       │           │  3. A 的 id 不变          │
  │  4. A 的 id 不变     │           │  4. 返回 None            │
  │     新集合 id 不同   │           │                          │
  └─────────────────────┘           └──────────────────────────┘
```

用 `id()` 验证这个差异：

```python
s1 = {1, 2, 3, 4}
s2 = {1, 2, 3, 4}
id_before_1 = id(s1)
id_before_2 = id(s2)

# intersection() → 新对象，id 变化
s1 = s1.intersection({3, 4, 5})
print(id(s1) != id_before_1)  # 输出：True（新对象）

# intersection_update() → 同一对象，id 不变
s2.intersection_update({3, 4, 5})
print(id(s2) == id_before_2)  # 输出：True（同一对象）
```

**运行结果**：

```text
True
True
```

### 4.2 引用共享与副作用

原地修改的副作用在多变量引用同一集合时会暴露出来：

```python
shared = {1, 2, 3, 4}
ref = shared  # ref 和 shared 指向同一个集合对象

# intersection_update() 原地修改：ref 也会看到变化
shared.intersection_update({2, 3})
print(ref)  # 输出：{2, 3}  ← ref 看到了变化

# intersection() 不修改原集合：没有副作用
shared2 = {1, 2, 3, 4}
ref2 = shared2
_ = shared2.intersection({2, 3})
print(ref2)  # 输出：{1, 2, 3, 4}  ← ref2 不受影响
```

**运行结果**：

```text
{2, 3}
{1, 2, 3, 4}
```

这意味着：如果代码中有多处引用同一个集合对象，使用 `intersection_update()` 会影响到所有引用。如果这不是你的意图，使用 `intersection()` 更安全。

### 4.3 运算符重载机制

`&` 和 `&=` 运算符背后通过 Python 的运算符重载机制实现：

```python
a = {1, 2, 3}
b = {2, 3, 4}

# 以下两行等价
print(a & b)            # 运算符写法
print(a.__and__(b))     # 特殊方法调用

# 以下两行也等价
s = {1, 2, 3}
s &= {2, 3}             # 运算符写法
# s.__iand__({2, 3})    # 特殊方法调用

# intersection() 和 & 的关系
print(a.intersection(b) == a.__and__(b))  # True
```

**运行结果**：

```text
{2, 3}
{2, 3}
True
```

**特殊方法对应关系**：

| 运算符 | 特殊方法 | 对应方法 |
|--------|---------|---------|
| `A & B` | `A.__and__(B)` | `A.intersection(B)` |
| `A &= B` | `A.__iand__(B)` | `A.intersection_update(B)` |

`__and__` 方法返回新集合（对应 `intersection`），`__iand__` 方法原地修改（对应 `intersection_update`）。Python 在执行 `A &= B` 时，先尝试调用 `A.__iand__(B)`；如果该方法不存在（如 `frozenset`），则退化为 `A = A.__and__(B)`（创建新对象赋值给 A）。

### 4.4 为什么运算符只接受集合而方法接受任意可迭代对象

这个设计决策源于**类型对称性**的考虑：

`&` 运算符的设计哲学是对称运算——`A & B` 中 A 和 B 应该是同类型对象。如果允许 `{1,2} & [3,4]`，就破坏了对称性：左侧是 `set`，右侧是 `list`，类型不一致容易引发歧义。

`intersection()` 方法的设计哲学是灵活性——方法名已经明确表达了"我在做集合运算"的意图，参数可以是任意可迭代对象，Python 内部会自动提取元素。这让方法在实际使用中更方便，不需要手动转换类型。

```python
a = {1, 2, 3}

# 方法：灵活，接受任意可迭代对象
a.intersection([3, 4])       # 列表 → OK
a.intersection((3, 4))       # 元组 → OK
a.intersection("ab")        # 字符串 → OK（每个字符作为元素）

# 运算符：严格，只接受集合
a & {3, 4}                  # 集合 → OK
# a & [3, 4]                # 列表 → TypeError
# a & (3, 4)                # 元组 → TypeError
```

这个设计理念在 Python 的其他集合运算符（`|`、`-`、`^`）中也是一致的：运算符要求类型对称，方法则更灵活。

## 5. 总结

本文围绕集合的交集操作展开，主要介绍了以下内容：

- 交集操作找出多个集合中共同拥有的元素。Python 提供了 `intersection()` 方法、`&` 运算符、`intersection_update()` 方法和 `&=` 运算符四种方式
- `intersection()` 方法和 `&` 运算符返回新集合，原集合不变——适合需要保留原始数据的场景
- `intersection_update()` 方法和 `&=` 运算符原地修改当前集合，返回 `None`——适合逐步收窄范围、不需要保留原始数据的场景
- `intersection()` 和 `intersection_update()` 接受任意可迭代对象作为参数，而 `&` 和 `&=` 运算符只接受集合类型——这是方法与运算符最重要的使用差异
- 多集合求交集时，`intersection()` 支持一次传入多个参数，`&` 通过链式调用实现，大量集合可用 `A.intersection(*sets)` 解包处理
- `intersection()` 返回新对象（id 变化），`intersection_update()` 原地修改（id 不变）——多变量引用同一集合时需注意 `intersection_update()` 的副作用
- 两个集合简单求交集推荐用 `&` 运算符（简洁），与非集合类型求交集推荐用 `intersection()` 方法（灵活），逐步收窄推荐用 `&=`（高效）
