# 字典的访问与查找

## 1. 介绍

### 1.1 字典访问的核心问题

字典是一种映射类型——数据以"键→值"的形式存储。因此，字典的访问与查找和列表有本质区别：列表用位置编号找数据，字典用"键"找数据。这看似简单，但实际开发中会遇到一系列问题：键不存在时怎么处理？需要判断键是否存在但不需要取值时怎么写？嵌套字典多层访问时如何安全地逐层取值？在大规模数据查找时如何利用字典的 O(1) 特性？

Python 提供了多种字典访问和查找方式，每种方式在安全性、性能和适用场景上各有取舍：

```python
# 方式一：直接索引——最快，但键不存在时报错
value = d["name"]

# 方式二：get()——安全，键不存在时返回默认值
value = d.get("name")
value = d.get("name", "默认值")

# 方式三：in 判断——只判断是否存在，不取值
if "name" in d:
    ...

# 方式四：视图对象查找——在 keys/values/items 中查找
"a" in d.keys()
1 in d.values()
("a", 1) in d.items()
```

理解每种方式的机制和边界，才能在不同场景下选择最合适的写法——既保证安全，又不牺牲性能。

### 1.2 最简示例

先用最基础的直接索引方式访问字典中的值：

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# 通过键直接取值
print(d["name"])    # 张三
print(d["age"])     # 20
print(d["city"])    # 北京
```

这就是字典最基本的访问方式——用方括号 `d[key]` 通过键取值。但如果键不存在，这种方式会抛出 `KeyError`。后面几种方式都是在解决"键不存在时怎么办"的问题。

## 2. 核心内容

### 2.1 直接索引访问：d[key]

直接索引是字典最基本的访问方式——用方括号 `[]` 通过键获取对应的值，时间复杂度 O(1)。

**基本用法**

```python
d = {"name": "张三", "age": 20, "city": "北京", "score": 90.5}

# 通过键直接取值
print(d["name"])    # 张三
print(d["age"])     # 20
print(d["score"])   # 90.5
```

**键不存在时的 KeyError**

如果键不存在于字典中，直接索引会抛出 `KeyError` 异常：

```python
d = {"name": "张三", "age": 20}

try:
    print(d["height"])
except KeyError as e:
    print(f"KeyError: {e}")   # KeyError: 'height'
```

`KeyError` 的异常信息中只包含缺失的键名，可以通过异常变量获取这个键名：

```python
try:
    value = d["phone"]
except KeyError as missing_key:
    print(f"缺失的键: {missing_key}")   # 缺失的键: 'phone'
```

**参数和返回值**

| 表达式 | 参数 | 返回值 | 异常 |
|--------|------|--------|------|
| `d[key]` | `key`：任意可哈希类型 | 键对应的值 | `KeyError`（键不存在） |

**运行结果**：

```text
张三
KeyError: 'height'
缺失的键: 'phone'
```

**索引访问与赋值结合**

`d[key]` 不仅可以取值，还可以参与运算和复合赋值：

```python
d = {"name": "张三", "age": 20, "score": 90.5}

# 取值后参与运算
d["score"] = d["score"] + 5
print(d["score"])   # 95.5

# 复合赋值
d["age"] += 1
print(d["age"])     # 21
```

**键类型的注意事项**

字典的键可以是任意可哈希类型，但需要注意一些"看起来相等但实际不同"的键：

```python
# 数字键：int 1 和 str "1" 是不同的键
d = {1: "int", "1": "str"}
print(d[1])      # int
print(d["1"])    # str（与整数 1 完全不同）

# 布尔与整数键冲突：True == 1, False == 0
d2 = {True: "布尔True", 1: "整数1", False: "布尔False", 0: "整数0"}
print(d2)   # {True: '整数1', False: '整数0'}  ← 后写的覆盖先写的
# True 和 1 视为同一个键，False 和 0 视为同一个键
```

**适用场景**

- 确定键一定存在时，直接索引是最快、最简洁的方式
- 如果不确定键是否存在，需要用 `try/except` 捕获 `KeyError`，或者改用 `get()` 方式

### 2.2 get() 方法安全访问

`d.get(key)` 和 `d.get(key, default)` 提供了不抛异常的安全访问方式——键存在时返回对应的值，键不存在时返回默认值。

**基本用法**

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# 键存在 → 返回对应的值
print(d.get("name"))          # 张三
print(d.get("age"))           # 20

# 键不存在 → 返回 None（默认）
print(d.get("height"))        # None

# 键不存在 → 返回指定的默认值
print(d.get("height", "未知"))  # 未知
print(d.get("score", 0))       # 0
```

**参数和返回值**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `key` | 任意可哈希类型 | 无（必传） | 要查找的键 |
| `default` | 任意 | `None` | 键不存在时返回的值 |

| 返回值 | 说明 |
|--------|------|
| `value` | 键存在时返回对应的值 |
| `default` 或 `None` | 键不存在时返回默认值 |

**运行结果**：

```text
张三
None
未知
```

**get() 不修改字典**

`get()` 是纯读取操作，不会往字典里写入任何东西。即使指定了默认值，字典本身也不受影响：

```python
d = {"name": "张三", "age": 20}

result = d.get("height", "未知")
print(d)       # {'name': '张三', 'age': 20}  ← 没有新增 "height"
print(result)  # 未知
```

**get() 的典型应用场景**

```python
# 场景一：配置项有默认值
config = {"host": "localhost", "port": 5432}
timeout = config.get("timeout", 30)       # 不在配置中 → 用默认 30
retries = config.get("retries", 3)        # 不在配置中 → 用默认 3
debug = config.get("debug", False)       # 不在配置中 → 用默认 False
print(f"host={config['host']}, timeout={timeout}, retries={retries}, debug={debug}")

# 场景二：词频统计中安全累加
text = "apple banana apple cherry banana apple"
word_count = {}
for word in text.split():
    word_count[word] = word_count.get(word, 0) + 1
print(word_count)   # {'apple': 3, 'banana': 2, 'cherry': 1}

# 场景三：可选字段处理
user = {"name": "张三", "age": 20}
nickname = user.get("nickname")   # None
if nickname is None:
    print("用户未设置昵称")
```

**get() vs d[key] 等价模式**

以下两种写法等价，但 `get()` 更简洁：

```python
d = {"a": 1, "b": 2}

# 写法一：in + d[key]（冗长）
if "c" in d:
    val = d["c"]
else:
    val = 0
print(val)   # 0

# 写法二：get（一步到位）
val = d.get("c", 0)
print(val)   # 0
```

**get 链式嵌套安全访问**

对于嵌套字典，可以逐层用 `get()` 避免任意一层的 `KeyError`：

```python
company = {
    "name": "TechCorp",
    "hq": {
        "address": {
            "city": "北京",
            "zip": "100084",
        }
    }
}

# 每层用 get(key, {}) 提供空字典默认值
city = company.get("hq", {}).get("address", {}).get("city", "未知")
print(f"城市: {city}")   # 北京

street = company.get("hq", {}).get("address", {}).get("street", "未知")
print(f"街道: {street}")   # 未知

# 某一层完全缺失时
country = company.get("branch", {}).get("address", {}).get("country", "中国")
print(f"国家: {country}")   # 中国（branch 不存在，返回 "中国"）
```

**get() 返回可变对象时的注意事项**

`get()` 返回的是引用而非副本，如果取回的是可变对象，修改它会直接影响原字典：

```python
d = {"items": [1, 2, 3]}
items = d.get("items", [])
items.append(4)
print(d)   # {'items': [1, 2, 3, 4]}  ← 修改了原字典中的列表！
```

如果不希望影响原字典，需要显式创建副本：

```python
d = {"items": [1, 2, 3]}
items_copy = d.get("items", []).copy()
items_copy.append(4)
print(d)   # {'items': [1, 2, 3]}  ← 原字典不受影响
```

### 2.3 in 成员判断

`in` 操作符用于检查一个键是否存在于字典中，时间复杂度 O(1)。

**基本用法**

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# in 检查键
print("name" in d)        # True
print("height" in d)      # False

# not in 检查键不存在
print("height" not in d)  # True
print("name" not in d)    # False
```

**in 只检查键，不检查值**

```python
d = {"name": "张三", "age": 20}

print("张三" in d)           # False（"张三" 是值，不是键）
print("name" in d)           # True（直接检查键）
print("name" in d.keys())    # True（通过 keys() 视图检查键，等价）
print(20 in d.values())      # True（在 values 中查找值）
```

`in d` 和 `in d.keys()` 完全等价，但 `in d` 更简洁，是惯用写法。

**在 values 中查找**

```python
d = {"a": 1, "b": 2, "c": 3}
print(2 in d.values())   # True
print(99 in d.values())  # False
```

**注意**：`in d.values()` 的时间复杂度是 O(n)，因为值不是哈希表的索引维度，需要逐个扫描。`in d` 和 `in d.keys()` 的时间复杂度是 O(1)。

**in 与 d[key] 的搭配模式**

```python
d = {"name": "张三", "age": 20}
key = "score"

# 模式一：先判断再访问（安全但冗长）
if key in d:
    print(f"{key} = {d[key]}")
else:
    print(f"{key} 不存在")

# 模式二：用 get 一步到位（更简洁）
value = d.get(key, "不存在")
print(f"{key} = {value}")
```

**检查多个键是否存在**

```python
required_keys = ["name", "age", "phone", "email"]
d = {"name": "张三", "age": 20, "email": "zhang@example.com"}

# 检查哪些键存在，哪些缺失
present = [k for k in required_keys if k in d]
missing = [k for k in required_keys if k not in d]
print(f"存在的键: {present}")   # ['name', 'age', 'email']
print(f"缺失的键: {missing}")   # ['phone']

# 检查是否所有必需键都存在（数据校验）
all_present = all(k in d for k in required_keys)
print(f"所有键都存在: {all_present}")   # False

# 检查是否有任一键存在
any_present = any(k in d for k in ["phone", "email"])
print(f"任一键存在: {any_present}")     # True
```

### 2.4 视图对象查找

`dict.keys()`、`dict.values()`、`dict.items()` 返回的不是列表，而是**视图对象**（view object）。视图对象是字典的"实时投影"——字典变化时，视图自动更新。

**三个视图对象**

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4}

keys_view = d.keys()
values_view = d.values()
items_view = d.items()

print(type(keys_view))    # <class 'dict_keys'>
print(type(values_view))  # <class 'dict_values'>
print(type(items_view))   # <class 'dict_items'>

print(f"keys:   {keys_view}")     # dict_keys(['a', 'b', 'c', 'd'])
print(f"values: {values_view}")   # dict_values([1, 2, 3, 4])
print(f"items:  {items_view}")    # dict_items([('a', 1), ('b', 2), ('c', 3), ('d', 4)])
```

**在视图对象中查找**

```python
d = {"a": 1, "b": 2, "c": 3}

# in 操作
print("a" in d.keys())         # True
print("z" in d.keys())         # False
print(3 in d.values())        # True
print(("a", 1) in d.items())  # True
print(("a", 2) in d.items())  # False
```

**视图是实时投影**

字典修改后，视图对象自动同步更新：

```python
d = {"a": 1, "b": 2, "c": 3}
keys = d.keys()

d["d"] = 4
print(list(keys))   # ['a', 'b', 'c', 'd']  ← 自动包含新键

del d["a"]
print(list(keys))   # ['b', 'c', 'd']  ← 自动移除已删键
```

**视图对象不支持索引**

视图不是列表，不能用 `[0]` 索引访问：

```python
d = {"a": 1, "b": 2}
keys = d.keys()
# print(keys[0])   # TypeError: 'dict_keys' object is not subscriptable

# 需要先转为列表
keys_list = list(keys)
print(keys_list[0])   # 'a'
```

### 2.5 用 keys() 视图做集合运算

`dict_keys` 视图支持集合运算（因为键唯一），这在查找两个字典的交集、并集、差集时非常方便：

```python
d1 = {"a": 1, "b": 2, "c": 3}
d2 = {"b": 20, "c": 30, "d": 40}

# 交集：两个字典共有的键
print(d1.keys() & d2.keys())   # {'b', 'c'}

# 并集：所有键
print(d1.keys() | d2.keys())   # {'a', 'b', 'c', 'd'}

# 差集：d1 有但 d2 没有的键
print(d1.keys() - d2.keys())   # {'a'}

# 对称差集：只在其中一个字典中出现的键
print(d1.keys() ^ d2.keys())   # {'a', 'd'}
```

### 2.6 用 items() 视图做集合运算

`dict_items` 视图也支持集合运算，但参与比较的是完整的键值对（键和值都要匹配）：

```python
d1 = {"a": 1, "b": 2, "c": 3}
d2 = {"b": 2, "c": 30, "d": 4}

# 交集：键值对完全相同的
print(d1.items() & d2.items())   # {('b', 2)}  ← 只有 b=2 相同

# 差集：d1 有但 d2 没有的键值对
print(d1.items() - d2.items())   # {('a', 1), ('c', 3)}
```

**实际应用：配置差异对比**

```python
old_config = {"host": "localhost", "port": 5432, "debug": True, "workers": 4}
new_config = {"host": "localhost", "port": 5432, "debug": False, "retries": 3}

# 用 keys 集合运算找出增删
added = new_config.keys() - old_config.keys()       # {'retries'}
removed = old_config.keys() - new_config.keys()      # {'workers'}

# 用 items 集合运算找出修改的键值对
common = new_config.keys() & old_config.keys()
changed = {k for k in common if old_config[k] != new_config[k]}  # {'debug'}

print(f"新增: {added}")
print(f"删除: {removed}")
print(f"修改: {changed}")
print(f"不变: {common - changed}")  # {'host', 'port'}
```

### 2.7 嵌套字典深度访问

字典的值可以是另一个字典，形成嵌套结构。访问嵌套数据时需要逐层深入，但任意一层键不存在都会导致 `KeyError`。

**逐层访问**

```python
company = {
    "name": "TechCorp",
    "departments": {
        "engineering": {
            "head": "张三",
            "members": ["李四", "王五", "赵六"],
            "budget": 1000000,
        },
        "sales": {
            "head": "李四",
            "members": ["王五"],
            "budget": 500000,
        }
    }
}

# 逐层访问
print(company["name"])                                    # TechCorp
print(company["departments"]["engineering"]["head"])       # 张三
print(company["departments"]["sales"]["members"][0])       # 王五
```

**KeyError 链**

嵌套访问中，任意一层不存在都会 `KeyError`：

```python
try:
    print(company["departments"]["marketing"]["head"])
except KeyError as e:
    print(f"访问失败: KeyError({e})")   # KeyError('marketing')

try:
    print(company["departments"]["engineering"]["budget"]["total"])
except KeyError as e:
    print(f"访问失败: KeyError({e})")   # KeyError('total')
    # 注意：budget 的值是 1000000（int），不是字典
    # 实际会 TypeError: 'int' object is not subscriptable
```

**用 get 链实现安全嵌套访问**

```python
# 每层用 get(key, {}) 提供空字典默认值
city = company.get("address", {}).get("city", "未知")
print(f"城市: {city}")   # 未知（address 不存在）

subgroup_lead = (
    company
    .get("departments", {})
    .get("engineering", {})
    .get("subgroups", {})
    .get("devops", {})
    .get("lead", "未任命")
)
print(f"devops 负责人: {subgroup_lead}")   # 未任命
```

**get 链的陷阱：中间层非字典类型**

`get` 链的默认值 `{}` 只在键不存在时生效。如果键存在但值不是字典（如 `None`、`int`），后续的 `get` 调用会 `TypeError`：

```python
data = {"key": None}
# data.get("key", {}).get("sub", "default")
# AttributeError: 'NoneType' object has no attribute 'get'
# 因为 data.get("key") 返回 None（键存在但值是 None），不是 {}
```

**安全方案：自定义 safe_get 函数**

```python
def safe_get(d, *keys, default=None):
    """逐层安全访问嵌套字典，遇到非字典类型自动返回 default"""
    current = d
    for k in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(k, default)
        if current is None:
            return default
    return current if current is not None else default

# 安全使用
print(safe_get(company, "departments", "engineering", "head"))        # 张三
print(safe_get(company, "departments", "engineering", "subgroups", "devops", "lead"))  # None
print(safe_get({"key": None}, "key", "sub", default="安全"))          # 安全
print(safe_get({"a": [1, 2]}, "a", 0, default="安全"))                # 安全
```

### 2.8 递归查找嵌套字典中的键

在深度不确定的嵌套字典中查找某个键，可以用递归遍历：

```python
def find_key_path(d, target_key, path=None):
    """在嵌套字典中查找某个键的路径，返回键的路径列表"""
    if path is None:
        path = []
    for key, value in d.items():
        current_path = path + [key]
        if key == target_key:
            return current_path
        if isinstance(value, dict):
            result = find_key_path(value, target_key, current_path)
            if result:
                return result
    return None

# 示例
company = {
    "departments": {
        "engineering": {
            "subgroups": {
                "frontend": {"lead": "钱七"}
            }
        }
    }
}

print(find_key_path(company, "lead"))
# ['departments', 'engineering', 'subgroups', 'frontend', 'lead']

print(find_key_path(company, "nonexistent"))
# None
```

### 2.9 五种查找方式性能对比

**时间复杂度速览**

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| `d[key]` | O(1) | 哈希查找 |
| `d.get(key)` | O(1) | 哈希查找（略有函数调用开销） |
| `key in d` | O(1) | 哈希查找 |
| `key in d.keys()` | O(1) | 等价于 `key in d` |
| `val in d.values()` | O(n) | 需要遍历所有值 |
| `(k, v) in d.items()` | O(1) | 哈希查找（计算 key 的 hash） |

**性能基准测试**

```python
import time

n = 100000
big_dict = {str(i): i for i in range(n)}
big_list = [str(i) for i in range(n)]
target = "99999"

# d[key] 访问：O(1)
start = time.perf_counter()
for _ in range(1000000):
    _ = big_dict[target]
dict_index_time = time.perf_counter() - start

# d.get(key) 访问：O(1)
start = time.perf_counter()
for _ in range(1000000):
    _ = big_dict.get(target)
dict_get_time = time.perf_counter() - start

# key in d：O(1)
start = time.perf_counter()
for _ in range(1000000):
    _ = target in big_dict
dict_in_time = time.perf_counter() - start

# target in list：O(n)
start = time.perf_counter()
for _ in range(100000):
    _ = target in big_list
list_in_time = time.perf_counter() - start

print(f"dict d[key]     (100万次): {dict_index_time:.4f} 秒")
print(f"dict d.get(key) (100万次): {dict_get_time:.4f} 秒")
print(f"dict key in d   (100万次): {dict_in_time:.4f} 秒")
print(f"list x in lst   (10万次):  {list_in_time:.4f} 秒")
```

运行结果：

```text
dict d[key]     (100万次): 0.0215 秒
dict d.get(key) (100万次): 0.0312 秒
dict key in d   (100万次): 0.0223 秒
list x in lst   (10万次):  6.3632 秒
```

**关键发现**：字典的三种查找方式（`d[key]`、`d.get()`、`in`）都是 O(1)，耗时基本一致。列表的 `in` 查找是 O(n)，在 10 万元素中查找比字典慢了上千倍。

**不同规模下的查找性能**

```text
=== 字典 in 查找（O(1)）===
    1000 元素, 10万次 in: 0.0031 秒
   10000 元素, 10万次 in: 0.0032 秒
  100000 元素, 10万次 in: 0.0033 秒
 1000000 元素, 10万次 in: 0.0035 秒
  ← 规模翻 1000 倍，耗时几乎不变

=== 列表 in 查找（O(n)）===
    1000 元素, 1万次 in:  0.0064 秒
   10000 元素, 1万次 in:  0.0634 秒
  100000 元素, 1万次 in:  0.6363 秒
  ← 规模翻 10 倍，耗时也翻 10 倍
```

### 2.10 键不存在时的性能对比

当键不存在时，不同的访问方式有不同的性能表现：

```python
d = {"name": "张三", "age": 20}
reps = 5000000

# 方式一：try/except KeyError
start = time.perf_counter()
for _ in range(reps // 10):
    try:
        _ = d["missing"]
    except KeyError:
        pass
t_except = time.perf_counter() - start

# 方式二：get
start = time.perf_counter()
for _ in range(reps):
    _ = d.get("missing")
t_get = time.perf_counter() - start

# 方式三：in + d[key]
start = time.perf_counter()
for _ in range(reps):
    if "missing" in d:
        _ = d["missing"]
t_in = time.perf_counter() - start

print(f"try/except（{reps // 10:,} 次）: {t_except:.4f} 秒")
print(f"d.get(key)（{reps:,} 次）:      {t_get:.4f} 秒")
print(f"in + d[key]（{reps:,} 次）:     {t_in:.4f} 秒")
```

运行结果：

```text
try/except（500,000 次）: 0.1234 秒
d.get(key)（5,000,000 次）: 0.1389 秒
in + d[key]（5,000,000 次）: 0.0745 秒
```

**结论**：

| 方式 | 速度 | 原因 |
|------|------|------|
| `try/except` | 最慢（少了10倍次数仍慢） | 异常对象的创建和栈回溯开销大 |
| `d.get(key)` | 快 | C 层面一次哈希查找 + 返回默认值 |
| `in + d[key]` | 最快 | 两次哈希查找但无异常开销 |

键不存在时，推荐用 `get()` 或 `in + d[key]`，避免用 `try/except KeyError`。

### 2.11 将列表转为字典加速查找

当需要频繁判断"某元素是否在大量数据中"时，将列表转为字典或集合可以大幅提速：

```python
# 场景：黑名单校验
blacklist_list = [f"user_{i}" for i in range(50000)]
blacklist_dict = {u: True for u in blacklist_list}
blacklist_set = set(blacklist_list)

test_user = "user_49999"

# 列表查找：O(n)
start = time.perf_counter()
for _ in range(10000):
    _ = test_user in blacklist_list
list_time = time.perf_counter() - start

# 字典查找：O(1)
start = time.perf_counter()
for _ in range(10000):
    _ = test_user in blacklist_dict
dict_time = time.perf_counter() - start

# 集合查找：O(1)
start = time.perf_counter()
for _ in range(10000):
    _ = test_user in blacklist_set
set_time = time.perf_counter() - start

print(f"列表: {list_time:.4f} 秒")
print(f"字典: {dict_time:.4f} 秒")
print(f"集合: {set_time:.4f} 秒")
```

运行结果：

```text
列表: 2.9488 秒
字典: 0.0005 秒
集合: 0.0005 秒
```

字典和集合的 `in` 都是 O(1)，大规模数据查找时比列表快数千倍。如果只需要判断存在性（不需要键值对），用集合即可；如果需要关联额外的标记值，用字典。

### 2.12 批量多键访问

字典没有内置的"一次取多个键的值"的 API，但可以用各种方式实现：

```python
d = {"name": "张三", "age": 20, "city": "北京", "score": 90.5}

# 方式一：列表推导式 + d[key]（键不存在会 KeyError）
keys = ["name", "age", "city"]
values = [d[k] for k in keys]
print(values)   # ['张三', 20, '北京']

# 方式二：推导式 + get（安全多键取值）
safe_keys = ["name", "age", "phone", "height"]
results = {k: d.get(k, "N/A") for k in safe_keys}
print(results)
# {'name': '张三', 'age': 20, 'phone': 'N/A', 'height': 'N/A'}

# 方式三：用 operator.itemgetter（高效，适合批量取值）
from operator import itemgetter
getter = itemgetter("name", "age", "city")
print(getter(d))   # ('张三', 20, '北京')
```

## 3. 最佳实践

### 3.1 推荐用 d[key] 访问确定存在的键

```python
# 推荐：确定键一定存在时，直接索引最快
d = {"name": "张三", "age": 20}
name = d["name"]   # 确定存在，直接索引

# 不推荐：确定存在时仍用 get（多余开销）
name = d.get("name")   # 多了一次函数调用
```

### 3.2 推荐用 get() 访问不确定的键

```python
# 推荐：不确定键是否存在时用 get
age = d.get("age", 0)        # 不存在则用 0
email = d.get("email")       # 不存在则用 None

# 不推荐：手动判断（冗长）
if "age" in d:
    age = d["age"]
else:
    age = 0

# 不推荐：try/except（异常开销大）
try:
    age = d["age"]
except KeyError:
    age = 0
```

### 3.3 推荐用 in 判断存在性（不取值时）

```python
# 推荐：只需判断是否存在，不用 in
if "name" in d:
    print("有 name 字段")

# 不推荐：用 get 判断是否存在（语义不清晰）
if d.get("name") is not None:
    print("有 name 字段")
# 如果 d["name"] 本身是 None，这个判断就出错了
```

### 3.4 推荐用 keys() 集合运算对比字典

```python
# 推荐：用 keys() 集合运算找出差异
old = {"a": 1, "b": 2, "c": 3}
new = {"b": 2, "c": 30, "d": 4}

added = new.keys() - old.keys()      # {'d'}
removed = old.keys() - new.keys()     # {'a'}
common = old.keys() & new.keys()     # {'b', 'c'}

# 不推荐：手动遍历对比
added = [k for k in new if k not in old]
removed = [k for k in old if k not in new]
```

### 3.5 禁止用 try/except 处理频繁缺失的键

```python
# 不推荐：高频缺失时 try/except 性能最差
for key in lots_of_maybe_missing_keys:
    try:
        value = d[key]
    except KeyError:
        value = None

# 推荐：用 get（O(1)，无异常开销）
for key in lots_of_maybe_missing_keys:
    value = d.get(key)
```

### 3.6 大规模查找转为字典或集合

```python
# 场景：频繁检查元素是否在大量数据中

# 不推荐：用 list 存储 + in 查找（O(n)）
blacklist = ["user_1", "user_2", ..., "user_50000"]
if user in blacklist:   # O(n)，50000 个元素逐个对比

# 推荐：用 set 存储 + in 查找（O(1)）
blacklist_set = set(blacklist)
if user in blacklist_set:   # O(1)，一次哈希查找

# 推荐：如需要标记信息，用 dict
blacklist_dict = {u: True for u in blacklist}
if user in blacklist_dict:   # O(1)
```

### 3.7 嵌套字典用 get 链或安全函数

```python
# 不推荐：裸索引逐层访问（任意层不存在都会 KeyError）
city = company["departments"]["engineering"]["address"]["city"]

# 推荐：get 链（中间层提供 {} 默认值）
city = company.get("departments", {}).get("engineering", {}).get("address", {}).get("city", "未知")

# 推荐：封装 safe_get 函数处理中间层非字典的情况
def safe_get(d, *keys, default=None):
    current = d
    for k in keys:
        if not isinstance(current, dict):
            return default
        current = current.get(k)
        if current is None:
            return default
    return current if current is not None else default

city = safe_get(company, "departments", "engineering", "address", "city", default="未知")
```

### 3.8 访问方式选择速查指南

```text
你需要访问字典中的值时，问自己：

1. 你确定键一定存在吗？
   → 是 → 用 d[key]  （最快，一步到位）
   → 否 → 继续问

2. 你需要取值还是只判断存在？
   → 只判断 → 用 key in d
   → 需取值 → 继续问

3. 键不存在时你需要默认值吗？
   → 需要默认值 → 用 d.get(key, default)
   → 不需要（用 None 即可）→ 用 d.get(key)

4. 是嵌套字典？
   → 浅层 → d.get("a", {}).get("b", {}).get("c", "默认值")
   → 深层/不确定 → 封装 safe_get 函数

5. 需要在大量数据中频繁查找？
   → 转为 dict 或 set，利用 O(1) 查找
```

## 4. 原理

### 4.1 字典查找为什么是 O(1)

字典的 O(1) 查找来自底层的**哈希表**机制——通过哈希函数将键直接映射到存储位置：

```text
查找过程：d["name"]

1. 计算 hash("name") → 得到一个大整数（如 1234567890）
2. hash % 表大小 → 得到索引位置（如 1234567890 % 8 = 2）
3. 直接访问数组索引 2 → 拿到 "name" 对应的值

整个过程不需要遍历，直接定位 → O(1)
```

与列表查找的对比：

```text
列表查找："name" in big_list

1. 从索引 0 开始
2. 逐个比较 big_list[0] == "name"? → 否
3. big_list[1] == "name"? → 否
4. ... 一直比较到最后一个元素
5. 最好情况第一个就匹配（O(1)），最坏情况到最后才找到（O(n)）

平均时间复杂度: O(n)
```

### 4.2 哈希冲突对查找性能的影响

不同的键可能算出相同的哈希值取模结果（哈希冲突），此时需要用**开放寻址法**处理——冲突时往后探查下一个空槽：

```text
假设 hash("a") % 8 = 2
假设 hash("x") % 8 = 2  ← 冲突！

槽位 2: "a" → 1   (先存的 "a" 占了位置)
槽位 3: "x" → 99  (冲突，往后找一个空槽)

查找 "x" 时：
  1. hash("x") % 8 = 2
  2. 槽位 2 存的是 "a" ≠ "x" → 冲突
  3. 往后探查槽位 3 → 存的是 "x" → 命中
```

Python 字典在冲突较少时，查找接近 O(1)；极端情况下（大量冲突），最坏为 O(n)，但 CPython 通过动态扩容和小整数哈希优化使冲突概率极低。

### 4.3 get() 的 C 层面实现

`d.get(key, default)` 在 CPython 中由 C 函数 `dict_get_impl` 实现，核心逻辑与 `d[key]` 类似，差别在于键不存在时不抛异常而是返回默认值：

```c
// 简化的 dict_get 逻辑
PyObject *dict_get_impl(PyDictObject *d, PyObject *key, PyObject *default_value) {
    Py_hash_t hash = PyObject_Hash(key);    // 1. 计算键的哈希值
    PyDictKeyEntry *entry = lookdict(d, key, hash);  // 2. 哈希表查找

    if (entry == NULL) {
        // 3. 键不存在 → 返回默认值（不抛异常）
        return default_value;   // 默认为 Py_None
    }
    // 4. 键存在 → 返回对应的值
    return entry->me_value;
}
```

而 `d[key]` 的实现（`dict_subscript`）在键不存在时**抛出异常**：

```c
// 简化的 dict_subscript 逻辑
PyObject *dict_subscript(PyDictObject *d, PyObject *key) {
    Py_hash_t hash = PyObject_Hash(key);
    PyDictKeyEntry *entry = lookdict(d, key, hash);

    if (entry == NULL) {
        // 键不存在 → 抛出 KeyError 异常
        PyErr_SetObject(PyExc_KeyError, key);
        return NULL;   // 返回 NULL 表示出错
    }
    return entry->me_value;
}
```

**性能差异来源**：`d[key]` 和 `d.get(key)` 的哈希查找部分完全相同（都调用 `lookdict`）。差异在于：键不存在时 `d[key]` 需要创建 `KeyError` 异常对象、填充栈回溯信息——这比返回默认值慢得多。

### 4.4 in 操作符的底层实现

`key in d` 在 CPython 中调用 `dict___contains__` 方法：

```c
// 简化的 dict___contains__ 逻辑
int dict_contains(PyDictObject *d, PyObject *key) {
    Py_hash_t hash = PyObject_Hash(key);
    return lookdict(d, key, hash) != NULL;  // 找到 → 1(True), 没找到 → 0(False)
}
```

`in` 操作只判断"有没有"，不返回值，因此比 `d.get(key)` 少了一步"取值"操作——但实际上差异可忽略不计，两者都是 O(1)。

### 4.5 values() 视图查找为什么是 O(n)

`keys()` 和 `items()` 视图的 `in` 操作可以利用哈希表（按键查找），所以是 O(1)。但 `values()` 视图的 `in` 操作无法利用哈希表——值在哈希表中不是索引维度，只能逐个扫描：

```text
keys() 的 in 查找：
  计算 hash(key) → 定位槽位 → 比较键 → O(1)

values() 的 in 查找：
  遍历哈希表中的每个条目 → 逐个比较值 → O(n)
```

```python
# 验证：values() 的 in 是 O(n)
d = {i: i for i in range(100000)}

import time

# keys() in：O(1)
start = time.perf_counter()
for _ in range(100000):
    _ = 99999 in d.keys()    # 直接哈希查找
keys_time = time.perf_counter() - start

# values() in：O(n)
start = time.perf_counter()
for _ in range(100):   # 只做 100 次，因为 O(n) 很慢
    _ = 99999 in d.values()  # 需要遍历所有值
values_time = time.perf_counter() - start

print(f"keys()   in: {keys_time:.4f} 秒 (10万次)")
print(f"values() in: {values_time:.4f} 秒 (100次)")
```

### 4.6 视图对象的集合运算底层

`dict_keys` 和 `dict_items` 视图之所以支持集合运算，是因为它们实现了 `__and__`、`__or__`、`__sub__` 等集合协议方法。`dict_values` 没有实现这些方法，因为值可能重复，没有集合语义。

```python
# keys() 视图：支持集合运算
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}
print(d1.keys() & d2.keys())   # {'b'}  ← 交集
print(d1.keys() | d2.keys())   # {'a', 'b', 'c'}  ← 并集

# values() 视图：不支持集合运算
# d1.values() & d2.values()  # TypeError: unsupported operand type(s) for &: 'dict_values' and 'dict_values'
```

集合运算的底层实现是将视图对象先转为 `set`，然后执行集合运算并返回新的 `set` 对象：

```c
// 简化的 keys 视图交集逻辑
PyObject *dict_keys_intersection(PyObject *view1, PyObject *view2) {
    PyObject *result = set_new();           // 创建空集合
    for (key in view1) {
        if (key in view2) {                 // 利用 keys 的 O(1) 查找
            set_add(result, key);
        }
    }
    return result;
}
```

## 5. 总结

本文围绕"字典的访问与查找"展开，主要介绍了以下内容：

- **直接索引访问 `d[key]`**：最基本、最快的访问方式，通过键直接取值，时间复杂度 O(1)。键不存在时抛出 `KeyError` 异常。适用于确定键一定存在的场景。注意布尔与整数的键冲突（`True == 1`，`False == 0`）。

- **`get()` 安全访问**：`d.get(key)` 和 `d.get(key, default)` 提供不抛异常的安全访问方式，键存在时返回值，键不存在时返回默认值（`None` 或指定值）。不修改字典。适用于不确定键是否存在的场景，如配置项默认值、词频统计累加、可选字段处理。

- **`in` 成员判断**：`key in d` 检查键是否存在，O(1) 时间复杂度。`in d` 和 `in d.keys()` 等价。`in d.values()` 是 O(n)，因为值不是哈希索引维度。适用于数据校验、存在性判断、批量键检查。

- **视图对象查找**：`keys()`、`values()`、`items()` 返回视图对象而非列表，是字典的实时投影。`keys()` 和 `items()` 视图支持集合运算（交集 `&`、并集 `|`、差集 `-`），适合两个字典的差集对比。`values()` 视图不支持集合运算。

- **嵌套字典深度访问**：逐层用 `d["a"]["b"]["c"]` 访问，任意一层不存在都会 `KeyError`。用 `get` 链（`d.get("a", {}).get("b", {})`）可以安全访问，但中间层为非字典类型时仍有风险。封装 `safe_get` 函数可以处理任意中间层类型异常。

- **性能特点**：`d[key]`、`d.get()`、`in` 三种查找方式都是 O(1)，性能基本一致；列表 `in` 是 O(n)，大规模数据查找比字典慢数千倍。键不存在时 `try/except` 最慢（异常对象创建开销），`get()` 次之，`in + d[key]` 最快。

- **最佳实践**：确定键存在用 `d[key]`；不确定用 `get()`；只判断存在用 `in`；对比两个字典用 `keys()` 集合运算；频繁查找大量数据转为 `dict` 或 `set`；嵌套访问用 `get` 链或 `safe_get` 函数；避免用 `try/except` 处理高频缺失键。
