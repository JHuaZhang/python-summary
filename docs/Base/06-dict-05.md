# 字典的遍历方法

## 1. 介绍

### 1.1 什么是字典遍历

字典遍历是指依次访问字典中的键、值或键值对的过程。与列表、元组等序列类型不同，字典是映射类型，存储的是键值对（key-value pair），因此遍历字典有三种基本方式：只遍历键、只遍历值、同时遍历键和值。

在实际开发中，字典遍历几乎无处不在——读取配置项、处理 JSON 数据、统计计数结果、遍历嵌套结构等场景都需要你熟练掌握各种遍历方法。

### 1.2 最简示例

先看一个最基本的字典遍历：

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# 默认遍历——直接 for 循环字典，得到的是键
for key in d:
    print(key, d[key])
```

运行结果：

```text
name 张三
age 20
city 北京
```

这就是最简单的字典遍历。但 Python 提供了更多更强的方式，帮助你用更少的代码做更多的事。

### 1.3 遍历方法概览

| 方法 | 语法 | 获取内容 | 典型场景 |
|------|------|---------|---------|
| 默认遍历 | `for k in d` | 只获取键 | 只需要键名时 |
| `keys()` | `for k in d.keys()` | 只获取键 | 显式表达意图 |
| `values()` | `for v in d.values()` | 只获取值 | 只需要值时 |
| `items()` | `for k, v in d.items()` | 键和值 | 同时需要键和值 |
| `enumerate()` | `for i, k in enumerate(d)` | 索引 + 键 | 需要编号时 |
| `zip()` | `for k1, k2 in zip(d1, d2)` | 多字典同步遍历 | 对比多个字典 |
| `sorted()` | `for k in sorted(d)` | 排序后遍历 | 需要有序遍历 |

## 2. 核心内容

### 2.1 遍历键

#### 2.1.1 基本遍历：for k in d

直接对字典使用 `for` 循环，Python 默认遍历的就是键。这是最简洁的写法，也是最常见的遍历方式之一。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

for key in d:
    print(f"键: {key}")
```

运行结果：

```text
键: name
键: age
键: city
```

**关键点**：`for k in d` 和 `for k in d.keys()` 完全等价。Python 中对字典直接迭代时，会隐式调用 `dict.__iter__` 方法，而该方法返回的就是键的迭代器。选择哪种写法取决于可读性偏好——`for k in d` 更简洁，`for k in d.keys()` 更显式。

#### 2.1.2 显式遍历键：for k in d.keys()

`d.keys()` 返回一个 `dict_keys` 视图对象（view object），它是一个动态的、可迭代的对象，反映字典当前的状态。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

for key in d.keys():
    print(f"键: {key}")
```

运行结果：

```text
键: name
键: age
键: city
```

**视图对象的类型**：

```python
print(type(d.keys()))   # <class 'dict_keys'>
```

#### 2.1.3 遍历键并获取值

当你只需要键的名称，但同时想用键去访问对应的值时：

```python
d = {"name": "张三", "age": 20, "city": "北京"}

for key in d:
    print(f"  {key}: {d[key]}")
```

运行结果：

```text
  name: 张三
  age: 20
  city: 北京
```

这里 `d[key]` 每次都会进行一次哈希查找。虽然字典查找很快（平均 O(1)），但如果同时需要键和值，更推荐使用 `d.items()`——一次返回键值对，无需额外查找。

#### 2.1.4 dict_keys 视图对象的特性

视图对象不是列表，它有两个重要特性：

**特性一：动态性**——视图对象反映字典的实时状态。如果字典发生变化，视图对象自动更新。

```python
d = {"a": 1, "b": 2, "c": 3}
keys_view = d.keys()
print(f"原始视图: {list(keys_view)}")   # ['a', 'b', 'c']

d["d"] = 4   # 添加键
print(f"添加后视图: {list(keys_view)}")   # ['a', 'b', 'c', 'd']

del d["a"]
print(f"删除后视图: {list(keys_view)}")   # ['b', 'c', 'd']
```

运行结果：

```text
原始视图: ['a', 'b', 'c']
添加后视图: ['a', 'b', 'c', 'd']
删除后视图: ['b', 'c', 'd']
```

**特性二：不支持索引访问**——`dict_keys` 是可迭代对象，但不是序列，不能用下标访问。

```python
keys = d.keys()
# keys[0]   # TypeError: 'dict_keys' object is not subscriptable

# 需要索引访问时，先转成列表
keys_list = list(d.keys())
print(f"第一个键: {keys_list[0]}")
print(f"最后一个键: {keys_list[-1]}")
```

#### 2.1.5 dict_keys 支持集合运算

`dict_keys` 对象支持集合运算（交集、并集、差集、对称差集），因为字典的键天然是唯一的、可哈希的。这使得多个字典之间的键比较变得非常方便。

```python
d1 = {"a": 1, "b": 2, "c": 3}
d2 = {"b": 20, "c": 30, "d": 40, "e": 50}

# 交集：两个字典共有的键
common = d1.keys() & d2.keys()
print(f"交集: {common}")           # {'b', 'c'}

# 并集：所有键
all_keys = d1.keys() | d2.keys()
print(f"并集: {all_keys}")         # {'a', 'b', 'c', 'd', 'e'}

# 差集：d1 有但 d2 没有的键
diff = d1.keys() - d2.keys()
print(f"差集: {diff}")             # {'a'}

# 对称差集：只在其中一个字典中出现的键
sym_diff = d1.keys() ^ d2.keys()
print(f"对称差集: {sym_diff}")     # {'a', 'd', 'e'}
```

运行结果：

```text
交集: {'c', 'b'}
并集: {'d', 'b', 'e', 'c', 'a'}
差集: {'a'}
对称差集: {'d', 'e', 'a'}
```

注意：集合运算的结果是无序的 `set` 类型，不保留字典的插入顺序。如果需要有序结果，需要在运算后用 `sorted()` 排序。

#### 2.1.6 遍历键的常见应用场景

**场景一：提取所有键到列表**

```python
d = {"x": 10, "y": 20, "z": 30}
keys = list(d.keys())
print(f"所有键: {keys}")   # ['x', 'y', 'z']
```

**场景二：按键名过滤**

```python
config = {"debug": True, "port": 80, "host": "localhost", "secret_key": "abc"}
public_keys = [k for k in config if "secret" not in k.lower()]
print(f"非敏感配置键: {public_keys}")   # ['debug', 'port', 'host']
```

**场景三：按键名排序后遍历**

```python
scores = {"cherry": 95, "apple": 85, "banana": 90}

# 按键名升序遍历
for key in sorted(scores.keys()):
    print(f"  {key}: {scores[key]}")

# 按键名降序遍历
for key in sorted(scores.keys(), reverse=True):
    print(f"  {key}: {scores[key]}")
```

运行结果：

```text
apple: 85
banana: 90
cherry: 95
cherry: 95
banana: 90
apple: 85
```

### 2.2 遍历值

#### 2.2.1 基本遍历值：for v in d.values()

当你只关心字典中的值，不需要键时，使用 `d.values()` 遍历。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

for value in d.values():
    print(f"值: {value}")
```

运行结果：

```text
值: 张三
值: 20
值: 北京
```

`d.values()` 返回一个 `dict_values` 视图对象：

```python
print(type(d.values()))   # <class 'dict_values'>
```

#### 2.2.2 值的类型多样性

字典的值可以是任意类型——字符串、数字、列表、字典、元组、布尔值，甚至函数。遍历值时，你可能遇到各种类型的数据。

```python
mixed = {
    "name": "张三",           # str
    "age": 20,                # int
    "scores": [85, 92, 78],  # list
    "info": {"major": "CS"}, # dict
    "active": True,          # bool
    "tags": ("vip", "pro"),  # tuple
}

for value in mixed.values():
    print(f"  {value} (类型: {type(value).__name__})")
```

运行结果：

```text
张三 (类型: str)
20 (类型: int)
[85, 92, 78] (类型: list)
{'major': 'CS'} (类型: dict)
True (类型: bool)
('vip', 'pro') (类型: tuple)
```

#### 2.2.3 遍历值做聚合运算

`d.values()` 可以直接传递给内置聚合函数（如 `sum()`、`max()`、`min()`），这在统计场景中非常实用。

```python
prices = {"apple": 3.5, "banana": 2.8, "cherry": 8.0, "date": 6.5}

# 求和
total = sum(prices.values())
print(f"总价: {total}")
print(f"平均价: {total / len(prices):.2f}")

# 求最大值和最小值
print(f"最高价: {max(prices.values())}")
print(f"最低价: {min(prices.values())}")

# 统计满足条件的数量
expensive = sum(1 for v in prices.values() if v > 5)
print(f"价格>5的水果数: {expensive}")
```

运行结果：

```text
总价: 20.8
平均价: 5.20
最高价: 8.0
最低价: 2.8
价格>5的水果数: 2
```

#### 2.2.4 dict_values 视图对象的特性

与 `dict_keys` 一样，`dict_values` 也是动态视图：

```python
d = {"a": 1, "b": 2, "c": 3}
vals_view = d.values()
print(f"原始视图: {list(vals_view)}")   # [1, 2, 3]

d["a"] = 99   # 修改值
print(f"修改后视图: {list(vals_view)}")   # [99, 2, 3]

d["d"] = 4    # 添加键值对
print(f"添加后视图: {list(vals_view)}")   # [99, 2, 3, 4]
```

**重要区别**：与 `dict_keys` 不同，`dict_values` **不支持集合运算**。因为值可能重复，也可能不可哈希（如列表、字典等可变类型）。

```python
# d1.values() & d2.values()   # TypeError: unsupported operand type(s)
```

#### 2.2.5 遍历值找对应键

遍历值时无法直接知道对应的键。如果你需要"找到值最大的键"这类操作，推荐使用 `items()` 而非先遍历值再反查键。

```python
d = {"apple": 3.5, "banana": 2.8, "cherry": 8.0}

max_val = max(d.values())

# 推荐：用 items() 同时获取键和值
for key, value in d.items():
    if value == max_val:
        print(f"最贵的: {key} = {value}")
```

运行结果：

```text
最贵的: cherry = 8.0
```

#### 2.2.6 遍历嵌套字典的值

当字典的值本身也是字典或列表时，遍历外层字典的值可以进一步处理内部数据。

```python
school = {
    "cs": {"students": 500, "teachers": 30},
    "math": {"students": 200, "teachers": 15},
    "physics": {"students": 150, "teachers": 10},
}

total_students = 0
for dept_info in school.values():
    total_students += dept_info["students"]
print(f"总学生数: {total_students}")
```

运行结果：

```text
总学生数: 850
```

### 2.3 遍历键值对

#### 2.3.1 基本遍历键值对：for k, v in d.items()

`d.items()` 返回一个 `dict_items` 视图对象，其中每个元素是一个 `(key, value)` 元组。使用元组解包语法可以同时获取键和值。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

for key, value in d.items():
    print(f"  {key}: {value}")
```

运行结果：

```text
  name: 张三
  age: 20
  city: 北京
```

`d.items()` 返回类型：

```python
print(type(d.items()))   # <class 'dict_items'>
```

#### 2.3.2 元组解包

`items()` 的每个元素是一个 `(key, value)` 元组。`for k, v in d.items()` 利用了 Python 的元组解包语法——将元组中的两个元素分别赋值给 `k` 和 `v`。

如果不解包，可以直接获取整个元组：

```python
d = {"a": 1, "b": 2}

for item in d.items():
    print(f"  {item} (类型: {type(item).__name__})")
```

运行结果：

```text
  ('a', 1) (类型: tuple)
  ('b', 2) (类型: tuple)
```

#### 2.3.3 dict_items 视图对象特性

与 `dict_keys` 一样，`dict_items` 也是动态视图，并且支持集合运算——因为键值对中的键和值都参与比较。

```python
d = {"a": 1, "b": 2, "c": 3}
items_view = d.items()
print(f"原始视图: {list(items_view)}")

d["d"] = 4
print(f"添加后视图: {list(items_view)}")

d["a"] = 99
print(f"修改后视图: {list(items_view)}")
```

运行结果：

```text
原始视图: [('a', 1), ('b', 2), ('c', 3)]
添加后视图: [('a', 1), ('b', 2), ('c', 3), ('d', 4)]
修改后视图: [('a', 99), ('b', 2), ('c', 3), ('d', 4)]
```

#### 2.3.4 dict_items 支持集合运算

`dict_items` 也支持集合运算，比较的粒度是整个键值对——只有键和值都相同才算"相等"。

```python
d1 = {"a": 1, "b": 2, "c": 3}
d2 = {"b": 2, "c": 30, "d": 4}

# 交集：键值对完全相同的项
common = d1.items() & d2.items()
print(f"交集: {common}")   # {('b', 2)}

# 并集
all_items = d1.items() | d2.items()
print(f"并集: {all_items}")
# {('a', 1), ('b', 2), ('c', 3), ('c', 30), ('d', 4)}

# 差集
diff = d1.items() - d2.items()
print(f"差集: {diff}")   # {('a', 1), ('c', 3)}
```

运行结果：

```text
交集: {('b', 2)}
并集: {('c', 30), ('b', 2), ('c', 3), ('d', 4), ('a', 1)}
差集: {('a', 1), ('c', 3)}
```

注意 `d1` 中 `c=3` 和 `d2` 中 `c=30` 都保留在并集中——虽然键相同，但值不同，所以是两个不同的键值对。这意味着并集结果的元素数量可能超过任一原始字典的大小。

**使用场景**：当你需要比较两个配置字典哪些配置项完全一致、哪些发生了变化时，`items()` 的集合运算非常实用。

#### 2.3.5 遍历键值对的常见模式

**模式一：格式化输出**

```python
config = {"host": "localhost", "port": 8080, "debug": True}

for key, value in config.items():
    print(f"  {key:>10} = {value}")
```

运行结果：

```text
       host = localhost
       port = 8080
      debug = True
```

**模式二：条件过滤**

```python
scores = {"张三": 85, "李四": 92, "王五": 78, "赵六": 95}

for name, score in scores.items():
    if score > 80:
        print(f"  {name}: {score}")
```

运行结果：

```text
  张三: 85
  李四: 92
  赵六: 95
```

**模式三：值是容器时的遍历**

```python
classroom = {
    "一班": ["张三", "李四"],
    "二班": ["王五", "赵六", "钱七"],
}

for class_name, students in classroom.items():
    print(f"  {class_name}: {', '.join(students)} (共{len(students)}人)")
```

运行结果：

```text
  一班: 张三, 李四 (共2人)
  二班: 王五, 赵六, 钱七 (共3人)
```

#### 2.3.6 遍历 items 做字典转换

利用 `items()` 和字典推导式，可以方便地对字典进行各种转换：

```python
# 反转键值对
original = {"a": 1, "b": 2, "c": 3}
reversed_dict = {v: k for k, v in original.items()}
print(f"反转后: {reversed_dict}")   # {1: 'a', 2: 'b', 3: 'c'}

# 格式化为字符串列表
prices = {"apple": 3.5, "banana": 2.8, "cherry": 8.0}
formatted = [f"{k}={v}" for k, v in prices.items()]
print(f"格式化列表: {formatted}")
```

运行结果：

```text
反转后: {1: 'a', 2: 'b', 3: 'c'}
格式化列表: ['apple=3.5', 'banana=2.8', 'cherry=8.0']
```

#### 2.3.7 嵌套字典的 items 遍历

当字典嵌套时，需要使用多层 `items()` 循环。

```python
school = {
    "cs": {"students": 500, "teachers": 30},
    "math": {"students": 200, "teachers": 15},
}

for dept_name, dept_info in school.items():
    print(f"  {dept_name}:")
    for key, value in dept_info.items():
        print(f"    {key}: {value}")
```

运行结果：

```text
  cs:
    students: 500
    teachers: 30
  math:
    students: 200
    teachers: 15
```

### 2.4 enumerate 索引遍历

#### 2.4.1 基本用法

`enumerate()` 是 Python 内置函数，用于在遍历时获取元素的索引序号。对字典使用 `enumerate()` 时，默认枚举的是键（因为遍历字典默认遍历键）。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# enumerate(d) 枚举键
for index, key in enumerate(d):
    print(f"  [{index}] 键: {key}")

# enumerate(d.items()) 枚举键值对
for index, (key, value) in enumerate(d.items()):
    print(f"  [{index}] {key}: {value}")
```

运行结果：

```text
  [0] 键: name
  [1] 键: age
  [2] 键: city
  [0] name: 张三
  [1] age: 20
  [2] city: 北京
```

注意 `enumerate(d.items())` 的解包语法：`for index, (key, value) in enumerate(d.items())`。这里 `enumerate` 返回的是 `(index, (key, value))`，外层解包得到 `index` 和 `(key, value)`，内层再解包 `(key, value)` 得到 `key` 和 `value`。

#### 2.4.2 指定起始序号

`enumerate()` 默认从 0 开始计数。通过 `start` 参数可以指定起始序号。

```python
d = {"name": "张三", "age": 20, "city": "北京"}

for index, (key, value) in enumerate(d.items(), start=1):
    print(f"  {index}. {key}: {value}")
```

运行结果：

```text
  1. name: 张三
  2. age: 20
  3. city: 北京
```

#### 2.4.3 使用场景

**场景一：给字典项编号**

```python
students = {"张三": 85, "李四": 92, "王五": 78, "赵六": 95}

for rank, (name, score) in enumerate(students.items(), start=1):
    print(f"  第{rank}名: {name} - {score}分")
```

运行结果：

```text
  第1名: 张三 - 85分
  第2名: 李四 - 92分
  第3名: 王五 - 78分
  第4名: 赵六 - 95分
```

**场景二：交替输出**

```python
d = {"name": "张三", "age": 20, "city": "北京"}

for index, (key, value) in enumerate(d.items()):
    if index % 2 == 0:
        print(f"  [偶数索引] {key}: {value}")
    else:
        print(f"  [奇数索引] {key}: {value}")
```

运行结果：

```text
  [偶数索引] name: 张三
  [奇数索引] age: 20
  [偶数索引] city: 北京
```

### 2.5 zip 多字典遍历

#### 2.5.1 基本用法

`zip()` 函数可以将多个可迭代对象的元素配对。对多个字典使用 `zip()` 时，默认配对各字典的键。

```python
d1 = {"a": 1, "b": 2, "c": 3}
d2 = {"a": 10, "b": 20, "c": 30}

# zip(d1, d2) 等价于 zip(d1.keys(), d2.keys())
for k1, k2 in zip(d1, d2):
    print(f"  {k1} <-> {k2}")
```

运行结果：

```text
  a <-> a
  b <-> b
  c <-> c
```

#### 2.5.2 同时遍历多个字典的键值对

用 `zip(d1.items(), d2.items())` 可以同时获取两个字典的键值对：

```python
d1 = {"a": 1, "b": 2, "c": 3}
d2 = {"a": 10, "b": 20, "c": 30}

for (k1, v1), (k2, v2) in zip(d1.items(), d2.items()):
    print(f"  {k1}={v1} <-> {k2}={v2}")
```

运行结果：

```text
  a=1 <-> a=10
  b=2 <-> b=20
  c=3 <-> c=30
```

#### 2.5.3 长度不一致时的处理

`zip()` 以最短的可迭代对象为准——多余的部分被截断。

```python
d3 = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}
d4 = {"a": 10, "b": 20}

for k1, k2 in zip(d3, d4):
    print(f"  {k1} <-> {k2}")
```

运行结果：

```text
  a <-> a
  b <-> b
```

如果需要以最长的为准，使用 `itertools.zip_longest`，并用 `fillvalue` 填充缺失值：

```python
from itertools import zip_longest

d3 = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}
d4 = {"a": 10, "b": 20}

for k1, k2 in zip_longest(d3, d4, fillvalue="N/A"):
    print(f"  {k1} <-> {k2}")
```

运行结果：

```text
  a <-> a
  b <-> b
  c <-> N/A
  d <-> N/A
  e <-> N/A
```

#### 2.5.4 使用 zip 创建字典

`zip()` 配合 `dict()` 可以从键列表和值列表快速创建字典：

```python
keys = ["name", "age", "city"]
values = ["张三", 20, "北京"]

d = dict(zip(keys, values))
print(d)   # {'name': '张三', 'age': 20, 'city': '北京'}
```

#### 2.5.5 多字典同名键对比

实际场景中，多个字典往往有相同的键——比如多个科目的成绩表，每个学生有多个科目。这时可以遍历一个字典的键，用 `get()` 方法安全访问其他字典。

```python
scores_math = {"张三": 85, "李四": 92, "王五": 78}
scores_english = {"张三": 90, "李四": 88, "王五": 85}
scores_physics = {"张三": 78, "李四": 95, "王五": 82}

for name in scores_math:
    math = scores_math[name]
    english = scores_english.get(name, 0)
    physics = scores_physics.get(name, 0)
    total = math + english + physics
    print(f"  {name}: 数学{math} 英语{english} 物理{physics} 总分{total}")
```

运行结果：

```text
  张三: 数学85 英语90 物理78 总分253
  李四: 数学92 英语88 物理95 总分275
  王五: 数学78 英语85 物理82 总分245
```

#### 2.5.6 排序后遍历

结合 `sorted()` 和 `enumerate()` 可以实现按值排序后带名次输出：

```python
scores = {"张三": 85, "李四": 92, "王五": 78, "赵六": 95}

# 按值升序排列
sorted_by_value = sorted(scores.items(), key=lambda x: x[1])
for rank, (name, score) in enumerate(sorted_by_value, start=1):
    print(f"  第{rank}名: {name} - {score}分")

# 按键名排序
sorted_by_key = sorted(scores.items())
for name, score in sorted_by_key:
    print(f"  {name}: {score}")
```

运行结果：

```text
  第1名: 王五 - 78分
  第2名: 张三 - 85分
  第3名: 李四 - 92分
  第4名: 赵六 - 95分
  张三: 85
  李四: 92
  王五: 78
  赵六: 95
```

`sorted(d.items(), key=lambda x: x[1])` 的原理：`d.items()` 返回 `(key, value)` 元组序列，`key=lambda x: x[1]` 告诉 `sorted()` 按元组的第二个元素（即值）排序。

### 2.6 遍历时修改字典的陷阱

#### 2.6.1 问题的本质

在遍历字典的过程中，如果字典的大小发生变化（添加新键或删除已有键），Python 会抛出 `RuntimeError: dictionary changed size during iteration`。这是因为字典内部使用哈希表存储，增删键会导致哈希表重新排列，使正在进行的迭代器失效。

#### 2.6.2 危险操作一览

**添加新键——RuntimeError**

```python
d = {"a": 1, "b": 2, "c": 3}

try:
    for key in d:
        d[key + "_new"] = d[key]   # 改变了字典大小
except RuntimeError as e:
    print(f"RuntimeError: {e}")
```

运行结果：

```text
RuntimeError: dictionary changed size during iteration
```

**删除键——RuntimeError**

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}

try:
    for key in d:
        if d[key] < 3:
            del d[key]   # 改变了字典大小
except RuntimeError as e:
    print(f"RuntimeError: {e}")
```

运行结果：

```text
RuntimeError: dictionary changed size during iteration
```

**clear() 和 pop() 同样危险**

```python
d = {"a": 1, "b": 2, "c": 3}

try:
    for key in d:
        d.clear()
except RuntimeError as e:
    print(f"RuntimeError: {e}")
```

运行结果：

```text
RuntimeError: dictionary changed size during iteration
```

#### 2.6.3 安全方案

**方案一：先收集要操作的键，遍历后操作**

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}

# 第一步：遍历时只记录要删的键
to_delete = [key for key, value in d.items() if value < 3]
print(f"待删除的键: {to_delete}")

# 第二步：遍历结束后再删除
for key in to_delete:
    del d[key]
print(f"删除后: {d}")
```

运行结果：

```text
待删除的键: ['a', 'b']
删除后: {'c': 3, 'd': 4, 'e': 5}
```

**方案二：遍历字典的副本**

使用 `list(d.items())` 或 `list(d.keys())` 创建一份副本，遍历的是副本，操作的是原字典——两者互不影响。

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}

for key, value in list(d.items()):
    if value < 3:
        del d[key]
print(f"删除后: {d}")
```

运行结果：

```text
删除后: {'c': 3, 'd': 4, 'e': 5}
```

**方案三：字典推导式过滤（创建新字典）**

不修改原字典，而是通过字典推导式创建一个过滤后的新字典：

```python
d = {"a": 1, "b": 2, "c": 3, "d": 4, "e": 5}

d_filtered = {k: v for k, v in d.items() if v >= 3}
print(f"原字典: {d}")
print(f"新字典: {d_filtered}")
```

运行结果：

```text
原字典: {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5}
新字典: {'c': 3, 'd': 4, 'e': 5}
```

#### 2.6.4 遍历时修改值——安全

有一个重要的区别：遍历时**修改已有键的值**是安全的，因为这不会改变字典的大小。

```python
d = {"a": 1, "b": 2, "c": 3}

for key, value in d.items():
    d[key] = value * 10   # 安全：只是改值，没有增删键
print(f"修改后: {d}")   # {'a': 10, 'b': 20, 'c': 30}
```

同样，遍历时修改值所指向的可变对象（如列表、字典）的内容也是安全的：

```python
d = {"scores": [85, 92, 78], "names": ["张三", "李四", "王五"]}

for key, value in d.items():
    if isinstance(value, list):
        value.append("NEW")
print(f"修改后: {d}")
```

运行结果：

```text
修改后: {'scores': [85, 92, 78, 'NEW'], 'names': ['张三', '李四', '王五', 'NEW']}
```

#### 2.6.5 遍历时操作安全速查表

| 操作 | 是否安全 | 原因 |
|------|---------|------|
| 修改已有键的值 | 安全 | 不改变字典大小 |
| 修改嵌套可变对象内容 | 安全 | 不改变字典大小 |
| 添加新键 | 危险 | 改变字典大小，触发 RuntimeError |
| `del d[key]` | 危险 | 改变字典大小，触发 RuntimeError |
| `d.pop(key)` | 危险 | 改变字典大小，触发 RuntimeError |
| `d.clear()` | 危险 | 改变字典大小，触发 RuntimeError |
| `d.update(other)` | 危险 | 如果 other 含新键则改变字典大小 |

### 2.7 遍历性能对比

#### 2.7.1 各方式的时间复杂度

| 遍历方式 | 时间复杂度 | 空间开销 | 说明 |
|---------|-----------|---------|------|
| `for k in d` | O(n) | 无额外空间 | 只遍历键 |
| `for k in d.keys()` | O(n) | 无额外空间 | 同上，显式写法 |
| `for v in d.values()` | O(n) | 无额外空间 | 只遍历值 |
| `for k, v in d.items()` | O(n) | 无额外空间 | 遍历键值对 |
| `for k in d; d[k]` | O(n) | 无额外空间 | 遍历键再取值，多一次哈希查找 |
| `for k in sorted(d)` | O(n log n) | O(n) | 需要排序 |
| `list(d.items())` 遍历 | O(n) | O(n) | 额外创建列表 |

#### 2.7.2 性能对比实验

用一个包含 10 万元素的字典来对比各种遍历方式的耗时：

```python
import time

big_dict = {str(i): i for i in range(100000)}

# 方式一：遍历键再 d[k] 取值（低效——多一次哈希查找）
start = time.perf_counter()
total1 = 0
for k in big_dict:
    total1 += big_dict[k]
time1 = time.perf_counter() - start

# 方式二：遍历 items（高效——直接获取键值对）
start = time.perf_counter()
total2 = 0
for k, v in big_dict.items():
    total2 += v
time2 = time.perf_counter() - start

print(f"遍历键再取值: {time1:.4f}s")
print(f"遍历 items:   {time2:.4f}s")
print(f"items 更快: {time1 > time2}")
```

运行结果（具体数值会因机器而异）：

```text
遍历键再取值: 0.0152s
遍历 items:   0.0068s
items 更快: True
```

`items()` 更快的原因：遍历键再取值时，每次 `d[k]` 都要进行一次哈希查找；而 `items()` 在迭代过程中直接返回 `(key, value)` 元组，不需要额外的查找。

#### 2.7.3 视图对象 vs 列表的内存对比

```python
import sys

d = {str(i): i for i in range(1000)}

# 视图对象的内存占用
items_view = d.items()
keys_view = d.keys()
values_view = d.values()

# 转换为列表后的内存
items_list = list(d.items())
keys_list = list(d.keys())
values_list = list(d.values())

print(f"dict_items 视图: {sys.getsizeof(items_view)} bytes")
print(f"dict_keys 视图:  {sys.getsizeof(keys_view)} bytes")
print(f"dict_values视图: {sys.getsizeof(values_view)} bytes")
print(f"list(items):     {sys.getsizeof(items_list)} bytes")
print(f"list(keys):      {sys.getsizeof(keys_list)} bytes")
print(f"list(values):    {sys.getsizeof(values_list)} bytes")
```

运行结果：

```text
dict_items 视图: 112 bytes
dict_keys 视图:  104 bytes
dict_values视图: 104 bytes
list(items):     9040 bytes
list(keys):      8560 bytes
list(values):    8560 bytes
```

视图对象几乎不占额外内存——它只是对字典的引用，不复制数据。而 `list()` 转换会创建新列表，将所有元素复制一份，内存占用与字典大小成正比。

这也解释了为什么 Python 3 将 `keys()`、`values()`、`items()` 的返回值从列表改为视图对象——在大字典上，避免了不必要的内存复制。

## 3. 最佳实践

### 3.1 遍历方式选择建议

| 需求场景 | 推荐写法 | 说明 |
|---------|---------|------|
| 只需要键 | `for k in d` | 最简洁 |
| 只需要值 | `for v in d.values()` | 语义清晰 |
| 需要键和值 | `for k, v in d.items()` | 推荐，避免额外哈希查找 |
| 需要索引序号 | `for i, k in enumerate(d)` | 配合 start=1 更直观 |
| 多字典对比 | `zip(d1, d2)` 或遍历键+get | 注意长度不一致时的处理 |
| 需要排序 | `sorted(d.items())` | 按需指定 key 参数 |
| 遍历时删除 | `list(d.items())` 副本 | 安全遍历 |
| 遍历时过滤 | 字典推导式 | 创建新字典 |

### 3.2 推荐 vs 不推荐写法

**对比一：获取键和值**

推荐：

```python
for key, value in d.items():
    print(f"{key}: {value}")
```

不推荐：

```python
for key in d:
    print(f"{key}: {d[key]}")   # 多一次哈希查找
```

原因：`items()` 一次返回键值对，无需额外查找。在大字典上差异明显。

**对比二：遍历时过滤**

推荐：

```python
# 字典推导式——简洁、安全、返回新字典
filtered = {k: v for k, v in d.items() if v > threshold}
```

不推荐：

```python
# 遍历副本删除——啰嗦、容易出错
for key, value in list(d.items()):
    if value <= threshold:
        del d[key]
```

原因：字典推导式更简洁，且不修改原字典（避免副作用），更符合函数式编程思想。

**对比三：仅需值时的写法**

推荐：

```python
# 只需要值——直接用 values()
total = sum(d.values())
```

不推荐：

```python
# 先遍历键再取值——多此一举
total = sum(d[k] for k in d)
```

原因：`values()` 直接返回值的视图，语义更清晰，性能也更好。

**对比四：遍历时需要序号**

推荐：

```python
for i, (key, value) in enumerate(d.items(), start=1):
    print(f"{i}. {key}: {value}")
```

不推荐：

```python
# 手动维护计数器——啰嗦
i = 1
for key, value in d.items():
    print(f"{i}. {key}: {value}")
    i += 1
```

原因：`enumerate()` 是 Python 提供的标准做法，更简洁且不容易出错。

### 3.3 常见错误模式

**错误一：遍历时增删键**

```python
# 错误：运行时抛出 RuntimeError
d = {"a": 1, "b": 2, "c": 3}
for key in d:
    if d[key] < 2:
        del d[key]   # RuntimeError!
```

修正：遍历副本或用推导式。

```python
# 修正方案一：遍历副本
for key in list(d.keys()):
    if d[key] < 2:
        del d[key]

# 修正方案二：推导式
d = {k: v for k, v in d.items() if v >= 2}
```

**错误二：误以为 values() 支持集合运算**

```python
d1 = {"a": 1, "b": 2}
d2 = {"a": 1, "c": 3}

# 错误：values() 不支持集合运算
# common = d1.values() & d2.values()   # TypeError!
```

修正：转为集合或用 `items()` 的集合运算。

```python
# 修正：用 set() 转换（仅当值可哈希时）
common_values = set(d1.values()) & set(d2.values())
```

**错误三：以为字典遍历有固定顺序（Python 3.6 之前）**

在 Python 3.6 之前，字典遍历顺序是不确定的（取决于哈希表布局）。从 Python 3.7 开始，字典保证按插入顺序遍历（CPython 3.6 作为实现细节首先引入，3.7 正式成为语言规范）。但这个顺序只是"插入顺序"，不是"排序顺序"——如果需要有序遍历，仍然要使用 `sorted()`。

## 4. 原理

### 4.1 视图对象的设计

Python 3 中 `keys()`、`values()`、`items()` 返回的是视图对象（view object）而非列表。这个设计决策解决了 Python 2 中返回列表的性能和内存问题。

在 Python 2 中，`d.keys()` 返回一个全新的列表对象，包含字典所有键的副本。如果字典有 100 万元素，每次调用 `keys()` 都会创建一个 100 万元素的列表——这在大字典上是严重的内存浪费。

Python 3 的视图对象机制：

```text
┌──────────────────────────────────────────────────┐
│                   字典 d                          │
│  ┌─────────────────────────────────────────────┐ │
│  │  哈希表（存储键值对）                          │ │
│  │  [0] → ("name", "张三")                      │ │
│  │  [1] → ("age", 20)                           │ │
│  │  [2] → ("city", "北京")                       │ │
│  └─────────────────────────────────────────────┘ │
│           ↑                        ↑              │
│           │ 引用                   │ 引用          │
│  ┌────────┴────────┐    ┌─────────┴──────────┐   │
│  │  dict_keys      │    │  dict_items        │   │
│  │  (视图对象)      │    │  (视图对象)         │   │
│  │  不存储数据      │    │  不存储数据          │   │
│  │  只指向字典      │    │  只指向字典          │   │
│  └─────────────────┘    └────────────────────┘   │
│                                                   │
│  d.keys() → dict_keys 视图（几乎不占内存）          │
│  list(d.keys()) → 新列表（复制所有数据）            │
└──────────────────────────────────────────────────┘
```

视图对象的核心设计要点：

1. **不复制数据**：视图对象只保存对字典的引用，不复制键、值或键值对。
2. **动态反映字典状态**：当字典发生变化时，视图对象自动反映最新状态。
3. **惰性求值**：只有在真正迭代时才逐个返回元素，不预先生成列表。
4. **可重复迭代**：视图对象是可迭代的，可以多次遍历。

### 4.2 为什么遍历时增删键会报错

字典在内部用哈希表存储数据。当你遍历字典时，Python 创建一个迭代器，按照哈希表的内部布局逐个访问键值对。如果在遍历过程中添加或删除键，哈希表可能需要重新排列（rehash）或扩容，导致：

1. 迭代器记录的当前位置失效。
2. 新添加的键可能出现在已遍历过的位置（导致遗漏）或未遍历过的位置（导致多遍历）。
3. 删除的键可能使迭代器指向一个已被回收的槽位。

Python 选择在这种情况发生时抛出 `RuntimeError`，而不是产生难以调试的静默错误。这是一个"快速失败"（fail-fast）设计——让问题在发生时立即暴露，而不是让程序在错误状态下继续运行。

而修改已有键的值不会触发这个问题——因为哈希表中键的位置由键的哈希值决定，修改值不影响键的位置，字典的大小也不变，迭代器仍然能正确工作。

### 4.3 字典遍历顺序的演进

| Python 版本 | 遍历顺序 | 说明 |
|-------------|---------|------|
| 3.6 之前 | 不确定 | 由哈希表内部布局决定，受哈希随机化影响 |
| 3.6（CPython） | 插入顺序 | 作为实现细节引入，不保证所有实现都遵循 |
| 3.7+ | 插入顺序 | 正式成为语言规范，所有实现必须保证 |

Python 3.6 引入了 compact dict 实现，将键值对存储在两个紧凑数组中：一个稀疏的哈希索引数组指向紧凑的键值对数组。这种实现方式天然保持了插入顺序，同时减少了内存使用。

## 5. 总结

本文围绕 Python 字典的遍历方法展开，主要介绍了以下内容：

- 遍历键的两种等价方式：`for k in d`（默认遍历）和 `for k in d.keys()`（显式遍历），都返回 `dict_keys` 视图对象
- 遍历值使用 `for v in d.values()`，返回 `dict_values` 视图对象，不支持集合运算
- 遍历键值对使用 `for k, v in d.items()`，返回 `dict_items` 视图对象，支持集合运算
- `dict_keys` 和 `dict_items` 视图对象支持交集、并集、差集等集合运算，`dict_values` 不支持
- 视图对象具有动态性——反映字典的实时状态，且几乎不占额外内存
- `enumerate()` 可以为字典遍历添加索引序号，`zip()` 可以同步遍历多个字典
- 遍历时增删键会触发 `RuntimeError`，安全方案包括遍历副本、先收集后操作、字典推导式过滤
- 遍历时修改已有键的值是安全的，因为不改变字典大小
- `items()` 比遍历键再 `d[k]` 取值更高效，因为避免了额外的哈希查找
- 从 Python 3.7 开始，字典保证按插入顺序遍历
