## 1. 介绍

### 1.1 什么是 while 循环

`while` 是 Python 中最基础的条件循环结构。它根据一个布尔表达式的真值来决定是否继续执行循环体内的代码块，在每次迭代开始前重新评估条件。与 `for` 循环不同，`for` 遍历可迭代对象时隐式处理"何时停止"，而 `while` 将停止条件的判断完全交给开发者——这意味着它更加灵活，但也更加需要开发者对退出条件有清晰的设计。

`while` 在 Python 中的典型使用场景包括：不确定迭代次数的循环、基于用户输入的交互式循环、队列/栈的消费模式、以及需要手动控制迭代进度的算法实现。

### 1.2 基本语法与最小示例

`while` 的语法形式非常简洁：

```python
while condition:
    # 循环体代码
    # 每次迭代前重新评估 condition
```

`condition` 是一个布尔表达式，为 `True` 时执行循环体，为 `False` 时退出。`condition` 可以是任何最终能计算出布尔值的表达式。

先看一个最小的可运行示例，直观感受 `while` 的执行过程：

```python
# 从 0 数到 4，每次增加 1
count = 0
while count < 5:
    print(f"当前计数: {count}")
    count += 1
print("循环结束")
```

运行这段代码，你会看到输出：

```
当前计数: 0
当前计数: 1
当前计数: 2
当前计数: 3
当前计数: 4
循环结束
```

执行流程说明：每次进入循环体前，Python 都会检查 `count < 5` 这个条件，当 `count` 增加到 5 时条件变为 `False`，循环终止，程序继续执行 `while` 块之后的代码。注意，循环体内必须用某种方式改变 `condition` 中涉及的变量，否则条件永远不会变为 `False`，形成无限循环。

## 2. 核心内容

### 2.1 `while condition:` 基本语法与执行流程

`while` 语句的执行流程可以用一个"检查-执行-再检查"的三步模型来理解：

1. **条件评估**：计算 `condition` 表达式的值。
2. **条件为 True**：执行循环体中的全部语句，执行完毕后回到步骤 1。
3. **条件为 False**：跳过循环体，继续执行 `while` 块之后的代码。

这里的关键特征是"先检查，后执行"——如果初始时条件就是 `False`，循环体一次都不会被执行。这与后面要讨论的 `do-while` 模拟形成对比。

`condition` 可以是任何合法的 Python 表达式，支持布尔运算符组合：

```python
# 演示多种条件表达式的写法
def demo_condition_forms():
    """展示 while 条件的不同写法"""
    # 写法一：直接比较
    i = 0
    while i < 3:
        print(f"写法一: i={i}")
        i += 1

    print("---分隔线---")

    # 写法二：布尔组合
    x = 0
    y = 10
    while x < 5 and y > 5:
        print(f"写法二: x={x}, y={y}")
        x += 1
        y -= 1

    print("---分隔线---")

    # 写法三：使用布尔变量控制
    running = True
    step = 0
    while running:
        print(f"写法三: step={step}")
        step += 1
        if step >= 3:
            running = False

    print("---分隔线---")

    # 写法四：条件一开始就为 False，循环体一次都不执行
    j = 10
    while j < 5:
        print("这行不会被打印")
    print(f"条件初始为 False，循环体被跳过，j={j}")


demo_condition_forms()
```

运行结果：

```
写法一: i=0
写法一: i=1
写法一: i=2
---分隔线---
写法二: x=0, y=10
写法二: x=1, y=9
写法二: x=2, y=8
写法二: x=3, y=7
写法二: x=4, y=6
---分隔线---
写法三: step=0
写法三: step=1
写法三: step=2
---分隔线---
条件初始为 False，循环体被跳过，j=10
```

说明：写法二展示了复合条件检查，两个子条件同时满足时才继续循环。写法三用布尔变量 `running` 作为哨兵，这是一种常见模式，尤其适合在深层嵌套中优雅退出。写法四则强调了"先检查后执行"的特性——条件为 `False` 时循环体不执行。

### 2.2 无限循环与退出条件设计（`while True` + `break`）

`while True` 创建一个看似"永远执行"的循环，但实际上它配合 `break` 语句使用，将退出条件的判断放到循环体内部。这种模式在以下场景非常有用：

- 退出条件复杂，不适合放在 `while` 语句行（例如需要在循环体中间检查条件）
- 至少需要执行一次循环体（类似其他语言的 `do-while`）
- 需要从循环体多个位置退出（多个退出点）

`break` 会立即终止当前最内层循环，程序从循环后的第一条语句继续执行。

```python
# 使用 while True + break 构建"先执行后检查"的模式
# 场景：不断询问用户输入，直到输入 "quit"
def interactive_loop():
    """模拟一个简单的 REPL：用户输入命令，循环执行直到输入 quit"""
    print("简易命令处理器（输入 'quit' 退出）")
    print("可用命令: hello, time, help")

    while True:
        # 每次迭代都提示用户输入
        cmd = input(">>> ").strip().lower()

        # 在循环体中间检查退出条件
        if cmd == "quit":
            print("再见！")
            break

        # 业务逻辑处理
        if cmd == "hello":
            print("你好！欢迎使用命令处理器。")
        elif cmd == "time":
            import datetime
            print(f"当前时间: {datetime.datetime.now().strftime('%H:%M:%S')}")
        elif cmd == "help":
            print("可用命令: hello, time, help, quit")
        else:
            print(f"未知命令: '{cmd}'，输入 'help' 查看可用命令")

    print("循环已退出，程序结束。")

# 运行演示（这里用模拟输入来展示，避免真实等待用户输入）
# 实际执行时注释掉下面这行，改用模拟版本
# interactive_loop()
```

`while True` 的真正威力在于它可以有**多个退出点**：

```python
# 多个退出点的 while True 模式
# 场景：健康检查脚本，满足任何一个退出条件就停止
def health_check_with_multiple_exits(steps):
    """模拟健康检查，展示多个退出点的设计
    
    Args:
        steps: 模拟的总检查步骤数
    """
    print("开始健康检查...")
    current_step = 0

    while True:
        current_step += 1
        print(f"  第 {current_step} 步: 检查中...")

        # 退出点 1：超出最大步数（防止被非预期的无限循环卡死）
        if current_step >= steps:
            print(f"  达到最大检查步数 {steps}，退出循环")
            break

        # 模拟某个检查项的结果
        error_code = (current_step * 17) % 10  # 模拟随机错误码

        # 退出点 2：遇到致命错误
        if error_code == 7:
            print(f"  [致命] 第 {current_step} 步检测到错误码 {error_code}，终止检查")
            break

        # 退出点 3：检测到特定状态（非致命，但表示任务完成）
        if error_code == 0:
            print(f"  [完成] 第 {current_step} 步检测到完成信号")
            break

    print(f"健康检查结束，共执行 {current_step} 步")


health_check_with_multiple_exits(20)
```

运行结果（每次可能略有不同，取决于错误码计算）：

```
开始健康检查...
  第 1 步: 检查中...
  第 2 步: 检查中...
  第 3 步: 检查中...
  ...
  (具体步数取决于错误码 7 何时出现)
  健康检查结束，共执行 5 步（假设第 5 步时 error_code 达到 7）
```

`break` 只跳出当前最内层循环，不影响外层循环（此处涉及嵌套时再展开）。

### 2.3 `while-else` 子句

`while-else` 是 Python 中一个常被忽视但很有用的语法特性。它的语义与 `for-else` 完全相同：

- 如果 `while` 循环**正常结束**（即条件变为 `False` 而退出），则执行 `else` 子句中的代码。
- 如果 `while` 循环通过 `break` 退出，则**跳过** `else` 子句。

这个机制最适合"搜索确认"类场景：你需要在循环中查找某个元素，如果找到了就 `break`，如果循环结束了都没找到，说明不存在，此时执行 `else` 块中的"未找到"处理逻辑。

```python
# while-else 基本示例：搜索列表中的目标值
def search_value(target, data):
    """在列表中搜索目标值，使用 while-else 处理未找到的情况
    
    Args:
        target: 要搜索的值
        data: 数据列表
    
    Returns:
        找到时返回索引，未找到时返回 -1
    """
    index = 0
    while index < len(data):
        if data[index] == target:
            print(f"找到目标 {target}，索引为 {index}")
            break
        index += 1
    else:
        # 循环正常退出（未触发 break）时执行
        print(f"未找到目标 {target}，搜索结束")
        return -1

    return index


# 测试：搜索存在的值
print("--- 测试 1：搜索存在的值 ---")
result = search_value(42, [10, 20, 30, 40, 42, 50])
print(f"结果: {result}\n")

# 测试：搜索不存在的值
print("--- 测试 2：搜索不存在的值 ---")
result = search_value(99, [10, 20, 30, 40, 42, 50])
print(f"结果: {result}")
```

运行结果：

```
--- 测试 1：搜索存在的值 ---
找到目标 42，索引为 4
结果: 4

--- 测试 2：搜索不存在的值 ---
未找到目标 99，搜索结束
结果: -1
```

**更贴近实际的例子**：用 `while-else` 实现一个简易的质数判定：

```python
# while-else 的经典应用：质数判定
def is_prime(n):
    """判断一个正整数是否为质数
    
    通过 while-else 来区分"因 break 退出"与"循环自然结束"。
    
    Args:
        n: 要判定的正整数
    
    Returns:
        bool: 是否为质数
    """
    if n < 2:
        return False

    divisor = 2
    while divisor * divisor <= n:  # 只需检查到平方根
        if n % divisor == 0:
            # 找到了因数，通过 break 退出循环（else 不会执行）
            print(f"{n} 可被 {divisor} 整除")
            break
        divisor += 1
    else:
        # 循环正常结束，说明没有找到任何因数 -> 是质数
        print(f"{n} 没有因数，是质数")
        return True

    return False


# 测试用例
for num in [2, 3, 4, 17, 25, 29, 100]:
    result = is_prime(num)
    print(f"  -> {num} {'是' if result else '不是'}质数\n")
```

运行结果（部分）：

```
2 没有因数，是质数
  -> 2 是质数

3 没有因数，是质数
  -> 3 是质数

4 可被 2 整除
  -> 4 不是质数

17 没有因数，是质数
  -> 17 是质数

25 可被 5 整除
  -> 25 不是质数

29 没有因数，是质数
  -> 29 是质数

100 可被 2 整除
  -> 100 不是质数
```

`while-else` 的语义和 `for-else` 完全一致，只不过驱动条件是条件表达式而非迭代器。掌握其中一个就掌握了另一个。要注意的是，`else` 的缩进层级与 `while` 对齐，而不是与 `if` 对齐。

### 2.4 用 `while` 实现手动迭代

`for` 循环底层依赖迭代器协议，而 `while` 可以手动再现这个协议的完整流程。如果你理解了如何用 `while` 模拟 `for`，你就真正理解了 Python 的迭代机制。

**模拟迭代器协议的基本流程**：

1. 调用 `iter()` 获取迭代器对象
2. 在 `while` 循环中反复调用 `next()` 获取下一项
3. 捕获 `StopIteration` 异常来结束循环

```python
# 用 while 手动模拟 for 循环的迭代过程
def manual_iteration_example():
    """展示如何用 while 手动驱动迭代器协议"""
    fruits = ["苹果", "香蕉", "樱桃", "荔枝"]

    # 第一步：获取迭代器
    iterator = iter(fruits)
    print(f"迭代器对象: {iterator}")
    print(f"迭代器类型: {type(iterator)}")

    # 第二步：用 while 手动迭代
    print("\n开始手动迭代...")
    while True:
        try:
            fruit = next(iterator)
            print(f"  获取到: {fruit}")
        except StopIteration:
            print("  迭代器已耗尽，停止迭代")
            break

    # 验证：此时迭代器已耗尽，再次 next() 会抛出 StopIteration
    print("\n验证迭代器状态：")
    exhausted_iterator = iter([])
    try:
        next(exhausted_iterator)
    except StopIteration:
        print("  空迭代器的 next() 调用已抛出 StopIteration")


manual_iteration_example()
```

运行结果：

```
迭代器对象: <list_iterator object at 0x...>
迭代器类型: <class 'list_iterator'>

开始手动迭代...
  获取到: 苹果
  获取到: 香蕉
  获取到: 樱桃
  获取到: 荔枝
  迭代器已耗尽，停止迭代

验证迭代器状态：
  空迭代器的 next() 调用已抛出 StopIteration
```

**带默认值的 `next()`**：`next()` 可以接受第二个参数作为默认值，当迭代器耗尽时返回该默认值而不是抛出异常，这可以让手动迭代代码更简洁：

```python
# 使用 next() 的默认值参数简化手动迭代
def manual_iteration_with_default():
    """用 next(iterator, default) 避免显式捕获 StopIteration"""
    numbers = [10, 20, 30]
    it = iter(numbers)

    print("使用默认值的 next() 迭代：")
    while True:
        value = next(it, None)  # 耗尽时返回 None
        if value is None:
            break
        print(f"  值: {value}")

    print("迭代完成")


manual_iteration_with_default()
```

运行结果：

```
使用默认值的 next() 迭代：
  值: 10
  值: 20
  值: 30
迭代完成
```

**手动迭代的优势场景**：当你需要在一个循环中同时处理"当前项"和"下一项"时，手动迭代比 `for` 循环更自然：

```python
# 手动迭代处理"当前项与下一项的对比"
# 场景：数据去重——仅当相邻元素不同时才输出
def deduplicate_adjacent(items):
    """去除相邻重复项，只保留不相同的连续序列
    
    手动迭代使得"同时持有当前项和下一项"变得简单。
    
    Args:
        items: 输入序列
    
    Returns:
        去重后的列表
    """
    if not items:
        return []

    it = iter(items)
    result = [next(it)]  # 取出第一个元素

    while True:
        current = next(it, None)
        if current is None:
            break
        if current != result[-1]:
            result.append(current)

    return result


# 测试
data = [1, 1, 2, 2, 2, 3, 3, 4, 4, 4, 4, 5, 5]
print(f"原始数据:    {data}")
result = deduplicate_adjacent(data)
print(f"去重后:      {result}")

# 对比：用 for 循环实现同样功能更繁琐
def deduplicate_with_for(items):
    """用 for 循环实现同样的去重逻辑，注意对比差异"""
    if not items:
        return []

    result = [items[0]]
    for i in range(1, len(items)):
        if items[i] != result[-1]:
            result.append(items[i])

    return result

print(f"for版本结果: {deduplicate_with_for(data)}")
```

运行结果：

```
原始数据:    [1, 1, 2, 2, 2, 3, 3, 4, 4, 4, 4, 5, 5]
去重后:      [1, 2, 3, 4, 5]
for版本结果: [1, 2, 3, 4, 5]
```

### 2.5 `while` 循环中的计数器递增与递减

在 `while` 循环中手动控制计数器是最基础的使用方式。Python 没有 C 风格 `for (i=0; i<n; i++)` 语法，这类需求就要靠 `while` + 手动变量维护来实现。

**递增模式**：计数器从初始值逐步向目标值靠近：

```python
# 递增计数器的多种写法与场景
def counter_increment_examples():
    """展示 while 循环中计数器的各种递增写法"""
    print("=" * 50)
    print("示范一：标准递增")
    print("=" * 50)

    i = 0
    while i < 5:
        print(f"  i = {i}")
        i += 1  # 等价于 i = i + 1
    print(f"循环结束，i 的最终值: {i}")  # 注意：i 为 5，不再满足条件

    print("=" * 50)
    print("示范二：步长不为 1 的递增")
    print("=" * 50)

    j = 0
    while j <= 20:
        print(f"  j = {j}")
        j += 5  # 步长为 5
    print(f"循环结束，j 的最终值: {j}")

    print("=" * 50)
    print("示范三：指数递增（常用于退避重试）")
    print("=" * 50)

    import time

    delay = 1
    attempt = 0
    while delay <= 16:
        attempt += 1
        print(f"  第 {attempt} 次尝试，延迟 {delay} 秒")
        delay *= 2  # 指数增长：1, 2, 4, 8, 16
    print(f"最大延迟达到 {delay//2} 秒，停止")


counter_increment_examples()
```

**递减模式**：计数器从高值向低值靠近，用于倒计时、剩余配额跟踪等：

```python
# 递减计数器的实际应用
def counter_decrement_examples():
    """展示 while 循环中计数器的递减写法和应用场景"""
    print("=" * 50)
    print("场景一：倒计时")
    print("=" * 50)

    countdown = 5
    while countdown > 0:
        print(f"  倒计时: {countdown}...")
        countdown -= 1
    print("  发射！")

    print("=" * 50)
    print("场景二：剩余资源配额追踪")
    print("=" * 50)

    budget = 100  # 本月预算 100 元
    items = [
        ("文具", 35),
        ("交通", 20),
        ("零食", 15),
        ("书籍", 80),  # 这个会超出预算
        ("电影票", 30),
    ]

    remaining = budget
    purchased = []
    idx = 0

    while idx < len(items) and remaining > 0:
        name, cost = items[idx]
        if cost <= remaining:
            purchased.append(name)
            remaining -= cost
            print(f"  购买 {name}，花费 {cost} 元，剩余预算: {remaining} 元")
        else:
            print(f"  [跳过] {name} 价格 {cost} 超出剩余预算 {remaining}")
        idx += 1

    print(f"\n共购买: {purchased}")
```

### 2.6 嵌套 `while` 循环

在循环体内部再嵌套另一个循环结构，称为嵌套循环。`while` 可以嵌套 `while`，也可以嵌套 `for`，反之亦然。嵌套循环最常见的场景是处理二维数据结构，如矩阵、棋盘、二维坐标等。

**二维遍历基础**：外层循环控制行，内层循环控制列：

```python
            col += 1
```

### 2.7 `while` 与用户交互（`input` 循环直到合法输入）

```python
# 带重试次数限制的输入验证循环
def get_valid_email(max_attempts=3):
    """获取合法的邮箱地址，最多尝试 max_attempts 次
    
    Args:
        max_attempts: 最大尝试次数，达到后返回 None
    
    Returns:
        合法的邮箱字符串，或 None（超限时）
    """
    attempts = 0

    while attempts < max_attempts:
        email = input(f"请输入邮箱地址（剩余 {max_attempts - attempts} 次机会）: ").strip()

        # 检查是否为空
        if not email:
            print("[错误] 邮箱地址不能为空。")
            attempts += 1
            continue

        # 检查是否包含 @
        if "@" not in email:
            print("[错误] 邮箱地址必须包含 '@' 符号。")
            attempts += 1
            continue

        # 检查 @ 前后是否有内容
        local_part, _, domain = email.partition("@")
        if not local_part:
            print("[错误] '@' 前必须有内容。")
            attempts += 1
            continue
        if not domain:
            print("[错误] '@' 后必须有域名。")
            attempts += 1
            continue

        # 检查域名是否包含点
        if "." not in domain:
            print("[错误] 域名必须包含点号。")
            attempts += 1
            continue

        # 所有检查通过
        print(f"[成功] 邮箱地址 '{email}' 格式合法。")
        return email

    print(f"[失败] 已尝试 {max_attempts} 次均未通过，操作取消。")
    return None
```

### 2.8 `while` 与队列/栈的消费模式

`while` 循环配合队列（FIFO）或栈（LIFO）是一种非常常见的数据处理模式，尤其适用于任务调度、广度优先/深度优先遍历等工作流。

**队列消费模式**：从队列左侧取元素处理，直到队列为空：

```python
# 用 while 实现队列消费模式（FIFO）
def queue_consumption_demo():
    """展示 while 循环如何消费队列中的任务"""
    from collections import deque

    print("=" * 50)
    print("场景一：任务队列消费")
    print("=" * 50)

    # 任务队列：每个任务是一个 (任务名, 耗时秒数) 元组

        ("发送邮件通知", 1),
        ("生成报表", 4),
        ("清理缓存", 2),

    # 用 while 循环消费队列

    while task_queue:
        task_name, duration = task_queue.popleft()  # 从左侧取（FIFO）
        task_number += 1
        print(f"  任务 #{task_number}: {task_name}（预计耗时 {duration} 秒）")

    print(f"\n所有 {task_number} 个任务已处理完毕")

        "报告.docx": [],
        "照片.jpg": [],
        "截图.png": [],
        "歌曲.mp3": [],

            for child in children:
                if child not in visited:
                    bfs_queue.append(child)
        else:
            print(f"  [文件] {current}")

    print(f"\n共访问 {len(visited)} 个节点")
```

```python
# 用 while 实现栈消费模式（LIFO / 深度优先遍历）
def stack_consumption_demo():
    """展示 while 循环如何消费栈中的元素"""
    print("=" * 50)
    print("场景一：用栈实现回溯（undo 功能）")
    print("=" * 50)

    # 模拟操作历史栈
    action_stack = [
        "插入文本 'Hello'",
        "加粗文字",
        "插入图片",
        "修改字体大小",
        "添加链接",
    ]
    print(f"操作历史（从旧到新）: {action_stack}")

    # 撤销最近的两个操作
    undo_count = 0
    while action_stack and undo_count < 2:
        last_action = action_stack.pop()  # 从右侧取（LIFO）
        undo_count += 1
        print(f"  撤销 #{undo_count}: {last_action}")

    print(f"剩余操作: {len(action_stack)} 个（在撤销后保留）")

    print("=" * 50)
    print("场景二：用栈实现深度优先遍历（DFS）")
    print("=" * 50)

    # 用栈遍历文件目录（深度优先）
    filesystem = {
        "~": ["projects", "temp", "readme.txt"],
        "projects": ["web-app", "mobile-app"],
        "web-app": ["src", "README.md"],
        "src": ["main.py", "utils.py"],
        "mobile-app": ["app.py"],
        "temp": ["cache.bin"],
        "readme.txt": [],
        "README.md": [],
        "main.py": [],
        "utils.py": [],
        "app.py": [],
        "cache.bin": [],
    }

    dfs_stack = ["~"]
    visited = set()

    print("深度优先遍历结果：")
    while dfs_stack:
        current = dfs_stack.pop()  # 从栈顶取（最后进入的先处理）
        if current in visited:
            continue
        visited.add(current)

        children = filesystem.get(current, [])
        indent = "  " * (current.count("/") + (1 if "/" in current else 0))

        if children:
            print(f"  {indent}[目录] {current}")
            # 逆序压入栈，保证正序遍历
            for child in reversed(children):
                if child not in visited:
                    dfs_stack.append(child)
        else:
            print(f"  {indent}[文件] {current}")

    print(f"\n共访问 {len(visited)} 个节点")
```

### 2.9 用 `do-while` 模拟结构

Python 没有内置 `do-while` 循环（先执行一次循环体，再检查条件）。但很多场景需要"至少执行一次"的语义，例如：先读一次输入再判断是否继续、先尝试一次操作再根据结果决定是否重试。

**模拟 do-while 的标准写法**：`while True` + 在循环体末尾检查条件并用 `break` 退出：


### 2.10 `while` 循环的性能特性与适用场景

理解何时用 `while` 优于 `for`，是写出高效 Python 代码的关键。

**性能比较**：在纯迭代场景中，`for` 通常比 `while` 稍快，因为 `for` 底层使用 C 实现的迭代器协议，而 `while` 每次迭代都需要在 Python 层面执行条件评估和变量更新。

```python
# 性能对比：for vs while
def performance_comparison():
    """对比 for 循环和 while 循环的性能差异"""
    import time

    n = 10_000_000  # 一千万次迭代

    print(f"性能对比：{n:,} 次迭代")
    print("-" * 60)

    # for 循环
    start = time.perf_counter()
    total = 0
    for i in range(n):
        total += i
    for_duration = time.perf_counter() - start
    print(f"  for  循环: {for_duration:.4f} 秒  (总和={total})")

    # while 循环
    start = time.perf_counter()
    total = 0
    i = 0
    while i < n:
        total += i
        i += 1
    while_duration = time.perf_counter() - start
    print(f"  while 循环: {while_duration:.4f} 秒  (总和={total})")

    # 对比
    ratio = while_duration / for_duration
    print(f"\n  while/for 耗时比: {ratio:.2f}x")
    print(f"  while 比 for 慢了 {(ratio-1)*100:.1f}%")
```

### 3.1 避免无限循环的核心原则

无限循环是最常见的 `while` 相关 bug。以下原则可以有效规避：

```python
    print("=" * 50)
```

### 3.2 `while` 中的 `continue` 使用注意事项

`continue` 让循环跳过本次迭代的剩余部分，直接进入下一次条件检查。在 `while` 中错误使用 `continue` 的最大陷阱是**跳过条件变量的更新**：

```python

    print("=" * 50)

    print("""
  i = 0
  while i < 5:
      if i == 2:
          continue  # 跳到下一轮循环，i += 1 被跳过！
      print(i)
      i += 1
  # 当 i == 2 时 continue，i 不再更新，变成无限循环
  """)

    print("=" * 50)
    print("正确做法一：将计数器更新放在 continue 之前")
    print("=" * 50)

    i = 0
    while i < 5:
        i += 1  # 先更新计数器
        if i == 2:
            continue  # 不会跳过计数更新
        print(f"  i = {i}")
    print("  循环正常结束\n")

    print("=" * 50)

    print("=" * 50)

        if i == 2:
            continue
        print(f"  i = {i}")
    print("  for 循环中的 continue 没有跳过计数器的问题\n")

    print("=" * 50)
    print("正确做法三：条件表达式代替 continue")
    print("=" * 50)

    while i < 5:
        if i != 2:
```

### 3.3 `while` 与 `break` 的清晰编码规范

使用 `break` 退出循环时，应保证代码可读性——`break` 的使用应该是清晰的，不会让读者困惑：

```python
def break_usage_best_practice():
    """展示 break 使用的推荐与不推荐写法"""

    print("=" * 50)
    print("推荐做法：break 在可见范围内使用")
    print("=" * 50)

    # 清晰的搜索模式
    items = ["苹果", "香蕉", "樱桃", "荔枝"]
    target = "樱桃"
    found_index = -1
    i = 0

    while i < len(items):
        if items[i] == target:
            found_index = i
            break  # 清晰：找到目标立即退出
        i += 1

    print(f"  目标 '{target}' 的索引: {found_index}\n")

    print("=" * 50)
    print("不推荐做法：多个 break 分散在不同分支")
    print("=" * 50)

    print("""
  while condition:
      if cond_a:
          break        # break #1
      process_a()
      if cond_b:
          if cond_c:
              break    # break #2
          process_b()
      if cond_d:
          for x in y:
              if cond_e:
                  break    # break #3 只有这个 break 只跳出 for
      # 读者很难一眼看出循环的所有退出路径
  """)

    print("=" * 50)
    print("推荐改进：将退出逻辑集中到末端")
    print("=" * 50)

    print("""
  def should_exit(state):
      return state.cond_a or (state.cond_b and state.cond_c) or state.cond_d

  while not should_exit(state):
      process_a(state)
      # 业务逻辑
      process_b(state)
      # 条件更新在循环体内自然发生
```

### 3.4 使用 `while` 替代递归的考虑

在深度很大的场景中，`while` 循环比递归更节省栈空间：

```python
# 用 while 替代递归的示例
def while_vs_recursion():
    """展示 while 替代递归减少栈深度的场景"""
    print("=" * 50)
    print("递归方式：计算阶乘（深度到达会栈溢出）")
    print("=" * 50)

    def factorial_recursive(n):
        if n <= 1:
            return 1
        return n * factorial_recursive(n - 1)

    print(f"  5! = {factorial_recursive(5)}")

    # 尝试大数会栈溢出
    try:
        factorial_recursive(10000)
    except RecursionError as e:
        print(f"  [栈溢出] n=10000 时: {e}")

    print("\n" + "=" * 50)
    print("while 方式：计算阶乘（无栈溢出风险）")
    print("=" * 50)

    def factorial_while(n):
        result = 1
        current = n
        while current > 1:
            result *= current
            current -= 1
        return result

    print(f"  5! = {factorial_while(5)}")
    print(f"  10000! 计算结果约 {factorial_while(10000).bit_length()} 位二进制")
    print("  while 版本没有栈溢出问题\n")

    print("=" * 50)
    print("另一个例子：二分查找——递归 vs while")
    print("=" * 50)

    # 递归版本
    def binary_search_recursive(arr, target, low, high):
        if low > high:
            return -1
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            return binary_search_recursive(arr, target, mid + 1, high)
        else:
            return binary_search_recursive(arr, target, low, mid - 1)

    # while 版本（更省栈）
    def binary_search_while(arr, target):
        low, high = 0, len(arr) - 1
        while low <= high:
            mid = (low + high) // 2
            if arr[mid] == target:
                return mid
            elif arr[mid] < target:
                low = mid + 1
            else:
                high = mid - 1
        return -1

    data = sorted([3, 7, 1, 9, 4, 6, 8, 2, 5])
    target = 7
    print(f"  数据: {data}")
    print(f"  搜索目标: {target}")
    print(f"  递归版结果索引: {binary_search_recursive(data, target, 0, len(data)-1)}")
    print(f"  while版结果索引: {binary_search_while(data, target)}")
```

## 4. 原理

### 4.1 `while` 在 CPython 中的执行模型

`while` 循环是 Python 编译后的字节码层面的一个分支结构，理解它的执行方式有助于写出更可靠的循环代码。

从 CPython 的角度看，每条 Python 代码在编译时都会变成一组字节码指令。`while` 循环的字节码模式大致如下：

```python
# 通过反汇编查看 while 循环的字节码

    """展示 while 循环编译后的字节码"""
    import dis

    def simple_while():
        i = 0
        while i < 3:
            print(i)
            i += 1
        return "done"

    print("=" * 50)
    print("while 循环的字节码分析")
    print("=" * 50)
    print("\nPython 源代码：")
    print("""
  def simple_while():
      i = 0
      while i < 3:
          print(i)
          i += 1
      return "done"
  """)
    print("\n编译后的字节码：")
    dis.dis(simple_while)

    print("\n" + "-" * 50)
    print("字节码执行流程说明：")
    print("""
  1. LOAD_CONST 0 + STORE_FAST     -> 初始化 i = 0
  2. LOAD_FAST i  + COMPARE_OP <    -> 检查 i < 3
  3. POP_JUMP_IF_FALSE (到 RETURN)  -> 条件为 False 则跳出
  4. LOAD_GLOBAL print + CALL       -> 执行 print(i)
  5. LOAD_FAST i + LOAD_CONST 1     -> i += 1
  6. JUMP_ABSOLUTE (回到 比较指令)  -> 无条件跳转回条件检查
  7. LOAD_CONST RETURN              -> 返回 "done"
  """)
```


关键点总结：
- `POP_JUMP_IF_FALSE` 是条件检查的出口点，条件不满足时跳转到循环外的指令。
- `JUMP_ABSOLUTE` 是无条件跳回循环体开头，形成"回路"。
- **没有独立的"循环结束"检查**——条件评估和跳转是同一个字节码指令完成的。这意味着 `while` 循环的每次迭代都包含这两个字节码操作。

### 4.2 `while True` 与 `while 1` 的微妙差异

在 Python 中，`while True` 和 `while 1` 的行为相同，但在 CPython 字节码层面有细微差异——`True` 是一个需要查名字空间的全局变量（即使它不可赋值，解释器仍需要做一次名字查找），而 `1` 是字面常量，直接加载。不过，CPython 3.8+ 做了优化，`while True` 会被直接优化为无条件的 `JUMP_ABSOLUTE`，不再真正检查条件。


### 4.3 `while-else` 的语义实现

`while-else` 的底层实现并不复杂：`else` 块会被编译为跟在循环体之后、正常退出路径上的指令序列，而 `break` 指令会直接跳转越过 `else` 块。从字节码角度看：

- 循环正常退出（条件变 `False`）→ 执行顺序进入 `else` 块。
- 循环通过 `break` 退出 → `break` 的字节码直接跳转到 `else` 块之后的指令。

### 4.5 `while` 循环中的短路求值

`while` 的条件表达式同样遵循 Python 的短路求值规则。理解这一点可以避免不必要的计算，也可以利用短路来实现"先检查再使用"的模式：

```python
# while 条件中的短路求值
def short_circuit_in_while():
    """展示 while 条件中的短路求值行为"""
    print("=" * 50)
    print("场景：while 条件中的 and 短路")
    print("=" * 50)

    data = [1, 2, 3]
    index = 0

    # 先检查 index 是否越界，再访问列表元素
    while index < len(data) and data[index] > 0:
        print(f"  data[{index}] = {data[index]}")
        index += 1

    print("  循环正常结束（不会越界访问）")

    # 对比：如果交换顺序会抛出 IndexError
    print("\n  [注意] 以下代码会出错：")
    print("  while data[index] > 0 and index < len(data):  # IndexError!")
    print("  # 因为 data[index] 会在 index 越界时先执行\n")

    print("=" * 50)
    print("场景：while 条件中的 or 短路")
    print("=" * 50)

    def expensive_check():
        print("  [耗时] 执行 expensive_check()")
        return True

    def quick_check():
        print("  [快速] 执行 quick_check()")
        return True

    count = 0
    # or 短路：如果第一个为 True，不执行第二个
    while count < 2 or expensive_check():
        count += 1
        if count == 1:
            print("  quick_check 返回 True，短路了 expensive_check")
        break

    print("\n  while A or B: 当 A 为 True 时 B 不会被执行")
```

## 5. 总结

### 5.1 本文内容要点

**核心概念**：
- `while` 是 Python 中最基础的条件循环结构，每次迭代前检查布尔条件。
- 只要条件为 `True` 就持续执行循环体，条件为 `False` 时退出。
- 与 `for` 不同，`while` 需要开发者手动控制迭代进度和退出条件。

**核心 API 与用法**：
- **基本语法**：`while condition:`，支持任意布尔表达式，包括复合条件和短路求值。
- **无限循环**：`while True + break` 模式，适合退出条件复杂或"至少执行一次"的场景。
- **while-else**：循环正常结束（不通过 `break`）时执行 `else` 子句，典型于搜索未找到。
- **手动迭代**：`iter()` + `while True: next()` + `StopIteration` 异常机制。
- **计数器控制**：递增与递减的多种步长形式，指数步长用于退避重试。
- **嵌套循环**：二维遍历、多层退出使用标志变量。
- **交互循环**：`while + input + continue` 构建输入验证。
- **队列/栈消费**：`while deque: popleft()` 或 `while stack: pop()` 的消费模式。
- **do-while 模拟**：Python 无内置 `do-while`，使用 `while True + 末尾 break` 实现至少一次执行的效果。
- **性能特性**：纯迭代中 `for` 比 `while` 快（C 级迭代器协议），但 `while` 在处理次数未知、手动控制进度时更灵活。

**最佳实践**：
- 确保条件变量在循环体内更新，防止无限循环。
- 为不确定的循环加装最大迭代次数安全阀。
- `continue` 在 `while` 中可能跳过计数器更新——先将更新放在前面或用 `for` 代替。
- 清晰组织 `break` 的退出路径，避免分散在多层分支中。
- 深度大的算法用 `while` 替代递归防止栈溢出。
- 使用异常处理保护循环体，对不可恢复错误及时终止。
